## 0. 한 줄 요약

> 한국 중·고 영어 서술형 평가는 **정책적으로 확대 국면**(교육청별 학기 성적 25~40% 반영 권장·의무)이며, **영어 사교육비도 성장(영어 1인당 +10.4%)**한다. 경쟁 지형은 *AI 서술형 채점*(CLIPO·Engram)과 *변형문제 자동출제*(너른터·QBank)로 **분리되어 있고**, **"내신 서술형 내용 중심 채점 + 자동출제"를 학원용으로 결합한 솔루션은 아직 공백**이다. 단, **서울시교육청이 공공 AI 서·논술형 자동채점 시스템(2025.3~2027.2)을 직접 개발** 중이라는 점은 경쟁·대체 위협인 동시에 협업 기회다.

## 1. 정책·제도 트렌드 — "서술형 확대는 제도적 순풍"

### 1-1. 교육과정 차원
- **2022 개정 교육과정**(2025년 중1/고1 순차 적용)이 "수행평가 내실화와 **서술형·논술형 평가의 비중 확대**"를 공식 지침으로 명시. *(경남교육청 지침)*
- 정책 방향은 일관되게 **정답 중심 → 서·논술형 확대**. 단 구체 비율은 교육청·연도별로 상이하며 **하향 조정도 발생**(아래 표 참조).

### 1-2. 교육청별 서·논술형 반영 비율 (⚠️ 연도·교육청 스코프 필수)

| 교육청 | 학년도 | 서·논술형 반영 비율(학기 성적) | 비고 |
|---|---|---|---|
| **서울** | 2025 | 중 30% / 고 25% 이상 **권장** | 단계적 상향 명문화 |
| 서울 | 2026 | 30% | |
| 서울 | 2027 | **35%** | 예고 |
| 서울(신규 별도안) | 2027→2029 | 30% → **50%**까지 상향안 존재 | 별도 2025.12~2026.2 계획 |
| **경기** | 2025 | 고교 논술형 **35% 이상 의무** | 전 교과 논술형 포함 의무 |
| 경기 | 2026 | 중 40%/고 35% → **중·고 모두 30%로 통일·하향** | 용어 '지필→정기시험' 변경 |

→ **시사점**: 절대 수치는 등락하지만 "정기고사에 서·논술형을 반드시 포함"이라는 **구조 자체는 고착**되고 있음. 학원의 내신 대비 상품에서 서술형은 **선택이 아니라 필수 커버 영역**.

### 1-3. 영어 교과 별도 지침 (수요의 구조적 근거)
서울시교육청 「2025 중등 학생평가 내실화 계획」 영어 교과 붙임 기준:
- **말하기+듣기+쓰기 합산 50% 이상**(말하기 10% 이상) 권장
- 쓰기 40% 내 **"수행 서·논술형 20% + 정기고사 서·논술형 20%"** 예시
- 성취기준(예: [9영02-04])을 **지필 서·논술형 + 수행 논술**로 평가하도록 예시

→ **영어는 서술형이 수행·정기고사 양쪽에 구조적으로 내재.** 학원 입장에서 "쓰기 = 서술형 = 내신 직결"이 명확.

## 2. 시장 수요·규모 — "성장하나, 세그먼트 계량 데이터는 공백"

### 2-1. 확인된 정량 데이터 (공식 통계)
- **2024년 초·중·고 사교육비 총액 29.2조 원** (전년 +7.7%). 학생 수 -1.5% **감소에도 총액 성장**.
- **영어 1인당 월평균 사교육비 14.1만 원, +10.4%** — 전체 1인당 증가율(9.3%)을 **상회**. *(통계청·교육부)*

### 2-2. 한계 (정직한 공백)
- **"자동출제"·"서술형 채점" 세그먼트의 별도 매출·규모·성장률을 계량한 데이터는 확보 실패.**
- "중등 영어 서술형 급증"은 **정책 확대 + 제품 출현으로 정성적으로만** 뒷받침될 뿐, 문항 반영률의 **시계열 정량 데이터로 직접 입증되지는 않음.**

### 2-3. 자사 근거로 보강 (내부 설문·정성조사)
- **AI 기대영역 1위 = 자동출제 51%**(교습소 1순위 47%) — [P0-5:18](P0-5_내신자동출제_상세기획.md#L18)
- **어학원 세그먼트 1순위 = AI 작문·첨삭 50%**, 전체 AI 작문·에세이 첨삭 기대 35% — [통합기획서](01_통합기획서_v1.0.md), [P1-1:16](P1-1_Writing영역_상세기획.md#L16)
- 정성: "서술형이 학원 정체성"(디에이블), **"이상하게 쓰는 애 = 가짜로 이해한 애 → 서술형 = 이해도 진단 신호"**(디에이블)

→ **외부 정책 순풍 + 자사 설문 1순위 수요**가 교차 확인. 다만 **세그먼트 규모·지불의사(WTP)는 1차 수요조사로 별도 검증 필요**.

## 3. 경쟁 서비스 분석 — "채점과 출제가 분리, 결합 지점이 공백"

| 구분 | 서비스 | 기능·채점 방식 | 타깃 | 서술형 채점 | 자동출제 |
|---|---|---|---|---|---|
| **AI 서술형 채점(국내)** | **CLIPO(클리포)** | 성취기준 기반 루브릭 생성→예상점수·채점근거→교사 확인·수정→피드백·세특 기록. 손글씨/수식/그래프 인식. 전 과목 | **공교사** 지향 | ✅ | ✗ |
| | **Engram Class** | 손글씨 OCR·타이핑 답안을 5개 차원(과제수행·내용/논리·구조·어휘·문법) 루브릭 채점 | **학원/학교** | ✅ (영어 라이팅) | ✗ |
| **자동출제·문제은행(국내)** | **너른터** | 교과서·모의고사·EBS연계 기반 영어 **변형문제** AI 자동출제 | 고등 문법/변형 | ✗ | ✅ |
| | **QBank** | 영어변형문제은행, 3,509 문제지·35만+ 문항(인쇄형) | 중·고 시험대비 | ✗ | ✅ |
| **해외 자동채점** | **Cambridge Write & Improve** | 3천만 단어 코퍼스 지도학습, CEFR 0-13 자동점수·문법 피드백, 다회 수정 | 글로벌 EFL | △ 형식 중심 | ✗ |
| | **ETS e-rater** | NLP 다차원(문법·어법·word use·style·organization). GRE·TOEFL iBT | 글로벌 시험 | △ 형식 중심 | ✗ |
| **공공(진입 중)** | **서울시교육청 AI 서·논술형 평가지원시스템** | 자동채점-피드백, 2025.3~2027.2 개발, 25년 중·고 20교 시범→일반보급 | 공교육 | ✅ (개발 중) | ✗ |

### 핵심 발견 3가지
1. **결합 공백**: 국내에서 *서술형 채점*(CLIPO·Engram)과 *변형문제 자동출제*(너른터·QBank)는 **서로 다른 사업자로 분리**. **"내신 서술형 자동출제 + 내용 중심 채점"을 학원용으로 결합한 제품은 확인되지 않음** → **Picklass의 포지셔닝 공백.**
2. **해외 엔진의 한계 = 차별화 포인트**: Cambridge Write & Improve 공식 문서가 *"에세이가 문항에 얼마나 잘/완전히 답했는지(내용 적합성)는 평가하지 못한다"*고 명시. **내용·정답 중심인 한국 내신 서술형 채점은 이들이 못 하는 영역** → Picklass가 "범위 종속 내용 채점"으로 차별화 가능.
3. **LLM 채점은 아직 불안정** → **Human-in-the-loop 정당화**: GPT-4를 TOEFL Junior 구성형 과제 1,908개에 적용한 연구(Language Testing, 2025)에서 지표·과제·시험형태별 **성능 불일치** 보고. → **P0-4 검수(원장 최종 확인) 설계가 시장 실증적으로 정당함.**

## 4. 종합 시사점 → 기획 반영안

### 4-1. 전략적 결론
| 신호 | 방향 |
|---|---|
| 정책 순풍(서술형 정기고사 필수화) + 자사 설문 1순위 | **서술형은 P0-5의 폴백 대상이 아니라 핵심 차별화**로 격상 검토 |
| 채점·출제 결합 공백 | **"자동출제 + 내용 중심 채점" 결합**을 명시적 포지셔닝으로 |
| 해외 엔진의 내용 적합성 한계 | **"내신 범위 종속 내용 채점"**을 FR·마케팅 메시지로 명문화 |
| LLM 채점 불안정 연구 | **P0-4 Human-in-the-loop = 신뢰성 근거**로 문서에 인용 |
| 공공(서울교육청) 진입 | 위협(무상 대체)이자 기회(공교육 표준·데이터 연계) — **모니터링 항목 신설** |

### 4-2. P0-5 반영안 (내신 자동출제)

> ✅ **반영 완료**: 아래 4개 항목은 모두 현행 [P0-5 상세기획](P0-5_내신자동출제_상세기획.md)에 반영됨(2단 폴백 §10, `modelAnswer`·`rubricRef` §6, 서술형 하위유형 FR-2, 차별화 카피 §1). 이하는 그 근거·경위 기록.

- **§10 폴백 재검토**: '규모 크면 서술형 일괄 P1 축소' 대신, **어학원 1순위 수요 + 정책 필수화**를 감안해 **서술형 '문항 생성'은 MVP 유지, '자동채점'만 P1로 분리**하는 2단 폴백으로 격상 → [P0-5 §10 의사결정](P0-5_내신자동출제_상세기획.md#L99)에 반영됨.
- **FR 보강**: 서술형 하위 유형을 정책 예시에 맞춰 명시 → **조건 영작 / 문장 완성·배열 / 빈칸 서술 / 요약** (영어 성취기준 평가 예시 반영) → P0-5 FR-2에 반영됨.
- **데이터 모델**: [`ExamItem`](P0-5_내신자동출제_상세기획.md#L69)의 `essay` 타입에 `choices` 대신 **`modelAnswer`·`rubricRef`** 필드 보강 (2-1 지적 사항) → P0-5 §6에 반영됨.
- **차별화 카피**: "해외 자동채점이 못 하는 **내신 범위 종속 내용 채점**" 명문화 → P0-5 §1에 반영됨.

### 4-3. P1-1 반영안 (Writing 영역)
- **경계 정의**(L90·L91 오픈이슈 ④ 대응): P0-5는 *출제+범위종속 채점*, P1-1은 *학습·첨삭·진단 신호* — **루브릭은 공유, 채점 목적은 분리**로 명시.
- **루브릭 5차원 벤치마크**: Engram Class의 5차원(과제수행·내용/논리·구조·어휘·문법)을 [L67 `WritingFeedback`](P1-1_Writing영역_상세기획.md#L67) 루브릭 설계 레퍼런스로 참조.

## 5. 미해결 질문 (착수 전 확인 권장)

1. 국내 AI 서·논술형 채점(CLIPO·Engram)의 **실제 채점 정확도·교사 일치도 독립 벤치마크** 존재 여부 — 내신 채점 신뢰성·차별화 핵심.
2. **'자동출제'·'서술형 채점' 세그먼트 규모·성장률** 별도 계량 데이터(공공 통계/리서치).
3. **서울시교육청 공공 시스템(2027 일반보급)**이 학원 민간 수요를 잠식할지 vs 표준·데이터 연계로 확대할지.
4. 학원 현장 서술형 니즈가 **정기고사 대비 / 수행평가 대비 / 영작 첨삭** 중 무엇인지 — 학원·학부모·교사별 **페인포인트·WTP 1차 수요조사**.

---

## 6. 근거 한계 (Caveats)

- 서·논술형 반영 비율은 **교육청·학년도별 등락**(경기 고교 35%→30% 하향, 서울 35%→50%안 상향) — **특정 % 인용 시 반드시 연도·교육청 병기.**
- 경기·경남 원문 PDF는 이미지/바이너리로 기계 추출 불가 → 일부 수치는 **언론 2차 교차확인**(다수 독립 출처로 보강).
- 국내 경쟁사 기능 설명은 대부분 **벤더 자체 페이지** 기반 → 채점 정확도의 독립 검증 아님.
- QBank 문항 수(35만+) 등은 **실시간 카운터**로 시점 변동.
