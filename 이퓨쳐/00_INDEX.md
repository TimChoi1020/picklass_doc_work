# 00. 기획 폴더 인덱스 (Picklass 기획 문서 지도)

> 이 폴더의 모든 기획 문서를 유형·우선순위별로 정리한 **읽기 지도**다. 새 문서를 만들면 §명명 규칙에 맞춰 이름 짓고 아래 표에 한 줄 추가한다.

**한눈에 보는 제품 논지**: 학생 약점을 **진단**(P0-1) → 우리 학원 범위 문제 **자동 생성/처방**(P0-5) → 학부모에게 성장을 **증명하는 리포트**(P0-2)로 잇는, 끊기지 않는 학습 루프. **지불 스위치 = "성취도가 정확하게 보이는가"** 하나.

## 핵심 의존 관계

```
P0-1 진단 ──입력──▶ P0-2 리포트 ◀──환류── P1-2 과정데이터
                        ▲                    (성실도·이해도 근거)
                        │성장 델타
                   P1-3 Achievement
P0-5 출제 ─┐
P1-1 Writing┼─검수──▶ P0-4 검수 UX (공통 신뢰 장치)
P0-2 리포트 ┘
P0-3 온보딩 ──AcademyScope──▶ P0-5 출제
```

- **선후 주의**: P0-2(리포트, P0)의 완전한 성장·과정 데이터는 P1-2·P1-3(P1)에 의존 → MVP는 기존 수집 KPI로 근사(상세 [P0-2-1](P0-2-1_성장리포트_데이터정의_상세기획.md)).

## 명명 규칙 (새 문서용)

| 접두어 | 용도 | 예 |
|---|---|---|
| `00` | 인덱스 | `00_INDEX.md` |
| `01~09` | 마스터·전략 | `01_통합기획서_v1.0.md` |
| `10~19` | 시장·리서치 | `10_시장조사_서술형_v1.0.md` |
| `P0-n` / `P1-n` | 개발 백로그 상세기획(우선순위 매핑) | `P0-2_…` |
| `Pn-n-n` | 상위 항목의 하위 상세 | `P0-2-1_…` |
| `40~49_Nn` | 전략 노트(결정 전 제안·정리) | `40_N1_…` |

- 버전은 파일명 끝에 `_v1.0` (마스터·리서치만). 상세기획은 생략.
- 새 문서 추가 시 **이 인덱스 표에 한 줄 반드시 추가.**

## 유지보수 메모

- ✅ **줄번호 앵커 → 섹션 앵커 전환 완료(2026-07-25)**: N1·N2가 `01_통합기획서_v1.0.md`를 참조하던 `#L…` 줄번호 앵커 11곳을 모두 **섹션 번호 앵커**(예: §4.2 → `#42-과금--패키징`, §0.2 → `#02-시장-근거-본-문서-유일-출처`)로 전환했다. 이제 대상 문서 줄이 밀려도 링크가 안 깨진다. **앞으로 새 교차링크도 줄번호(`#L…`)가 아니라 섹션 제목/번호 앵커를 쓸 것.** (가시 텍스트에 `§X.Y`를 함께 표기해 렌더러가 슬러그를 못 잡아도 사람이 찾아갈 수 있게 한다.)
- 마스터/리서치 파일명(`01_`, `10_`)을 다시 바꾸면 여러 문서의 링크가 깨진다 — 변경 시 전체 grep으로 링크 동반 수정.
