## 1. 데이터 소스 (신 스키마 — P0-1 개정본 기준)

리포트는 아래 필드만으로 렌더된다(과장 0 원칙, [P0-2-1 §6](P0-2-1_성장리포트_데이터정의_상세기획.md) 준용).

**PT(진단) 소스 — `DiagnosticResult`(testType=PT)**

| 필드 | 리포트 사용처 |
|---|---|
| `vocabLevel` / `readingLevel` / `writingLevel` | 헤더 3레벨 히어로 |
| `readingKPI.R1_vocab` | Reading §2 어휘 지식 축 |
| `readingKPI.R2_comprehension{정보확인,직접추론,통합해석,평가비판}` | Reading §2 이해도 + **과정유형 4분할 막대** |
| `readingKPI.R3_rate{wpm, comprehensionGate}` | Reading §2 유창성 + **이해도 게이트 배지** |
| `writingKPI.W1_content … W5_mechanics` | Writing §3 5축 레이더 |
| `writingKPI.W3_lexical.mtld` / `W4_language.{errorRate,mlc}` | Writing §3 **CAF 객관수치** 병기 |
| `examEstimate.reading` / `.writing` | §6 공인시험 예상 |
| `itemLog` | §1 CAT 궤적, §4 Reading 오답 과정유형 |

**AT(성취) 소스 — `DiagnosticResult`(testType=AT) + `AchievementResult`**

| 필드 | 리포트 사용처 |
|---|---|
| `previousSessionId` | 직전 진단 오버레이(점선) 기준 |
| `deltaFromPrevious.level{vocab,reading,writing}` | 성장 배너·메트릭 |
| `deltaFromPrevious.kpi{R1,R2,R3,W1..W5}` | §2·§3 축별 변화(+/−) |
| `deltaFromBaseline` | "PT 누적 +Y" 병기 |
| `achievementRate` | 목표 달성률 |
| `stalledAxes[]` | **정체 축 경고** |

> ⚠️ **정합 항목(개발 전 확정)**: [P0-2-1](P0-2-1_성장리포트_데이터정의_상세기획.md)이 아직 구 스키마(`finalLevel`, `skillScores{vocab,readingSpeed,comprehension}`)를 참조한다. P0-1 개정으로 `vocabLevel/readingLevel/writingLevel`·`readingKPI`·`writingKPI`로 바뀌었으므로 **P0-2-1의 §3 매트릭스·§4 카탈로그를 신 스키마로 동기화** 필요.

## 4. R/W 특화 컴포넌트 4종 (구현 주의)

1. **R2 과정유형 4분할 막대** — 이해도를 총점이 아니라 정보확인·직접추론·통합해석·평가비판(PISA/PIRLS) 비중으로. 약한 과정을 처방으로 직결.
2. **R3 이해도 게이트 배지** — `comprehensionGate ≥70%`면 WPM 표시, 미만이면 "속도 판정 보류(이해 우선)" 회색 배지. 성장 미집계.
3. **Writing CAF 객관수치** — W3 옆 `MTLD`, W4 옆 `오류율·MLC`를 LLM 점수와 병기 → "주관 채점 아님" 신뢰 장치(스피킹의 ASR WPM·confidence 병기와 동형).
4. **3레벨 히어로** — Vocab/Reading/Writing 각각 레벨. Reading을 주 히어로(대형), Vocab·Writing 보조. MVP는 Writing 자리에 "진단 예정".

## 5. 단계별 릴리스

- **12월 MVP(PT)**: 헤더(Vocab·Reading) + §1 CAT 궤적 + §2 Reading 3축 + §5 처방 + §6 공인시험(Reading). Writing 섹션(§3·§4 작문)·AT 탭은 placeholder.
- **P1(P1-1 Writing 활성 + P1-3 AT)**: §3 Writing 5축·CAF, §4 작문 오류 분석, **AT 탭 전체**(성장·체인·정체 경고) 활성.

## 6. 오픈 이슈

- 헤더 3레벨 히어로 레이아웃(Reading 주 vs 3열 동등) 최종 결정 → 목업에서 A안(Reading 주) 채택, 검토 필요.
- Reading 3축은 레이더로 그리기엔 축이 적음 → 목업은 **바+상위%**로 표현(레이더는 Writing 5축만).
- 공인시험 R/W 환산표 초안 확정([P0-1 §12](P0-1_진단온보딩_상세기획.md) ⑦와 연동).
- [P0-2-1](P0-2-1_성장리포트_데이터정의_상세기획.md) 신 스키마 동기화(§1 정합 항목).
