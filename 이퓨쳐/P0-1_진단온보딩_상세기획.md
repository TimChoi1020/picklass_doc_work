## 0. 진단 체계 안에서의 위치 (P-ALT 두 트랙)

Picklass의 적응형 진단은 **P-ALT(Picklass AI Adaptive Level Test)** 브랜드 아래 스킬 트랙으로 나뉜다.

| 트랙 | 측정 스킬 | 기획 | 상태 |
|---|---|---|---|
| **스피킹 트랙** | Vocab(공유) · Speaking(낭독·대화·발표) | [P-ALT_Speaking_v81](../참고/P-ALT_Speaking_v81.docx) | 별도 완결 (참고) |
| **리딩·라이팅 트랙** ← **본 문서** | Vocab(공유) · Reading · Writing | 이 문서 (P0-1) | 신규 |

- **공유 엔진**: 두 트랙의 **P1 Vocab Size CAT**(문장 내 밑줄 단어 4지선다, `words_18levels_6000.picklass_rank` 18단계)은 **동일 어휘 진단 엔진**을 공유한다. 리딩·라이팅 트랙은 이 엔진을 재사용하고 P2(독해)·P3(작문) 파트만 신설한다.
- **공유 철학 계승**: PT/AT 체인 구조, CAT 적응형 출제, 공인시험 예상 구간 연계, 비교군 리포트 — 스피킹 트랙의 설계 원칙을 그대로 준용해 두 트랙의 결과가 한 리포트 안에서 정합적으로 읽히게 한다.
- **경계**: Speaking(낭독 유창성·대화 화용성·주제 발표)은 본 트랙 범위 밖 → P-ALT 스피킹이 담당. 본 문서는 **어휘·독해·작문**만 다룬다.

## 1. 목적·배경

신규생이 학원에 등록하는 순간, **적응형 진단으로 현재 어휘·독해(·작문) 수준과 약점을 파악**하고 그 결과를 이후 수업 설계와 학부모 리포트의 초기값(baseline)으로 삼는다. 이 진단이 곧 R/W 트랙의 **Placement Test(PT)**이며, 이후 학습 사이클마다의 **Achievement Test(AT, [P1-3](P1-3_AchievementTest_상세기획.md))**와 체인을 이룬다.

- 시장 근거: 추가희망 기능 1위 = **AI 학습진단 45%**, 보습 세그먼트 1순위(59%). "입학 테스트를 봐도 리포트 카드가 안 나온다"는 아쉬움(토피아 원장).
- 표준화 시험(넬트)은 거부, **우리 학원 진단용 적응형**은 강한 수요(정성 ⑦). 중형 학원이 최강 수요층.
- 진단은 P0-2(리포트)의 입력이므로 **선행 개발**되어야 한다.

## 2. 사용자 스토리

- (원장) 신규생이 오면 종이 레벨테스트 대신 태블릿으로 15분 진단을 돌리고, 끝나면 바로 약점 리포트를 받고 싶다.
- (학생) 내 수준에 맞는 문항으로 부담 없이 진단받고, 결과를 이해하기 쉽게 보고 싶다.
- (학부모) 입학 시점의 객관적 출발점을 문서로 받고 싶다. (스피킹 트랙 결과와 함께 볼 수 있으면 더 좋다.)

## 3. 범위 (In/Out)

**In (MVP, 12월 파일럿)**
- **P1 Vocab Size CAT** — 스피킹 트랙과 공유하는 어휘 진단 엔진 재사용. 어휘 레벨 확정 + P2 시작점 산출.
- **P2 Reading 적응형 진단** — 이미 ✅ 완료된 Reading 모듈·난이도 분석 재사용. 이해도(comprehension) + 독해 속도(WPM) 측정.
- 문항 난이도 분기(정답→상향, 오답→하향), 종료 조건, 레벨 산출(1–18 / 6그룹).
- 진단 결과 요약(레벨·영역별 강약점) 저장 → P0-2 리포트로 전달. **이 세션이 PT baseline**.

**Phased-in (P1-1 연동 시 활성화)**
- **P3 Writing 진단** — [P1-1 Writing](P1-1_Writing영역_상세기획.md) 엔진 완성과 함께 활성화. LLM이 문법·표현·구성 축을 채점(스피킹 트랙 P3·P4의 LLM 단일 호출·13개 오류 유형 분류 준용).

**Out (본 트랙 밖)**
- **Speaking 진단(낭독·대화·발표)** → [P-ALT 스피킹](../참고/P-ALT_Speaking_v81.docx)이 담당. 본 문서는 참조·병기만.
- MBTI형 성향·환경 분석(T1 정밀 진단, Phase 2).
- 정기 Achievement Test 체인 전체 운영 → [P1-3](P1-3_AchievementTest_상세기획.md)에서 정식화(본 문서는 PT + baseline 훅만 제공).

## 4. 파트 구조 (P-ALT R/W 트랙)

스피킹 트랙과 동일한 파트 넘버링·CAT 원칙을 쓴다. **P1은 공유 엔진**, P2·P3이 R/W 트랙 신설.

| 단계 | 파트명 | 형식 | 측정 목표 | MVP |
|---|---|---|---|---|
| **P1** | Vocab Size | 문장 내 밑줄 단어 뜻 4지선다 CAT (스피킹 트랙 공유) | 어휘 레벨 확정 + P2 시작점 | ✅ 포함 |
| **P2** | Reading | 지문 + 이해 문항 적응형(CAT). 이해도·독해속도(WPM) | 독해 이해도·속도 독립 레벨 | ✅ 포함 |
| **P3** | Writing (조건부) | 프롬프트 기반 작문 → LLM 채점 | 문법·표현·구성 레벨 | ⏳ P1-1과 함께 |

- **P1 시작점**: 추정 레벨 시스템(✅) 초기값 또는 L9 기본(스피킹 트랙 PT 관례 준용).
- **P2 CAT**: §9.4 8지표·18단계 난이도 기준으로 지문 난이도 상/하향. 정답 연속 시 +, 오답 시 −.
- **P3 진입(활성화 후)**: P2 평균 일정 레벨 이상에서 조건부 실행(스피킹 트랙 P4 조건부 실행 패턴 준용). 미실행 시 작문 기여분은 독해·어휘 값으로 대체.

## 5. 루브릭 축(KPI) · 최종 레벨 산출

Reading과 Writing은 CEFR·측정학적으로 **별개 스킬**(CEFR도 읽기·쓰기 척도를 분리)이므로 **레벨을 분리 산출**한다. Vocab은 두 스킬에 공통 투입되는 **공유 엔진**이다. 각 KPI는 임의 축이 아니라 확립된 학술 프레임워크에 근거한다.

### 5.1 Reading — 3대 KPI (Simple View of Reading 기반)

이론 뼈대: **Simple View of Reading**(Gough & Tunmer, 1986) — *독해력 = 단어재인 × 언어이해*. Scarborough(2001) Reading Rope가 두 축을 하위 가닥으로 세분. 여기에 **속도(유창성)**를 더한 3축.

| # | KPI | 학술 근거 | 측정 (엔진) | 레벨 앵커 / 가중 | MVP |
|---|---|---|---|---|---|
| **R1** | 어휘 지식 (Lexical Coverage) | Nation(2006), Laufer & Ravenhorst-Kalovski(2010): **98% 커버리지 = 8,000–9,000 word family**(문어) | P1 Vocab CAT (스피킹 트랙 **공유 엔진**), word-family 단위 | 2–3천(기초)·5천(일반 독해)·8–9천(원문) → CEFR 대응 | ✅ |
| **R2** | 독해 이해도 (Comprehension) | Simple View 언어이해 축. **과정 유형은 PISA/PIRLS 분류** | 지문+문항 CAT, 문항을 **과정 유형별 태깅** | PIRLS 가중치 준용: 정보확인 20 · 직접추론 30 · 통합·해석 30 · 평가·비판 20 | ✅ |
| **R3** | 독해 유창성 (Comprehension-based Rate) | 이해도 연동 묵독 속도(Hiebert·Samuels·Rasinski; Spichtig 등) | 지문 소요시간 기반 WPM | **이해도 ≥70% 게이트 통과 시에만 유효**. 밴드는 파일럿 규준 보정 | ✅ |

**측정 규칙**
- **R2는 총점이 아니라 과정 유형별 프로파일로 저장**한다("정보확인 강·추론 약·평가 미흡" → 처방 가능한 진단; Scarborough의 가닥별 개입 논지).
- **R3는 반드시 이해도로 게이트**한다 — 속도-이해 트레이드오프 때문에 이해 없는 속도는 성장이 아니다(안구운동 연구의 유효성 기준 = 이해 70%).
- (저학년 옵션) Simple View의 **단어재인/디코딩** 축은 초기 학습자에 한해 별도 측정. EFL 중·고학년은 R1 어휘로 대체.

**Reading 레벨** = R1·R2·R3 가중합 → 반올림(1–18 / CEFR 6그룹). 가중치 초기값은 개발팀 확정(§12), 파일럿 데이터로 보정.

### 5.2 Writing — 5대 KPI (Jacobs ESL Composition Profile 기반) · P3 활성화 시

**Jacobs et al.(1981) ESL Composition Profile** — EFL 작문 평가 표준, **구성요소별 실증 가중치 보유**. 여기에 **CAF**(Complexity·Accuracy·Fluency) 자동 계산 지표와 **IELTS 밴드 축**을 매핑해 LLM 채점의 객관 근거를 붙인다.

| # | KPI (Jacobs) | 가중치 | IELTS 대응 축 | 자동 보조지표 (CAF) |
|---|---|---|---|---|
| **W1** | 내용·과제 충실도 (Content) | **30%** | Task Achievement/Response | 과제 관련성·논지 전개 (LLM) |
| **W2** | 구성·응집성 (Organization) | **20%** | Coherence & Cohesion | 연결어·문단 구조 (LLM) |
| **W3** | 어휘 자원 (Vocabulary) | **20%** | Lexical Resource | **어휘 다양성 MTLD/VOCD·정교도** (자동) |
| **W4** | 언어 사용·문법 (Language Use) | **25%** | Grammatical Range & Accuracy | **정확성**(오류율)·**복잡성**(MLC, 절/T-unit) (자동) |
| **W5** | 어법·표기 (Mechanics) | **5%** | (밴드 내 반영) | 철자·구두점·대소문자 (자동) |

- **채점 방식**: LLM 단일 호출 analytic 채점(스피킹 트랙 P3·P4 준용, 13개 오류 유형 분류 공유) **+ CAF 계산 지표로 객관 앵커**. 이는 스피킹 트랙이 발음·유창성을 ASR의 WPM·confidence로 객관화한 것과 동일 패턴 → LLM 주관성 상쇄.
- **Writing 레벨** = W1~W5 Jacobs 가중치 합산 → 반올림(1–18 / CEFR 6그룹).

### 5.3 레벨 산출 종합

- **3개 레벨 분리 산출**: **Vocab / Reading / Writing** 각각 1–18(CEFR 6그룹). 가중합 방식은 스피킹 트랙 §2-2 준용.
- **MVP(파일럿)**: Vocab + Reading 레벨(R1·R2·R3) 산출. **Writing 레벨은 P1-1 활성화 시** 추가.
- **공인시험 예상 구간 병기**: Reading → TOEIC RC·TOEFL Reading·IELTS Reading / Writing → TOEFL·IELTS Writing. 리포트 헤더에 병기(스피킹 트랙 §3 연계 준용, 환산표는 파일럿 후 실측 보정).

## 6. 기능 요구사항 (FR)

- **FR-1** 진단 세션 시작: 학생 배정 후 원장/학생이 "진단 시작" 진입. 트랙=R/W, testType=**PT** 고정(신규생 자동 1회). 재응시 허용.
- **FR-2** 적응형 문항 출제: P1(어휘)→P2(독해) 순. 각 파트 시작 레벨에서 출발, 정답 연속 시 +, 오답 시 −. §9.4 8지표·18단계 난이도 기준 활용.
- **FR-3** 종료 조건: 파트별 최소/최대 문항 수 도달 또는 레벨 수렴(연속 정답·오답 폭 축소) 시 종료.
- **FR-4** 레벨 산출: 최종 레벨(1–18, 6그룹) + 루브릭 축별 강약점 스코어 + 공인시험 예상 구간.
- **FR-5** 결과 저장: `DiagnosticResult`(testType=PT)로 저장, 학생 프로필·리포트에 연결. `passageLevel` pre-fill로 §10 수업 설계 전달. **이 세션 id가 이후 AT의 baseline(previousSession)**.
- **FR-6** 결과 뷰: 원장용 요약 화면(레벨 배지 + 강약점 3줄 + 스피킹 트랙 결과 있으면 병기). 상세 리포트는 P0-2 담당.
- **FR-7** 재진단/AT 훅: 원장이 필요 시 PT 재실행 가능(이력 보존). 학습 사이클 후 AT는 이 결과를 baseline으로 비교([P1-3](P1-3_AchievementTest_상세기획.md)).
- **FR-8** (P1-1 활성화) P3 Writing 파트: 프롬프트 출제 → 작문 수집 → LLM 채점(문법·표현·구성 + 오류 문장 추출).

## 7. 화면·플로우

```
[Studio/학생앱] 학생 배정 → [진단 시작] (트랙=R/W, PT)
   → 진단 인트로(소요시간·방식 안내)
   → P1 Vocab CAT (밑줄 단어 4지선다)      ← 스피킹 트랙 공유 엔진
   → P2 Reading CAT (지문→이해문항→난이도 조정)  ← §10 런타임 on-demand
   → (P1-1 활성화 시) P3 Writing (프롬프트→작문→LLM 채점)
   → 진단 종료
   → 결과 요약 화면 (레벨 + 강약점 + 공인시험 예상 구간)
        ├─ [수업 설계에 반영]  → passageLevel pre-fill
        └─ [학부모 리포트 생성] → P0-2 (스피킹 트랙 결과와 병합 가능)
```

## 8. 데이터 모델 / 입출력

**입력**: `studentId`, `track`(=readingWriting), `testType`(=PT), `startLevel`(추정 레벨 or 기본값)

**엔티티 `DiagnosticResult`(요약)** — 스피킹·R/W 트랙 공통 스키마, 트랙/파트로 구분

| 필드 | 설명 |
|---|---|
| id, studentId, sessionId | 식별 |
| track | **readingWriting** (vs speaking) |
| testType | **PT** (vs AT). AT는 P1-3에서 사용 |
| previousSessionId | AT 체인용 baseline 참조(PT는 null) |
| vocabLevel | 1–18 / CEFR 그룹 (R1, 공유 엔진) |
| readingLevel | 1–18 / CEFR 그룹 (R1·R2·R3 가중합) |
| writingLevel | 1–18 / CEFR 그룹 (W1~W5 가중합) — P3 활성화 시 |
| readingKPI | { R1_vocab, R2_comprehension:{정보확인, 직접추론, 통합해석, 평가비판}, R3_rate:{wpm, comprehensionGate} } |
| writingKPI | { W1_content, W2_organization, W3_lexical:{score, mtld}, W4_language:{score, errorRate, mlc}, W5_mechanics } — P3 활성화 시 |

## 9. 기존 자산 연계 (재사용/확장)

- **재사용(구현 즉시)**: Reading 모듈(✅), 8지표·18단계 난이도 분석(§9.4 ✅), 추정 레벨 시스템(✅), On-demand 문항 생성(§2.6), 레벨 1–18/6그룹 체계(§14.2), **스피킹 트랙의 Vocab Size CAT 엔진·`words_18levels_6000` 코퍼스**.
- **확장(신규)**: P2 Reading CAT 적응형 분기 로직, R/W 공인시험 환산표(파일럿 보정), P3 Writing 채점(P1-1과 함께).
- **정합성**: PT/AT 체인·CAT·리포트 구조를 스피킹 트랙과 동일 규격으로 맞춰, 두 트랙 결과가 하나의 성장 리포트(P0-2)에서 통합 표현되게 한다.

## 10. 예외·엣지 케이스

- 중도 이탈: 세션 저장 후 이어하기. 미완료 진단은 리포트 생성 차단.
- 문항 풀 부족(특정 레벨): 인접 레벨 문항으로 폴백, 신뢰도 낮음 표기.
- 최상/최하 레벨 도달: 경계에서 조기 종료.
- On-demand 생성 실패: 캐시 문항 폴백(§2.6 후속 과제 정책 준용).
- P3 미활성(MVP): Writing 레벨 없이 Vocab·Reading 레벨만 산출 — 리포트에 "작문 진단 미포함" 명시.
- R3 유효성: 이해도 <70%면 WPM을 레벨에 반영하지 않고 "속도 판정 보류(이해 우선)" 표기.

## 11. 완료 정의(DoD) · QA

- 신규생 1명 R/W PT 진단 → 15분 내 종료 → 레벨·강약점·공인시험 예상 구간 산출 → 리포트로 전달까지 E2E 동작.
- P1 Vocab 엔진이 스피킹 트랙과 동일 결과를 재현(공유 엔진 검증).
- 동일 학생 재진단(PT) 시 이력 보존·비교 가능. 세션 id가 이후 AT baseline으로 참조됨.
- 적응형 분기가 정답률에 따라 실제로 난이도를 조정함(QA 시나리오 3종: 상위/중위/하위 학생).

- **선행**: §15 Level Test(PT) 데이터 스키마 확정, 추정 레벨 초기값 정책, 스피킹 트랙 Vocab 엔진 인터페이스 확인(공유).
