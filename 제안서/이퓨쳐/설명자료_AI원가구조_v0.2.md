# AI 학습 원가 구조 안내

| 항목 | 내용 |
|------|------|
| **문서 목적** | 사업제휴 논의를 위한 모듈별 AI 원가 구조 공유 |
| **버전** | v0.2 (실측 기반 · v0.1 대체) |
| **작성일** | 2026-08-14 |
| **근거** | 코드에 고정된 호출 구조(문항 수·턴 수·재도전 규칙) + 각 API 공시 요율 |
| **표기 방식** | **지수(Index)** — 표준 레슨을 100으로 한 상대값. 절대 원가가 아님 |

---

## 1. 요약

1. 모듈의 AI 원가는 **"실시간 AI 음성 생성이 있는가"** 하나로 갈립니다.
2. 원가 등급은 **3개**뿐입니다 — 무료급(0) / 드릴급(6~25) / 대화급(25~143).
3. **드릴형 모듈은 아무리 많이 편성해도 원가가 거의 오르지 않습니다.** 자유 대화 10분 1개가 드릴 모듈 9개분입니다.

---

## 2. 원가 등급 3개

> 표준 레슨(드릴 4개 + 자유 대화 3분) = **지수 100** 기준

| 등급 | 모듈 | 대표 지수 | 범위 | 원가 구성 |
|---|---|---:|---:|---|
| **무료급** | 표현 학습 | **0** | — | 영상·카드만, 유료 호출 없음 |
| | 어휘 학습 | **0** | — | 단어 오디오 1회 합성 후 캐시 재사용 |
| **드릴급** | 역할극 기본 | **6** | 4~9 | 발음평가만 (AI 음성은 캐시) |
| | 채워 말하기 | **8** | 5~20 | 발음평가 5~10회 |
| | 1분 말하기 | **14** | 13~28 | 발음평가 60초 + 평가 1회 |
| | 따라 말하기 | **15** | 13~30 | 발음평가 15회 (5문항 × 3속도) |
| | 문장 만들기 | **25** | 16~65 | 음성인식 + 발음평가 + 코칭 1회 |
| **대화급** | 역할극 자유 | **25** | 18~33 | 실시간 음성합성 + 인식·발음평가 |
| | 자유 대화 3분 | **50** | 40~80 | 〃 |
| | 레벨 테스트 (전체) | **100** | 60~165 | 인터뷰 구간이 대부분 |
| | 자유 대화 10분 | **143** | 115~225 | 〃 |

---

## 3. 왜 이렇게 갈리는가

원가를 만드는 것은 **AI의 지능 사용량이 아니라 "실시간으로 만들어내는 음성"**입니다.

| | 드릴급 | 대화급 |
|---|---|---|
| **AI 음성** | 사전 확정 문장 → **1회 합성 후 캐시 재사용** | 학습자 발언에 따라 **매번 새로 생성** |
| **원가 구성** | 발음평가 100% | 실시간 음성합성 **60~70%** + 인식·발음평가 + 생성 AI |
| **이용 규모 증가 시** | 학습자가 늘수록 **단위 원가 하락** | **하락하지 않음** |

**대화급의 음성 비중이 높은 것은 낭비가 아니라 학습 설계입니다.** 대화 시간에는 학습자의 발화뿐 아니라 **듣기 입력과 실시간 교정**이 포함되며, 이것이 회화 학습의 핵심입니다. 예를 들어 자유 대화 3분 중 학습자 발화는 약 24초이고 나머지는 듣기와 교정 시간입니다.

> **따라서 대화급 원가는 품질을 유지하는 한 압축할 수 없습니다.** 관리 수단은 절감이 아니라 **편성량 조절**입니다.

---

## 4. 레슨 구성별 원가

| 레슨 구성 | 지수 |
|---|---:|
| 드릴 중심 (대화형 미편성) | **53** |
| **표준 (드릴 4개 + 자유 대화 3분)** | **100** |
| 자유 대화 10분으로 확대 | **189** |
| 레벨 테스트 포함 회차 | **+100** |

드릴 모듈을 4개에서 7개로 늘려도 지수는 약 13만 오릅니다. **원가를 움직이는 것은 대화형 모듈의 편성 여부와 시간뿐입니다.**

---

## 5. 원가 통제 방법

관리 대상은 **대화급 3개 항목**입니다.

| 통제 수단 | 효과 |
|---|---|
| **대화형 모듈 편성 여부** | 레슨 원가의 약 절반 결정 |
| **자유 대화 시간 설정** (3분 / 10분 등) | 3분 → 10분 시 **약 2.9배** |
| **자유 대화 월 횟수 상한** | 학습자당 월 원가 상한 확정 |
| 레벨 테스트 실시 주기 | 회차당 +100 |

> **드릴형 모듈은 통제 대상이 아닙니다.** 학습량을 늘리는 데 원가 제약이 사실상 없습니다.
>
> 위 항목의 상한을 함께 확정하면 **학습자당 원가 상한을 계약 시점에 고정**할 수 있습니다.

---

## 6. 전제 및 정확도

| 구분 | 내용 |
|---|---|
| **정확** | 호출 횟수·구조 (문항 수·턴 수·재도전 규칙) — 코드에 고정된 값 |
| **추정** | 학습자 발화 시간, 음성 문장 길이 → 개별 모듈 **±50%**, 표의 범위 상단이 최악 경계 |
| **연동** | 실계약 요율(할인 티어 등) 확정 시 **전체가 같은 비율로 이동** — 상대 관계는 유지 |

- 본 자료의 모든 수치는 **상대 지수**이며 절대 원가를 나타내지 않습니다.
- 개별 모듈 오차는 ±50%이나, **레슨 단위로 합산하면 오차가 상쇄**되어 정확도가 높아집니다.
- 모든 외부 API 호출을 호출 단위로 기록하는 **사용량·비용 추적 체계를 가동 중**이며, 실사용 세션이 누적되면 **가정을 실측치로 대체한 개정본**을 공유드리겠습니다.
