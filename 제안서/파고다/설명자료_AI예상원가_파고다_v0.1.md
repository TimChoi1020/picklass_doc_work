| 항목 | 내용 |
|------|------|
| **문서 목적** | 단가 책정 · BM 설계 논의를 위한 모듈별 AI 원가 구조 및 예상 원가 공유 |
| **버전** | v0.1 |
| **작성일** | 2026-08-17 |

## 1. 한 줄 요약

1. 원가의 지배 요인은 **AI의 지능(LLM)이 아니라 실시간으로 생성되는 음성(TTS)** 입니다.
2. 모듈은 원가 성격상 **3개 등급**으로만 갈립니다 — 무료급(0원) / 드릴급(회당 0~50원) / 대화급(회당 50~300원대).
3. **회당 원가를 지배하는 것은 대화형 모듈의 편성 여부와 시간**입니다. 자유 대화 10분 1회가 드릴 모듈 9개분에 해당합니다.
4. 다만 **모든 회당 원가는 월 20회 레슨 기준으로 20배 누적**되며, **나만의 수업은 콘텐츠 생성 원가가 상각되지 않아 정규 레슨보다 구조적으로 비쌉니다**(→ §5.1, §5.2).

> ⚠️ **본 자료의 모든 수치는 외부 AI API 호출 비용만을 집계한 값입니다.**
> **서버 · 네트워크 · 스토리지 · CDN 등 인프라 비용은 포함되어 있지 않습니다.** 이들 비용은 학습 1회 단위가 아니라 동시 접속 규모 · 총 이용자 수 · 미디어 전송량에 따라 결정되는 별개의 원가 축이며, 도입 규모가 확정되면 별도 산정해 공유드리겠습니다.
> 따라서 **본 자료의 수치를 서비스 총원가로 사용하지 마시고, 단가 · BM 설계 시 인프라 비용을 별도 항목으로 계상해 주시기 바랍니다.**

## 2. 원가를 만드는 것은 "실시간으로 생성되는 음성"입니다

| | 드릴급 | 대화급 |
|---|---|---|
| **AI 음성** | 사전 확정 문장 → **1회 합성 후 캐시 재사용** | 학습자 발언에 따라 **매번 새로 생성** |
| **원가 구성** | 발음평가 100% | 실시간 음성합성 **60~70%** + 음성인식 · 발음평가 + 생성형 LLM |
| **이용 규모 증가 시** | 학습자가 늘수록 **단위 원가 하락** | **하락하지 않음** |

- **생성형 LLM은 어느 모듈에서도 전체 원가의 10% 미만**입니다. 따라서 AI 모델 단가 협상이나 모델 다운그레이드는 유효한 원가 레버가 아닙니다.
- 대화형 모듈의 나머지 원가는 **학습자 발화 시간에 정비례**합니다(음성인식 + 발음평가 합산 **발화 1분당 약 55원**).
- 사전에 확정된 문장의 오디오(어휘 학습 단어 음성, 역할극 기본의 NPC 대사)는 최초 1회만 합성하고 캐시를 재사용하므로 **사실상 무료**입니다. 단, 이는 **같은 콘텐츠를 여러 학습자가 공유할 때** 성립합니다 — 학습자 1인 전용 콘텐츠는 예외입니다(→ **§5.2 나만의 수업**).

---

## 3. 대화형 원가는 절감이 아니라 편성으로 관리합니다

자유 대화 3분 중 **학습자의 실제 발화는 약 24초**이며, 나머지는 **듣기 입력과 실시간 교정 시간**입니다. 이는 회화 학습의 의도된 설계이지 낭비가 아닙니다. **따라서 대화형 원가는 품질을 유지하는 한 압축할 수 없으며**, 관리 수단은 절감이 아니라 편성량 조절입니다.

| 통제 수단 | 효과 |
|---|---|
| **대화형 모듈 편성 여부** | 레슨 원가의 약 절반을 결정 |
| **자유 대화 시간 설정** (3분 / 10분 등) | 3분 → 10분 시 **약 2.9배** |
| **자유 대화 월 횟수 상한** | 학습자당 **월 원가 상한 확정** |
| **나만의 수업 월 생성 횟수 상한** | 상각되지 않는 콘텐츠 생성 원가의 상한 확정 (→ §5.2) |
| 레벨 테스트 실시 주기 | 실시 회차당 **+약 200원** |

> **드릴형 모듈은 1순위 통제 대상이 아닙니다.** 다만 **모든 원가는 월 20회 레슨 기준으로 20배 누적**되므로, 회당 수십 원의 차이도 월·연 단위에서는 유의미해집니다(→ §5.1).
> 위 항목의 상한을 함께 확정하면 **학습자당 월 원가 상한을 계약 시점에 고정**할 수 있습니다.

### 5.1 레슨 구성별 합계 — 회당 원가는 월 20회로 누적됩니다

**단가 판단의 실질 단위는 회당 원가가 아니라 학습자 1인의 월 원가입니다.** 월 20회 레슨 기준으로 회당 원가는 그대로 **20배**가 됩니다.

| 레슨 구성 | 회당 | **월 20회** | 연 240회 |
|---|---:|---:|---:|
| 드릴 4개 (대화형 미편성) | 약 50~90원 | 약 1,000~1,800원 | 약 1.2~2.2만원 |
| **표준 — 드릴 4개 + 자유 대화 3분** | **약 150~250원** | **약 3,000~5,000원** | **약 3.6~6.0만원** |
| 정규 8모듈 전편성 (자유 대화 제외) | 약 185원 | 약 3,700원 | 약 4.4만원 |
| 드릴 4개 + 자유 대화 10분 | 약 390원 | 약 7,800원 | 약 9.4만원 |
| 레벨 테스트 (월 1회 실시 시) | +약 200원 | +약 200원 | +약 2,400원 |

**편성 결정이 월 원가에 미치는 영향**

| 편성 변경 | 회당 증가 | **월 20회 기준 증가** |
|---|---:|---:|
| 드릴 모듈 4개 → 7개 | 약 +25~30원 | **약 +500~600원** |
| 자유 대화 3분 → 10분 | 약 +185원 | **약 +3,700원** |
| 자유 대화를 편성하지 않음 → 3분 편성 | 약 +100원 | **약 +2,000원** |

> 회당 25~30원은 작아 보이지만 **월 20회에서는 500~600원, 학습자 1인당 연 6,000~7,000원**입니다. 드릴 모듈 편성도 규모가 커지면 무시할 수 없습니다.
> 다만 **원가를 지배하는 변수는 여전히 대화형 모듈의 편성 여부와 시간**입니다 — 드릴 3개 추가분의 약 6배가 자유 대화 시간 하나에서 발생합니다.

### 5.2 나만의 수업 — 콘텐츠 생성 원가가 상각되지 않습니다

§2에서 "사전 확정 콘텐츠의 오디오는 캐시 재사용으로 사실상 무료"라고 설명드렸으나, 이는 **같은 콘텐츠를 여러 학습자가 공유할 때** 성립하는 이야기입니다.

**나만의 수업은 학습자가 직접 만든 지문으로 수업이 구성됩니다.** 지문 1건에 대해 문항 · 핵심 표현 · 대화문 생성 LLM 호출과 모듈 오디오 합성이 발생하는데, 이 콘텐츠를 쓰는 학습자가 **그 1인뿐이므로 생성 원가가 전액 그 학습자에게 귀속**됩니다. 여기에 자유 대화까지 진행되므로 **정규 레슨보다 구조적으로 비쌉니다.**

| 항목 | 예상 원가 | 비고 |
|---|---:|---|
| **콘텐츠 생성** (지문 1건) | **약 100원** | 문항 · 표현 · 대화문 생성 LLM + 모듈 오디오 합성. **재사용 없음 → 전액 1인 부담** |
| 모듈 런타임 | 약 50~90원 | 정규 레슨과 동일 |
| 자유 대화 3분 | 약 100원 | |
| **나만의 수업 1회 합계** | **약 250~290원** | 표준 레슨(150~250원)의 **상단 이상** |
| **월 4회 생성 기준** | **약 1,000~1,200원** | 정규 레슨 월 원가에 **추가로** 발생 |

| 콘텐츠 재사용 인원 | 학습자 1인이 부담하는 콘텐츠 생성 원가 |
|---|---:|
| **나만의 수업 (항상 1인)** | **약 100원 전액** |
| 정규 과정 (현재 평균 약 2인) | 약 50원 |
| 정규 과정 (5인 재사용 시) | 약 20원 |

> **나만의 수업은 월 생성 횟수 상한이 곧 원가 상한입니다.** 정규 과정은 같은 지문을 여러 학습자 · 기수가 재사용할수록 콘텐츠 생성 원가가 1/N로 희석되지만, 나만의 수업은 **항상 N=1**이므로 이 효과가 없습니다.
>
> ※ 콘텐츠 생성 원가는 **§5 런타임 표와 별도로 산출한 값**입니다(산정 시점 · 적용 모델이 달라 실계약 요율 확정 시 함께 재환산합니다). 생성 단계 모델을 런타임과 동일한 경량 모델로 전환하면 **지문당 약 100원 → 약 55원** 수준까지 내려갈 여지가 있으며, 검증 후 별도 공유드리겠습니다.

## 6. 전제와 정확도

| 구분 | 내용 |
|---|---|
| **집계 범위** | **외부 AI API 호출 비용만 포함.** 인프라(서버 · 네트워크 · 스토리지 · CDN) · 인건비 · 라이선스 등은 **불포함** |
| **정확** | 호출 횟수 · 구조 (문항 수 · 턴 수 · 재도전 규칙) — 코드에 고정된 값 |
| **추정** | 학습자 발화 시간(가정: 시도당 3~5초, 인터뷰 턴당 10~20초) · 음성합성 문장 길이 |
| **오차 범위** | 개별 모듈 **±50% 안팎**, 최악 경계는 표의 **범위 상단** |
| **요율 연동** | 실계약 요율과 다르면 **전체가 같은 비율로 이동** — 모듈 간 상대 관계는 유지 |
| **별도 기준** | §5.2 **콘텐츠 생성 원가**는 런타임 표와 산정 시점 · 적용 모델이 달라 **별도 산출값**이며, 요율 확정 시 함께 재환산 |

- 개별 모듈의 오차는 ±50%이나, **레슨 단위로 합산하면 오차가 상쇄**되어 정확도가 높아집니다. **월 20회로 누적하면 상쇄 효과가 더 커져 월 원가 추산의 신뢰도가 가장 높습니다.**
- 실계약 요율은 **첫 청구서와 대조해 확정**할 예정이며, 확정 시 본 표를 재환산해 공유드립니다.

## 7. 사용량 추적 체계

테스트 기간 중에는 사용량 측정이 파편화되어 있었습니다 — 자유 대화 일부만 기록되고 8개 모듈 · 레벨 테스트 · 음성합성 경로는 측정이 없어 일관된 원가 집계가 불가능했습니다.

현재는 **모든 외부 API 호출을 호출 단위로 기록하는 사용량 · 비용 추적 시스템을 구현**했으며, 어드민에서 **기간별 · 모듈별로 상시 조회**가 가능합니다. 실사용 세션이 10~20건 누적되면 **위 가정을 전부 실측치로 대체한 표를 다시 공유**드리겠습니다.
