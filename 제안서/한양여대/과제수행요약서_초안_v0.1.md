# 1. 연구개발과제의 필요성 🟩

## 1-1. 기술적 수요 — 전공·수준에 맞는 외국어 학습 자원이 없다

대학에는 수십 개 전공이 있으나, **전공과 수준에 동시에 맞는 외국어 교재를 찾기는 매우 어렵다.** 일반 영어교재는 호텔 프런트·기내 서비스·구강 검진실의 실제 상황을 담지 못하고, 해외 원서는 학생 수준과 맞지 않는다. 제2외국어는 공백이 더 심하다. 호텔·관광 계열은 중국·일본 관광객 응대로 중국어·일본어 실무 회화 수요가 크지만, "호텔 중국어"·"관광 일본어" 같은 전공×언어 특화 교재는 영어보다도 찾기 어렵다.

교수는 매 학기 자료를 직접 제작해 사용하지만, 그 자료는 **파편적으로 흩어지고 축적되지 않는다.** 전공 교수는 직무 지식은 있으나 외국어 콘텐츠를 체계적으로 제작할 시간과 도구가 없고, 어학 교수는 전공 직무 상황 지식이 부족하다. **"전공 지식 × 외국어 콘텐츠 제작"의 결합 지점**이 기술적으로 비어 있다.

## 1-2. 산업적 수요 — 말하기 실습이 물리적으로 불가능하다

직무 외국어의 핵심은 말하기다. 고객을 응대하고, 불만을 처리하고, 안내하는 상황이 곧 직무 역량이다. 그러나 교실에서 학생 한 명 한 명이 이 상황을 **반복 실습**하기란 물리적으로 어렵다. 학생 수만큼의 회화 실습 시간이 존재하지 않기 때문이다.

또한 학생의 직무 외국어 실력은 곧 취업 경쟁력이지만, **"무엇을 얼마나 할 수 있는지"를 증명할 데이터가 없다.** 성적표 한 줄로는 호텔·항공사 채용에서 변별력이 없다.

## 1-3. 지역적 수요 — 서울 서비스 산업의 다국어 응대 인력

서울은 국내 관광·호텔·항공 산업이 집중된 지역이며, 코로나 이후 회복된 외국인 관광객 응대 수요는 **영어를 넘어 중국어·일본어 다국어 응대 역량**을 요구한다. 서울 소재 전문대학은 이 산업에 실무 인재를 직접 공급하는 위치에 있으나, 다국어 직무 회화를 반복 훈련시킬 교육 자원은 부족하다.

본 과제는 서울 서비스 산업의 인력 요구와 서울 소재 전문대학의 인재 공급 기능을 **직무 외국어 콘텐츠·실습 인프라**로 잇는다. 서울시 지역혁신중심 대학지원체계의 목적에 직접 부합한다.

| 축 | 기존 기술 | 본 과제 |
|---|---|---|
| **콘텐츠 범위** | 범용 어학 학습 도구 — 일반 주제 위에서 작동 | **전공 직무 스코프 종속** — 그 학과의 직무 상황·용어 안에서만 콘텐츠가 생성됨 |
| **산출 형태** | 온라인 학습 콘텐츠에서 종료 | **단일 원본 다중 출력** — 앱 화면·전자책·인쇄 교재가 하나의 원본에서 동시 생성, 개정 시 동기화 |

또한 본 과제의 콘텐츠는 **교수진의 직무 지식에 근거한 원저작**이므로, 검정 교과서 변형과 같은 2차적저작물 저작권 리스크가 구조적으로 낮다. 이는 개발 결과물을 외부에 유통·사업화할 때의 법적 부담이 작다는 점에서 기존 어학 콘텐츠 사업과 구분되는 강점이다.

## 2-2. 연구개발과제의 내용 🟩

### 모듈 1. 직무 도메인 시드 기반 콘텐츠 생성 엔진

교수가 학과·직무 상황·요구 수준을 등록하면, 이 **직무 스코프가 지문·문항·회화·리포트가 공유하는 단일 기준**이 된다. 콘텐츠 소재는 세 경로로 유입된다.

| 경로 | 내용 | AI 역할 | 저작권 성격 |
|---|---|---|---|
| **S1 자료 편입** | 교수가 쓰던 강의자료·유인물을 업로드해 디지털화·구조화 | 파싱 보조만 | 교수 원저작 |
| **S2 변형 생성** | 업로드 자료 기반 난이도 조정·확장·문항화 | 변형 생성 | 교수 원저작 기반 |
| **S3 프롬프트 생성** | 주제·직무 상황·레벨·분량 입력 → 신규 생성 | 순수 생성 | 플랫폼 생성물 |

- 세 경로는 한 교재 안에서 혼합되며, 모든 자산은 **소스 태그와 출처 메타데이터**를 달고 저장되어 개정판 관리·저작권 추적의 기반이 된다.
- 생성 파라미터는 주제·목표 레벨·분량·유형·문체·금칙어·필수 포함 어휘를 지정할 수 있다.
- 출력 **형식 템플릿**을 교수가 저장해두면, 범위·내용이 바뀌어도 같은 형태로 반복 생성된다(예: 뜻→단어 / 음성→철자 / 표 빈칸 채우기).

### 모듈 2. CEFR 난이도 자동 추정 (하이브리드)

정량 지표군과 언어모델 정성 분석을 결합한 **하이브리드 레벨 추정 엔진**을 개발한다.

**(a) 정량 지표 8종**

| # | 지표 | 측정 내용 |
|---|---|---|
| 1 | 어휘 난이도 (LTI) | 어휘 빈도 기반 난이도 점수 |
| 2 | 어휘 다양성 (TTR) | 중복 제거 단어 / 전체 단어 비율 |
| 3 | 지문 길이 | 전체 단어 수 |
| 4 | 평균 문장 길이 | 총 단어 수 / 총 문장 수 |
| 5 | 문장 구조 복잡도 (SCI) | 접속사·관계사·특수구두점 기반 복잡도 |
| 6 | 문법 다양성 (GWS) | 문법 요소별 가중치 합 / 전체 문장 수 |
| 7 | 정보 밀도 (CCR) | 실질어 비율 |
| 8 | 배경지식 의존도 (KDI) | 고유명사 비율 + 어휘 난이도 결합 |

**(b) 언어모델 정성 분석** — 문맥적 난이도, 주제 복잡성, 배경지식 요구 수준, 관용 표현 밀도, 문화적 생소함을 구조화 출력으로 분석해 정량 지표가 놓치는 영역을 보완한다.

**(c) 통합 로직** — 정량 8지표 산출 → 1차 등급 → 정성 분석 호출 → 2차 보정 → 최종 등급 + 신뢰도 출력. 목표 레벨과 추정 레벨 편차가 기준 이상이면 재생성을 권고한다.

**(d) 검수 지원 산출물** — "왜 이 등급인가"를 설명하는 **기여 지표 상위 3종**과 판정 근거 주석을 검수 화면에 함께 제시한다.

### 모듈 3. 전문가 검수 게이트 (Human-in-the-loop)

```
[AI 생성] → [자동 분석] → [교수 검수 화면]
                              │
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
     [승인]              [부분 수정]           [재생성 요청]
        │                     │                     │
        ▼                     ▼                     ▼
   라이브러리 축적        수정 후 재분석         프롬프트 조정
```

- 상태 흐름: `draft → approved → published`. **미승인 콘텐츠는 학생 배포·교재 발행이 차단**된다.
- 교수는 AI 개입 강도(최소/보통/최대)와 문체를 지정할 수 있다.
- 변경 전후 비교, 레벨 재추정, 어휘 재추출 기능을 제공한다.
- 정확성이 생명인 직무 외국어에서 이 게이트가 **"대학 이름을 걸 수 있는 품질"의 보증 장치**다.

### 모듈 4. 단일 원본 다중 출력 출판 파이프라인

```
 교재 원본 1개 (구조화 마크업, Single Source of Truth)
   │  ← 승인된 콘텐츠 자산을 단원으로 조합, 목차 초안 자동 구성
   │
   │  [발행 이벤트]
   │
   ├──► [경로 A] 앱 실시간 렌더 → 교재 연동 온라인 학습 화면 (과정 데이터 수집)
   │
   └──► [경로 B] 서버 비동기 생성
          ├──► B-1. 전자책(EPUB) → 앱 뷰어. 각 단원·문항에 학습 모듈 딥링크 삽입
          └──► B-2. 인쇄용 PDF → 식별코드(QR) 삽입 → 주문형 인쇄 발주
```

- **버전 연결 보존** — 생성 파일이 어느 교재 버전 기준인지 추적해 개정판·재인쇄 관리의 기반으로 삼는다.
- **식별코드 결속** — 인쇄 교재의 문항에 코드를 넣어, 종이로 푼 답안도 촬영 시 온라인 채점·리포트로 연결된다. 공통 교재는 콘텐츠 식별 코드 + 로그인 세션으로 학생을 식별하고, 개인화 인쇄물은 학생×문항 코드를 쓰는 2단 설계를 적용한다.
- 조판 스택은 문서 변환 엔진 + 조판 엔진 조합을 1차 후보로 하며, **영한 혼합 조판**과 **문항·답란·보기 레이아웃**은 본 과제의 기술 검증 항목이다.

### 모듈 5. 직무 상황 말하기 실습 및 역량 증명

**(a) 학습 흐름** — 목표 제시 → 학습 → 정밀 드릴 → 적용 → 측정의 5단계 구조 위에 원자 모듈을 배치한다. 직무 롤플레이는 적용 단계의 핵심 모듈로, 기본 롤플레이(대본 기반)와 자유 롤플레이(변형 상황) 2단계로 구성한다.

| 학과 | 롤플레이 직무 장면 예시 |
|---|---|
| 호텔관광과 | 체크인·체크아웃, 객실 변경 요청, 컴플레인 응대, 시설 안내, 예약 확인 |
| 실무영어과 | 전화 응대, 이메일 문의 처리, 고객 요구 확인, 대안 제시 |

**(b) 대화 엔진** — 한 번의 통합 호출로 상황 판단·오류 분석·피드백 생성·응답 생성·다음 질문 생성·힌트 생성을 동시 수행해 응답 지연을 줄인다. 학습자가 말하지 못하고 멈추면 **사고 시간을 먼저 보호한 뒤 단계적으로 힌트를 제시**하고, 음성 인식 신뢰도가 낮으면 재요청한다.

**(c) 레벨별 대화 정책** — 레벨 그룹별로 AI 1턴 발화 길이 상한, 문장 간 간격, 대기 시간, 교정 강도, 따라 읽기 여부를 다르게 적용한다. 교정은 ① 명확한 문법 오류 ② 레벨 학습 포인트 ③ 일반적 어색함의 우선순위로 통제해 매 턴 모든 오류를 지적하지 않는다.

**(d) 언어 비종속 설계** — 음성 입출력 채널과 대화 구조는 언어에 종속되지 않도록 설계하여, 동일한 롤플레이·측정 틀 위에서 중국어·일본어로 확장 가능하게 한다. **본 과제에서는 영어로 실증하고 확장 설계·검증까지 수행하며, 언어별 커리큘럼·발음 평가 최적화는 후속 범위로 둔다.**

**(e) 측정 및 역량 리포트** — 발화 데이터를 절대 단위로 수집한다.

| 지표 | 측정 방법 | 단위 |
|---|---|---|
| 유창성 | 발화 속도, 침묵 구간 분석 | WPM, % |
| 정확성 | 문법·어휘 오류율 | 오류/문장, % |
| 복잡성 | 문장 구조 다양성, 평균 발화 길이 | 단어/발화 |
| 상호작용성 | 질문·호응 빈도, 턴 분석 | 횟수 |
| 발음 | 음성 인식 기반 발음 정확도 | % |

리포트는 ① 현재 레벨 ② 강약점 ③ 학습량·성실도 ④ 성장 추이(학기 전후 델타) ⑤ 교수 코멘트의 5개 섹션으로 구성하고, **모든 수치는 실제 저장된 학습 기록에만 근거**한다(데이터 부족 시 "축적 중" 표기). 교수 승인 전에는 발행되지 않는다.

## 2-3. 수행일정 및 주요 결과물 🟩

# 4. 연구개발성과의 활용방안 및 기대효과 🟩

## 4-1. 활용방안 — 3단계 확산

| 층 | 대상 | 공급 형태 | 시기 |
|---|---|---|---|
| **① 교내 정착** | 참여학과 재학생 | 교재(전자책) + 온라인 학습·말하기 실습을 교과·비교과에 편성 | 과제 종료 직후 |
| **② 콘텐츠 확산** | 동일 전공 전국 대학·전문대 | 교재 라이선스, 주문형 인쇄·ISBN 유통 | 과제 종료 후 1년 내 |
| **③ 산업체·해외** | 호텔·관광·항공 재직자, 해외 대학 | 직무 외국어 과정, 기업 대상 라이선스 | 후속 |

**확장은 두 축이다.** 위 대상 확산에 더해 **언어 축**(영어 → 중국어·일본어)이 직교한다. "호텔 × 영어/중국어/일본어", "항공 × 영어/중국어/일본어"처럼 **전공 × 언어의 콘텐츠 격자**로 자산이 늘어나며, 저작·출판·실습 파이프라인은 공통으로 재사용된다.

## 4-2. 기대효과

### 교육적 효과
- 매 학기 소모되던 강의자료 제작 노동이 **누적 가능한 출판 자산**으로 전환된다.
- 교수의 역할이 "자료 제작자"에서 **"감수자·저자"** 로 상향된다.
- 학생은 교실에서 확보할 수 없던 **1:1 말하기 반복 훈련**을 시간 제약 없이 수행한다.
- 학생 성취가 **취업 증빙 가능한 데이터**로 남는다.

### 산업적 효과
- 서울 호텔·관광·항공 산업이 요구하는 **다국어 응대 인력의 실무 준비도**가 개선된다.
- 채용 현장에 학습 기록 기반의 **직무 어학 역량 정보**를 제공해 서류 중심 평가의 변별 한계를 보완한다.

### 경제적 효과
- **주문형 인쇄** 방식은 재고 부담 없이 소규모 특수목적 교재의 출판 손익분기를 낮춘다.
- **저작 자동화**는 교재 1종 개발에 투입되는 인건비와 기간을 절감한다.
- **언어 비종속 설계**는 영어 자산을 타 언어로 재사용하게 하여 자산 규모를 배가한다.
- 대학 명의 교재의 외부 유통으로 **콘텐츠 지식재산 수익**과 산학협력 수익 모델을 확보한다.

### 사업단 목적 부합
글로벌서비스 ICC의 목적인 **"IT 융복합·서비스 산업의 AI·DX 기반 글로벌 서비스 인재 양성"** 에 대해, 본 과제는 ① AI 기반 교육 콘텐츠 생산 기술을 대학에 이식하고 ② 서비스 직무 외국어 역량을 데이터로 관리하며 ③ 어학 학과와 AI 학부의 융복합 연구 경험을 학생에게 제공한다.
