## Part A. 안전한 신규 추가 (배경·정책·확정 수치) — 배치 승인 후보

### A-1. 포지셔닝 (§14.1)
- **슬로건**: "30년 노하우로 만든 파고다 AI, 매일 자라나는 나만의 영어 회화" (마스터플랜 §0)
- **포지셔닝 3축**: A.파고다 교수철학 / B.무제한 개인화 콘텐츠 / C.자라나는 AI
- **경쟁사 약점 정조준**: 스피킹맥스(닫힌 수업구조·위약금) / 스픽(성과측정 모호·공공장소 사용난)

### A-2. 발화량 챌린지 (§14.4.6 차별점5)
- **기본 목표 수치 확정**: 일일 30 · 주간 200 · 월간 800 · 페르소나 50문장 (기획서는 공식만, 기본값 미기재)
- **탭 모드 ×0.6 가중 집계**: 마이크 OFF 발화를 0.6 가중으로 발화량 인정 (수료·챌린지·리포트 전 집계 일관) — ※명칭 충돌 B-8 참조
- **Quiz↔발화량 시너지**: 문장 마스터리(질) 발화가 발화량 미터(양)의 데이터 유입원 (이중 리워드)

### A-3. 문장 마스터리 / 표현카드 (§14.4.9 계층3, §14.9.0 챌린지탭)
- **단일 "문장 마스터리 엔진" 통합**: 망각곡선(Quiz=시스템 복습 큐)·표현노트(상시)가 동일 발화수 엔진, 진입점만 다름
- **마스터 임계값 확정**: Lv0=0 / Lv1=1~2 / Lv2=3~4 / Lv3=5~7 / **Lv4(마스터)=누적 발화 8회** (mastery_target 기본 8)
- **발화당 리워드 시각화 원칙**: 발화 1회=pip 1칸(8칸 게이지) + 즉각 3감각 반응(시각 pip팝/청각 성공음/촉각 햅틱). 반응 지연 최소화 = 절대 원칙
- **게임성 2축 채택 결정**: 순간 피드백(Juice)+수집·완성(Collection) 채택. 발음 별점·스트릭 상실회피는 그라인드 우려로 후속 유보. 배지=완성 결과로만 부여
- **Quiz 제공량 정책**: 세션당 6문장(5~8 상한), 문장별 1~2발화, 하루 1세션 권장, "짧고 자주(2~4분)". 과다 제공 금지
- **문장 출처 3소스**: learning(과정 핵심표현 자동편입) / note(수동) / preset(backoffice 큐레이션·기관·레벨 매핑, B2B 차등)

### A-4. 학습 설정·프로필 (§14.9.0 마이탭)
- **학습설정 기본값**: 일일 목표 20분 · 재생속도 1.0배
- **레벨 변경 3경로**: PT(최초 진단·재응시) / AT(성장 확인) / 학습 중 조정(무세션). 이력 전량 추적
- **영어 닉네임 정책**: 원어민 호명+랭킹 표시용, 영문·16자·유일성 없음(중복 허용), 없으면 가입명 폴백
- **수강내역 단일 통합 목록**: 수강중/종료 미분할, 단일 최신순 + 상태 배지. 카드 단위=수강계약(재수강 각각 카드)

### A-5. 모듈 학습 정책 (§14.4.2)
- **표현 연계 원칙**: LRN→(따라말)→(채워말)→(만들어말) 4모듈이 동일 N개 핵심표현 순차 내재화, 모듈 독립 추출 금지
- **레벨별 핵심표현 N개**: Pre-A1~A1:3 / A2:3 / B1:4 / B2:4 / C1~C2:5 (기획서 "5개 고정" → 차등 재정의)
- **대화문 레벨별 턴수**: 6/8/10/10/12턴
- **재도전 정책**: 모듈 정답률 70% 미만 시 1회 자동 재도전(초과 불가), OMP만 재도전 불가
- **LLM 3계 전략**: Seed(사전생성)/Slot(템플릿)/LLM(실호출), LLM 실호출은 SMK·OMP 2모듈만, 세션당 2~3회
- **콘텐츠 사전생성 근거**: 핵심표현·대화문을 Studio 지문 등록 시점에 선행 확정(모듈 간 일관성·비용). core null 시 온디맨드 생성

### A-6. 수강·게이팅 정책 (§14.1, §16, §14.2)
- **수강 소스 2갈래**: 픽클래스 기본 B2B(access_code=단일 과정) vs 파트너(외부 API=전체 과정)
- **과정 탐색 게이트**: 파트너 카테고리 보유자만 "과정 탐색하기" 노출, 2-Depth 카테고리(분류/교재 시리즈)
- **파고다 파트너 상품**: 정규(레슨 N회)/무제한(기간), 나만의수업 차감(정규=풀 공유차감·무제한=20회 cap), 이수조건=이수율·발화량·수업시간
- **레벨테스트 진입 게이팅**: 신규 PT 미완료 시 수업 하드블록(서버 방어), 갱신 PT·AT는 soft_prompt. PT에서 닉네임·레벨 동시 수집

### A-7. 화이트라벨 3티어 (§14.4.6 또는 03/Backoffice)
- **3티어**: Tier1 Co-Brand(로고) / Tier2 Skin(+메인컬러) / Tier3 White Label(앱명·도메인)
- **변경 불가 3종**: 5축 KPI 색상 / AI 캐릭터 외형(IP) / 학습 모듈 흐름(교수법)

### A-8. 리포트(피드백) 탭 구성 (§14.9.0)
- **Quality/Quantity/Growth 3블록**: Quality(발음·유창·문법·화용 + 기관평균 대비) / Quantity(발화·듣기·섀도잉) / Growth(5축 절대변화량)
- **역할 분리**: 리포트=기간 학습량 집계 / 챌린지 탭=목표 진행도

### A-9. KPI 단위 원칙 (§14.6)
- **절대단위 전면화**: 100점 환산 폐기, 절대단위(%·WPM·오류/문장·문장수)로 통일, 외부7+내부8 계층 분리
- **서브웨이 KPI 2개 정식화**: 듣기 누적 분 · 섀도잉 카운트
- **Q/Q/G 3축**: Growth를 5축 절대변화량으로 단순화(OMP·CEFR 도달% 의존 폐기)

## Part C. 06_진단평가_PPD로 (Speaking 범위 밖 — 별도 승인)

P-ALT 진단 체계는 Speaking이 아니라 `00_공통/06_진단평가_PPD.md` 소유:
- PT 1회 + AT 체인(직전 진단 baseline, AT 하한 보호)
- 공인시험 4종 환산(OPIc/TOEIC-S/IELTS/TOEFL) L1~L18 매핑
- 4파트 구조(P1 Vocab Size CAT / P2 문장낭독 CAT / P3 일상대화 / P4 주제발표)
- Vocab Size 측정 철학(비정의 캐리어 문장, 재인 수준) · 6대 루브릭(어휘·유창성·발음·문법·표현·화용성)
- probe(측정 의도) 기반 런타임 질문 생성 원칙
- 어휘 레벨링 권위=CEFR(picklass_rank), COCA는 참고값

> ⚠️ 진단 6루브릭 vs 학습 5축 — 축 불일치. 의도된 분리인지 06 문서에서 정의 필요.
