# **2.1 설계 철학**

"정확하게 \+ 많이 \+ 측정 가능하게" — 100% AI 기반 차별화

픽클래스의 학습 철학은 두 경쟁사의 장점을 결합하되 100% AI 기반으로 차별점을 구축하는 것이다. 스피킹맥스의 '정확한 콘텐츠 기반 드릴'과 스픽의 '자유 대화 발화량'을 한 레슨 안에서 통합하고, 여기에 파고다의 검증된 교수법(CEFR·5축 지표)을 AI 시스템 설계 원칙으로 입혀 운영한다.

### **핵심 설계 5원칙**

* 입력→출력→측정의 3계 구조

* 사전 설정 미션 기반 진행 \+ 미션 내부에서 AI 자유도 부여

* 공공장소·이동 중에는 "듣기 인풋 \+ 발화 보충 연결"로 학습 사이클 유지 (v1.5 갱신)

* 학습 성과 정량 측정 (5+2 KPI)

* 신뢰 구조 유지 “내부 보상 정책”

## **2.1.5 학습 방식 2모드 ★ (v1.5 신설)**

Mode A 정규과정 (정확하게 배우고) \+ Mode B 발화 챌린지 (많이 말하고) \+ 측정 (자란다)

픽클래스의 학습은 두 모드 중심으로 진행된다. 학습자는 상황·시간·목적에 따라 두 모드를 자유롭게 오간다. 두 모드는 같은 Learner Memory를 공유하며, 한 모드의 학습이 다른 모드의 콘텐츠로 자동 연결된다.

| 축 | Mode A 정규과정 | Mode B 발화 챌린지 |
| :---- | :---- | :---- |
| 역할 | 교육적으로 정확한 학습 | 양적으로 많은 발화 연습 |
| 흐름 | 5단계 (PICK→LEARN→DRILL→APPLY→MEASURE) | 표현 카드 단위 1\~3분 발화 |
| 1세션 시간 | 18\~22분 골든타임 | 1\~3분 짧은 단위 |
| 콘텐츠 소스 | 정규 코스 · AI 큐레이션 · 학습자 요청 주제 | (1) 표현 노트 즐겨찾기 (2) AI 제안 표현 |
| 진입 위치 | 홈 Hero "오늘의 미션" · 학습 탭 | 홈 Hero "발화 1분 연습" · 챌린지 §4.4 · 표현 노트 |
| 측정 결합 | 5축 점수 \+ 1MP | 발화량 챌린지 4종 미터 \+ 5축 |

두 모드의 균형이 픽클래스의 차별점이다. Mode A만으로는 "많이 말하기"가 부족하고 Mode B만으로는 "정확성"이 부족하다. 모든 IA·콘텐츠·KPI 결정은 이 2축을 지원하도록 설계된다.

# **2.2 픽클래스 5단계 학습 흐름 (Pick-Speak Method)**

## **1단계: PICK (목표 픽업) — 1\~2분**

2가지 진입 방식을 학습자가 선택한다.

### **방식 A — 지정 과정·추천 레슨**

정규과정에 등록된 학습자는 다음 진도 레슨이 자동 노출된다. 등록 과정이 없거나 정규 진도 외 학습을 원하는 경우 AI 큐레이션 추천 레슨 3개가 표시된다. 추천 사유 라벨(약점·직무·시험·인기)이 카드에 함께 노출되어 알고리즘 투명성을 확보한다.

### **방식 B — 나의 관심사 주제 학습**

학습자가 직접 주제를 입력 또는 키워드 선택 ("우리 회사 신제품 발표", "동료와의 점심 약속", "여행 중 호텔 체크인" 등). 1분 내에 LRN 콘텐츠 \+ 핵심 표현 \+ 드릴 문장 \+ 롤플레이 시나리오 \+ 1MP 주제가 자동 생성된다. 스피킹맥스의 닫힌 정규코스 구조를 정면으로 무력화하는 픽클래스 시그니처 기능.

두 방식은 PICK 화면에서 토글로 자유 전환되며, AI는 학습자의 사용 패턴을 학습해 다음 진입 시 선호 방식을 우선 노출한다.

## **2단계: LEARN (입력 학습) — 3\~5분**

파고다 교수법 자산을 디지털화한 짧은 비디오 강의로 핵심 표현·패턴을 학습한다. 자막 토글(한국어·영어·없음)과 재생 속도(0.7×·1.0×·1.3×)는 학습자 레벨에 맞춰 자동 기본값이 설정된다.

### **핵심 표현·어휘 수 레벨별 차등**

| CEFR 레벨 | 핵심 표현 수 | 핵심 어휘 수 |
| :---- | :---- | :---- |
| Pre-A1 \~ A1 | 3개 | 5개 |
| A2 | 4개 | 6개 |
| B1 | 5개 | 8개 |
| B2 | 6개 | 10개 |
| C1 \~ C2 | 7개 | 12개 |

학습자 레벨이 올라갈수록 한 세션에서 다루는 표현·어휘 양이 증가한다. 입문자에게는 부담 없는 3개, 고급자에게는 풍부한 7개로 좌절·지루함을 동시에 방지.

## **3단계: DRILL (정밀 드릴) — 5\~8분**

### **3-1. 어휘 워밍업 (VLM) — 0:30, 초·중급만**

LEARN의 핵심 어휘(레벨별 5\~12개)를 카드 형태로 빠르게 플립하며 듣고 의미 확인한다. 단어 발화는 ASR 한계로 학습 효과가 약하므로 듣기 \+ 의미 매칭 방식만 사용. B2+ 고급은 워밍업 자동 스킵.

### **3-2. 정밀 드릴 (EDR) — 5\~7분 ★ 픽클래스 시그니처**

핵심 표현·어휘 수가 LEARN과 동일하게 레벨별 차등 적용된다. 5축 즉시 피드백(발음정확도·유창성·문법정확성·화용성·발화량)이 모듈의 본질이다.

#### **3가지 드릴 활동을 순차 진행**

| 단계 | 활동명 | 메커니즘 |
| :---- | :---- | :---- |
| Drill 1 | 읽는 쉐도잉 (Shadowing) | 학습 문장 화면 표시 \+ 원어민 음성 → 학습자가 동시·직후 따라 발화. 발음·억양·리듬 정밀 측정 |
| Drill 2 | 블랭크 채워 읽기 (Fill-in) | 같은 문장에서 핵심 표현 부분이 블랭크 처리 → 학습자가 블랭크를 채워 전체 문장 발화. 표현 인출 능력 측정 |
| Drill 3 | 표현으로 문장 만들기 (Sentence Making) | 핵심 표현 \+ 한국어 가이드 → 학습자가 그 표현을 활용한 새 문장 자유 발화. 응용 능력 측정 |

세 활동 모두 5축 KPI 동시 측정. 통과 시 다음 활동으로 자동 전환.

#### **3-3 서브웨이 모드 (Subway Mode) ★ v1.6 동작 명세**

발화가 어려운 환경(지하철·만원 버스·도서관·러닝)을 위한 모드. v1.4까지의 "탭 모드(4지선다)"는 폐기. 말하기의 기본은 듣기라는 원칙에 따라 "이어폰만으로 고품질 듣기 \+ 학습은 미완료 상태로 두어 다음 진입 시 이어가기"로 정의.

정규과정 서브웨이 모드 (v1.6 정정): 별도 버튼·동작이 없다. 서브웨이로 진입하면 듣기 모드로 단어(VLM) → 드릴(EDR) → 롤플레잉(RPL) → 표현 노트까지 한 번에 쭉 진행된다. 학습자가 모드를 매 단계 선택할 필요가 없다.

#### **서브웨이 모드 4가지 듣기 활동 동작 (v1.6 정정)**

| \# | 활동 | 동작 |
| :---- | :---- | :---- |
| 1 | VLM 어휘 반복 | 한 단어를 정상 속도로 3회 들려준 뒤 샘플 문장을 1회 읽어주고 다음 단어로 자동 이동. 화면 시선 불필요. 5\~10개 카드 묶음 약 90초 |
| 2 | EDR 쉐도잉 | 한 문장 3패스: 빠름 1.2 → 빠름 1.2 → 정상. 패스 사이 짧은 공백으로 Subvocal Shadowing 권장. 자막 ON/OFF·한글 의미 토글 |
| 3 | RPL 시나리오 | 그냥 듣기. AI 캐릭터 간 대화를 자연 속도로 청취. 따라하기·답변 시점 강제 없음. 5\~8턴 약 3\~4분 |
| 4 | 표현 노트 리스닝 | EDR과 동일 3패스 로직: 빠름 1.2 → 빠름 1.2 → 정상. 즐겨찾기 표현 우선. 마스터리 낮은 항목부터 |

* 이어폰만으로 작동 가능 — 화면 시선 불필요한 블라인드 모드

* 5축 KPI는 측정 안 함 (발화 없음). 듣기 누적 분 · 섀도잉 카운트로만 측정

#### **3-4 서브웨이 모드 학습 사이클 연결 (v1.6 단순화)**

v1.5의 알림·미션 생성·가산점·뱃지·코스 추천 메커니즘은 모두 삭제되었다. v1.6에서는 "학습이 멈춰도 자연스럽게 이어가도록" 단순 보존 정책으로 운영.

* 서브웨이 모드에서 EDR 단계부터는 "미완료" 상태로 저장 — 학습자가 발화 가능 환경에서 다시 진입하면 그 단계부터 자연스럽게 재개

* 자동 발화 보충 미션 생성·푸시 알림은 운영하지 않음 (학습자 압박·이탈 방지)

* 학습 알람은 사용자가 설정한 "학습 시간"만 단순 리마인드 — 특정 콘텐츠 학습과 강제로 연결하지 않음

* 발화량 챌린지는 발화 가능 시 자연스럽게 누적되는 구조 유지 (§2.4)

서브웨이 모드의 본질: 학습을 멈춰도 다음에 자연스럽게 이어가게 하는 "학습 사이클 유지 도구". 압박이 아닌 흐름 보존이 핵심 설계.

## **4단계: APPLY (적용·자유화) — 5\~10분**

### **4-1. Phase 1 — 롤플레이 (RPL)**

기본 대화 따라하기 \+ 자율 롤플레이 2단계 구조.

#### **Sub-Phase 1A — 기본 대화 따라하기 (Modeling)**

AI 캐릭터가 시나리오의 표준 대화 1턴을 발화하면 학습자가 PTT로 그대로 따라 발화. LEARN에서 학습한 핵심 표현이 자연스럽게 입에 붙도록 하는 단계. 4\~5턴 진행.

AI: "Hi Tim\! Welcome to the team. How was your flight?" 학습자 PTT: (AI 발화 그대로 모방 발화) → AI: "Let's get started. The flight was great, thanks for asking." 학습자 PTT: (모방 발화) — "Let's get started" 핵심 표현 자연스럽게 사용

이 단계는 학습자의 표현 정착에 집중하며, 발화 부담이 낮다.

#### **Sub-Phase 1B — 자율 롤플레이 (Free Role-Play) ★ v1.6 정의 정정**

Sub-Phase 1A에서 학습한 기본 대화를 기반으로, AI와 "새로 대화를 시작"하여 학습자가 자유롭게 대화하는 방식이다. 같은 시나리오 안에서 변형 질문·예상 못한 분기를 AI가 던지면 학습자는 본인 답변으로 응답한다. 매칭된 AI 페르소나(Sarah·Mike·Emma·David·피클)의 톤·관심사·이전 메모리가 일관되게 유지되어야 자연스러운 대화가 가능하므로 페르소나의 일관성이 1B의 핵심 품질 요소이다.

* 미션 표현 5개 사용 추적 \+ 5축 KPI 실시간 측정

* 발화 부담은 1A보다 높지만, AI 페르소나가 학습자 컨텍스트를 기억하므로 "아는 사람과의 대화" 느낌으로 진입 장벽 완화

* 페르소나 일관성 보장 책임: 픽클래스 슈퍼관리자 도구 §9.4 \#2 캐릭터·시나리오 관리

#### **AI 페르소나 자동 설정**

학습자가 매번 캐릭터를 고르지 않아도 시스템이 자동 매칭한다.

| 학습자 컨텍스트 | 자동 매칭 캐릭터 |
| :---- | :---- |
| 직무: 마케팅·영업·비즈니스 / 목표: 비즈니스 영어 | Sarah (미국 마케팅 동료) |
| 목표: 면접·이직 / 키워드: interview | Mike (영국 인터뷰어) |
| 목표: 여행 / 일상 / 카테고리: 여행·일상 | Emma (호주 카페 직원) |
| 목표: 시험 (OPIc·토익S) / 카테고리: 학술 | David (캐나다 강의자) |
| 목표 미설정 또는 자유 대화 | 피클 (FRT 전용 AI 튜터) |

매칭된 캐릭터의 톤·관심사·이전 대화 메모리도 자동 적용되어 학습자는 별도 설정 없이 자기 학습 목표에 맞는 자연스러운 대화 경험을 갖는다.

### **4-2. Phase 2 — 자유 대화 (FRT) — 5\~10분 ★ v1.6 시간 확장**

AI와의 자유 발화. 대화 챌린지 미터 (Conversation Challenge Meter)가 시그니처 메커니즘. 양적 발화량은 §2.4 독립 기능으로 분리, FRT는 대화의 질을 측정한다. v1.6에서 세션 시간을 1\~5분에서 5\~10분으로 확장하여 깊이 있는 대화 흐름 확보.

#### **대화 챌린지 미터 작동 방식**

* FRT 세션 시작 시 "오늘 Sarah와 5턴 대화 \+ 평균 2문장 이상" 같은 목표 노출

* AI 캐릭터와의 Turn 수 · 학습자 응답 길이 · AI 후속 질문 활용도를 종합 평가

* 도달 시 "Sarah와 좋은 대화 나눴어요" \+ 친밀도 \+1

* 학습자에게는 "얼마나 많이 말했는지"가 아닌 "얼마나 의미 있게 대화했는지" 메시지

초급(A1\~A2)은 자동 비활성화. 중급 5\~7분, 고급 7\~10분 활성화.

### **4-3. Phase 3 — 1 Minute Presentation (OMP) — 3분**

LEARN 콘텐츠 기반 30초 준비 \+ 1분 발표 \+ 종합 피드백. OPIc·토익S·면접·비즈니스 발표 통합 시그니처 모듈.

#### **OMP 결과 화면 — OPIc·토익S 예상점수 표시 (v1.6 신설) ★**

* 결과 화면에 OPIc 예상 등급 (IL / IM / IH / AL) 표시

* 결과 화면에 토익S 예상 점수 (80\~200) 표시

* 예상 점수는 5축 \+ 발표 4영역(논리·표현·발음·시간) 가중 합산

* 시험 환산표는 슈퍼관리자 도구에서 관리하며 모델 업데이트 시 재산정

* 학습자에게 "시험을 본다면 이 정도 점수가 예상돼요"로 동기 부여 \+ 응시 시점 가늠

OMP는 단순 학습 모듈을 넘어 "내가 실제 시험에서 어떤 점수일까"를 모의 측정하는 도구. v1.6에서 시험 환산 표시가 정식화되어 시험 대비 학습자에게 더 강력한 동기 부여.

## **5단계: MEASURE — 2\~3분**

5각 레이더 차트 \+ 1MP 점수 카드 \+ 약점 분석 \+ 다음 추천. 서브웨이 모드로 진행한 활동은 발화량 0으로 명시되며 "발화 보충 권장" 메시지가 약점 분석에 자동 포함된다. 듣기 누적 분·섀도잉 카운트는 별도ㅈ 위젯으로 표시.

# **2.3 픽클래스만의 5가지 차별 메커니즘**

| \# | 차별점 | 적용 모듈 | 경쟁사 대비 우위 |
| :---- | :---- | :---- | :---- |
| 1 | 5축 즉시 피드백 시스템 | EDR · MEASURE | 두 경쟁사 모두 2축 이하 |
| 2 | 서브웨이 모드 (Subway Mode) ★ v1.5 | VLM·EDR·RPL·표현 노트 청취 | 스픽의 공공장소 사용 불만 \+ 듣기 인풋 강화 \+ 발화 보충 연결 |
| 3 | 발화량 챌린지 (Mode B) \+ 독립 측정 | 전 모듈 통합 (VLM·DRILL·FRT·RPL·OMP) | 두 경쟁사 모두 발화량 시각화 부재 \+ 학습 모드 1급 |
| 4 | 1 Minute Presentation 모듈 | OMP | 별도 모놀로그 모듈 부재한 시장 빈틈 공략 |
| 5 | 자라나는 AI (페르소나·요청 콘텐츠·적응형 난이도) — 검토중 (v1.6) | 모든 모듈 | 100% AI 영역의 차별화 — 구체 적용 범위 검토 진행 (8월 MVP까지 확정) |

## **차별점 1 — 5축 즉시 피드백 시스템**

발음정확도·유창성·문법정확성·화용성·발화량 5축을 한 화면에 동시 시각화. EDR의 3가지 드릴 활동 모두에서 작동.

## **차별점 2 — 서브웨이 모드 (Subway Mode) ★ v1.5**

지하철·도서관·만원 버스·러닝 등 발화가 어려운 환경을 위한 모드. 4지선다 탭 방식은 폐기되고, "이어폰만으로 듣기 \+ 발화 가능 시간에 보충 연결"로 재정의되었다. 4가지 듣기 활동(VLM 반복·EDR 쉐도잉·RPL 시나리오·표현 노트 청취)으로 학습 인풋을 끊김 없이 유지하고, 다음 발화 세션을 자동으로 약속한다. 상세 §3.5.3.

## **차별점 3 — 발화량 챌린지 (Mode B \+ 독립 측정)**

v1.5에서 발화량 챌린지는 "측정"에서 "학습 모드 1급"으로 격상되었다. Mode B 발화 챌린지의 실행 도구로서 표현 노트 즐겨찾기·AI 제안 표현 2종을 카드로 묶어 1\~3분 단위로 즉시 발화 연습한다. 측정 면에서는 전 모듈 통합(VLM·DRILL·FRT·RPL·OMP) 누적 발화 문장을 일·주·월·페르소나 4종 미터로 추적한다. 상세 §2.4.

## **차별점 4 — 1 Minute Presentation 모듈**

OPIc·토익S 답변 형식과 정확히 일치하는 시그니처 시험 대비 모듈. 비즈니스 발표·면접 자기소개로도 동일 활용. 두 경쟁사 모두 별도 모놀로그 모듈 부재.

## **차별점 5 — 자라나는 AI (AI 기술 영역) — 검토중 (v1.6)**

100% AI 영역에서 작동하는 3가지 자동 메커니즘. v1.6 시점에서 3개 항목 모두 적용 범위·기술 깊이를 "검토중" 상태로 두고, 8월 MVP 출시 전까지 구체 명세를 확정 예정.

| 항목 | 상태 | 내용 |
| :---- | :---- | :---- |
| 5-A. AI 페르소나 자동 설정 | 검토중 | 학습자 직무·목표 기반 캐릭터(Sarah·Mike·Emma·David·피클) 자동 매칭. 학습자가 매번 캐릭터를 고르지 않아도 학습 목표에 맞는 캐릭터가 자동 등장 |
| 5-B. 학습자 요청 콘텐츠 1분 내 생성 | 검토중 | 학습자가 "오늘은 \~ 주제로"라고 입력하면 1분 내 LRN \+ DRILL \+ APPLY 모든 콘텐츠 자동 생성 |
| 5-C. 적응형 난이도 엔진 | 검토중 (v1.6 정책 정정) | 학습자 5축 추이를 보고 정체 구간이면 점수·문제 자체를 조정하지 않고, 학습자에게 "다른 난이도의 정규과정·콘텐츠를 추천"하는 방식. 너무 쉬우면 상위 난이도 콘텐츠, 너무 어려우면 하위 난이도 콘텐츠 추천 |

v1.6 적응형 난이도 정책 변경: 학습자에게 보여주는 점수·문제를 자동으로 변형하면 "진짜 내 점수가 무엇인지" 모호해진다. 대신 학습자가 어려워하거나 쉽다고 느낄 때 다른 코스·콘텐츠 추천 카드를 띄워 학습자 본인이 선택하도록 한다.

차별점 5는 AI 시스템이 학습자 컨텍스트를 자동으로 이해하고 학습 경로를 추천하는 영역. 학습자의 정서적 보상 영역(Memory·친밀도)은 §2.5 동기 부여 시스템으로 이동.

# **2.4 발화량 챌린지 — 독립 기능 명세**

## **배경 및 필요성**

서브웨이 모드 학습자는 발화량 0으로 기록되므로 챌린지 미터의 효과를 받지 못한다. 또한 VLM·DRILL·FRT·RPL·OMP 등 모든 모듈에서 발화한 문장을 통합 집계하는 게 사용자에게 더 의미 있다. v1.5에서는 발화량 챌린지를 단순 측정 기능이 아닌 "Mode B 학습 실행 도구 \+ 독립 측정"의 이중 역할로 격상하여 챌린지 탭 안 1급 메뉴로 운영한다.

## **기능 정의**

위치: 챌린지 탭 메인 영역 \+ MEASURE 화면 요약 카드 \+ 홈 탭 미니 위젯 3곳에 동시 노출.

추적 범위: RPL \+ FRT \+ OMP의 모든 발화 문장 누적. EDR의 드릴 발화도 옵션으로 합산 가능 (학습자 설정).

### **미터 4종 구성**

| 미터 | 추적 범위 | 갱신 주기 |
| :---- | :---- | :---- |
| 일일 챌린지 | 오늘 누적 발화 문장 수 | 실시간 |
| 주간 챌린지 | 7일 누적 발화 문장 수 | 일 1회 |
| 월간 챌린지 | 30일 누적 발화 문장 수 | 일 1회 |
| 페르소나 챌린지 | 같은 직무·레벨 평균 대비 | 주 1회 |

## **서브웨이 모드와의 관계 (v1.6 단순화)**

발화량 챌린지는 학습자가 발화 가능 환경에서 자연스럽게 누적되는 구조 유지.

* 서브웨이 모드— 미완료 상태가 다음 진입 시 그대로 재개됨

* 듣기는 듣기 누적 분 \+ 섀도잉 카운트로 기록 (발화량과 분리)

* 주간 통계에 "듣기 누적 분 ↔ 발화 누적 문장" 균형만 표시 (서브웨이 자체에 대한 압박 없음)

## **동적 목표 산정 알고리즘**

오늘 목표 \= max(   지난 7일 평균 × 1.10,   지난 30일 평균 × 1.05 )  학습자가 평탄기에 있으면 자동으로 목표 \-5% 하향 조정해 좌절 방지

## **UI 사양**

* 미터 형태: 가로 진행 바 \+ 카운터 ("23 / 30 문장")

* 도달 시: 콘페티 애니메이션 \+ 친밀도 \+2 보너스

* 미달 시: 피클 멘트 — "오늘은 조금 짧았네요. 내일은 함께 챌린지\! 🌱"

* 서브웨이 모드 보충 배지: 코랄 색상으로 시각적 구분

## **FRT 대화 챌린지 미터와의 통합 운영**

| 구분 | 발화량 챌린지 (독립) | 대화 챌린지 미터 (FRT 내부) |
| :---- | :---- | :---- |
| 측정 대상 | 모든 모듈의 누적 발화 문장 수 | FRT 세션의 대화 깊이·연속성 |
| 핵심 지표 | 문장 수 (Quantity) | Turn 수, 대화 지속 시간, 응답 적절성 |
| 표시 시점 | 전역 (챌린지 탭·홈·MEASURE) | FRT 세션 내부만 |
| 게이미피케이션 | 일일·주간·월간 목표 도달 | 세션 내 "AI와 깊은 대화 도달" 보상 |

이 분리로 학습자는 양적 챌린지(발화량)와 질적 챌린지(대화 깊이)를 별도로 추적·도전할 수 있어 동기 부여 다층화가 가능하다.

# **2.5 학습 동기 부여 시스템 — 4계층 구조**

스피킹맥스의 코인 환급 시스템(위약금 논란)을 회피하고 학습 자체에 보상을 내재화하는 구조. v1.4에서는 정서적 동기 부여 영역을 대폭 강화해 4계층으로 운영.

## **2.5.1 계층 1 — 행동 보상 (Action)**

* 일일 스트릭 (연속 학습일) \+ 복구권 1회/월

* 주간·월간 챌린지 \+ 보상 등급

* 뱃지 시스템 (첫 학습·30일 스트릭·100문장·1MP 5회 등)

* 등급 시스템 (Silver → Gold → Platinum → Diamond — 4축 평균 점수 기반)

* 현금성 환급 없음, 약정 없음 — 학습 가치형 보상만

## **2.5.2 계층 2 — 측정 보상 (Measurement)**

* 5축 점수 향상 시각화

* 시험 등급 환산 (OPIc IL/IM/IH/AL, 토익S 80\~200점)

* 1MP 발표 점수 추이 영상 갤러리

* CEFR 레벨 변화 타임라인

## **2.5.3 계층 3 — 챌린지 보상 (Challenge)**

* 발화량 챌린지 (§2.4 — 일일·주간·월간·페르소나 4종 미터)

* 대화 챌린지 미터 (FRT 세션 내부)

* 회사 미션 (B2B 한정)

* 시즌 이벤트 (분기별 한정)

## **2.5.4 계층 4 — 관계 보상 (Relationship) ★ v1.4 신규**

학습자의 학습 지속을 가장 강력하게 만드는 정서적 동기 부여 영역. 측정 압박 없이도 학습자가 매일 돌아오게 만드는 메커니즘.
