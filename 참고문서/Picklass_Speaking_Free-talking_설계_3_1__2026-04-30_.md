# **1\. 프로젝트 개요**

## **1.1 프로젝트 목적**

Picklass Speaking Tutor는 AI 기반 영어 말하기 학습 플랫폼으로, 실시간 음성 인식(STT)과 음성 합성(TTS)을 활용하여 학습자와 AI 튜터(피클) 간의 자연스러운 영어 대화를 제공합니다.

## **1.2 핵심 가치**

* 적응형 학습: 18단계 세분화 레벨에 따른 맞춤형 대화

* 실시간 피드백: AI 기반 문법 교정 및 발음 개선

* 자연스러운 대화: 연속 대화 모드로 끊김 없는 학습 경험

* 데이터 기반 성장: 5가지 KPI로 학습 진도 정량화

## **1.3 주요 기능**

* 레벨별 맞춤 대화 (Level 1\~18)

* AI 기반 의도 분류 및 응답

* 문법 교정 및 따라 읽기

* 역질문 대응 및 질문 유도

* 종합 학습 리포트 제공

## **1.4 사용자 대상**

* 영어 초급 학습자 (A1-A2)

* 중급 학습자 (B1-B2)

* 고급 학습자 (C1-C2)

* 시험 준비생 (토익 스피킹, 오픽 등)

* 비즈니스 영어 학습자

## **2.3 대기 정책 — Take your time \+ 힌트 발동 2단계**

**\[v3.1 변경\]** *v3.0의 단일 침묵 타이머(5/8/10초)를 두 단계로 분리. 학습자 사고 시간을 보호하면서, 도움이 필요한 시점에는 힌트가 발동되도록 함.*

**1단계 — "Take your time" 노출 (사고 시간 모드 진입)**

이 시간 동안에는 힌트가 발동되지 않습니다. 학습자가 영어 문장을 조립하는 사고 시간으로 보호됩니다.

| 레벨 그룹 | 무발화 지속 → "Take your time" 노출 |
| ----- | ----- |
| L1-6 (Starter, Beginner) | 10초 |
| L7-12 (Intermediate, Upper-Inter.) | 15초 |
| L13-18 (Advanced, Proficient) | 20초 |

**2단계 — 힌트 발동**

"Take your time" 노출 후 추가 시간이 경과해야 힌트가 발동됩니다.

| 레벨 그룹 | "Take your time" 후 → 힌트 발동까지 |
| ----- | ----- |
| L1-6 | 추가 10초 (총 20초) |
| L7-12 | 추가 15초 (총 30초) |
| L13-18 | 추가 20초 (총 40초) |

원본 대비 학습자의 무발화 허용 시간이 4\~6배로 늘어남. "Take your time" 메시지가 노출되는 동안 학습자는 AI에게 버려지지 않았다는 신호를 받으면서 충분히 생각 가능. UX 노출은 단순 텍스트보다 명시적 시각 신호(예: 튜터 아바타의 기다리는 표정, 부드러운 펄스 애니메이션) 와 함께 노출되는 것이 효과적.

# **3\. 대화 흐름 (3단계)**

Phase 1 (진입) → Phase 2 (순환 루프 Step A\~E) → Phase 3 (종료) 의 3단계 구조. v3.0과 골격 동일. Step B/C/D 내부 구현이 v3.1에서 수정됨.

## **3.1 Phase 1: 진입 단계**

### **3.1.1 세션 초기화**

* 입력 정보: Level (1\~18), 주제, 시간(3/5/10/15/20분), 사용자 ID(향후)

* 시스템 설정: WPM 자동 매핑, TTS 속도 계산, \[v3.1\] 인터벌 설정, \[v3.1\] Take your time 임계치 설정, 대화 히스토리 초기화

### **3.1.2 Opening (첫 질문)**

AI 역할: 피클(Pickle) \- 친근하고 격려하는 영어 튜터. 사용자 입력 주제 분석 → 레벨에 맞는 질문 난이도 선택 → 영어로만 제시(초급은 한글 가이드 병행) → TTS 재생(레벨별 WPM 적용) → 맥락 기반 힌트 3단계 동시 생성. v3.0과 동일.

## **3.2 Phase 2: 순환 루프 단계**

### **3.2.1 Step A: 발화 유도 질문**

AI가 학습자에게 질문을 던져 발화를 이끌어냄. 레벨에 맞는 질문 \+ 맥락 기반 힌트 3단계 동시 생성. 텍스트로 화면 표시 \+ TTS 재생(영어 부분만). 침묵 타이머 시작 \+ STT 활성화. v3.0과 동일.

**\[v3.1 변경\]** *AI 발화는 \[2.6\] 단어 수 상한을 따름. 영어 텍스트와 한국어 설명은 별도 채널로 분리(자세한 내용은 4.2).*

### **3.2.2 Step B: 대기 및 상태 감지**

**\[v3.1 변경\]** *단일 침묵 타이머(5/8/10초)를 두 단계로 분리. 1단계 대기 동안 사고 시간 보호, 2단계 대기 후 힌트 발동.*

**상태 분기**

* 1단계 대기 (사고 시간 모드): 학습자 무발화 → 그룹별 임계치 (10/15/20초) → "Take your time" 메시지 노출. 힌트 발동 안 함.

* 2단계 대기 (힌트 발동 대기): "Take your time" 노출 후 → 추가 임계치 (10/15/20초) → 힌트 1단계 발동. 추가 시간 경과 시 힌트 2단계 → 힌트 3단계.

* STT Confidence \< 0.5 → "못 들었어요"(로컬, LLM 호출 안 함). v3.0과 동일.

* 정상 입력 → Step C로 진행.

**UX 권장 사항**

* "Take your time" 메시지는 단순 텍스트가 아니라 시각 신호 동반(아바타 표정, 부드러운 펄스 애니메이션 등).

* 힌트 발동 직전 노티스("힌트가 곧 나옵니다") 는 노출하지 않음 — 학습자가 힌트를 기다리는 패턴 학습 방지.

### **3.2.3 Step C: 통합 AI 처리 (Unified AI Processing)**

**\[v3.1 변경\]** *교정 우선순위 ①②③ 정의 \+ 그룹별 강도 \+ ② 가드 메커니즘 도입. 출력 JSON 스키마 확장.*

**교정 우선순위**

| 순위 | 교정 항목 | 설명 |
| ----- | ----- | ----- |
| ① | 문법적으로 완전한 오류 | 시제, 단복수, 동사 변화, 관사, 주어-동사 일치 등 명확한 규칙 위반. 모든 레벨 공통. |
| ② | 레벨 학습 포인트 위반 | Starter/Beginner — 불완전한 문장 (단어 나열, 주어·동사 누락). 완전한 문장 발화가 학습 목표. Intermediate/Upper-Inter. — 단순 평행 문장 반복. 복문(접속사·관계절·종속절) 활용이 학습 목표. Advanced/Proficient — 비격식 표현, 구어적 축약, 부적절한 어조. 격식 있는 문장 발화가 학습 목표. |
| ③ | 그 외 일반적으로 어색한 표현 | ①②에 해당하지 않으나 자연스럽지 않은 영어. 약하게 처리, 매 턴 잡지 않음. |

**그룹별 교정 강도**

| 그룹 | 교정 강도 | 특징 |
| ----- | ----- | ----- |
| Starter / Beginner | 완전 교정문 \+ 따라 읽기 | 교정문을 하나만 제시. 학습자가 따라 말하도록 강제. 패턴 정착이 목표. |
| Intermediate / Upper-Inter. / Advanced | 부분 교정 \+ 선택지 | 한국어 설명 안에 영어 권장 표현이 포함되어 한 번에 들려짐. 단일 모범답안 강제 없음, 여러 대안 동시 제시. |
| Proficient | 대안 제시만 | 교정이 아닌 어휘 풍부화. 학습자가 잘하고 있음을 전제로 선택지만 제공. 한국어 설명은 최소화. |

**② 가드 메커니즘 — 매 턴 발동 방지**

②(레벨 학습 포인트 위반)는 학습 정의상 "대부분 발화가 학습 포인트에 미달"하는 상황(특히 저레벨)에서 매 턴 발동될 위험. 이를 막기 위해 ②는 위반 발견이 아닌 목표 방향 유도로 정의하고, 다음 세 장치로 통제.

**가드 1\. ②의 트리거 조건 엄격화**

* Starter/Beginner — 발동: 명백한 단어 나열만 했을 때 (1\~2 단어, 또는 주어·동사 둘 다 부재). 비발동: 짧은 답변이 자연스러운 맥락(Yes/No 응답).

* Intermediate/Upper-Inter. — 발동: 연속 2\~3턴 단순 평행 문장만 사용했을 때, 또는 두 단순문이 because/and/which 등으로 묶일 수 있는 자리에 인접해 있을 때. 비발동: 단순문이지만 의미가 충분한 경우.

* Advanced/Proficient — 발동: 명백한 비격식 마커 사용(gonna, kinda, ain't, 슬랭 등), 토론 맥락인데 구어적 어조 두드러질 때. 비발동: 평이한 격식 영어 사용 중.

**가드 2\. ②의 액션 격하 — 교정이 아닌 권장(suggestion)**

* ①은 교정(correction) — 그룹별 강도에 따라 처리.

* ②는 권장(suggestion) — 따라 읽기 강제 없음, 단일 모범답안 강제 없음. 한국어 TTS로 살짝 알려주는 톤으로 한 번 노출하고 다음 턴 진행.

* ③은 가능한 무시 — 발화 흐름이 매끄럽게 유지되는 한 그냥 통과.

**가드 3\. 빈도 가드 — 발화량 cool-down \+ 흡수 신호 \+ 직전 1턴 룰**

절대 횟수(N)와 절대 턴 수(K)는 세션 길이가 가변(시간/토큰 옵션)일 때 깨지므로, "간격"과 "흡수 신호"로 통제.

| 가드 | 내용 |
| ----- | ----- |
| 발화량 cool-down | ② 발동 후 학습자 누적 발화 단어 30개 이상이 채워져야 ② 재발동 가능. 시간 cool-down은 적용하지 않음. 세션 길이(시간/토큰)와 무관하게 자동 비례. |
| 흡수 신호 기반 자가 조정 | ② 발동 후 학습자가 권장 패턴을 다음 2\~3턴 안에 시도하면 해당 학습 포인트는 마스터 처리. 같은 영역 ②는 더 이상 발동하지 않음. 시도 안 하면 cool-down 통과 후 다른 형태로 한 번 더 권장 가능. |
| 직전 1턴 룰 | 직전 1턴에 ② 발동이 있었으면 이번 턴은 무조건 ② 비활성화. cool-down의 최소 단위 보장. |

**Step C 출력 JSON 스키마 (수정안)**

기존 단일 correction 필드를 다음과 같이 확장.

| 필드명 | 타입 | 설명 |
| ----- | ----- | ----- |
| english\_response | string | 영어 TTS용. 학습자 발화에 대한 응답 \+ 다음 질문. |
| should\_correct | boolean | ① 또는 ②(트리거+가드 통과) 시 true. |
| correction\_priority | "1\_grammar" | "2\_level\_focus" | "3\_general\_awkwardness" | null | 교정 우선순위. |
| correction\_action | "correct" | "suggest" | null | ① → correct, ② → suggest. 교정과 권장을 코드에서 구분. |
| correction\_strength | "full\_repeat" | "partial\_choice" | "alternatives\_only" | null | 그룹별 강도. action=correct일 때만 의미 있음. |
| corrections\_or\_suggestions | string\[\] | Starter/Beginner는 1개, 나머지는 2\~3개. |
| korean\_explanation\_with\_english | string | 한국어 TTS용. 한국어 설명 안에 영어 권장 표현이 자연스럽게 포함된 형태. |
| level\_focus\_area | string | null | ② 발동 시 어느 학습 포인트 영역인지(예: "complete\_sentence", "complex\_sentence", "formal\_register"). 마스터리 트래킹용. |
| next\_question | string | 다음 질문(Step E에서 사용). |

### **3.2.4 Step D: 실시간 분석 및 피드백**

**\[v3.1 변경\]** *영어 TTS와 한국어 TTS 두 채널로 분리. 그룹별 교정 강도 정책 명시.*

**두 TTS 채널의 역할**

| 채널 | 내용 | 음성 모델 |
| ----- | ----- | ----- |
| 영어 TTS (원어민) | 대화 진행 중심 — 학습자 발화에 대한 자연스러운 응답 \+ 다음 질문 | 구글 기본 Voice (확정) |
| 한국어 TTS (한국인 화자) | 교정 설명 \+ 영어 권장 표현 낭독. 한국어 설명 안에 영어 표현이 포함되며 그 부분도 한국어 TTS가 읽음 | TBD (다국어 검토) |

**재생 시퀀스**

* 300ms 내 추임새 (영어 TTS): "Great\!", "Nice\!" 등

* Step C 출력의 영어 응답 (영어 TTS): 학습자 발화 인정 \+ 다음 질문

* Step C 출력의 한국어 설명 (한국어 TTS): 교정 설명, 영어 권장 표현 포함 — should\_correct=true 시

* 따라 읽기 모드 (Starter/Beginner의 경우만): 교정 문장 영어 TTS 재생 후 학습자 따라 말하기 대기

**그룹별 처리 예시**

**(1) Starter / Beginner — 완전 교정문 \+ 따라 읽기**

학습자: "I like movie" (단복수 오류 — 우선순위 ①)

* 영어 TTS: "Good\! I like movies, too. What kind of movies do you enjoy?"

* 한국어 TTS (별도): "복수형에는 \-s를 붙여야 해요. 'I like movies' 라고 말하면 돼요. 따라 해보세요."

* TTS로 교정 문장 재생: "I like movies"

* 따라 읽기 모드 진입 (8초 대기, 75% 유사도, 1회 재시도)

**(2) Intermediate / Upper-Inter. / Advanced — 부분 교정 \+ 선택지**

학습자: "It's exciting because lots of action" (어색한 표현 — 우선순위 ②, Intermediate 학습 포인트인 복문 인접)

* 영어 TTS: "Nice\! Action makes movies fun for sure. What's your favorite action movie?"

* 한국어 TTS (별도): "'because' 뒤에는 보통 명사구나 절이 와요. 'because of all the action' 또는 'because there's a lot of action.'"

* 따라 읽기 모드 없음. 학습자가 다음 발화에서 자연스럽게 선택해 쓰도록 유도.

**(3) Proficient — 대안 제시만**

학습자: "It really is a thrilling experience" (오류 없음, Proficient 학습 포인트인 격식도 만족)

* 영어 TTS: "Absolutely. Some films just stay with you long after the credits roll. Which scenes affected you the most?"

* 한국어 TTS: 보통 노출하지 않음. 단, 어휘 풍부화 권장이 있는 경우 한정 노출 — "좀 더 격식 있는 표현으로는 'an absolute thrill' 또는 'truly riveting' 같은 표현도 있어요."

### **3.2.5 Step E: 다음 액션 (Next Action)**

**한국어 TTS의 영어 발음 처리 (운영 후 단계적 개선)**

1차 적용: 한국어 화자 보이스가 영어 권장 표현을 그대로 낭독. 단순한 재생 흐름 \+ 비용 효율. 한국인 학습자에게 친숙한 발음 모델 노출.

* 단계적 개선 후보 (가): 다국어 지원 TTS(예: ElevenLabs, Microsoft Neural Voice 등)로 한국어 화자 보이스가 영어 부분을 영어 발음으로 읽도록 SSML 처리. 비용·지연 영향 검토 필요.

* 단계적 개선 후보 (나): 권장 표현만 별도 영어 TTS로 짧게 끼워넣기. 재생 흐름이 두 번 끊기고 트랙 전환 발생.

*1차 적용 후 사용자 피드백을 모아 (가) 또는 (나) 로 단계적 개선이 합리적.*

| 5 | 문법 정확성 (Grammar) | 오류 발화 수 기반: (정확한 발화 / 총 발화) × 100 | L1-3: 60-70% / L4-6: 70-80% / L7-9: 75-85% / L10-12: 80-90% / L13-15: 85-95% / L16-18: 90-100% |

* ② 가드 후처리는 서버 측 메모리 처리 — 추가 API 비용 없음.

*실제 영향 측정은 1차 적용 후 데이터 확보하여 재산정.*
