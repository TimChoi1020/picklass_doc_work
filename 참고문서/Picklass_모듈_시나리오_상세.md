## 0. 공통 수정 사항

### 0.1 화면 구성 — 모바일 3분할 (상단/중간/하단)

기존 데스크톱형 3분할(좌상단/좌하단/우측)을 모바일 우선 **상단·중간·하단** 세로 3분할로 통일.

| 영역 | 역할 | 표시 요소 |
|---|---|---|
| **상단 (Top)** | 진도·헤더·메타 | 5단계 진행 인디케이터, 모듈명, 시간/카운트다운, 시나리오 정보 |
| **중간 (Middle)** | 메인 학습 콘텐츠 | 문장, 카드, 영상, 대화 흐름, 차트, 5축 피드백 |
| **하단 (Bottom)** | 입력·액션 | 마이크/녹음 버튼, 힌트 버튼, 모드 토글, 다음/이전 |

피클(Pickle) Agent의 멘트는 **상단의 작은 말풍선** 또는 **중간 영역 위 토스트** 형태로 노출되며 별도 채팅 패널을 차지하지 않는다. 학습자의 발화 흐름을 방해하지 않는 비침습적 노출.

### 0.2 AI 선제 개입 → 힌트 버튼 (사용자 요청형)

기존 **자동 선제 개입**(타이머 경과 시 자동 힌트 제공)을 **힌트 버튼 사용자 요청형**으로 전환.

- 모든 모듈의 하단 영역에 **\[💡 힌트\] 버튼** 상시 노출
- 학습자가 힌트 버튼을 **직접 클릭한 경우에만** 힌트 제공
- 자동 타이머 개입 없음 (사용자 학습 흐름 존중)
- 힌트 사용 횟수는 측정·기록되지만 점수에 직접 반영하지 않음 (정책: 학습자 자율성 우선)
- 단, **무발화 5초 이상**(FRT)·**60초 발화 정체**(OMP) 등 특수 트리거는 학습 진행에 필수적이므로 유지

### 0.3 멘트 사전 생성·저장 구조

기존 단계별 멘트 가이드 표를 **세션 진입 시 사전 생성·저장하는 멘트 데이터 구조**로 전환.

**0단계 데이터 준비 시 LLM이 학습자 컨텍스트(이름·레벨·직전 학습 결과·페르소나)를 반영해 모든 단계의 멘트를 사전 생성**, 트리거 시점에 즉시 재생되어 응답 지연이 없다.

```javascript
// 세션 멘트 데이터 구조 (예시)
{
  session_id: "ses_20260507_001",
  module_code: "EDR",
  user_context: { name: "Tim", level: "B1", weak_axis: "화용성" },
  ments: [
    { id: "M01_INTRO",       trigger: "MODULE_ENTRY",        variants: [...3종] },
    { id: "M02_HINT",        trigger: "USER_HINT_CLICK",     variants: [...5종] },
    { id: "M03_PASS",        trigger: "FEEDBACK_PASS",       variants: [...5종] },
    { id: "M04_RETRY_1",     trigger: "FEEDBACK_RETRY_1",    variants: [...3종] },
    { id: "M05_RETRY_FINAL", trigger: "FEEDBACK_RETRY_FINAL",variants: [...3종] },
    { id: "M06_3STRIKE",     trigger: "3STRIKE_ALERT",       variants: [...2종] },
    { id: "M07_OUTRO",       trigger: "MODULE_COMPLETE",     variants: [...3종] }
  ]
}
```

각 멘트는 변형 2~5종이 사전 생성되어 **무작위 노출**되므로 같은 트리거에서도 매번 다른 멘트가 들린다(반복 학습 시 신선도 유지). 학습자별 컨텍스트 반영으로 "Tim님, 어제 화용성 +3점 올랐어요\!" 같은 개인화 멘트도 사전 생성된다.

### 0.4 모듈 코드 변경

| 변경 전 | 변경 후 | 사유 |
|---|---|---|
| WSP (Word Speaking) | **VLM (Vocabulary Listening & Meaning)** | 단어 스피킹의 ASR 한계 + 의미 약함 → 듣고 의미 확인 방식 |
| LR/SHD/SXP (3 모듈) | **EDR (Expression Drill, 단일 모듈 + 3-stage)** | 통합 운영, 내부 Read→Fill-in→Expand 점진 진행 |
| RLP (Role-Playing) | **RPL (Role-Play, PTT)** | 코드 변경 + Push-to-Talk 방식 |
| OMS (One-Minute Topic Speaking) | **OMP (One Minute Presentation)** | 명칭 통일 |

**최종 9개 모듈 코드 확정** *(⚠️ v1.2 — v1.1의 6모듈에서 EDR·RPL 분리)*:

| 코드 | 모듈명 | 단계 | 핵심 메커니즘 |
|---|---|---|---|
| **LRN** | Learn & Study | 2단계 LEARN | 콘텐츠 입력 + 표현 카드(레벨별 3~5개) |
| **VLM** | Vocabulary Listening & Meaning | 3-1 어휘 워밍업 | 듣고 의미 확인 (스피킹 X) |
| **SHD** | Shadowing Drill *(← EDR Stage1)* | 3-2 정밀 드릴 ① | 따라말하기 (원문 발화) + 5축 |
| **SFB** | Sentence Fill-in Blank *(← EDR Stage2)* | 3-2 정밀 드릴 ② | 채워말하기 (블랭크 완성) + 5축 |
| **SMK** | Sentence Making Drill *(← EDR Stage3)* | 3-2 정밀 드릴 ③ | 만들어말하기 (문장 확장, LLM+20초 힌트) + 5축 |
| **RPB** | Role-Play Basic *(← RPL)* | 4-1 Phase 1 ① | PTT 정형 시나리오 대화 |
| **RPF** | Role-Play Free *(← RPL)* | 4-1 Phase 1 ② | PTT 자유 확장 대화 |
| **FRT** | Free Talking | 4-2 Phase 2 | 자유 대화 + 챌린지 미터 |
| **OMP** | One Minute Presentation | 4-3 Phase 3 | 30초 준비 + 1분 발표 |

> **표현 연계 (LRN→SHD→SFB→SMK)**: 레벨별 동일 N개 표현을 4모듈이 순차 공유 — LRN(소개)→SHD(따라말)→SFB(채워말)→SMK(만들어말). **LLM은 SMK·OMP 2모듈만** 실호출.

## 1. LRN — Learn & Study (2단계 LEARN)

콘텐츠(지문·영상·오디오)를 시청·청취하고 핵심 표현 5개를 카드 형태로 흡수하는 입력 학습 모듈.

### 0단계: 데이터 준비

- **콘텐츠 매핑**: 영상 또는 지문 1개 + 핵심 표현 5개 사전 추출
- **표현 카드 사전 구성**: 영어 표현 + 한국어 의미 + 사용 상황 + TTS + 즐겨찾기 옵션
- **자막 데이터**: 한국어/영어/없음 3종
- **재생 속도**: 0.7×/1.0×/1.3×
- **멘트 사전 생성**: M01_INTRO·M02_HINT·M03_OUTRO 변형 3종씩
- **측정 지표**: 카드 관람 완료율, 자막 사용 패턴, 즐겨찾기 표현 수

### 레벨별 매트릭스

| CEFR | 영상 길이 | 표현 카드 수 | 자막 기본값 | 비고 |
|---|---|---|---|---|
| Pre-A1 ~ A1 | 1.5분 | 5개 (단순) | 한국어 ON | 한국어 안전망 |
| A2 | 2분 | 5개 | 한/영 토글 | 카드 길게 누르면 예문 |
| B1 | 2.5분 | 5개 (관용 1개) | 영어 ON | 카테고리 라벨 |
| B2 | 3분 | 5개 (격식 차이) | 영어 ON | 격식·비격식 구분 |
| C1 / C2 | 3분 | 5개 (수사 표현) | OFF | 뉘앙스 보충 |

### 1단계: 수업 시작
- **상단**: 진도 인디케이터 (LEARN) + 미션 제목
- **중간**: 비디오 플레이어 (자동 재생 ❌, 일시정지 화면)
- **하단**: \[재생\] 버튼 + 자막·속도 토글 + \[💡 힌트\]
- 진입 즉시 M01_INTRO 멘트 재생: *피클: "오늘 배울 표현 5개를 영상으로 만나볼 거예요. 자막 편하게 켜고 끄세요\! 🎬"*

### 2단계: 탐색 및 학습
- **중간 영상 재생 중**: 핵심 표현 등장 시 자동 하이라이트 + 우상단 카드 스택 자동 적층
- **하단 카드 영역**: 좌우 스와이프 5개 카드 탐색, ♪ 발음 듣기, 길게 누르면 즐겨찾기

### 3단계: 힌트 (사용자 요청 시)
- **트리거**: 학습자가 \[💡 힌트\] 클릭
- M02_HINT 멘트 재생: *피클: "한 번 더 들어볼까요? 자막 켜고 0.7배속으로 들어볼게요\! 💪"*
- 자동 동작: 자막 자동 ON + 0.7× 재생 + 정지 위치 5초 전 시점부터 재생

### 4단계: 답안 수행
- LRN은 답안 입력 없음 (입력 학습)
- 카드 5개 모두 1회 이상 관람 + 영상 시청 완료 시 \[드릴 시작 →\] 활성화

### 5단계: 피드백 확인
- 영상 종료 시 자동 요약 토스트
- *피클: "오늘의 핵심 표현 5개, 모두 만나봤어요\! 🌟"*
- 즐겨찾기 표현 마이페이지 표현 노트 자동 저장 안내

### 6단계: 심화 및 재도전
- **재도전 조건**: 카드 관람률 60% 미만 또는 영상 시청 30% 미만
- 분기: \[다시 볼게요\] / \[드릴로 가요\]

### 7단계: 학습 완료
- M03_OUTRO 멘트: *피클: "표현 흡수 완료\! 정밀 드릴로 입에 붙여볼게요\! 🎊"*
- 데이터 확정: 영상 완료율, 카드 관람 수, 즐겨찾기 표현 수
- \[드릴 시작 →\] 활성화

### 사전 생성 멘트 데이터

| 멘트 ID | 트리거 | 변형 수 | 변수 슬롯 | 예시 |
|---|---|---|---|---|
| M01_INTRO | MODULE_ENTRY | 3종 | {{name}}, {{topic}} | "오늘은 {{topic}} 표현 만나볼게요\! 🎬" |
| M02_HINT | USER_HINT_CLICK | 3종 | — | "자막 켜고 0.7배속\! 💪" |
| M03_OUTRO | MODULE_COMPLETE | 3종 | {{cardCount}} | "{{cardCount}}개 카드 흡수 완료\! 🎊" |

## 2. VLM — Vocabulary Listening & Meaning (3-1 어휘 워밍업) ✦ v0.15 재설계

LRN 학습 표현 속 핵심 어휘 5개를 **듣고 의미를 확인**하는 30초 워밍업 모듈. 단어 스피킹은 ASR 정확도 한계와 학습 효과 약함으로 제외, **청각 입력 + 의미 인지** 방식으로 재설계.

### 0단계: 데이터 준비

- **콘텐츠 매핑**: LRN 표현 5개 → 핵심 어휘 5개 자동 추출
- **카드 사전 구성** (각 어휘별):
  - 원어민 음성 (TTS, 자연 속도 1.0× + 슬로우 0.7× 2종)
  - 영어 단어 (음절 분리 가이드 포함)
  - 한국어 의미 + 이미지(있으면)
  - 정답 의미 1개 + 오답 의미 2개 (선택형 검증용)
- **자동 진행**: 어휘당 6초 (총 30초)
- **멘트 사전 생성**: M01·M02·M03 변형 3종씩
- **측정 지표**: 의미 선택 정답률, 카드 관람 완료율, 슬로우 재생 사용 횟수

### 레벨별 매트릭스

| CEFR | 활성화 | 어휘 수 | 카드당 시간 | 의미 확인 방식 |
|---|---|---|---|---|
| Pre-A1 ~ A1 | ✓ | 5개 (전부) | 6초 | 한국어 의미 자동 노출 |
| A2 | ✓ | 5개 | 6초 | 한국어 3지선다 |
| B1 ~ B2 | ✓ (선별) | 1~3개 (미즐겨찾기만) | 6초 | 영어 정의 3지선다 |
| B2+ ~ C1 | ✗ 자동 스킵 | — | — | — |

### 1단계: 수업 시작
- **상단**: 워밍업 30초 라벨 + 카운트다운 바
- **중간**: 첫 어휘 카드 (영어 단어 + 음절 분리)
- **하단**: \[시작\] 버튼 + \[워밍업 스킵\] + \[💡 힌트\]
- M01_INTRO: *피클: "본격 드릴 전에 30초 워밍업\! 단어 듣고 의미만 가볍게 확인해볼게요\! 🎧"*

### 2단계: 탐색 및 학습 (듣기 + 의미 확인)

각 어휘별 흐름:
1. **듣기 (1.5초)**: 원어민 음성 자동 재생 + 영어 단어 표시 + 음절 분리 가이드
2. **의미 확인 (3.5초)**:
   - 초급(A1~A2): 한국어 의미 자동 노출 ("apple → 사과 🍎")
   - 중급(B1~B2): 한국어 3지선다 또는 영어 정의 3지선다 → 학습자 탭 선택
3. **다음 카드 자동 전환 (1초)**: 다음 어휘로 슬라이드

학습자는 마이크 발화 없이 듣고 보고 (필요시 탭) 진행. ASR 부담 0.

### 3단계: 힌트 (사용자 요청 시)
- **트리거**: \[💡 힌트\] 클릭
- M02_HINT: *피클: "한 번 더 천천히 들려드릴게요\! 🎧"*
- 자동 동작: 0.7× 슬로우 재생 + 음절 분리 시각적 강조

### 4단계: 답안 수행
- 중급 이상의 의미 선택만 답안 수행에 해당
- 정답 선택 시 ✓ 시각 피드백, 오답 시 정답 자동 노출 (감점 없음)

### 5단계: 피드백 확인
- 30초 완료 시 미니 토스트
- *피클: "워밍업 완료\! 5개 어휘 의미 확인했어요\! 본격 드릴 시작\! ✨"*
- 모두 정답 시 보너스 +5pt

### 6단계: 심화 및 재도전
- 워밍업이므로 재도전 강요 안 함
- 의미 정답률 < 60% 시 *피클 토스트: "어휘가 좀 어렵네요. 드릴에서 다시 만나볼게요\!"*

### 7단계: 학습 완료
- M03_OUTRO: *피클: "귀가 좀 풀렸나요? 진짜 드릴 갑니다\! 🚀"*
- 데이터 확정: 의미 정답률, 슬로우 재생 사용 횟수, 워밍업 참여율
- 화면 자동 전환: VLM 종료 → EDR 시작

### 사전 생성 멘트 데이터

| 멘트 ID | 트리거 | 변형 수 | 예시 |
|---|---|---|---|
| M01_INTRO | MODULE_ENTRY | 3종 | "30초 워밍업\! 단어 듣고 의미만 확인\! 🎧" |
| M02_HINT | USER_HINT_CLICK | 3종 | "한 번 더 천천히\! 🎧" |

## 3. SHD · SFB · SMK — 정밀 드릴 3모듈 (3-2) ✦ v1.2 재정의 (구 EDR 분리)

> ⚠️ **v1.2 — 구 EDR(3-stage 단일 모듈)이 SHD·SFB·SMK 3개 독립 모듈로 분리**. 아래 시나리오의 **Stage 1(Read) = SHD(Shadowing Drill, 따라말하기)**, **Stage 2(Fill-in) = SFB(Sentence Fill-in Blank, 채워말하기)**, **Stage 3(Expand) = SMK(Sentence Making Drill, 만들어말하기)** 로 대응한다. 각 모듈은 독립 5축 피드백을 가지며, SMK만 LLM 코칭 + 무발화 20초 후 힌트 1회. 표현당 SHD→SFB→SMK 순차 통과.

LRN 표현을 **3개 모듈로 점진적 발화**(따라말 → 채워말 → 만들어말)하며 5축 KPI 즉시 피드백을 받는 픽클래스 핵심 차별 구간. 콘텐츠는 **레벨에 맞는 관용표현(이디엄·숙어) 포함 필수**.

### 0단계: 데이터 준비

- **콘텐츠 매핑**: LRN 표현 5개 + **레벨별 관용표현·이디엄·숙어 사전 매핑**
  - 초급: 빈도 높은 기본 관용 (예: "Let's get started", "Thanks for joining")
  - 중급: 비즈니스 관용 (예: "circle back", "touch base", "on the same page")
  - 고급: 수사적 관용 (예: "moving the needle", "hit the ground running")
- **3단계 콘텐츠 사전 구성** (표현당):
  - **Stage 1 (Read)**: 원문 문장 그대로 (관용표현 굵게 강조)
  - **Stage 2 (Fill-in)**: 핵심 표현 부분을 블랭크 처리 (예: "Let's _____." 또는 "_____ for joining the meeting.")
  - **Stage 3 (Expand)**: 같은 표현을 활용한 새 문장 만들기 (한국어 가이드 + 핵심 단어 힌트)
- **5축 평가 알고리즘**: 발음정확도·유창성·문법정확성·화용성·발화량
- **자동 정지**: 문장 길이 × 1.5초
- **재시도 카운트**: Stage당 최대 3회
- **모드**: PTT(라이트)·Always-On(노멀)·Silent Drill(조용한 모드 차별점)
- **멘트 사전 생성**: M01~M07 변형 3~5종

### 레벨별 매트릭스

| CEFR | Stage별 표현 수 | 관용표현 비중 | 콘텐츠 예 (Stage 3 확장) |
|---|---|---|---|
| Pre-A1 ~ A1 | 5표현 × 3 Stage | 1개 | "Let's get started." → "Let's get started with the meeting." |
| A2 | 5표현 × 3 Stage | 2개 | "Thanks for joining." → "Thanks for joining us today." |
| B1 | 5표현 × 3 Stage | 3개 | "Let's circle back to this." → "Let's circle back to this issue next week." |
| B2 | 5표현 × 3 Stage | 4개 | "We need to be on the same page." → "Before we move forward, let's make sure we're on the same page about the timeline." |
| C1 / C2 | 5표현 × 3 Stage | 5개 | "Move the needle." → "These initiatives should genuinely move the needle on customer retention." |

### 1단계: 수업 시작
- **상단**: 진도 (DRILL) + ★ 핵심 차별점 배지 + Stage 인디케이터 (1/3·2/3·3/3)
- **중간**: 학습 문장 영역 + 5축 피드백 그리드 자리(빈 상태)
- **하단**: 모드 토글 (PTT·Always-On·Silent) + 마이크 버튼 + \[💡 힌트\]
- M01_INTRO: *피클: "5축 정밀 드릴 시작\! 읽기 → 블랭크 채우기 → 문장 확장 3단계로 마스터해볼게요\! 🎙"*

### 2단계: 탐색 및 학습 (Stage별 진행)

**Stage 1 — Read (문장 읽기)**
- 중간: 원문 문장 + IPA 발음 가이드 + 관용표현 굵게 강조
- 학습자가 마이크로 그대로 발화
- 5축 측정 → 5단계 피드백

**Stage 2 — Fill-in (블랭크 채우기)**
- 중간: 같은 문장 + 핵심 표현 부분 블랭크 (예: "Let's _______ the meeting.")
- 학습자가 블랭크 채워 전체 문장 발화
- 블랭크 정답 일치 + 5축 측정 → 5단계 피드백

**Stage 3 — Expand (문장 확장)**
- 중간: 같은 표현을 활용한 새 문장 만들기 미션 + 한국어 가이드 (예: "이 미팅으로 회의 시작해볼게요'를 영어로")
- 학습자가 자유롭게 영작 발화
- 표현 사용 여부 + 5축 측정 → 5단계 피드백

각 Stage 내부에서 5축 측정과 피드백이 동일하게 진행되며, 통과 시 다음 Stage로 자동 전환.

### 3단계: 힌트 (사용자 요청 시)
- **트리거**: \[💡 힌트\] 클릭
- Stage별 힌트 차등:
  - Stage 1: M02_HINT_READ — *피클: "강세에 신경 쓰면서 따라 해봐요\! 💪"* + 0.7× 다시 들려주기
  - Stage 2: M02_HINT_FILL — *피클: "이 표현이 들어가요\!"* + 핵심 어휘 첫 글자 노출
  - Stage 3: M02_HINT_EXPAND — *피클: "이렇게 시작해볼까요?"* + 한국어 가이드 + 핵심 단어 원형

### 4단계: 답안 수행
- PTT/Always-On 모드: 마이크 발화 → \[Stop\] 또는 자동 정지
- Silent Drill 모드: 키보드 입력 또는 작은 음성 발화
- **5축 동시 분석** (실시간):
  - 발음정확도: 음소 단위
  - 유창성: WPM + 휴지
  - 문법정확성: 단어 일치 + 어순
  - 화용성: 상황 적절성 (특히 Stage 3에서 강조)
  - 발화량: 발화 시간 + 문장 충실도

### 5단계: 피드백 확인 (Stage별)
- **중간 영역에 5축 그리드 (2×3 — 4축 + 발화량 통합 셀)** 즉시 활성화
- **정답 시 (5축 평균 80% 이상)**:
  - M03_PASS: *피클: "딩동댕\! 5축 모두 멋져요\! 🌟"*
  - 다음 Stage로 자동 전환 (Stage 1→2→3)
- **1~2회차 오답**:
  - M04_RETRY_1: 가장 약한 축 1개 우선 코칭
  - *예: "발음 좋은데 'circle'의 'r' 발음 좀 더 굴려볼까요? (남은 기회 2회) 😊"*
- **3회차 최종 오답**:
  - M05_RETRY_FINAL: 정답 음성 자동 재생 + 종합 코멘트
  - *피클: "정답은 \[{{Sentence}}\]였어요. 다음 Stage로\! 🎯"*

### 5-A단계: Stage 사이클 + 표현 사이클

### 6단계: 심화 및 재도전

## 4. RPB · RPF — Role-Play (4-1 Phase 1) ✦ v1.2 재정의 (구 RPL 분리)

> ⚠️ **v1.2 — 구 RPL이 RPB(Role-Play Basic, 정형)·RPF(Role-Play Free, 자유 확장) 2모듈로 분리**. 아래 시나리오는 두 모듈 공통이며, RPB는 표준 대화문 턴(레벨별 6~12턴)을 정형 진행, RPF는 자유 확장(재도전 없음)한다. 캐릭터는 Sarah·Mike·Emma·David.

AI 원어민 캐릭터(Sarah·Mike·Emma·David)와 시나리오 기반 대화를 진행하며 LRN 학습 표현을 미션으로 사용. **Always-On 자동 인식 대신 PTT(Push-to-Talk) 방식** — 학습자가 명시적으로 마이크를 누르고 있을 때만 인식되어 학습 흐름 통제권 확보.

### 0단계: 데이터 준비

- **시나리오 구성**: 4~6턴 대화 사전 설계 (비즈니스 미팅·면접·여행 등)

- **PTT 동작 사양**:
  - 마이크 버튼 **누르고 있는 동안만 녹음** (떼면 즉시 인식 종료)
  - 짧은 발화·생각 시간 허용
  - 무발화 자동 종료 없음 (PTT 특성)
- **한국어 안전망**: 1회 한국어 발화 가능 → AI가 영어로 풀어줌

### 0단계: 데이터 준비

- **대화 시간**: 초급 비활성 / 중급 1~2분 / 고급 3~5분
- **발화량 챌린지 미터**: 7일 평균 + 오늘 목표 사전 계산
- **멘트 사전 생성**: M01~M07 변형

### 레벨별 매트릭스

| CEFR | 활성화 | 첫 질문 유형 | 제한 시간 | 무발화 힌트 (자동) |
|---|---|---|---|---|
| Pre-A1 ~ A1 | ✗ 자동 비활성 | — | — | — |
| A2 | △ 보조 | Closed | 1분 | 문장 완성형 |
| B1 | ✓ | Semi-open | 1~2분 | 부드러운 리프레이즈 |
| B2 | ✓ | Open-ended | 2분 | AI 리프레이즈 |
| C1 / C2 | ✓ | 의견 충돌·전략 | 3~5분 | 없음 |

### 1단계: 수업 시작
- **상단**: 발화량 챌린지 미터 ("지난 7일 28문장 → 오늘 목표 30문장")
- **중간**: 모드 토글 (Chatting / Audio Only) + 대화 흐름 영역
- **하단**: PTT 마이크 + \[💡 힌트\] + \[종료\]
- M01_INTRO: *피클: "이번엔 자유 대화\! 미션 없어요. 평소보다 더 많이 말해보는 게 목표\! 💬"*

### 2단계: AI 첫 질문 + 대화 시작
- AI 첫 질문 발화 + TTS 재생
- PTT 마이크 활성화
- 챌린지 미터 실시간 작동

### 3단계: 힌트 (사용자 요청 시 + 무발화 자동 트리거)
- **사용자 요청**: \[💡 힌트\] 클릭 → M02_HINT
- **자동 트리거** (FRT 특수): 5초 화이트노이즈 → 자동 빈 말풍선 + M03_NOSPEECH
  - 초급: "I'd stay or I'd not stay'로 시작해봐요. 천천히 한 마디부터\! 💪"
  - 중급: AI 리프레이즈
  - 고급: 자율 응답 유도 (개입 없음)

### 4단계: 답안 수행
- AI 원어민이 발화에 반응 + 후속 질문 ("Tell me more about it.")
- 챌린지 미터 실시간 채워짐

### 5단계: 피드백 확인 (실시간 + 종합)
- **초·중급 (실시간 바이링구얼 교정)**:
  - 문법·단어·표현·발음 즉시 교정
  - M04_LIVE_CORRECT: *"가정법 써봐요\! → 'I'd stay, but I would feel...' 🌐"*
- **고급 (메타 피드백)**:
  - 서브 코멘트 패널 + 논리·반론 대안
- **Feedback Review 패널**: 누적 표시

### 5-A단계: 챌린지 도달
- 챌린지 30문장 도달 시 M05_CHALLENGE_HIT — *피클: "🎉 오늘 목표 달성\! 30문장 돌파\!"*

### 6단계: 심화 및 재도전
- 발화량 미달 시 AI 추가 질문으로 대화 연장

### 7단계: 학습 완료
- AI 마무리: "Time's up\! Great conversation. I'll send a summary\!"
- M06_OUTRO: *피클: "오늘 {{N}}문장\! 평소보다 +{{Diff}}문장 더 말했어요\! 🎊"*

## 6. OMP — One Minute Presentation (4-3 Phase 3) ✦ v0.15 코드 변경 (OMS → OMP)

LRN 콘텐츠 기반 30초 준비 + 1분 발표 + 종합 피드백. OPIc·토익S 답변 형식과 일치하는 픽클래스 시그니처 시험 대비 모듈. B1 이상 활성화.

### 0단계: 데이터 준비

- **지문 매핑**: LRN 콘텐츠 자동 연동 발표 주제
- **메모 템플릿 6항목**:
  1. The topic is about ___
  2. It mainly says that ___
  3. In my opinion ___
  4. I agree / disagree because ___
  5. For example ___
  6. So overall, I think ___
- **타이머**: 30초 준비 + 60초 발화 + 1.5분 피드백
- **5영역 평가** (5대 KPI 매핑): 발음정확도·유창성·문법정확성·화용성·발화량
- **레벨 차등**: A1~A2 자동 비활성
- **멘트 사전 생성**: M01~M09 변형

### 레벨별 매트릭스

| CEFR | 활성화 | 주제 유형 | 메모 가이드 | 피드백 |
|---|---|---|---|---|
| Pre-A1 ~ A1 | ✗ 자동 비활성 | — | — | — |
| A2 | △ 보조 | 일상·기초 의견 | 항목별 단계 안내 | 격려 중심 |
| B1 | ✓ | 의견 + 근거 | 근거 제시 가이드 | 구조 완성도 |
| B2 | ✓ | 사회·업무 이슈 | 반론 가이드 | 논리 전개 |
| C1 / C2 | ✓ | 추상·정책·전략 | 담화 표지 | 수사·구조 |

### 1단계: 수업 시작
- **상단**: 진도 (4단계 + Phase 3) + 30초 카운트다운 타이머
- **중간**: 발표 주제 카드 (HERO) + 핵심 키워드 칩 + Intro-Body-Conclusion 3단 구조 가이드
- **하단**: \[준비 완료, 시작 →\] + \[스킵\] + \[💡 힌트\]
- M01_INTRO: *피클: "1분 발표 시작\! 30초 메모 정리부터\! ⏱"*

### 2단계: 메모 작성 (30초)
- 발표 주제 + 한국어 보조
- 핵심 키워드 칩 3~5개 (LRN 표현 자동 매핑)
- Intro 10초 / Body 35초 / Conclusion 15초 시각 비율
- 30초 카운트다운 (마지막 5초 색 변화 + 햅틱)
- 조기 시작 가능 + 스킵 옵션

### 3단계: 힌트 (사용자 요청 시)
- **트리거**: \[💡 힌트\] 클릭
- M02_HINT: *피클: "메모 어렵나요? 'The topic is about ~'부터 천천히\! 💪"*
- 메모 항목별 시작 표현 가이드

### 4단계: 답안 수행 (1분 발화 / PTT 변형)
- \[Speak\] 클릭 → 60초 타이머 시작 (1회 클릭으로 시작, 60초 후 자동 종료 — OMP는 PTT보다 시간 제어가 중요해 변형 적용)
- **상단 통합 미터 바**: 시간 카운트 + 발화량 누적 + 누적 5축 미니 점수
- **구조 진행 인디케이터**: Intro→Body→Conclusion 자동 강조 (30초 Body, 50초 Conclusion)
- **30초 마무리 토스트**: M03_30SEC_WARN — *"🎯 마무리 준비\! (30초 경과)"* + 햅틱
- **50초 결론 토스트**: M04_50SEC_WARN — *"🏁 결론 시작\!"*
- 60초 자동 종료
- **조기 종료 정책**: 30초 이전 \[마무리\] 클릭 시 "발표가 짧아요. 계속하시겠어요?" 모달

### 5단계: 종합 피드백 (1.5분)
- 종합 점수 (대형 원형) + 0→실제값 카운트업
- **5영역 평가 그리드**:
  - 발음정확도 / 유창성 / 문법정확성 / **화용성 ✦** / 발화량
- 각 영역 점수 + 1줄 피드백 + 게이지
- M05_FEEDBACK_GENERAL: *피클: "{{Score}}점\! 첫 1분 발표 완성\! 더 좋은 표현은 이렇게~ 💡"*
- M06_AI_SUGGEST (AI 추천 더 좋은 발표 구조):
  - *예: "Conclusion에서 'To wrap up, ...' 마무리 표현 추가 권장"*
- \[내 발표 다시 듣기\] 옵션 (음성+텍스트 동기 재생)

### 5-A단계: (해당 없음)
OMP는 1회 발표 후 종합 피드백. 재도전은 6단계 분기 처리.

### 6단계: 심화 및 재도전
- **재도전 조건**: 5영역 평균 < 80% 또는 메모 항목 4개 이하 충족
- M07_RETRY: *피클: "한 번 더 도전\! 피드백 반영해서 훨씬 매끄럽게~ 🔥"*
- 분기: \[다시할게요\] (같은 주제 재발표) / \[이해했어요\]

### 7단계: 학습 완료
- M08_OUTRO: *피클: "1분 안에 또박또박\! 시험에서도 자신감 있게\! 🎊"*
- **시험 학습자 한정**: M09_TEST_PREDICT — *"이 페이스라면 OPIc IH 도달 예상\!"*
- 데이터 확정: 5영역 점수·발화량·구조 완성도·키워드 사용률
- MEASURE 자동 이동 + 1분 발표 점수 카드 누적 노출

## 통합 흐름 요약 (v1.2 — 9모듈)

```
LRN (콘텐츠 + 표현 카드 레벨별 3~5개)
  ↓
VLM (어휘 듣기·의미 확인 30초, 초·중급만) ✦ v0.15 재설계
  ↓
SHD → SFB → SMK (정밀 드릴 3모듈, 따라말→채워말→만들어말) ✦ v1.2 EDR 분리
  ↓ (시퀀싱 분기, 사용자 노출 없음)
RPB → RPF (롤플레이 2모듈, 정형→자유, PTT) ✦ v1.2 RPL 분리
  ↓ (시퀀싱 분기)
FRT (자유 대화, B1+ 활성)
  또는 OMP (1분 발표, B1+ 시험·면접)
  ↓
MEASURE (5축 + 1MP 점수 결산)
```

**공통 적용**: 모바일 상단/중간/하단 3분할 · 힌트 버튼 사용자 요청형 · 멘트 사전 생성 저장 · 모든 단계에서 피클 Agent의 일관된 친근한 존댓말과 격려 톤.
