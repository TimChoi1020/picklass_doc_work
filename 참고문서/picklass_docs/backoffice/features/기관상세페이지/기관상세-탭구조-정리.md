## 1. 변경 배경

`/admin/institute/[id]` 상세 페이지와 `/admin/institute/[id]/settings` 독립 페이지가 병존하여 수업설정 구현이 두 곳으로 분산된 상태였다.

| 항목 | `[id]/page.tsx` SettingsTab | `[id]/settings/page.tsx` |
|------|----------------------------|--------------------------|
| API 연동 | ✅ 실제 연동 | ❌ Mock 데이터 |
| 이수조건 UX | 체크 해제 시 input 숨김 | 항상 표시 + dim 처리 |
| 나만의수업 | 단순 체크박스 | 토글 스위치 |
| 마이크 모드 | 가로 체크박스 나열 | 카드 형식 + 설명 |
| 저장 액션 | 저장만 | 저장 + 초기화 |

`settings/page.tsx`의 UI가 기획(§2-7-3)에 더 부합하나 API 미연동 상태였고, `[id]/page.tsx`는 API는 연동됐으나 UI가 단순했다.

## 2. 변경 사항

### 2-1. 탭 구조 단순화

#### 변경 전

| 조직 type | 탭 |
|-----------|-----|
| partner | 기본정보 · 산하조직 · 관리자계정 |
| group | 기본정보 · 산하조직 · 관리자계정 |
| institution | 기본정보 · 관리자계정 · 수업설정 |

#### 변경 후

| 조직 type | 탭 |
|-----------|-----|
| partner | 기본정보 |
| group | 기본정보 |
| institution | 기본정보 · 수업설정 |

> partner·group의 산하조직·관리자계정 탭, institution의 관리자계정 탭 제거.
> 기획 §4 원안의 institution [과정(N)·강사(N)·학습자(N)] 탭은 미구현 상태로 유지(추후 과제).

### 2-2. SettingsTab UI 교체

`settings/page.tsx`의 UI를 `[id]/page.tsx`의 `SettingsTab` 컴포넌트에 이식하고 API 연동 로직은 기존 것을 유지.

**교체된 UI 항목:**

| 항목 | 변경 전 | 변경 후 |
|------|--------|--------|
| 섹션 구분 | 없음 | "과정 운영 설정" / "FRT 모듈 설정" 카테고리 구분선 |
| 섹션 설명 | 없음 | 각 섹션 h3 아래 설명 문구 |
| 이수조건 | 체크 해제 시 input 숨김 | 항상 표시 + 체크 해제 시 dim 처리 (카드 형식) |
| 나만의수업 | 체크박스 | 토글 스위치 + 설명 텍스트 |
| 마이크 모드 | 가로 체크박스 나열 | 카드 형식 (desc 포함, 최소 1개 강제) |
| 저장 버튼 | 저장만 | 저장 + 초기화 버튼 쌍 |

**초기화 동작**: API에서 불러온 원본값(`original` state)으로 되돌림.

### 2-3. settings/page.tsx 삭제

`/admin/institute/[id]/settings` 독립 페이지 삭제. 수업설정은 `[id]/page.tsx`의 탭으로만 접근.

### 2-4. 목록 페이지 "수업설정" 버튼 경로 수정

목록(`/admin/institute`)의 institution 행에 있는 "수업설정" 버튼 경로 수정.

```
변경 전: /admin/institute/${id}/settings
변경 후: /admin/institute/${id}?tab=수업설정
```

`[id]/page.tsx`에서 `useSearchParams`로 `?tab=` 파라미터를 읽어 초기 활성 탭으로 설정.

## 3. 수업설정 탭 상세 (구현 기준)

> 기관 type이 `institution`인 경우에만 노출.

### 섹션 구성

**카테고리: 과정 운영 설정**

| 섹션 | 필드 | 입력 방식 | API 필드 |
|------|------|----------|---------|
| 1. 전체 수업 최대시간 | 회차별 최대 수업 시간 | select 프리셋: 무제한 / 5·10·…·50분 | `maxTotalClassMinutes` |
| 2. 이수조건 기본값 | 발화량 | 체크박스 + 숫자 입력 (문장 수) | `defaultCompletionSentences` |
| 2. 이수조건 기본값 | 레슨이수율 | 체크박스 + 숫자 입력 (%, 0~100) | `defaultCompletionLessonRate` |
| 2. 이수조건 기본값 | 누적 수업시간 | 체크박스 + 숫자 입력 (분) | `defaultCompletionMinutes` |
| 3. 나만의수업 | 자유학습 허용 | 토글 스위치 | `freeLearningEnabled` |

**카테고리: FRT 모듈 설정**

| 섹션 | 필드 | 입력 방식 | API 필드 |
|------|------|----------|---------|
| 4. FRT 모듈 최대시간 | FRT 최대 시간 | select 프리셋: 무제한 / 5·10·…·30분 | `maxFrtModuleMinutes` |
| 5. 허용 마이크 모드 | Push to talk / Hybrid / Always on | 카드형 체크박스 (최소 1개 필수) | `allowedMicModes` |
| 5. 허용 마이크 모드 | 학습자 변경 허용 | 체크박스 | `micModeUserChange` |

### 이수조건 UX 규칙
- 체크 해제 시 input이 dim 처리되고 값은 유지됨 (숨기지 않음)
- 저장 시 체크 해제된 조건은 `null`로 전송 → DB에서 해당 조건 미적용
- 체크된 조건만 AND로 적용

### 마이크 모드 제약
- 마지막 남은 1개는 체크 해제 불가 (disabled + opacity 0.6)
- 저장 전 `allowedModes.length === 0` 검증 (client-side guard)

## 4. API

```
GET /institutions/:id/settings   → 수업설정 조회 (탭 진입 시 자동 호출)
PUT /institutions/:id/settings   → 수업설정 저장
```

응답/요청 타입: `InstitutionSettingsResponse` / `UpdateInstitutionSettingsDto` (`@repo/types`)
