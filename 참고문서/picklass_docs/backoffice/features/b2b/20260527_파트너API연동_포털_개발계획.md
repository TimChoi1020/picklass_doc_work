## 0. 개요

### 배경

B2B 파트너 연동에서 파트너 담당자(`partner_admin`)가 아래 작업을 하기 위한 화면이 없었다:
- 자신이 구현해야 할 API 스펙 확인
- 현재 연동 설정(엔드포인트 URL) 조회
- 연동 상태 파악

기존에는 모든 B2B 관련 메뉴가 `system_admin` 전용이었으며, 파트너 담당자는 픽클래스 담당자에게 개별 문의해야 했다.

### 목표

> **파트너 담당자가 백오피스에 로그인하여 API 스펙과 연동 현황을 자립적으로 확인할 수 있게 한다.**

- `partner_admin` 로그인 후 API 스펙 문서 확인 가능
- 자신의 엔드포인트 설정 현황 조회 가능
- `system_admin`은 동일 메뉴에서 전체 파트너 관리

### Phase F-4 통합

`20260526_B2B파트너_외부API_연동_개발계획.md` Phase F-4에서 계획된  
`시스템 > API 설정` (`/admin/b2b/api-configs`)을 본 포털의  
`파트너 API 연동 > 내 연동 설정` (`/admin/partner/settings`)으로 통합한다.

## 3. 페이지 설계

### 3-1. API 연동 가이드 `/admin/partner/api-guide`

**목적**: 파트너가 구현해야 하는 API 스펙을 확인하고, 현재 연동 현황을 한눈에 파악한다.

#### 구성 요소

**[A] 내 연동 현황 카드**

- `partner_admin`: 자기 기관 자동 표시
- `system_admin`: 파트너 선택 드롭다운

| 요소 | 내용 |
|------|------|
| 기관명 | `institutions.name` |
| 로그인 페이지 URL | ✅ 설정됨 / ❌ 미설정 (`partner_api_configs.login_page_url` 유무) |
| 수강목록 API | ✅ 설정됨 / ❌ 미설정 |
| 상태 | `partner_api_configs.status_code` (active / inactive / 미설정) |

**[B] § 1. 로그인 인증 API 스펙**

픽클래스가 파트너 로그인 페이지로 학습자를 redirect한다. 파트너가 자체 인증 후 서명된 토큰을 callback으로 전달한다. **픽클래스는 비밀번호를 수신하지 않는다.**

- Step 1·Step 2 흐름 설명
- signed JWT payload 예시 코드 블록 + [복사] 버튼
- 안내 문구

```
┌─ Step 1. 파트너 로그인 페이지 진입 (픽클래스 → 파트너) ────────────────────┐
│  GET  {login_page_url}                                               [복사] │
│       ?callback={picklass_callback_url}                                     │
│       &institutionId={institution_uuid}                                     │
│       &state={nonce}                                                        │
└─────────────────────────────────────────────────────────────────────────────┘

  → 파트너 자체 로그인 폼을 표시. 학습자 인증 성공 시 Step 2 진행.
    인증 실패 시 파트너가 자체 오류 페이지 표시 (callback 호출 없음).

┌─ Step 2. 인증 완료 후 callback redirect (파트너 → 픽클래스) ───────────────┐
│  GET  {picklass_callback_url}?token={signed_jwt}&state={nonce}              │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ signed JWT payload (auth_secret으로 HS256 서명) ──────────────────────────┐
│  {                                                                   [복사] │
│    "institutionId": "inst-uuid-001",                                        │
│    "user_pk_id": "partner-internal-pk-001",                                 │
│    "userId": "partner_user_001",                                            │
│    "exp": 1716883500                                                        │
│  }                                                                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

> `exp`: **발급 후 5분 이내** 필수 (픽클래스가 만료 검증).  
> `auth_secret`은 픽클래스 담당자에게 발급 요청. [내 연동 설정]에서 확인 가능.

**[C] § 2. 수강목록 API 스펙**

- Endpoint 블록 + [복사] 버튼
- Response 200 예시 코드 블록 + [복사] 버튼
- 오류 코드 규격 표 (MEMBER_NOT_FOUND / NO_ENROLLMENT / INVALID_OPTIONS)
- `picklass_course_id` 사전 등록 안내

```
┌─ Endpoint ──────────────────────────────────────────────┐
│  GET  {enrollment_endpoint}?user_pk_id={user_pk_id} [복사]│
└─────────────────────────────────────────────────────────┘

┌─ Response 200 ──────────────────────────────────────────┐
│  {                                                [복사] │
│    "enrollments": [{                                    │
│      "enrollment_id": "partner-enroll-001",             │
│      "enrolled_at": "2026-01-15T09:00:00Z",             │
│      "expires_at": "2027-01-15T23:59:59Z",              │
│      "status": "active",                                │
│      "course_scope": "SPECIFIC",                        │
│      "picklass_course_ids": ["uuid-a", "uuid-b"],       │
│      "options": {                                       │
│        "course_type": "MANDATORY_COURSE",               │
│        "completion_criteria": {                         │
│          "utterance_goal": 300,                         │
│          "lesson_completion_rate": 0.8                  │
│        },                                               │
│        "free_learning_enabled": false,                  │
│        "frt": {                                         │
│          "termination_mode": "TIME",                    │
│          "termination_value": 900,                      │
│          "mic_mode": "PTT"                              │
│        }                                                │
│      }                                                  │
│    }]                                                   │
│  }                                                      │
└─────────────────────────────────────────────────────────┘
```

> `course_scope`: `SPECIFIC`(지정 과정) 또는 `ALL`(픽클래스 전체 과정). `ALL`이면 `picklass_course_ids`는 빈 배열.  
> `picklass_course_ids`: 파트너는 픽클래스로부터 사전에 과정 UUID를 전달받아 자체 시스템에 보관해야 한다.  
> `options.frt.termination_value`: 종료 조건 수치 — `TIME`이면 초(sec), `TOKEN`이면 개수.  
> `options.frt`: 해당 수강의 전체 FRT 모듈에 일괄 적용. `null`이면 FRT 모듈 없는 수강.  
> `options`: `null`이면 픽클래스 기본 설정 적용.

**[D] § 3. 이수 완료 Push**

수강신청 이수 조건 충족 시 픽클래스가 자동으로 호출한다. 파트너가 수신 엔드포인트를 구현한다.

- Endpoint + Request Body 코드 블록 + [복사] 버튼
- 오류 코드 규격 표 (ENROLLMENT_NOT_FOUND / ALREADY_COMPLETED)
- 안내 문구

```
┌─ Endpoint ──────────────────────────────────────────────────┐
│  POST  {partner_completion_endpoint}                 [복사] │
│  Content-Type: application/json                             │
│  Authorization: Bearer {api_key}  ← 요구하는 경우만         │
└─────────────────────────────────────────────────────────────┘

┌─ Request Body ──────────────────────────────────────────────┐
│  {                                                   [복사] │
│    "institutionId": "inst-uuid-001",                        │
│    "userPkId": "partner-internal-pk-001",                   │
│    "userId": "partner_user_001",                            │
│    "enrollmentId": "partner-enroll-001",                    │
│    "completedAt": "2026-05-28T10:00:00Z",                   │
│    "achievement": {                                         │
│      "utteranceCount": 350,                                 │
│      "lessonCompletionRate": 0.9                            │
│    }                                                        │
│  }                                                          │
└─────────────────────────────────────────────────────────────┘
```

> `completion_endpoint` 미설정 기관은 Push 생략.  
> Push 실패 시 1회 재시도. 실패해도 학습 흐름에 영향 없음 (비동기 처리).

**[E] § 4. 이전 학습내역 API**

이전 학습내역 화면 진입 시 픽클래스가 호출한다. 파트너가 구현한다.

- Endpoint + Response 예시 코드 블록 + [복사] 버튼
- 오류 코드 규격 표 (MEMBER_NOT_FOUND / NO_HISTORY)
- 안내 문구

```
┌─ Endpoint ──────────────────────────────────────────────────┐
│  GET  {history_endpoint}                             [복사] │
│       ?user_pk_id={user_pk_id}&page=1&limit=20              │
│  Authorization: Bearer {api_key}  ← 요구하는 경우만         │
└─────────────────────────────────────────────────────────────┘

┌─ Response 200 ──────────────────────────────────────────────┐
│  {                                                   [복사] │
│    "total": 12, "page": 1, "limit": 20,                     │
│    "history": [{                                            │
│      "enrollment_id": "partner-enrollment-001",             │
│      "enrolled_at": "2025-01-01T00:00:00Z",                 │
│      "completed_at": "2025-03-31T00:00:00Z",                │
│      "status": "completed",                                 │
│      "course_scope": "SPECIFIC",                            │
│      "picklass_course_ids": ["uuid-a"],                     │
│      "options": { ... }                                     │
│    }]                                                       │
│  }                                                          │
└─────────────────────────────────────────────────────────────┘
```

> `history_endpoint` 미설정 기관은 해당 기능 비활성.  
> `status`: `completed` (이수 완료) | `expired` (기간 만료).

**[F] § 5. 학습결과 조회 API (픽클래스 제공)**

픽클래스가 제공하는 API. 파트너가 호출하여 학습자 학습결과를 수집한다.

```
┌─ Base URL ──────────────────────────────────────────────┐
│  https://api.picklass.com                          [복사] │
└─────────────────────────────────────────────────────────┘

┌─ KPI 1. 기간별 학습현황 ────────────────────────────────┐
│  GET  /b2b/reports/learning-status                [복사] │
│  Authorization: Bearer {API_KEY}                        │
└─────────────────────────────────────────────────────────┘

┌─ KPI 2. 기간별 학습결과(수업KPI) ──────────────────────┐
│  GET  /b2b/reports/class-kpi                      [복사] │
│  Authorization: Bearer {API_KEY}                        │
└─────────────────────────────────────────────────────────┘

┌─ KPI 3. 기간별 학습 성과(레벨테스트) ──────────────────┐
│  GET  /b2b/reports/level-test                     [복사] │
│  Authorization: Bearer {API_KEY}                        │
└─────────────────────────────────────────────────────────┘

공통 Query 파라미터
┌──────────────────────────┬──────┬──────────────────────────────┐
│ 파라미터                 │ 필수 │ 설명                          │
├──────────────────────────┼──────┼──────────────────────────────┤
│ startDate                │  ✅  │ 기간 시작일 (ISO 8601)        │
│ endDate                  │  ✅  │ 기간 종료일 (ISO 8601)        │
│ userId                   │ 선택 │ 특정 회원 필터 (파트너 로그인 ID) │
│ courseId                 │ 선택 │ 과정 필터 (UUID)              │
└──────────────────────────┴──────┴──────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│  ℹ️ API Key는 픽클래스 담당자에게 발급 요청하세요.          │
│  발급된 Key는 [내 연동 설정]에서 확인할 수 있습니다.        │
└─────────────────────────────────────────────────────────┘
```

> **응답 예시 및 상세 스펙**: [B2B파트너_외부API_연동_개발계획](./20260526_B2B파트너_외부API_연동_개발계획.md) §3-5
