## 0. 개요

B2B 파트너 회원은 픽클래스 내부 사용자와 별도로 관리된다.  
파트너 시스템이 회원 데이터의 원천(source of truth)이며, 픽클래스는 로그인 이력(`partner_auth_logs`)만 기록한다. `users` 레코드는 생성하지 않는다.

> 로그인 흐름·DB DDL·파트너 API 스펙은  
> [B2B파트너_외부API_연동_개발계획](../b2b/20260526_B2B파트너_외부API_연동_개발계획.md) §1·§2·§3 참조.

## 1. 사용자 유형 비교

| 항목 | 픽클래스 내부 사용자 | B2B 파트너 회원 |
|------|-------------------|----------------|
| 등록 방식 | 백오피스 수동 등록 | 로그인 시 파트너 인증 API 호출 → `partner_auth_logs`에 이력 기록 |
| 관리 주체 | 픽클래스 운영팀 | 파트너사 (픽클래스는 로그 조회만) |
| userId 범위 | 전역 유일 | 기관(institution) 내 유일 |
| 로그인 방식 | 로컬 DB 인증 | 파트너 인증 API 호출 |
| 로그인 키 | userId 단독 | institution_code + userId 복합 |
| DB 저장 | `users` 레코드 생성 | `partner_auth_logs` 기록만 (users 레코드 없음) |
| 백오피스 조작 | 등록·수정·삭제 | 조회 전용 (로그 기반) |
| 메뉴 위치 | `/admin/users` | `/admin/b2b/members` |

## 2. 백오피스 회원관리 UI

### 2-1. 위치 및 접근 권한

| 경로 | `system_admin` | `partner_admin` | 데이터 범위 |
|------|:--------------:|:---------------:|------------|
| `/admin/b2b/members` | ✅ | ❌ | system_admin 전용 |

> `partner_auth_logs`는 API 호출 이력 전체를 담으므로 파트너사에 노출하지 않는다.

### 2-2. 검색 필터

```
파트너(기관) | 파트너 회원 ID (userId) | 파트너 내부 PK (partnerMemberId)
```

- `system_admin` 전용 — `partner_admin` 접근 불가
- 이름·이메일 등 개인정보 필터 없음 (`partner_auth_logs`에 미저장)

### 2-3. 테이블 컬럼

> `partner_auth_logs`에서 `(institution_id, user_id)` 기준 그룹화하여 표시.

| 컬럼 | 내용 |
|------|------|
| No. | 일련번호 |
| 파트너명 | 소속 기관명 (`institutions` 조인) |
| 파트너 회원 ID | `partner_auth_logs.user_id` |
| 파트너 내부 PK | `partner_member_id` (최근 성공 로그인의 값) |
| 마지막 로그인 | `MAX(created_at) WHERE success=true` |
| 로그인 시도 수 | `COUNT(*)` |
| 마지막 결과 | 성공 / 실패 |

### 2-4. 허용 조작

| 조작 | 허용 여부 | 비고 |
|------|:--------:|------|
| 조회 | ✅ | 로그인 이력 기반 데이터 열람 |
| 등록 | ❌ | 로그인 시 자동 생성 |
| 수정 | ❌ | 파트너 시스템이 관리 주체 |
| 삭제 (물리) | ❌ | 로그인 이력 보존 필요 |
| 비활성화 | ❌ | 파트너 시스템에서 관리 |
| 비밀번호 초기화 | ❌ | 픽클래스에 비밀번호 미저장 — 파트너사 처리 |

## 3. API 설계

```
GET /b2b/members
  Query:    institutionId?, userId?, partnerMemberId?, page, limit
  Response: B2bMemberListResponse  (§4 참조)
```

---

## 4. packages/types

```typescript
export interface B2bMemberResponse {
  institutionId: string;
  institutionName: string;
  userId: string;              // 파트너 회원 ID (partner_auth_logs.user_id)
  partnerMemberId: string | null;  // 최근 성공 로그인의 memberId
  loginCount: number;          // 총 로그인 시도 수
  lastLoginAt: string | null;  // 마지막 성공 로그인 일시
  lastResult: 'success' | 'failure';
}

export interface B2bMemberListResponse {
  data: B2bMemberResponse[];
  pagination: {
    page: number;
    limit: number;
    total: number;
    totalPages: number;
  };
}

export interface B2bMemberQueryDto extends PaginationQuery {
  institutionId?: string;
  userId?: string;             // 파트너 회원 ID 검색
  partnerMemberId?: string;
}
```

## 6. 의도적 제외

| 항목 | 이유 |
|------|------|
| `users` 테이블 B2B 회원 레코드 생성 | 픽클래스가 파트너 회원 데이터 미소유 — `partner_auth_logs`에 로그만 기록 |
| 회원 상세 조회 (`/b2b/members/:id`) | 목록 조회만으로 충분, 상세 페이지 불필요 |
| 이메일 등 개인정보 표시 | 개인정보 수집 불필요 정책 (`partner_auth_logs`에 미저장) |
| 비밀번호 초기화 | 픽클래스에 비밀번호 미저장 — 파트너사 자체 처리 |
