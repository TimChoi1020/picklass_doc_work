# 기관관리 Billing 페이지 (billing.html)  

## 개요
Pickclass 관리자가 등록된 기관의 구독 현황, 요금제, 계약 정보를 관리하고 청구 현황을 파악할 수 있는 중앙 집중식 관리 페이지입니다.

---

## 사용자 흐름 (User Flow)

### 1. 대시보드 조회 흐름
```
관리자 접속 
  ↓
기관관리 Billing 페이지 로드
  ↓
상단 통계 자동 표시
  - 요금제별 가입 현황 (실시간 집계)
  - 월간 매출액 추이 (최근 3개월)
  ↓
기관 구독 플랜 현황 테이블 로드
  - 전체 기관 목록 표시 (최대 5개/페이지)
```

### 2. 기관 검색 흐름
```
관리자 
  ↓
검색 필터 입력 (기관명/요금제/상태)
  ↓
검색 버튼 클릭
  ↓
조건에 맞는 기관만 테이블에서 필터링
  ↓
페이지 1에서 다시 시작
  ↓
결과 없음 → "검색 결과가 없습니다" 메시지 표시
```

### 3. 기관 등록 흐름
```
관리자 → "+ 기관 등록" 버튼 클릭
  ↓
기관 등록 모달 열기
  - 모달 제목: "기관 등록"
  - 버튼: "등록"
  - 폼: 초기화된 상태
  ↓
1단계: 가입정보 입력
  - 기관명, 유형, 담당자, 연락처 등
  ↓
2단계: 부가정보 입력
  - 지점 수, 운영 형태, 현재 수강생 규모
  ↓
3단계: 라이선스 & 요금제 입력
  - 플랜 선택 → 학생당 단가 자동 계산
  - 학생 수/계정 수/청구주기 등 입력
  ↓
3단계: 라이선스 & 요금제 입력
  - 플랜 선택 → 학생당 단가 자동 계산
  - 학생 수/계정 수/청구주기 등 입력
  ↓
4단계: 계약 기본 정보 입력
  - 계약 상태, 시작/종료일, 자동갱신 등
  ↓
"등록" 버튼 클릭
  ↓
성공 메시지 표시 → 모달 자동 닫기
```

### 4. 기관 정보 수정 흐름
```
관리자 → 테이블에서 기관 행의 "수정" 버튼 클릭
  ↓
기관 수정 모달 열기
  - 모달 제목: "기관 수정"
  - 버튼: "저장"
  - 폼: 해당 기관의 모든 정보 사전 입력
  ↓
기관 정보 수정
  - 4개 섹션(가입정보/부가정보/라이선스/계약정보) 모두 수정 가능
  ↓
"저장" 버튼 클릭
  ↓
성공 메시지 표시 → 모달 자동 닫기
```

### 5. 미납 기관 처리 흐름
```
관리자 → 테이블에서 "미납" 상태 확인
  ↓
해당 기관의 "미납해결" 버튼 클릭
  ↓
기관 수정 모달 열기 (미납 기관 정보 사전 입력)
  ↓
계약 상태 변경 또는 기타 정보 업데이트
  ↓
"저장" 버튼 클릭
  ↓
성공 메시지 표시 → 모달 자동 닫기
```

### 6. 페이지네이션 흐름
```
관리자 → 검색 필터 미적용 상태에서 테이블 확인
  ↓
기관이 5개 이상인 경우
  ↓
하단 페이징 버튼 표시 (페이지 1/1 또는 1/N)
  ↓
"다음" 버튼 클릭 → 다음 5개 행 표시
  ↓
"이전" 버튼 클릭 → 이전 페이지로 이동
```

## 기능 정의 (IA)

### F1. 통계 대시보드 보기

| 항목 | 내용 |
|------|------|
| **목적** | 요금제별 현황과 월간 매출 추이를 한눈에 파악 |
| **입력** | 없음 (자동 로드) |
| **출력** | 요금제별 가입 현황, 월간 매출액 추이 테이블 |
| **조건** | 페이지 로드 시 자동 집계 |
| **트리거** | 페이지 초기 로드 |

**상세:**
- 요금제별 가입 현황: Lite/Pro/Enterprise별 기관 수 및 월간 수익 표시
- 월간 매출액 추이: 최근 3개월 데이터 표시

---

### F2. 기관 목록 조회

| 항목 | 내용 |
|------|------|
| **목적** | 등록된 모든 기관의 구독 정보를 테이블 형식으로 제공 |
| **입력** | 없음 (페이지 로드 시 전체 조회) |
| **출력** | 기관명, 요금제, 단가, 사용자, 최대허용수, 기간, 상태, 작업 |
| **조건** | 한 페이지당 최대 5개 행 표시 |
| **트리거** | 페이지 로드 또는 검색/수정 후 갱신 |

**상세:**
- 테이블 컬럼: 기관명 / 요금제 / 단가(인) / 사용자 / 최대허용수 / 시작일~종료일 / 상태 / 작업
- 상태 표시: 활성화(초록색), 미납(빨간색)
- 각 행에는 "수정" 또는 "미납해결" 버튼 포함

---

### F3. 기관 검색/필터

| 항목 | 내용 |
|------|------|
| **목적** | 특정 조건에 맞는 기관만 필터링하여 표시 |
| **입력** | 기관명(텍스트), 요금제(선택), 상태(선택) |
| **출력** | 조건에 일치하는 기관 목록 |
| **조건** | 3개 조건을 모두 만족하는 기관만 표시 (AND 로직) |
| **트리거** | "검색" 버튼 클릭 |

**필터 옵션:**
- 기관명: 부분 일치 (텍스트 입력)
- 요금제: 정확 일치 (전체/Lite/Pro/Enterprise/Starter)
- 상태: 정확 일치 (전체/활성화/미납)

**결과:**
- 일치 결과 있음 → 필터링된 목록 표시
- 일치 결과 없음 → "검색 결과가 없습니다" 메시지 표시

- 기관명, 기관 유형, 담당자, 연락처, 운영형태, 수강생 규모

## 정책 (Policy/Business Rules)

### B1. 요금제 정책

**기본 원칙:**
- 모든 기관은 하나의 플랜에만 가입 가능
- 플랜 변경은 수정 기능으로만 가능 (재등록 불가)

**플랜 종류:**
- **Lite 플랜**: 월 10만원 기본료, 학생당 1.2만원
- **Pro 플랜**: 월 100만원 기본료, 학생당 0.8~1.2만원 (구간 할인 적용)
- **Enterprise 플랜**: 제휴/맞춤형 가격, 협상 필요
- **제휴 플랜**: 협의 중

**API 연동비:**
- Pro 플랜만 추가 가능
- 일회성 비용 (월마다 반복 과금되지 않음)

**플랜 관리:**
- 요금제는 시스템관리의 플랜관리(코드관리)에서 중앙집중식으로 관리
- 제품의 변경사항을 즉각 반영하여 실시간 업데이트 가능
- 기존 결제 완료된 기관에게는 영향을 미치지 않음 (역사적 가격 유지)
- 기관 등록 시 3단계(라이선스 & 요금제) 화면에 플랜관리의 코드 내용을 기본값으로 표시

---

### B2. 계약 정책

**계약 상태:**
- **협의중**: 아직 최종 승인되지 않은 상태
- **계약완료**: 계약서 서명 완료, 아직 서비스 미개시
- **활성**: 서비스 개시 상태, 청구 대상
- **만료**: 계약 종료일 도래
- **해지**: 계약 중도 해지

**자동갱신 정책:**
- Y(갱신): 계약 종료일 도래 시 자동 연장
- N(미갱신): 계약 종료일에서 자동 종료
- 갱신 조건: 특수한 갱신 규칙 기재

**계약 기간:**
- 최소: 1개월
- 최대: 제한 없음
- 갱신: 1년 단위 권장

---

### B3. 청구 정책

**청구 주기:**
- **월납**: 매월 청구 (기본값)
- **연납**: 연 1회 청구

**연납 할인:**
- 선택적 입력 (기관당 상이할 수 있음)
- 0~100% 범위 내
- 기획 합의 후에만 적용

**추가 비용:**
- 기술지원비: 부가서비스 비용
- IP 전환비: 기존 교재 → AI 모듈화 시 일회성 비용
- API 연동비: Pro 플랜 일회성 비용

---

### B4. 기관 정보 정책

**필수 정보:**
- 기관명, 기관 유형: 시스템에서 기관을 식별하기 위한 핵심 정보
- 담당자 및 연락처: 계약 관련 의사소통을 위한 필수 정보
- 운영형태: 직영/가맹 구분으로 지원 정책 결정

**지점 수:**
- 직영: 회사가 직접 운영하는 지점 수
- 가맹: 가맹점 개수 (기관 내부 관리)
- 행정 목적: 고객 유형 파악, 확장성 평가

**수강생 규모:**
- 현재: 현 시점의 실제 학생 수
- 최대 허용: 계약상 허용되는 최대 학생 수
- 청구 기준: 현재 수강생을 기본 청구 인원으로 산정
- 관리계정수: 기관에서 사용 가능한 관리자 계정 수

---

### B5. 검색 정책

**검색 방식:**
- 기관명: 부분 문자열 일치 (대소문자 구분 안 함)
- 요금제: 정확한 선택지만 일치 (선택지 외 불가)
- 상태: 정확한 선택지만 일치

**검색 로직:**
- AND 조건: 입력된 모든 조건을 만족하는 기관만 표시
- 빈 필드: 해당 조건은 무시 (필터링 안 함)
- 예: 기관명 입력 + 상태 선택 → 기관명 일치 AND 상태 일치하는 기관만 표시

**검색 범위:**
- 현재 로드된 모든 기관 데이터에서 검색
- 검색 결과는 페이지 1부터 시작

---

### B6. 데이터 검증 정책

**필수 필드 검증:**
- 필수 필드는 비워둘 수 없음
- 양식 제출 전 필수 필드 모두 입력 필수

**데이터 형식 검증:**
- 기관명: 1자 이상 텍스트
- 연락처: 010-0000-0000 형식 권장
- 날짜: YYYY-MM-DD 형식
- 숫자: 0 이상 정수만 허용

**중복 검증:**
- 기관명 중복: 시스템에서 처리 (동명 기관 가능하나, 담당자 연락처로 구분)
- 계약 중복: 한 기관은 동시에 여러 계약 불가

---

### B7. 상태 표시 정책

**통계 표시:**
- 요금제별: 현재 활성화된 기관만 카운트
- 매출액: 청구 완료된 기관만 포함 (미납 제외 권장)

**테이블 상태 표시:**
- 활성화: 계약 상태가 "활성"인 기관
- 미납: 청구되었으나 결제되지 않은 상태

---

### B8. 페이지네이션 정책

**기본 설정:**
- 한 페이지당 20개 행 고정
- 검색 필터 미적용 상태에서만 페이징 작동
- 검색 적용 시 페이징 비활성화

**페이지 표시:**
- 형식: "현재 페이지 / 총 페이지"
- 예: 1 / 3 (총 15개 기관, 페이지당 5개)

**버튼 활성화:**
- 첫 페이지: "이전" 버튼 비활성화
- 마지막 페이지: "다음" 버튼 비활성화
- 중간 페이지: 모든 버튼 활성화

---

### B9. 모달 정책

**열기/닫기:**
- 버튼 클릭 시 모달 열기
- "취소" 버튼 또는 X 버튼 또는 배경 클릭 시 모달 닫기
- 닫을 때 폼 데이터 자동 초기화

**폼 제출:**
- "등록" 또는 "저장" 버튼 클릭 시 데이터 제출
- 필수 필드 미입력 시 제출 불가
- 제출 후 성공 메시지 표시 및 모달 자동 닫기

**모드 전환:**
- 등록 모드: 빈 폼 제시
- 수정 모드: 기존 데이터 자동 입력, 모든 필드 수정 가능

---

### B10. 사용자 메시지 정책

**성공 메시지:**
- 기관 등록: "기관이 성공적으로 등록되었습니다."
- 기관 수정: "기관 정보가 성공적으로 수정되었습니다."

**안내 메시지:**
- 검색 결과 없음: "검색 결과가 없습니다."
- 빠른 피드백 제공으로 사용자 경험 개선

## 향후 개선 사항

1. **검색 개선** - 전체 기관 데이터에서 번개 검색 가능
2. **필터 초기화** - 검색 필터 적용 후 리셋 버튼 재추가 고려
3. **대량 작업** - 여러 기관 일괄 처리 (체크박스)
4. **내보내기** - 기관 목록 CSV/Excel 다운로드
5. **감사 로그** - 수정 내역 및 담당자 기록
6. **푸시 알림** - 미납 기관 자동 안내
7. **계약 자동갱신** - 계약 만료 자동 감지 및 갱신
