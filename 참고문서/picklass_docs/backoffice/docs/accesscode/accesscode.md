# 액세스코드 관리 시스템 (Access Code Management)

## 📋 개요
Picklass 관리 페이지의 액세스코드 관리 시스템입니다. 강사와 학생에게 발급할 접근 코드를 생성, 조회, 상태관리합니다.

**파일 경로:**
- 관리: `src/app/(admin)/admin/accesscode/page.tsx`
- 생성: `src/app/(admin)/admin/accesscode/generate/page.tsx`

**상태 정의:** src/lib/constants.ts의 ACCESS_CODE_STATUSES, ACCESS_CODE_DURATIONS 사용

**상태:** 업데이트 완료 (2026-03-14)

---

## 📊 상수 정의

### ACCESS_CODE_STATUSES (상태)
```
상태명      상태코드    설명
────────────────────────────────────
활성        active      사용 중인 유효한 접근코드
예약됨      reserved    생성됨, 아직 배포 전
사용됨      used        모든 허용량 사용 완료
만료됨      expired     유효기간 만료
```

### ACCESS_CODE_DURATIONS (유효기간)
```
기간명    코드   일수   설명
────────────────────────────────
1개월    1M    30     30일 유효
3개월    3M    90     90일 유효
6개월    6M    180    180일 유효
12개월   12M   365    365일 유효
```

**정책:** 기간 선택 시 만료일 자동 계산 (발급일 + 일수)

### 1.1 액세스코드 생성 흐름
```
관리자 → 액세스코드 생성 페이지 → 필수 정보 입력 → 생성 → 관리 페이지로 이동
         (/admin/accesscode/generate)
```

**세부 단계:**

1. **액세스코드 관리 페이지 접근**
   - URL: `/admin/accesscode`
   - 기존 액세스코드 목록 조회
   - "+ 액세스코드 생성" 버튼 우측 정렬

2. **액세스코드 생성 페이지로 이동**
   - URL: `/admin/accesscode/generate`
   - 제목: "액세스코드 생성"
   - 사용자는 필수 정보 입력

3. **필수 정보 입력**
   - 사용자 유형 선택 (강사/학생)
   - 생성할 액세스코드 개수 입력 (1-1000개)
   - 등록 만료일 선택
   - 사용 기간 선택
   - 학생 선택 시 제공할 과정 선택

4. **생성 버튼 클릭**
   - 유효성 검사 수행
   - 액세스코드 생성 처리
   - 성공 메시지 표시
   - `/admin/accesscode`로 리다이렉트

5. **생성 완료**
   - 새로 생성된 액세스코드 목록에 추가
   - 상태는 초기 "미사용"

### 1.2 액세스코드 상태 관리 흐름
```
액세스코드 목록 → 상태 확인 → 상태 전환 버튼 클릭 → 상태 변경
                                 (사용 ↔ 미사용)
```

**세부 단계:**

1. **액세스코드 목록 조회**
   - URL: `/admin/accesscode`
   - 모든 액세스코드 테이블 표시
   - 각 액세스코드의 현재 상태 표시

2. **상태 확인**
   - 코드상태 컬럼 확인
   - 사용: 초록색 배지
   - 미사용: 주황색 배지

3. **상태 전환 버튼 클릭**
   - 사용 상태 → "미사용 전환" 버튼 (회색)
   - 미사용 상태 → "사용 전환" 버튼 (파랑)

4. **상태 변경 확인**
   - 확인 메시지 표시
   - 테이블 업데이트
   - 새로운 상태로 반영

## 2. 기능 정의 (Information Architecture)

### 2.1 액세스코드 생성 기능

#### 기능명
**Access Code Generation**

#### 목적
새로운 액세스코드를 일괄 생성하여 사용자에게 발급

#### 입력 (Input Parameters)
| 항목 | 타입 | 필수 | 제약사항 | 설명 |
|-----|-----|------|--------|------|
| userType | enum | ✓ | 'teacher' \| 'student' | 대상 사용자 유형 |
| codeCount | number | ✓ | 1 ~ 1000 | 생성할 액세스코드 개수 |
| expiryDate | date | ✓ | 오늘 이후 | 액세스코드 등록 가능한 기한 |
| usagePeriod | enum | ✓ | '1month' \| '3month' \| '6month' \| '1year' \| 'unlimited' | 액세스코드 사용 가능 기간 |
| selectedCourse | enum | 조건부 | 'course1' \| 'course2' \| 'course3' \| 'all' | 학생 선택 시 필수 (제공할 과정) |

#### 출력 (Output)
```json
{
  "success": true,
  "message": "50개의 강사 액세스코드가 생성되었습니다.",
  "codes": [
    {
      "code": "ABC123",
      "status": "미사용",
      "expiryDate": "2026-05-01",
      "usagePeriod": "3개월",
      "createdAt": "2026-03-10"
    }
  ]
}
```

#### 유효성 검사
- codeCount: 1 이상 1000 이하
- expiryDate: 미래 날짜만 허용
- usagePeriod: 정의된 값 중 하나
- selectedCourse (학생): 미선택 시 에러

#### 비즈니스 로직
1. 입력값 유효성 검사
2. 액세스코드 생성 (format: 영문대문자 + 숫자 조합)
3. 데이터베이스 저장
4. 성공 메시지 표시
5. 관리 페이지로 리다이렉트

| status | enum | × | 사용/미사용 필터링 |
| role | enum | × | 강사/학생 필터링 |
| keyword | string | × | 액세스코드 또는 사용자명 검색 |

#### 출력 (Table Columns)
| 컬럼명 | 타입 | 설명 |

| 소속 | string | 사용자 소속 기관 |
| 사용자명 | string | 액세스코드를 사용할 사용자명 |

| 사용기간 | string | 액세스코드 활용 기간 |
| 활성일 | date | 액세스코드 활성화된 날짜 |
| 작업 | button | 상태 전환 버튼 |

#### 페이지네이션
- 기본 표시: 10개 항목/페이지
- 네비게이션: 이전/다음 페이지 버튼

### 2.3 액세스코드 상태 전환 기능

#### 기능명
**Access Code Status Toggle**

#### 목적
액세스코드의 사용/미사용 상태를 전환

#### 입력
| 항목 | 타입 | 설명 |
|-----|-----|------|
| code | string | 대상 액세스코드 |
| currentStatus | enum | 현재 상태 (사용/미사용) |

#### 출력
```json
{
  "success": true,
  "message": "ABC123의 상태를 '미사용'으로 변경했습니다.",
  "data": {
    "code": "ABC123",
    "status": "미사용",
    "updatedAt": "2026-03-10T14:30:00Z"
  }
}
```

#### 상태 전환 규칙
- **사용 → 미사용**: "미사용 전환" 버튼 표시 (회색)
- **미사용 → 사용**: "사용 전환" 버튼 표시 (파랑)
- **미사용 상태 (-)**:  버튼 없음, 대시(-) 표시

#### 조건
- 사용 상태인 경우에만 미사용으로 전환 가능
- 미사용 상태인 경우에만 사용으로 전환 가능
- 상태 변경 후 UI 즉시 반영

## 3. 정책 (Policy & Business Rules)

### 3.1 액세스코드 생성 정책

#### 생성 규칙
```
액세스코드 형식: [영문대문자(4자)] + [숫자(4-6자)]
예시: ABC1234, XYZ123456
```

#### 개수 제한
- **최소**: 1개
- **최대**: 1000개
- 초과 요청 시 에러 메시지: "최대 1,000개까지 생성 가능합니다."

#### 중복 방지
- 동일한 액세스코드가 존재하면 새로 생성
- 생성된 모든 코드는 고유성 보장

#### 만료일 정책
- 등록 만료일은 반드시 미래 날짜
- 과거 날짜 선택 불가
- 만료일 이후 새로운 사용자 등록 불가

#### 사용 기간 정책
```
기간별 액세스 권한:
- 1개월: 생성일로부터 1개월
- 3개월: 생성일로부터 3개월
- 6개월: 생성일로부터 6개월
- 1년: 생성일로부터 1년
- 무제한: 제한 없음
```

#### 학생별 과정 제한
- **강사**: 과정 선택 불필요 (전체 과정 접근)
- **학생**: 반드시 과정 선택 필수
  - 영어 기초
  - 영어 심화
  - 비즈니스 영어
  - 전체 과정

### 3.2 액세스코드 관리 정책

#### 상태 관리
```
상태 흐름:
생성 (미사용) → 사용 → 미사용 → 사용 (...)

- 새로 생성된 코드 초기상태: 미사용
- 사용자가 등록하면: 사용 상태로 전환
- 필요시 관리자가 수동 전환 가능
```

#### 상태별 의미
| 상태 | 설명 | 사용 가능 여부 |
|------|------|--------------|
| 사용 | 현재 활성화된 액세스코드 | O |
| 미사용 | 아직 사용되지 않은 코드 | O (등록 만료일까지) |

#### 만료 처리
- 등록 만료일이 지나면 새로운 사용자 등록 불가
- 기존 사용자의 액세스코드는 계속 유효
- 관리자는 만료된 코드 삭제 가능

### 3.3 보안 정책

#### 접근 제어
- 액세스코드 관리는 관리자 역할만 접근 가능
- `/admin/accesscode` 페이지는 인증된 관리자만 접근
- `/admin/accesscode/generate` 페이지는 인증된 관리자만 접근

#### 감사 로그
- 모든 액세스코드 생성 기록 저장
- 상태 변경 기록 저장
- 변경자 정보 및 시간 기록

#### 민감 정보 보호
- 액세스코드는 평문으로 저장하지 않음 (해시 처리)
- 목록 조회 시 사용자명, 등록 정보만 표시
- 전체 액세스코드 노출 방지

### 3.4 유효성 검사 정책

#### 필수 항목 검증
```
생성 페이지:
- userType: 선택 필수
- codeCount: 1~1000 범위
- expiryDate: 필수, 미래 날짜
- usagePeriod: 선택 필수
- selectedCourse (학생): 선택 필수
```

#### 에러 메시지
| 오류 상황 | 메시지 |
|----------|--------|
| 필수 항목 미입력 | "필수 항목을 입력해주세요." |
| codeCount 범위 초과 | "최대 1,000개까지 생성 가능합니다." |
| 만료일 과거 날짜 | "등록 만료일은 오늘 이후로 설정해주세요." |
| 학생 과정 미선택 | "학생 선택 시 제공할 과정을 선택해주세요." |

### 3.5 UI/UX 정책

#### 버튼 배치
- "+ 액세스코드 생성" 버튼: 테이블 우측 정렬
- 취소/생성 버튼: 폼 우측 정렬

#### 상태 표현
- 배지 색상으로 상태 시각화
  - 사용: 녹색 (#4CAF50)
  - 미사용: 주황색 (#FFC107)
- 역할별 색상 구분
  - 강사: 주황색 (#FF9800)
  - 학생: 보라색 (#9C27B0)

#### 반응성
- 모바일 반응형 테이블 (필요시 스크롤)
- 작은 화면에서도 주요 정보 표시
