## 0. 개요

`access_codes` 테이블은 **INTERNAL(픽클래스 내부 수강) 전용**으로 재확정되었다.

**정정된 아키텍처**: 픽클래스가 파트너 API를 호출하는 **PULL 방식**. 픽클래스는 파트너 회원정보·수강데이터를 소유하지 않으며, API 호출 이력만 전용 로그 테이블에 기록한다.

> 상세 설계: [B2B파트너_외부API_연동_개발계획](../b2b/20260526_B2B파트너_외부API_연동_개발계획.md)

따라서 기존에 추가했던 B2B 컬럼·테이블은 **DROP**하고, B2B 전용 로그 테이블 3개를 신설했다.  
관리자가 코드 생성 시 수강 시작일/종료일을 직접 지정하는 기능은 그대로 유지한다.

### 핵심 변경 요약

| 레이어 | 변경 내용 |
|--------|----------|
| DB | `access_codes`에서 컬럼 3개 DROP (`source_type`, `auth_key`, `partner_member_id`); `access_code_options`, `frt_lesson_options` 테이블 DROP; 신규 테이블 3개 생성 (`partner_api_configs`, `partner_auth_logs`, `partner_enrollment_logs`); FK 제약 2개 추가 (`courses→institutions`, `access_codes→courses`) |

| core | sourceType 필터/저장 코드 제거; course include는 FK 추가로 정상화; **`effectiveStatus()` 추가** — `active` + `usageEndDate` 경과 시 `expired` 반환 (Phase F) |
| core (`findAll`) | status 필터 고도화 — `expired` 필터 시 DB `expired` + 만료된 `active` 모두 포함; `active` 필터 시 `usageEndDate` 미경과 레코드만 포함 (Phase F) |

## Phase F — 학습 종료 코드 조회 시점 만료 계산 ✅ 완료

### 구현 원칙

DB의 `status_code` 값은 변경하지 않는다. 서비스 레이어 **조회 시점**에 `effectiveStatus`를 계산해 클라이언트에 반환한다.  
배치 잡·스케줄러·DB 트리거 불필요.

| DB `status_code` | `usageEndDate` | `effectiveStatus` 반환값 | 비고 |
|-----------------|----------------|--------------------------|------|
| `active` | `null` | `active` | 무기한 수강 |
| `active` | 미래 | `active` | 수강 중 |
| `active` | 현재 이전 | `expired` | 기간 만료 — DB 값은 `active` 유지 |
| `inactive` | (무관) | `inactive` | 등록 전 코드 — `usageEndDate` 적용 안 함 |
| `completed` | (무관) | `completed` | 수강 완료 — 변경 없음 |
| `expired` | (무관) | `expired` | 기존 expired 레코드 |

> **`inactive` 코드의 만료**: `inactive` 코드는 아직 학습자가 등록하지 않은 상태이므로 `usageEndDate` 가 아닌 `registrationExpiry`(등록 만료일)가 유효기간 개념이다. `effectiveStatus()` 는 `inactive` 코드에 적용하지 않는다.

### 변경 파일

#### `packages/core/src/access-code/access-code.service.ts`

**① `effectiveStatus()` private 헬퍼 추가**

```typescript
// 조회 시점에 만료 여부 계산 — DB의 status_code 값은 변경하지 않음
// active + usageEndDate 경과 → expired 반환 / 나머지는 DB 값 그대로
private effectiveStatus(record: { statusCode: string; usageEndDate: Date | null }): string {
  if (
    record.statusCode === 'active' &&
    record.usageEndDate !== null &&
    record.usageEndDate <= new Date()
  ) {
    return 'expired';
  }
  return record.statusCode;
}
```

**② `toAccessCodeResponse()` — `effectiveStatus()` 적용**

```typescript
// 변경 전
statusCode: accessCode.statusCode,

// 변경 후
statusCode: this.effectiveStatus(accessCode),
```

**③ `findAll()` — status 필터 고도화**

```typescript
const now = new Date();
const where: Prisma.AccessCodeWhereInput = {
  ...(query.institutionId && { institutionId: query.institutionId }),
  ...(query.roleCode && { roleCode: query.roleCode }),
};

if (query.statusCode === 'expired') {
  // DB expired + 조회 시점 만료된 active(usageEndDate 경과) 모두 포함
  where.OR = [
    { statusCode: 'expired' },
    { statusCode: 'active', usageEndDate: { lte: now } },
  ];
} else if (query.statusCode === 'active') {
  // 진짜 수강 중인 것만 — usageEndDate가 없거나 미래인 active
  where.AND = [
    { statusCode: 'active' },
    { OR: [{ usageEndDate: null }, { usageEndDate: { gt: now } }] },
  ];
} else if (query.statusCode) {
  where.statusCode = query.statusCode;
}
```
