# AI 모듈 필드 재분류 개발 계획

> **작성일**: 2026-04-24  
> **목적**: Agent if문 남발 방지 — 필드를 기능별 그룹으로 재분류하고 Derived Flags 패턴 도입  
> **영향 프로젝트**: picklass-backoffice, tutoring.picklass.com

---

## 배경

튜터링 Orchestrator가 모듈별 동작 분기를 위해 개별 필드를 직접 조합하는 if문이 누적되고 있음.

```typescript
// 현재 — 조건 조합이 산발적
if (context.pedagogyProfile.answerType === 'sentence-explain') return null;
if (context.pedagogyProfile.scoringMode === 'holistic' && context.pedagogyProfile.questionCount === 'single') { ... }
switch (context.pedagogyProfile.passageExposureMode) { ... }
```

→ 필드를 **기능 그룹 단위**로 재분류하고 **AiModuleFlags** 파생 객체를 도입하여,  
   Agent가 개별 필드 조합 대신 의미 있는 단일 플래그를 참조하도록 개선.

---

## 확정된 변경 사항

### 제거 대상 필드 (3개)

| 필드 | 이유 |
|------|------|
| `passageExposureMode` | `passageMode`와 중복. 값 범위가 subset (`hidden/preview/full` ⊂ `passageMode`). 통합 |
| `hintTypes` (String) | String[] 타입으로 전환. DB-Agent 간 CSV 파싱 로직 제거 |
| `feedbackType` | 구형 contentConfig 스테이지 시스템 잔재 (`Slot/LLM/Button`). 현재 Agent에서 미사용 확인 |

### passageMode 값 정리

```
현재 passageExposureMode  →  passageMode (통합 후)
─────────────────────────────────────────────────
hidden                    →  hidden
preview                   →  preview          ← 'preview-then-reveal'에서 이름 변경
full                      →  full
(해당 없음)               →  timed-blur
```

### Phase 7 세부 완료 내용

**실제 구현과 계획의 차이점:**

1. **`AiModuleFlags` 인터페이스** — 계획보다 단순화된 플래그 구현:
   - 계획: `passageVisible`, `passageStartsPreview`, `isExactScoring`, `isHolisticScoring` 등 13개 플래그
   - 실제: Orchestrator 현재 규칙에서 실제로 사용하는 8개 플래그만 구현
     - `isPassageHidden`, `isPassagePreview`, `isPassageTimedBlur`, `isVoiceModule`, `isMultiQuestion`, `hasRightWrongConcept`, `hasRetry`, `hasHints`

2. **`passageExposureMode` in `ModulePedagogyProfile`** — 계획과 달리 **유지** (제거 보류):
   - 계획: `ModulePedagogyProfile`에서 `passageExposureMode` 제거
   - 실제: `'timed-blur'` 값 추가 후 유지. `GenericAdapter`가 `passageMode`에서 파생하여 채움
   - 이유: `ruleInitialEntry`의 switch가 명시적이고 `timed-blur` 지원이 필요했음

3. **`ruleInitialEntry`** — switch 유지 (플래그 분기로 전환 보류):
   - 4개 케이스(`hidden`, `preview`, `timed-blur`, `full`)로 확장하는 방식으로 완료
   - 계획의 플래그 기반 분기 리팩터링은 다음 스프린트로 이월
