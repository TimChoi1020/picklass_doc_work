## 1. 개요

### 배경

백오피스 로그인 화면을 **통합 진입점**으로 구성한다. 사용자가 계정 하나로 로그인하면 백엔드가 역할(`role_code`)을 기준으로 행선지를 결정한다.

| 역할 | 로그인 결과 |
|------|-----------|
| `system_admin` | 백오피스 대시보드 |
| `partner_admin` | 백오피스 대시보드 |
| `group_admin` | 백오피스 대시보드 |
| `academy_admin` | 백오피스 대시보드 |
| `teacher` | studio.picklass.com (핸드오프 토큰 + 리다이렉트) |
| `student` | tutoring.picklass.com (핸드오프 토큰 + 리다이렉트) |
| 그 외 / 비활성 | 거부 |

## 2. 인증 방식

### 2-1. 핵심 결정

| 항목 | 결정 |
|------|------|
| 인증 방식 | **JWT Bearer** 단독 (express-session 제거) |
| 어드민 토큰 key | `picklass_admin_token` (localStorage) |
| 사용자 토큰 key | `picklass_auth_token` (localStorage, studio·tutoring 공용) |
| JWT_SECRET | **세 시스템 공유 단일 값** — 핸드오프 토큰 상호 검증 가능 |
| 핸드오프 방식 | 공유 `JWT_SECRET` + URL 쿼리 파라미터 전달 (단명 60초) |

### 2-2. 토큰 만료 정책

| 토큰 | 만료 | 비고 |
|------|------|------|
| 어드민 JWT | `1h` (`JWT_EXPIRES_IN_ADMIN`) | 유휴 시 재발급으로 연장 |
| 핸드오프 JWT | `60s` (`JWT_EXPIRES_IN_HANDOFF`) | 1회성 단명 |
| 사용자 JWT (studio · tutoring) | `1h` (`JWT_EXPIRES_IN`) | 유휴 시 재발급으로 연장 |

> Phase 2 이전: 어드민 `8h`, studio·tutoring `7d` → 모두 `1h`로 축소.

## 3. 유휴 만료 (Phase 2)

### 3-1. 저장소 — DB `users.last_active_at`

- 보호된 모든 요청에서 가드가 `last_active_at` 조회 → 1시간 경과 시 401 반환.
- 60초 throttle: 마지막 업데이트로부터 60초 이내는 DB UPDATE + JWT 재발급 스킵.
- `last_active_at = NULL`인 기존 계정은 체크 스킵 (마이그레이션 호환).

### 3-2. 흐름 요약

```
보호된 API 요청
  → AdminAuthGuard / AuthGuard
    → verifyAdminToken (JWT 검증)
    → touchActivity (유휴 검사)
        ok=false → 401
        ok=true  → 쿠키 갱신 + (throttle 초과 시) X-Refresh-Token 반환
  → 컨트롤러
```

### 3-3. JWT 재발급

- 가드가 통과할 때마다 throttle을 초과하면 새 JWT를 `X-Refresh-Token` 응답 헤더로 반환.
- 프론트엔드 fetch 래퍼가 해당 헤더를 감지하면 localStorage 토큰을 교체.
- 활동이 지속되는 사용자는 JWT 1h 절대 만료에 걸리지 않음.

## 4. 쿠키 식별 (Phase 2)

로그인 성공 및 가드 통과 시 `users.id` 값을 담은 쿠키를 발급한다. 인증 수단은 여전히 JWT이며, 쿠키는 서버 측 식별 보조 수단이다.

| 항목 | 값 |
|------|---|
| 이름 | `picklass_user_id` |
| 값 | `users.id` (UUID) |
| Max-Age | `3600` (활동 시 매 요청마다 리셋) |
| HttpOnly | `true` |
| SameSite | `Lax` |
| Secure | prod=`true`, dev=`false` |
| Domain | 각 사이트 독립 (크로스 도메인 공유 없음) |

> 서브도메인 통합 후 `Domain=.picklass.com`으로 변경 예정 (Phase 5).

### 5-1. 백엔드 `ADMIN_ROLES`

|-------|------|
| `login()` | 어드민 JWT 발급 분기 |
| `verifyAdminToken()` | 가드 통과 여부 |
| `getMe()` | 세션 유지 |
| `issueHandoffToken()` | 수동 핸드오프 발급 권한 |

### 5-2. 프론트엔드 메뉴 권한

[`apps/admin/frontend/src/lib/constants.ts`](../../apps/admin/frontend/src/lib/constants.ts)

```ts
const ALL_ADMIN     = ['system_admin', 'partner_admin', 'group_admin', 'academy_admin'];
const ORG_ABOVE     = ['system_admin', 'partner_admin', 'group_admin'];
const PARTNER_ABOVE = ['system_admin', 'partner_admin'];
const PLATFORM_ONLY = ['system_admin'];
```

| 역할 | 접근 가능 메뉴 |
|------|-------------|
| `system_admin` | 전체 |
| `partner_admin` | ALL_ADMIN + ORG_ABOVE(기관 학습 현황·출석률) + PARTNER_ABOVE(파트너 API 연동) |
| `group_admin` | ALL_ADMIN + ORG_ABOVE(기관 학습 현황·출석률) |
| `academy_admin` | ALL_ADMIN (조직관리 포함, 단 등록 버튼 없음 / 기관 학습 현황·출석률 접근 불가) |

`AdminRoleGate`가 `ADMIN_MENU.allowedRoles` 기준으로 라우트 접근을 통제한다. URL 직접 접근 시 `/admin/dashboard`로 리다이렉트.

> 전체 메뉴 트리 및 구현 현황은 [20260527_메뉴구조_권한모델_개발계획.md](../menu-redesign/20260527_메뉴구조_권한모델_개발계획.md) 참조.

## 6. 데이터 범위 제한 (Phase 3)

### 6-1. `resolveUserScope`

[`packages/core/src/course/course.service.ts`](../../packages/core/src/course/course.service.ts)

| 역할 | 반환값 | 의미 |
|------|--------|------|
| `system_admin` | `null` | 전체 데이터 |
| `partner_admin` | `string[]` | 자기 기관 + 모든 하위 기관 (재귀 CTE) |
| `group_admin` | `string[]` | 자기 기관 + 모든 하위 기관 (재귀 CTE) |
| `academy_admin` | `string[]` | 자기 기관 1개 |

### 6-2. 재귀 CTE 쿼리

```sql
WITH RECURSIVE descendants AS (
  SELECT id FROM institutions
  WHERE id = :myInstitutionId AND deleted_at IS NULL
  UNION ALL
  SELECT i.id FROM institutions i
  INNER JOIN descendants d ON i.parent_id = d.id
  WHERE i.deleted_at IS NULL
)
SELECT id FROM descendants
```

`institutions.parent_id`를 통한 자기 참조 계층 구조를 순회해 산하 전체 기관 ID 목록을 반환한다.

### 6-3. 조직 계층 구조

```
institutions (type='partner',      parent_id=null)     ← partner_admin 소속
  └── institutions (type='group',       parent_id=partner.id)  ← group_admin 소속
        └── institutions (type='institution', parent_id=group.id)   ← academy_admin 소속
```
