## 8. 로그인 실패 — user_id vs email 식별자 불일치

- **증상**: `pkls001@pkls.pick` / `1234`로 로그인 시 "계정을 찾을 수 없습니다" 에러
- **원인**: DB `users` 테이블에서 해당 계정은 `user_id = 'pkls001@pkls.pick'`이지만 `email = null`. 로그인 쿼리가 `WHERE email = $1`로 조회하여 찾지 못함.
- **근본 원인**: 백오피스에서 사용자를 생성할 때 `user_id`가 기본 식별자이고 `email`은 옵션 필드. 로그인은 `user_id` 기반이어야 함.
- **수정**:
  - `auth.service.ts`: `login(email)` → `login(userId)`, 쿼리 `WHERE user_id = $1`
  - `auth.controller.ts`: `body.email` → `body.userId`
  - `useAuth.ts`: `login(email, password)` → `login(userId, password)`
  - `LoginModal.tsx`: 이메일 입력 → 아이디 입력 (type="text", placeholder="아이디")
- **파일**: `auth.service.ts`, `auth.controller.ts`, `useAuth.ts`, `LoginModal.tsx`

## 10. DB 타입 캐스팅 오류 — uuid = text 비교 실패

- **증상**: `operator does not exist: uuid = text` — 로그인 시 last_login_at 업데이트 및 getMe 쿼리 실패
- **원인**: `$queryRawUnsafe`에서 `WHERE id = $1`로 전달되는 값이 text 타입인데, DB `id` 컬럼은 UUID 타입이라 비교 연산자가 없음

- **파일**: `apps/api/src/auth/auth.service.ts:106, 122`
