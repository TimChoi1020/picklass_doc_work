## 4. SCN 모듈 "이해했어요" 후에도 AI 채팅 무한 반복 (피드백 중복 체크 실패)

- **증상**: SCN(short-text) 모듈에서 답변 후 피드백 → "이해했어요" → 다시 피드백 → 무한 반복
- **원인**: `ruleHolisticFeedback`의 피드백 중복 체크가 `context.recentMessages`에서 `Q${number}번` 라벨 포함 여부로 판단. Gemini API가 생성한 피드백 텍스트에는 이 라벨이 없어서 매번 새 피드백으로 판단됨. 또한 holistic/correctness 피드백 발화 후 `feedbackGivenIds`에 기록하지 않았음.
- **수정**:
  1. `ruleHolisticFeedback`: 중복 체크를 `recentMessages` 텍스트 검색 → `feedbackGivenIds['holistic']` 배열 체크로 변경
  2. `ruleWrongAnswerFeedback`: 동일하게 `feedbackGivenIds['correctness']` 배열 체크로 변경
  3. `giveFeedback` holistic/correctness 실행 시 `feedbackGivenIdsRef.current`에 questionId 기록 추가
- **파일**: `ModuleOrchestratorAgent.ts` (2곳), `useModuleOrchestrator.ts` (feedbackGivenIds 기록 추가)

## 8. 오답 시 0% 점수 표시 — calcScore 동작 설명

- **증상**: 객관식(mixed) 문항에서 오답이면 score 0%로 표시됨
- **설명**: `calcScore()`에서 `type`이 essay/short-text/audio-record/sentence-write가 아닌 경우 `answers[q.id] === q.answer` 정확 비교. 오답이면 correct = 0 → 0%. 이것은 현재 설계 의도임 (객관식 정오답 기반).
- **정책 참고**: `type: "mixed"`는 객관식과 동일하게 정확 비교로 처리. 부분 점수가 필요하면 별도 정책 결정 필요.

## 15. "학습 모듈이 구성되어 있지 않습니다" — currentModuleIdx 잔존

- **증상**: 동일 lessonId로 재접근 시 `currentModuleIdx=4`(이전 세션 값) + `completedResults=1`(초기화됨) → `sequence[4]` undefined
- **원인**: `key={lessonId}`가 동일 lessonId에서는 재마운트를 트리거하지 않음. 이전 세션에서 4개 모듈 완료 후 idx=4 상태가 유지됨.
- **수정 (3중 보호)**:
  1. `page.tsx`: `sessionKeyRef` + `setLessonPlan(null)` + `key={lessonId-sessionKey}` → 다른 lessonId 이동 시 재마운트
  2. `LessonSession`: `prevLessonIdRef`로 lessonId 변경 감지 → `setCurrentModuleIdx(0)` + `setCompletedResults([])` 강제 초기화
  3. 로딩 가드: `lessonPlan === null` 시 스피너 표시
  4. `isLessonComplete` 조건에 `currentModuleIdx >= sequence.length` 추가 → 인덱스 초과 시 레슨 완료 화면 표시 (첫 모듈로 리셋하는 것이 아님)
  5. `safeModuleIdx` 보정 제거 → 대신 `sequence.length === 0` 가드만 유지
- **파일**: `page.tsx`, `LessonSession.tsx`
