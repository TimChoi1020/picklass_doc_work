## 3. 정책

### PassageMode 값 정책 (구 → 신)

| 구 값 | 신 값 | 비고 |
|---|---|---|
| `preview-then-reveal` | `preview` | PRD 모듈 |
| `timed-then-blur` | `timed-blur` | SCN 모듈 |
| `hidden` | `hidden` | WRD, WSD |
| `full` | `full` | 기본값 |
| — | `timed-select` | 예정 (선택 모드) |

### hintTypes 파싱 정책

- API 응답 `string[] | null` → `HintType[]`
- 빈 배열 또는 null → `['none']`
- CSV 파싱 로직 완전 제거 (구: `raw.split(',')`)

### AiModuleFlags 플래그 정책

`buildModuleFlags(profile)` 호출 위치: `useModuleOrchestrator.ts:755`  
컨텍스트에 `flags` 추가되어 Orchestrator 규칙에서 참조 가능.

```typescript
// 현재 구현된 AiModuleFlags
interface AiModuleFlags {
  isPassageHidden: boolean;      // passageExposureMode === 'hidden'
  isPassagePreview: boolean;     // passageExposureMode === 'preview'
  isPassageTimedBlur: boolean;   // passageExposureMode === 'timed-blur'
  isVoiceModule: boolean;        // answerType === 'audio-record'
  isMultiQuestion: boolean;      // questionCount !== 'single'
  hasRightWrongConcept: boolean; // scoringMode === 'exact'
  hasRetry: boolean;             // questionMaxAttempts > 1
  hasHints: boolean;             // hintTypes.length > 0 && !includes('none')
}
```

## 6. 기술부채 / 알려진 문제

### P1 — passageExposureMode 브릿지 코드 (GenericAdapter.ts:120)

`ModulePedagogyProfile`에 `passageExposureMode`가 유지되고 있음.  
`passageMode` 값을 그대로 매핑하므로 실질적으로 중복.  
브릿지 제거 시 `buildModuleFlags` + 다수 Orchestrator 규칙 동시 수정 필요.

### P2 — AiModuleFlags 일부 미구현

계획 대비 실제 구현된 flags가 subset:
- `isPassiveModule` (CLR 전용, inputLanguage === 'none') — 미구현
- `isHolisticScoring`, `isPronunciationScoring` — 미구현, 대신 `hasRightWrongConcept`으로 우회
- `isSingleQuestion`, `isContentDriven` — 미구현, 대신 `isMultiQuestion`으로 우회

→ Orchestrator 규칙에서 여전히 `pedagogyProfile.scoringMode === 'holistic'` 직접 비교 다수 존재.

### P3 — hint.ts 프롬프트 — hintTypes 배열 처리 미검증

`apps/api/src/ai/prompts/hint.ts` 에서 `hintTypes`를 어떻게 처리하는지 확인 필요.  
구 CSV → 배열 전환 이후 프롬프트 생성 로직이 배열을 올바르게 다루는지 검증 안 됨.

### P4 — pedagogy_profiles.ts 동기화

`apps/web/src/lib/pedagogy/picklass_pedagogy_profiles.ts`의 하드코딩 pedagogy 프로파일에서  
`passageExposureMode` 값이 신규 `PassageMode` 값과 일치하는지 확인 필요.
