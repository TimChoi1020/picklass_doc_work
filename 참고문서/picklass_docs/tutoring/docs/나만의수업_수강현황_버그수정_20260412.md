# 나만의 수업 — 수강 현황 미노출 버그 수정 계획

> 작성일: 2026-04-12

---

## 1. 문제

"나만의 수업"으로 생성한 커스텀 과정이 `GET /lessons/enrolled-courses` 수강 현황 목록에 노출되지 않음.

---

## 2. 원인

`LessonsService.getEnrolledCourses()` (`apps/api/src/lessons/lessons.service.ts:66-79`)의 코스 조회 쿼리가 `access_codes` 테이블 JOIN으로만 과정을 조회함.

커스텀 과정은 `courses` + `course_lessons`만 생성하고 `access_codes` 레코드를 생성하지 않으므로 쿼리 결과에서 누락됨.

```sql
-- 현재 쿼리 (access_codes 경로만 조회)
SELECT DISTINCT c.id, c.title, c.level_code, c.total_lessons
FROM access_codes ac
JOIN courses c ON ac.course_id = c.id
WHERE ac.status_code = 'inactive'
  AND ac.course_id IS NOT NULL
  AND ac.user_id = '{studentId}'
  AND c.deleted_at IS NULL
ORDER BY c.title
```

---

## 3. 수정 방법

기존 쿼리에 UNION으로 커스텀 과정 조회를 추가.

```sql
-- 기존: 액세스코드 기반 과정
SELECT DISTINCT c.id as course_id, c.title as course_title, c.level_code, c.total_lessons
FROM access_codes ac
JOIN courses c ON ac.course_id = c.id
WHERE ac.status_code = 'inactive'
  AND ac.course_id IS NOT NULL
  AND ac.user_id = '{studentId}'
  AND c.deleted_at IS NULL

UNION

-- 추가: 나만의 수업 (커스텀 과정)
SELECT c.id as course_id, c.title as course_title, c.level_code, c.total_lessons
FROM courses c
WHERE c.created_by = '{studentId}'
  AND c.genre_code = 'custom'
  AND c.deleted_at IS NULL

ORDER BY course_title
```

## 4. 변경 범위

| 파일 | 위치 | 내용 |
|------|------|------|
| `apps/api/src/lessons/lessons.service.ts` | 66~79줄 (SQL 쿼리) | UNION 쿼리 추가 |

- 이후 로직(82~136줄)은 `courses` 배열을 순회하는 구조이므로 변경 불필요
- `total_lessons` 컬럼이 0이어도 116줄에서 `lessons.length`로 실제 카운트하므로 영향 없음
