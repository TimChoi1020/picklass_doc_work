# 모듈 렌더링 데이터드리븐 리팩토링 (2026-04-08)

## 목적

기존 `uiTemplate` switch-case 분기 방식을 제거하고, DB 필드만으로 모든 모듈의 렌더링 동작을 제어하는 아키텍처로 전환.  
신규 모듈 추가 시 코드 변경 없이 DB 등록만으로 동작 가능하게 함.

---

## 아키텍처 개요

기존 방식 → 신규 방식

```
uiTemplate switch-case              passageMode (지문 패널 동작)
  'standard'  → ModuleRunnerInner     'full'               : 항상 표시
  'vocab-deck'→ VocabDeckFlow  →      'hidden'             : 숨김
  'process-writing' → ...            'preview-then-reveal': 미리보기→공개
  'interactive' → ...                'timed-then-blur'    : 타이머→블러

                                    questionFlowMode (문항 패널 동작)
                                      'sequential' : 순서대로 표시
                                      'deck'       : 카드 1장씩 (재시도 dots)
                                      'locked-steps': 전체 표시, 미완료 잠금
```

두 필드는 독립적으로 조합 가능.  
예) `passageMode=timed-then-blur` + `questionFlowMode=deck` → 타이머 블러 지문 + 카드형 문항

### 마이그레이션 방법
Supabase cross-schema 이슈로 `prisma migrate`가 실패하여 직접 SQL 실행:

```sql

ALTER TABLE ai_modules ADD COLUMN IF NOT EXISTS question_flow_mode VARCHAR(30) NOT NULL DEFAULT 'sequential';
```

> 기존 데이터는 모두 default값(`full` / `sequential`)으로 유지 — 동작 변경 없음.

### LessonSession.tsx — usePassageMode 훅 + ModuleRunnerInner 분기

**제거된 것:**
- `ScanningGate` 컴포넌트 (timer + blur 로직을 훅으로 흡수)
- `uiTemplate` switch-case → `ModuleRunner`가 항상 `ModuleRunnerInner`를 직접 렌더
- SCN 전용 props: `passageVisibleOverride`, `onFirstAnswerSubmitted`, `contentPanelFooter`

**추가된 것:**
```typescript
function usePassageMode(passageMode: string, firstAnswerSubmitted: boolean) {
  // 'timed-then-blur': 타이머 0 도달 시 blur, contentPanelFooter로 타이머 UI 제공
  // 'hidden':          passageVisibleOverride = false
  // 'full' / 'preview-then-reveal': override 없음 (Orchestrator 제어)
  return { passageVisibleOverride, contentPanelFooter };
}

// ModuleRunnerInner 내부
const passageMode    = moduleData.passageMode    ?? 'full';
const questionFlowMode = moduleData.questionFlowMode ?? 'sequential';
const firstAnswerSubmitted = Object.keys(answers).length > 0;
const { passageVisibleOverride, contentPanelFooter } = usePassageMode(passageMode, firstAnswerSubmitted);
```
