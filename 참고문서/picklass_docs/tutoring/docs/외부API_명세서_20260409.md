# Picklass Tutoring 외부 API 명세서

> 버전: 1.0
> 작성일: 2026-04-09
> Base URL: `https://tutoring.picklass.com/api`

---

## 1. 개요

Picklass 튜터링 플랫폼의 레슨 데이터를 외부 시스템에서 안전하게 조회할 수 있는 API입니다.
원타임 토큰 기반 인증을 사용하며, 토큰은 Picklass 내부에서 자동 생성되어 전달됩니다.

**외부 연동 대상 모듈 코드**: `SNR`, `FRT`
(레슨의 `skill_modules` 시퀀스에 위 모듈 중 하나라도 포함되면, 레슨 플랜 조회 시 모듈별로 원타임 토큰이 자동 발급됩니다.)

---

## 2. 인증 방식

모든 요청은 **HTTP 헤더**로 인증합니다.

| 헤더 | 필수 | 설명 |
|------|------|------|
| `X-Access-Token` | O | Picklass에서 발급한 원타임 토큰 |
| `X-Module-Code` | O | 조회할 모듈 코드 (`SNR`, `FRT`) |

토큰은 발급 시점부터 **60분** 유효하며, 만료 시 재발급이 필요합니다.

---

## 3. API 엔드포인트

### 3.1 토큰 검증 및 데이터 조회

레슨의 사용자 정보, 모듈 메타데이터, 지문 데이터를 조회합니다.

```
GET /external/verify
```

#### Request

**Headers:**

```
X-Access-Token: {token}
X-Module-Code: SNR
```

#### Response (200 OK)

```json
{
  "lessonId": "4a9106be-fbd6-4ff1-9866-dd2cb31cf7a8",
  "user": {
    "userId": "student01@example.com",
    "name": "홍길동"
  },
  "module": {
    "code": "SNR",
    "name": "Scenario Talking",
    "skill": "speaking",
    "uiTemplate": "standard",
    "answerType": "free_speech",
    "scoringMode": "ai_eval",
    "passageExposureMode": "full",
    "feedbackStyle": "immediate",
    "questionCount": "single",
    "questionMinCount": 1,
    "questionMaxCount": 1
  },
  "lesson": {
    "id": "4a9106be-fbd6-4ff1-9866-dd2cb31cf7a8",
    "topic": "The World of Apps: How do mobile applications make our daily lives easier?",
    "lessonOrder": 1,
    "text": {
      "title": "Apps Make Life Easier and More Fun",
      "content": "Many people use apps every day on their smartphones...",
      "speakingContent": "# Apps Make Life Easier and More Fun\n\nMany people use apps...",
      "level": "A2",
      "category": "설명문",
      "wordCount": 125
    }
  }
}
```

#### Response 필드 설명

| 필드 | 타입 | 설명 |
|------|------|------|
| `lessonId` | string (UUID) | 레슨 고유 ID |
| **user** | | |
| `user.userId` | string | 사용자 로그인 ID |
| `user.name` | string | 사용자 이름 |
| **module** | | |
| `module.code` | string | 모듈 코드 |
| `module.name` | string | 모듈 이름 |
| `module.skill` | string | 스킬 분류 (예: speaking, vocabulary) |
| `module.uiTemplate` | string | UI 템플릿 타입 |
| `module.answerType` | string | 응답 유형 |
| `module.scoringMode` | string | 채점 방식 |
| `module.passageExposureMode` | string | 지문 노출 방식 |
| `module.feedbackStyle` | string | 피드백 방식 |
| `module.questionCount` | string | 문항 수 유형 (single / multi) |
| `module.questionMinCount` | number | 최소 문항 수 |
| `module.questionMaxCount` | number | 최대 문항 수 |
| **lesson** | | |
| `lesson.id` | string (UUID) | 레슨 고유 ID |
| `lesson.topic` | string | 레슨 주제 |
| `lesson.lessonOrder` | number | 레슨 순서 |
| `lesson.text` | object \| null | 지문 데이터 (없을 수 있음) |
| `lesson.text.title` | string | 지문 제목 |
| `lesson.text.content` | string | 지문 본문 |
| `lesson.text.speakingContent` | string \| null | 스피킹 연습용으로 변환된 지문 본문 (Markdown). 백오피스에 등록된 시스템 프롬프트로 자동 생성되며, 비동기 변환 중이거나 변환 실패 시 `null` |
| `lesson.text.level` | string \| null | 지문 레벨 (CEFR: A1~C2) |
| `lesson.text.category` | string \| null | 지문 카테고리 |
| `lesson.text.wordCount` | number \| null | 단어 수 |

#### Error Responses

| 상태 코드 | 응답 | 원인 |
|-----------|------|------|
| 401 | `{"message": "X-Access-Token 헤더가 필요합니다."}` | 토큰 헤더 누락 |
| 401 | `{"message": "X-Module-Code 헤더가 필요합니다."}` | 모듈 코드 헤더 누락 |
| 401 | `{"message": "유효하지 않은 토큰입니다."}` | 존재하지 않는 토큰 |
| 401 | `{"message": "모듈 코드가 일치하지 않습니다."}` | 토큰의 모듈 코드와 헤더 불일치 |
| 403 | `{"message": "만료된 토큰입니다."}` | 토큰 만료 (시간 초과 또는 수동 만료) |
| 404 | `{"message": "사용자를 찾을 수 없습니다."}` | 매핑된 사용자 없음 |
| 404 | `{"message": "모듈을 찾을 수 없습니다."}` | 비활성 또는 삭제된 모듈 |
| 404 | `{"message": "레슨을 찾을 수 없습니다."}` | 레슨 데이터 없음 |

### 3.2 임시 토큰 발급 (한시적)

> ⚠️ 이 엔드포인트는 외부 연동 테스트용 한시적 API로, 추후 제거될 예정입니다.
> 발급 파라미터(user/lesson/module)는 서버 내 상수로 고정되어 있으며, 요청 body는 없습니다.

```
POST /external/tokens/issue
```

#### Request

**Headers:**

```
X-Admin-Secret: {EXTERNAL_TOKEN_ISSUE_SECRET}
```

#### Response (201 Created)

```json
{
  "moduleCode": "SNR",
  "token": "fff39da5-d946-4a96-95fb-80fe2bca6270",
  "expiresAt": "2026-04-22T15:30:00.000Z"
}
```

#### 동작

- 고정값: `userId=bad9cd45-039b-493e-8899-0f0e59682e1a`, `courseLessonId=4a9106be-fbd6-4ff1-9866-dd2cb31cf7a8`, `moduleCode=SNR`, 유효시간 60분
- 동일 조합의 **미만료 토큰이 존재하면 기존 토큰을 재사용**하여 반환합니다. 없으면 신규 발급합니다.
- 새 토큰을 받으려면 먼저 `POST /external/tokens/expire` 로 기존 토큰을 만료 처리해야 합니다.

#### Error Responses

| 상태 코드 | 응답 | 원인 |
|-----------|------|------|
| 401 | `{"message": "유효하지 않은 X-Admin-Secret 헤더입니다."}` | 시크릿 헤더 누락 또는 불일치 |
| 401 | `{"message": "EXTERNAL_TOKEN_ISSUE_SECRET 환경변수가 설정되지 않았습니다."}` | 서버 환경변수 미설정 |

#### cURL

```bash
curl -X POST https://tutoring.picklass.com/api/external/tokens/issue \
  -H "X-Admin-Secret: {EXTERNAL_TOKEN_ISSUE_SECRET}"
```

### 3.3 토큰 만료 처리

발급된 토큰을 수동으로 만료 처리합니다.

```
POST /external/tokens/expire
```

#### Request

**Headers:**

```
X-Access-Token: {token}
X-Module-Code: SNR
```

#### Response (200 OK)

```json
{
  "token": "fff39da5-d946-4a96-95fb-80fe2bca6270",
  "isExpired": true,
  "expiredAt": "2026-04-09T14:30:00.000Z"
}
```

#### Error Responses

| 상태 코드 | 응답 | 원인 |
|-----------|------|------|
| 401 | `{"message": "X-Access-Token 헤더가 필요합니다."}` | 토큰 헤더 누락 |
| 401 | `{"message": "X-Module-Code 헤더가 필요합니다."}` | 모듈 코드 헤더 누락 |
| 404 | `{"message": "토큰을 찾을 수 없습니다."}` | 존재하지 않는 토큰 |
| 409 | `{"message": "이미 만료된 토큰입니다."}` | 이미 만료 처리된 토큰 |

### 3.4 Gateway 리다이렉트 (한시적)

> ⚠️ 이 엔드포인트는 외부 연동 테스트용 한시적 API로, 추후 제거될 예정입니다.
> 외부 시스템의 모든 작동이 끝난 뒤 사용자를 앱 내 페이지로 이동시키는 용도입니다.

```
GET /external/gateway?token={최초토큰값}
```

#### Request

- 인증 없음 (브라우저가 직접 이동하는 공개 URL)
- `token` 쿼리 파라미터: 선택. 있으면 메타 조회 후 분기, 없으면 기본 페이지로 이동

#### Response

- **HTTP 302 Redirect**
- `Location` 헤더로 이동 대상 절대 URL 반환 (`EXTERNAL_GATEWAY_BASE_URL` + 분기 경로)

#### 환경변수

| 변수 | 예시 | 설명 |
|------|------|------|
| `EXTERNAL_GATEWAY_BASE_URL` | prod: `https://tutoring-picklass-com.vercel.app` / local: `http://localhost:3001` | 리다이렉트 대상 프론트엔드 베이스 URL. 미설정 시 베이스 없이 경로만 반환 |

#### 분기 규칙 (현재)

| 조건 | 이동 대상 경로 |
|------|---------------|
| 토큰 없음 | `/my-classes` |
| 토큰 조회 실패 / 존재하지 않는 토큰 | `/my-classes` |
| `moduleCode === 'SNR'` | `/my-classes` |
| `moduleCode === 'FRT'` | `/my-classes` |
| 기타 | `/my-classes` |

> 현재는 모든 경우 `/my-classes` 로 이동합니다. 분기 구조만 심어두었으며, 추후 `moduleCode` 또는 `courseLessonId` 기반으로 경로가 추가될 예정입니다.

#### 호출 예시

```
https://tutoring.picklass.com/api/external/gateway?token=fff39da5-d946-4a96-95fb-80fe2bca6270
```

브라우저에서 위 URL로 이동하면 `https://tutoring-picklass-com.vercel.app/my-classes` 로 자동 리다이렉트됩니다 (prod 환경 기준).

## 4. 호출 예시

### cURL

```bash
curl -X GET https://tutoring.picklass.com/api/external/verify \
  -H "X-Access-Token: fff39da5-d946-4a96-95fb-80fe2bca6270" \
  -H "X-Module-Code: SNR"
```

### JavaScript (fetch)

```javascript
const response = await fetch('https://tutoring.picklass.com/api/external/verify', {
  method: 'GET',
  headers: {
    'X-Access-Token': 'fff39da5-d946-4a96-95fb-80fe2bca6270',
    'X-Module-Code': 'SNR',
  },
});

const data = await response.json();
console.log(data.lessonId);       // "4a9106be-..."
console.log(data.user.name);      // "홍길동"
console.log(data.lesson.text);    // { title, content, level, ... }
```

### Python (requests)

```python
import requests

response = requests.get(
    'https://tutoring.picklass.com/api/external/verify',
    headers={
        'X-Access-Token': 'fff39da5-d946-4a96-95fb-80fe2bca6270',
        'X-Module-Code': 'SNR',
    },
)

data = response.json()
print(data['lessonId'])
print(data['user']['name'])
print(data['lesson']['text']['content'])
```

## 5. 주의사항

| 항목 | 설명 |
|------|------|
| 토큰 유효시간 | 발급 후 **60분**. 만료 시 재발급 필요 |
| 토큰 재사용 | 유효 기간 내 동일 토큰으로 반복 조회 가능 |
| 토큰 발급 | Picklass 내부에서 자동 발급. 외부에서 직접 발급 불가 |
| 지원 모듈 코드 | `SNR`, `FRT` (그 외 모듈 코드로는 자동 발급되지 않음) |
| 모듈 코드 검증 | 토큰 발급 시 지정된 모듈 코드와 요청 헤더의 모듈 코드가 반드시 일치해야 함 (SNR 토큰으로 FRT 조회 불가) |
| HTTPS | 프로덕션 환경에서는 반드시 HTTPS 사용 |
