## 2. 아키텍처

### 데이터 흐름

```
레슨 완료
  │
  ├─ saveLessonResult() 호출 (모든 모듈 완료 시)
  │   ├─ ① computeWeakKpiCodes() — 룰 기반, 즉시
  │   ├─ ② LevelEstimateService.estimate() — 히스토리 기반 CEFR 레벨
  │   ├─ ③ lesson_results CREATE/UPDATE
  │   │   └─ weak_kpi_codes, estimated_level 포함
  │   └─ ④ generateAndSaveSummary() — fire-and-forget (Gemini)
  │       └─ 완료 후 lesson_results UPDATE (summary_feedback, strengths, improvements, next_steps)
  │
  └─ LessonCompleteView 마운트
      ├─ 즉시: fetchCompleteSummary() → moduleResults + weak_kpi_codes + estimated_level
      └─ 5초 후: 재조회 → AI 피드백 (summaryFeedback 등) 갱신
```

### 약점 KPI 판별 로직 (computeWeakKpiCodes)

```
INVERSE_KPI_CODES = { GRAMMAR_ERROR, WRITING_ERROR, RECOG_SPEED, RESPONSE_LATENCY }
WEAK_THRESHOLD = 60

일반 KPI: 평균 < 60 → 약점
역방향 KPI: 평균 > 60 → 약점 (낮을수록 좋음)
```

### DB-first + React state fallback

```typescript
// LessonCompleteView.tsx
const dbResults = summary?.moduleResults ?? [];
const effectiveResults = dbResults.length > 0
  ? dbResults
  : completedResults.map(r => ({ ...r, timeSpentSeconds: r.timeSpentSeconds ?? r.timeSpentMinutes * 60 }));
```

- API에서 `module_histories` 최신 1건 per module_code 반환
- 네트워크 실패 시 React state (현재 세션) 폴백

## 4. API 스펙 (현재 구현)

### `GET /lessons/:lessonId/complete-summary`

**인증**: JWT 필요 (AuthGuard)

**응답** (`CompleteSummary`):
```typescript
{
  lessonTitle: string | null;           // course_lessons.topic
  passageTitle: string | null;          // texts.title (지문 타이틀)
  moduleNames: Record<string, string>;  // ai_modules.code → name
  moduleResults: Array<{                // module_histories 최신 1건 per module_code
    moduleCode: string;
    score: number;
    kpis: { kpi_code?: string; label: string; value: number; unit: string; description: string; pending?: boolean }[];
    engagementLevel: 'high' | 'medium' | 'low';
    hintUsedIds: string[];
    attemptCounts: Record<string, number>;
    timeSpentSeconds: number;
    completedAt: string;
  }>;
  summaryFeedback: string | null;       // Gemini 생성 (fire-and-forget)
  strengths: string[] | null;
  improvements: string[] | null;
  nextSteps: string[] | null;
  estimatedLevel: number | null;        // LevelEstimateService.inferredIndex
  weakKpiCodes: string[] | null;        // computeWeakKpiCodes() 결과
}
```
