## 1. 배경 및 목적

**수강 상태는 계약 기간 기반**으로 정의한다:

| 상태 | 기준 |
|------|------|
| 수강중 | `usage_end_date IS NULL` 또는 `usage_end_date >= 오늘` |
| 수강종료 | `usage_end_date < 오늘` |

나만의 수업(custom 과정)은 수강 구독에 종속된 부가 기능이다. "내가 만든 과정" 섹션으로 별도 분리하며, 수강중인 일반 과정이 하나 이상 있을 때만 진입 가능하다.

### course_type 기반 서비스 필터 정책

`courses` 테이블은 tutoring·speaking이 공유하므로, 각 서비스는 자신에게 해당하는 과정 유형만 조회한다.

| 서비스 | 조회 대상 `course_type` |
|--------|------------------------|
| tutoring.picklass.com | `tutoring`, `integrated` |
| speaking.picklass.com | `speaking`, `integrated` |

`course_type IS NULL`인 기존 레코드는 `integrated`로 일괄 업데이트한다 (SQL: `2026-06-19_backfill_course_type_null_to_integrated.sql`).

## 2. 현황 문제

| 레이어 | 문제 |
|--------|------|
| API | `usage_end_date > NOW()` 필터로 만료 과정이 응답에서 제외됨. `usage_end_date` / `usage_start_date` 필드 없음 |
| API | `completedLessons`가 `0` 하드코딩 — `lesson_results` 미참조 |
| API | `genre_code` 미반환 — 나만의 수업(custom) 구분 불가 |
| 프론트엔드 | `completedLessons` 기반 split — 날짜 무관한 이수율 기준 |
| 프론트엔드 | 나만의 수업이 수강중 섹션에 혼합 — 별도 섹션 없음 |
| 프론트엔드 | 수강종료·이용 제한 과정 "레슨 보기" 버튼 활성화 상태 |

## 3. Phase 1 — 백엔드

**파일**: `apps/api/src/lessons/lessons.service.ts`

### 3-1. `getEnrolledCourses()` 쿼리 변경

```sql
-- INTERNAL 수강 과정
SELECT DISTINCT
  c.id            AS course_id,
  c.title         AS course_title,
  c.level_code,
  c.total_lessons,
  ac.usage_start_date,
  ac.usage_end_date,
  c.course_type,
  c.genre_code                             -- 추가 (isCustom 구분용)
FROM access_codes ac
JOIN courses c ON ac.course_id = c.id
WHERE ac.status_code = 'active'
  AND ac.course_id IS NOT NULL
  AND ac.user_id = '${studentId}'
  AND (c.course_type IN ('tutoring', 'integrated') OR c.course_type IS NULL)
  AND c.deleted_at IS NULL

UNION

SELECT
  c.id            AS course_id,
  c.title         AS course_title,
  c.level_code,
  c.total_lessons,
  NULL            AS usage_start_date,
  NULL            AS usage_end_date,
  c.course_type,
  c.genre_code
FROM courses c
WHERE c.created_by = '${studentId}'
  AND c.genre_code = 'custom'
  AND (c.course_type IN ('tutoring', 'integrated') OR c.course_type IS NULL)
  AND c.deleted_at IS NULL

ORDER BY course_title
```

### 3-2. `completedLessons` 실계산

`lesson_results` 테이블의 `completed_at IS NOT NULL` 레코드를 기준으로 완료 레슨 수를 계산한다.

```typescript
const completedResults = await this.prisma.lesson_results.findMany({
  where: {
    course_lesson_id: { in: lessonIds },
    student_id: studentId,
    completed_at: { not: null },
  },
  select: { course_lesson_id: true },
});
const completedSet = new Set(completedResults.map((r) => r.course_lesson_id));

completedLessons: completedSet.size,  // 하드코딩 0 → 실계산
```

### 3-3. `nextLesson` 로직 개선

```typescript
// 미완료 레슨 중 text가 있는 것 우선, 없으면 첫 미완료, 전부 완료면 마지막 레슨
lessons.find((l) => !completedSet.has(l.id) && l.text_id !== null)
  ?? lessons.find((l) => !completedSet.has(l.id))
  ?? lessons[lessons.length - 1]
```

### 3-4. 반환 필드 요약

```typescript
isCustom:      course.genre_code === 'custom',
courseType:    course.course_type ?? null,
usageStartDate: ...,
usageEndDate:   ...,
completedLessons: completedSet.size,
// lessons 각 항목에:
isCompleted: completedSet.has(l.id),
```

  usageEndDate: string | null;

### 4-2. 3섹션 split 로직

```typescript
const today = new Date();
today.setHours(0, 0, 0, 0);

const nonCustomCourses = courses.filter((c) => !c.isCustom);
const customCourses    = courses.filter((c) => c.isCustom);
const activeCourses    = nonCustomCourses.filter(
  (c) => !c.usageEndDate || new Date(c.usageEndDate) >= today
);
const expiredCourses   = nonCustomCourses.filter(
  (c) => !!c.usageEndDate && new Date(c.usageEndDate) < today
);

// 내가 만든 과정 이용 가능 여부
const canUseCustom = activeCourses.length > 0;

// 수강 가능 기간: 무제한 과정 있으면 null, 아니면 활성 과정 중 최대 종료일
const hasUnlimitedActive = activeCourses.some((c) => !c.usageEndDate);
const maxActiveEndDate = hasUnlimitedActive
  ? null
  : activeCourses.reduce<string | null>((max, c) => {
      if (!c.usageEndDate) return max;
      if (!max || c.usageEndDate > max) return c.usageEndDate;
      return max;
    }, null);
```

### 4-3. 섹션 구성

| 섹션 | 표시 조건 | 아이콘 | 색상 |
|------|-----------|--------|------|
| 수강중인 과정 | 항상 | Sparkles | 초록 |
| 내가 만든 과정 | `customCourses.length > 0` | PenLine | 앰버 |
| 수강종료 과정 | 항상 | CalendarX | 회색 |

### 4-4. 내가 만든 과정 — 잠금 및 수강 기간 표시

- `canUseCustom = true` + `maxActiveEndDate` 있음 → 헤더에 `~ YYYY.MM.DD 까지 이용 가능` 표시
- `canUseCustom = false` → 섹션 상단에 잠금 안내 배너 표시, 카드 `isExpired={true}` (흐림 + 버튼 비활성)

```tsx
{!canUseCustom && (
  <div className="mb-3 flex items-center gap-2 rounded-xl bg-amber-50 border border-amber-200 px-4 py-3">
    <Lock className="h-4 w-4 text-amber-500 shrink-0" />
    <p className="text-sm text-amber-700">수강 중인 과정이 없어 이용이 제한됩니다.</p>
  </div>
)}
```

### 4-5. CourseCard — 과정 유형 배지

|---|---|---|
| `integrated` | 통합 | 보라 |
| `speaking` | 스피킹 | 파랑 |
| `tutoring` / `null` | 없음 | — |
