## 개요

Pickle AI 채팅 패널에 표시되는 AI 메시지를 Azure Neural TTS로 읽어주는 기능.
선생님이 직접 설명하는 느낌의 몰입감을 제공하며, 토글로 켜기/끄기 가능 (기본값: off).

## 1. 설계 원칙

- **토글 기본값 off** — 학습 흐름을 방해하지 않는 선택적 기능
- **무음 실패 처리** — TTS API 실패 시 오류 메시지 없이 조용히 스킵
- **중복 재생 방지** — 새 메시지 도착 시 이전 재생 즉시 중단 후 신규 발화
- **isLoading 중단** — AI 응답 생성 중(`isLoading`)에는 재생 중인 음성 즉시 stop
- **localStorage 유지** — 토글 ON/OFF 상태를 `tts_enabled` 키로 저장, 모듈 이동 시에도 유지

## 2. 아키텍처

```
[FeedbackPanel]
  latestAiId 변경 감지
      ↓
  useTTS.speak(message.text)
      ↓
  enabled 확인 → off이면 종료 (API 호출 없음)
      ↓

      ↓
  callTts(cleanText)             — aiModuleService.ts
      ↓
  POST /ai/tts { lang: 'ko-KR' }  — NestJS
      ↓
  TtsService.synthesizeMixed()   — 한국어/영어 구간 분리
    ├─ 한국어 구간 → ko-KR-SunHiNeural
    └─ 영어 구간  → en-US-JennyNeural
    → Buffer.concat() → base64 MP3
      ↓
  new Audio('data:audio/mp3;base64,...').play()
```

## 3. 파일 변경 명세

### 3.1 백엔드

#### `apps/api/src/ai/tts.service.ts` — 한영 혼용 분리 합성

`lang === 'ko-KR'` 일 때 `synthesizeMixed()`로 위임.
텍스트를 한국어/영어 구간으로 분리해 각각 적절한 voice로 합성 후 MP3 버퍼 병합.

```typescript
const EN_VOICE = 'en-US-JennyNeural';

async synthesize(text, voiceId = 'en-US-AriaNeural', speed = 1.0, lang = 'en-US') {
  if (lang === 'ko-KR') return this.synthesizeMixed(text, voiceId, speed);
  const buffer = await this.synthesizeSegment(text, voiceId, speed, lang);
  return { audioBase64: buffer.toString('base64'), audioSize: buffer.length };
}

private async synthesizeMixed(text, koVoice, speed) {
  const segments = this.parseLanguageSegments(text);
  const buffers = await Promise.all(
    segments.map(seg =>
      this.synthesizeSegment(
        seg.text,
        seg.isEnglish ? EN_VOICE : koVoice,
        speed,
        seg.isEnglish ? 'en-US' : 'ko-KR',
      )
    )
  );
  const combined = Buffer.concat(buffers);
  return { audioBase64: combined.toString('base64'), audioSize: combined.length };
}

// 알파벳 시작 단어 연속열 = 영어 구간
private parseLanguageSegments(text) {
  const engPattern = /[A-Za-z][A-Za-z0-9]*(?:[-'][A-Za-z0-9]+)*(?:\s+[A-Za-z][A-Za-z0-9]*(?:[-'][A-Za-z0-9]+)*)*/g;
  // ... ko/en 구간 교대로 push
}
```

컨트롤러 `POST /ai/tts` body에 `lang?` 추가:
```typescript
async synthesize(@Body() body: { text: string; voiceId?: string; speed?: number; lang?: string }) {
  return this.ttsService.synthesize(body.text, body.voiceId, body.speed, body.lang);
}
```

### 3.2 프론트엔드

#### `apps/web/src/lib/services/aiModuleService.ts` — `callTts()` 추가

```typescript
export async function callTts(text: string): Promise<string | null> {
  const apiUrl = process.env.NEXT_PUBLIC_TUTORING_API_URL;
  if (!apiUrl) return null;
  try {
    const res = await fetch(`${apiUrl}/ai/tts`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        text,
        voiceId: 'ko-KR-SunHiNeural',
        speed: 0.95,
        lang: 'ko-KR',
      }),
    });
    if (!res.ok) return null;
    const { audioBase64 } = await res.json() as { audioBase64: string };
    return `data:audio/mp3;base64,${audioBase64}`;
  } catch {
    return null;  // 실패 시 무음 처리
  }
}
```

> `/ai/tts`는 Auth Guard 없음 — 별도 인증 헤더 불필요.

#### `apps/web/src/lib/hooks/useTTS.ts` — 신규 파일

```typescript
'use client';
import { useState, useRef, useCallback } from 'react';
import { callTts } from '@/lib/services/aiModuleService';

const TTS_KEY = 'tts_enabled';

function stripForTts(text: string): string {
  return text
    .replace(/\*\*(.+?)\*\*/g, '$1')        // **bold** → bold (s 플래그 제거: ES2017 호환)
    .replace(/\*(.+?)\*/g, '$1')
    .replace(/^#{1,6}\s/gm, '')
    .replace(/`([^`]+)`/g, '$1')
    .replace(/^\s*[-*+•·]\s/gm, '')
    .replace(/[\u{1F000}-\u{1FFFF}]/gu, '') // SMP 이모지 (u 플래그는 ES2015+, ES2017 OK)
    .replace(/[☀-➿]/gu, '')                // Misc 기호 블록 U+2600–U+27BF
    .replace(/[【】『』「」〈〉《》〔〕]/g, '')
    .replace(/[★☆◆◇■□▲△▼▽○●]/g, '')
    .replace(/\n{2,}/g, '. ')
    .replace(/\n/g, ' ')
    .trim();
}

export function useTTS() {
  // localStorage에서 초기값 읽기 — SSR guard 포함
  const [enabled, setEnabled] = useState<boolean>(() => {
    if (typeof window === 'undefined') return false;
    return localStorage.getItem(TTS_KEY) === 'true';
  });
  const [isFetching, setIsFetching] = useState(false);
  const audioRef = useRef<HTMLAudioElement | null>(null);

  const stop = useCallback(() => {
    if (audioRef.current) {
      audioRef.current.pause();
      audioRef.current.src = '';
      audioRef.current = null;
    }
    setIsFetching(false);
  }, []);

  // toggle: 상태 변경 + localStorage 동기화 + off 시 자동 정지
  const toggle = useCallback((val: boolean) => {
    setEnabled(val);
    localStorage.setItem(TTS_KEY, String(val));
    if (!val) stop();
  }, [stop]);

  const speak = useCallback(async (text: string) => {
    if (!enabled) return;
    stop();
    const clean = stripForTts(text);
    if (!clean) return;
    setIsFetching(true);
    const dataUrl = await callTts(clean);
    setIsFetching(false);
    if (!dataUrl) return;
    const audio = new Audio(dataUrl);
    audioRef.current = audio;
    audio.onended = () => { audioRef.current = null; };
    await audio.play().catch(() => { audioRef.current = null; });
  }, [enabled, stop]);

  return { enabled, toggle, speak, stop, isFetching };
}
```

**설계 포인트:**
- `setEnabled` 직접 노출 제거 → `toggle(val: boolean)` 만 공개 — localStorage 동기화 누락 방지
- `\p{Extended_Pictographic}` 미사용 — web tsconfig `target: ES2017`에서 TS1501 에러 발생하므로 `\u{...}` 범위로 대체

|---|---|---|
| 한국어 음성 | `ko-KR-SunHiNeural` | 여성, 자연스럽고 친근한 교사 톤 |

| SSML lang | `ko-KR` / `en-US` | 구간별 자동 전환 |

| 음성 ID | 특징 |

## 5. 텍스트 전처리 (`stripForTts`)

AI 메시지에는 마크다운 기호·이모지가 포함되므로 TTS 전송 전 정제 필요.

| 패턴 | 처리 |
|---|---|
| `**bold**`, `*italic*` | 기호 제거, 텍스트 유지 |
| `` `코드` `` | 기호 제거, 텍스트 유지 |
| `# 제목` (H1–H6) | `#` 기호만 제거 |
| `- 항목`, `* 항목`, `• 항목` | 불릿 기호만 제거, 텍스트 유지 |
| U+1F000–U+1FFFF (SMP 이모지) | 완전 제거 (`[\u{...}]` 범위, `u` 플래그) |
| U+2600–U+27BF (☀–➿ 기호 블록) | 완전 제거 |
| 동아시아 장식 괄호 【】『』 등 | 완전 제거 |
| 도형 기호 ★☆◆■▲○● 등 | 완전 제거 |
| 연속 개행 `\n\n` | `. `로 대체 — 문장 구분 유지 |
| 단일 개행 `\n` | 공백으로 대체 |

**ES2017 호환 주의사항:**
- `\p{Extended_Pictographic}` (ES2018+) 사용 불가 — web tsconfig `target: ES2017`
- `/gs` 플래그의 `s` (dotAll, ES2018+) 사용 불가 → `\*\*(.+?)\*\*/g` 로 대체
- `\u{XXXX}` 코드포인트 이스케이프 + `u` 플래그는 ES2015+ ✅

## 6. UX 정책

| 상황 | 동작 |
|---|---|
| TTS off (기본) | `callTts()` 미호출 — API 비용 없음 |
| 새 AI 메시지 도착 | 이전 재생 즉시 중단 → 신규 발화 |
| AI 응답 생성 중 (`isLoading`) | 재생 중인 음성 즉시 stop |
| API 실패 / 네트워크 오류 | 무음 처리 (오류 메시지 노출 없음) |
| 토글 off 전환 | 재생 중이면 즉시 stop |
| 모듈 이동 / 새로고침 | localStorage에서 이전 토글 상태 복원 |
| 기기 시스템 무음 | API 호출은 발생 (토글 ON 시) — 브라우저 API로 감지 불가, 별도 처리 없음 |
