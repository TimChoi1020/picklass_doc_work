## 개요

CLR(Comprehension & Learning Reading) 지문 패널에 TTS를 연동하여, 학습자가 지문을 귀로 들으며 읽을 수 있도록 한다.

기존 FeedbackPanel TTS(선생님 음성, `20260702_AI메시지_TTS_선생님음성_개발계획.md`)와 별개로,
**지문 전체를 연속 재생**하는 기능이며 WPM 속도 조절을 함께 제공한다.

**제공 기능:**
- 재생 / 정지 컨트롤 박스 (ContentPanel 헤더 우측)
- WPM 속도 조절 슬라이더 — 70 ~ 150 WPM, 10 WPM 단위 (9단계)
- 재생 상태 시각 피드백 (로딩 스피너, 재생 중 표시)
- WPM 설정값 localStorage 저장 (재방문 시 유지)

## CLR 렌더링 축과 TTS 배치 근거

CLR 모듈 DB 설정:

| DB 축 | 값 | 의미 |
|-------|-----|------|
| `passage_mode` | `full` | 처음부터 지문 전체 공개. **floatingTimer 없음** |
| `ui_template` | `embedded` | 별도 문항 패널 없음. ContentPanel 내 SentenceExplainPopover 임베드 |
| `question_count` | `content-driven` | 지문 문장 수 기반 완료 조건 |

`passage_mode: 'full'`이면 `usePassageMode`가 `floatingTimer: undefined`를 반환하므로
ContentPanel 헤더 우측이 비어 있다. 이 자리에 TtsPlayerBox를 배치한다.

**CLR 헤더 before / after 비교:**
```
[before]
┌─────────────────────────────────────────┐
│ 📖 지문 제목                            │
└─────────────────────────────────────────┘

[after]
┌─────────────────────────────────────────────────────────┐
│ 📖 지문 제목         [▶ 재생  ■ 정지]  [100 WPM ━━●━━] │
└─────────────────────────────────────────────────────────┘
```

## WPM ↔ Azure rate 변환

Azure Neural 음성 기본 속도 ≈ 150 WPM = rate 1.0.

```
rate = wpm / 150
```

| WPM | rate | 체감 |
|-----|------|------|
| 70  | 0.47 | 매우 느림 (입문) |
| 80  | 0.53 | 느림 |
| 90  | 0.60 | 느린 보통 |
| 100 | 0.67 | **기본값** (학습용) |
| 110 | 0.73 | 보통 |
| 120 | 0.80 | 빠른 보통 |
| 130 | 0.87 | 빠름 |
| 140 | 0.93 | 원어민 근접 |
| 150 | 1.00 | 원어민 자연 속도 |

SSML 적용 위치 (기존 `tts.service.ts` 수정 없이 `speed` 파라미터만 전달):
```xml
<prosody rate="${wpm / 150}">텍스트</prosody>
```

## 변경 파일 상세

### 1. `apps/web/src/lib/hooks/useTTS.ts` — 기존 파일 수정

WPM 상태 추가:

```typescript
const WPM_KEY = 'tts_wpm';
const DEFAULT_WPM = 100;

export function useTTS() {
  const [enabled, setEnabled] = useState(...);
  const [isFetching, setIsFetching] = useState(false);
  // 추가
  const [wpm, setWpm] = useState<number>(() => {
    if (typeof window === 'undefined') return DEFAULT_WPM;
    return Number(localStorage.getItem(WPM_KEY) ?? DEFAULT_WPM);
  });

  const changeWpm = useCallback((newWpm: number) => {
    setWpm(newWpm);
    localStorage.setItem(WPM_KEY, String(newWpm));
  }, []);

  const speak = useCallback(async (text: string) => {
    if (!enabled) return;
    stop();
    const clean = stripForTts(text);
    if (!clean) return;
    setIsFetching(true);
    const dataUrl = await callTts(clean, wpm / 150);  // speed 파라미터 전달
    setIsFetching(false);
    ...
  }, [enabled, stop, wpm]);

  return { enabled, toggle, speak, stop, isFetching, wpm, changeWpm };
}
```

> **주의**: 기존 FeedbackPanel의 `useTTS` 사용처(`speak(text)` 호출)는 변경 없음.
> speed 파라미터는 callTts 내부에서 처리하며, wpm 기본값(100)이 자동 적용된다.
