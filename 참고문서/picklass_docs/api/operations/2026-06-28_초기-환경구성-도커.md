# api.picklass.com 초기 환경 구성 (도커)

- 날짜: 2026-06-28
- 대상 저장소: `../api.picklass.com`
- 상태: 스캐폴드 완료(빌드/타입체크/린트 통과). 도메인 엔드포인트는 샘플 1세트.

## 결정 사항

| 항목 | 결정 | 근거 |
|---|---|---|
| 구조 | **단일 패키지 NestJS** (turbo/모노레포 X) | 웹 프론트 없는 순수 API |
| 데이터 접근 | **공유 Supabase DB 직접** (Prisma) | 기존 4개 서비스와 동일 조직 표준 |
| Prisma | **5.22 + `datasources.url`** | speaking/tutoring/backoffice 다수파와 일치 |
| 배포 | **Docker** | 본 서비스 운영 환경 |
| 인증 | **API Key + 원타임 토큰** 2종 | 기존 외부 API 두 패턴 통합 |

## 스택

NestJS 11 · TypeScript 5(ES2021, commonjs, strict) · Prisma 5.22 · pnpm
부가: `@nestjs/swagger`(문서), `@nestjs/throttler`(rate limit), `helmet`(보안 헤더), `class-validator`/`class-transformer`.

## 디렉터리 (요약)

```
api.picklass.com/
├── Dockerfile · docker-compose.yml · .dockerignore
├── package.json · tsconfig(.build).json · nest-cli.json
├── eslint.config.mjs · .prettierrc.json · .env.example
├── prisma/schema.prisma          # 공유 DB read-only 서브셋 (마이그레이션 없음)
└── src/
    ├── main.ts · app.module.ts
    ├── config/env.validation.ts  # DATABASE_URL 필수 검증
    ├── prisma/                    # @Global PrismaModule/Service
    ├── common/
    │   ├── guards/{api-key,access-token}.guard.ts
    │   ├── filters/all-exceptions.filter.ts     # {code, message}
    │   ├── interceptors/logging.interceptor.ts
    │   └── decorators/{partner,access-token}.decorator.ts
    ├── health/                    # GET /api/v1/health (공개)
    ├── partners/                  # API Key 인증 (파트너 pull)
    └── handoff/                   # 원타임 토큰 인증 (학습 핸드오프)
```

## 부트스트랩(main.ts)

helmet → 글로벌 prefix `api` + URI 버저닝(`defaultVersion: '1'`) → ValidationPipe(whitelist/transform/forbidNonWhitelisted) → CORS(`ALLOWED_ORIGINS` 화이트리스트, 미설정 시 차단) → Swagger `/docs`.
글로벌 provider: `ThrottlerGuard` · `AllExceptionsFilter` · `LoggingInterceptor` (app.module 에 APP_GUARD/APP_FILTER/APP_INTERCEPTOR 로 등록).

## 엔드포인트

| 경로 | 인증 | 설명 |
|---|---|---|
| `GET /api/v1/health` | 없음 | 헬스 체크 |
| `GET /api/v1/partners/me` | API Key | 파트너 기관 스코프 확인(샘플) |
| `GET /api/v1/handoff/verify` | 원타임 토큰 | 토큰 검증 + 사용자/모듈/레슨 데이터 |
| `POST /api/v1/handoff/expire` | 원타임 토큰 | 토큰 만료 처리 |
| `GET /docs` | 없음 | Swagger UI |

## 도커 운영

```bash
cp .env.example .env          # 값 채우기
docker compose up -d --build  # 4200 기동
docker compose logs -f api    # http://localhost:4200/docs
docker compose down
```

Dockerfile: `node:20-slim` 멀티스테이지(base→build→runtime), openssl(Prisma 엔진) + corepack/pnpm, `prisma generate` 후 `nest build`, 비루트(`node`) 실행. compose 는 공유 Supabase 를 쓰므로 DB 컨테이너 없음, healthcheck 는 `/api/v1/health`.

## 스키마 동기화

`prisma/schema.prisma` 는 손으로 작성한 read-only 서브셋(`partner_api_keys`, `external_access_tokens`, `users`, `ai_modules`, `texts`, `course_lessons`). 실제 컬럼 정합은 `pnpm prisma:pull` 로 맞춘다. 마이그레이션 금지(타 서비스 소유).
