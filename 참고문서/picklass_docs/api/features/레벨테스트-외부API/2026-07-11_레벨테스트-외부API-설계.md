## 1. 목표·역할 분담

우유랩스 스피킹앱이 Doc B(8개 학습 모듈)와 **함께 레벨테스트(PT/AT)** 도 픽클래스 API로 제공받는다.

| 주체 | 책임 |
|---|---|
| **우유랩스 앱** | 시험 화면(문항 표시·녹음·타이머·결과 표시). 사용자 인터랙션 |
| **픽클래스 API** | 문항 출제(적응형) · 응답 채점 · **최종 레벨 산출** · 공인시험 환산 · 세션/결과 저장(`alt_*`) |

> 레벨 판정 로직(CAT·6대 루브릭·환산)은 **픽클래스 자산** → 채점·레벨은 반드시 픽클래스가 계산해 반환한다. 우유랩스는 결과를 받기만.

## 2. 시험 흐름 (기획서 §1·§10)

```
PT(신규 배치) / AT(재진단)
  P1 어휘 CAT       → 잠재 어휘량 레벨 (P2 시작난이도·환산 0.5가중)
  P2 문장낭독 CAT   → 유창성·발음  (복합점수 상/중/하 → 다음문장 ±)
  P3 일상대화(6~10턴)→ 문법·표현·화용·어휘 4축(LLM 1회) + P4 진입판정
  P4 주제발표(조건부)→ 4축 + 유창성·발음 (평균 L7+ 시 진행, L6-/화용L4- 생략)
  최종레벨 = (어휘1.5+유창성1.5+발음1.0+문법1.5+표현1.0+화용성1.0)/7.5
           (P4 생략 시 P3로 대체, AT 하한보호)
```

**적응형(CAT)** 이 핵심 — P1·P2는 이전 응답 결과로 다음 문항 난이도가 정해진다. → API는 **세션 상태 기반 "다음 문항" 방식**(한 번에 전부 dump 불가).

## 3. 채점 공식 (기획서 인용 — 발명 아님)

| 파트 | 공식 |
|---|---|
| P1 어휘 | 자체 코퍼스 CAT, `picklass_rank` 기반 잠재 어휘량 레벨 |
| P2 낭독 | **복합점수 = WPM(50%) + 단어일치율(30%) + ASR confidence(20%)** → 상(≥목표·≥95%·≥0.85)/중/하, 다음문장 ±1~2 (§7-2) |
| P3 대화 | LLM 1회 호출 = 문법·표현·화용·어휘 4축 동시 + 오류문장 추출 (§8) |
| P4 발표 | ASR 전사 → LLM 4축 + ASR 유창성·발음 (§9) |
| 최종 | 6대 루브릭 가중합산 §10-1 + AT 하한보호 |
| 환산 | `alt_exam_conversion`(레벨→OPIc·TOEIC-S·IELTS·TOEFL 예상구간) §3-2 |

## 4. 외부 API 엔드포인트 (초안)

세션 상태 기반. 경로 컨벤션 `/external/*`(Doc B와 동일).

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/external/level-test/sessions` | 세션 시작(`testType: PT\|AT`). `alt_sessions` 생성. 반환: `sessionId` + 첫 문항(P1) |
| GET | `/external/level-test/sessions/:id/next` | 현재 상태의 다음 문항(적응형). 파트 전환·종료 신호 포함 |
| POST | `/external/level-test/sessions/:id/responses` | 파트별 응답 제출 → 채점 → 다음 문항 or 파트완료 반환. `alt_p1~p4_responses` 적재 |
| POST | `/external/level-test/sessions/:id/complete` | 최종 레벨 산출 + 환산 + 리포트 데이터. `alt_results` 적재 + `recordLevelChange` 재사용 |
| GET | `/external/level-test/sessions/:id/result` | 완료된 결과 재조회(리포트 6섹션 데이터) |

- 멱등·재시도: 세션 상태로 판정(같은 파트 재제출 방어).
- 문항 원천: `alt_p1_questions`·`alt_p2_sentences`·`alt_p3_topics/probes`·`alt_p4_topics`(시드 완료).

## 5. ✅ 확정 — ASR/음성 경계 = **A(전사+지표 전송)** (2026-07-11)

**우유랩스가 전사문 + WPM·confidence·단어일치율을 보내고, 픽클래스는 공식 적용 + P3/P4 LLM 채점 + 레벨산출.** (우유랩스가 자체 ASR 보유). 아래 원표 유지.

### (원) 핵심 결정 — ASR/음성 경계 (우유랩스 협의)

채점엔 WPM·단어일치율·ASR confidence·전사문이 필요. **누가 음성인식(ASR)을 하나?**

| 옵션 | 우유랩스가 보내는 것 | 픽클래스가 하는 것 | 비고 |
|---|---|---|---|
| **A. 전사+지표 전송(권장)** | 전사문 + WPM·confidence·단어일치율 | 공식 적용 + P3/P4 LLM 채점 + 레벨산출 | 우유랩스가 이미 ASR 보유(스피킹앱). 페이로드 가벼움 |
| **B. 오디오 전송** | 오디오 파일/스트림 | ASR + 전사 + 전 채점 | 픽클래스 ASR 인프라 필요, 무거움. IP 통제↑ |

> 권장 **A** — 우유랩스는 AI 스피킹앱이라 ASR 산출물(전사·지표)을 이미 만든다. 픽클래스는 지표를 받아 **공식·LLM·레벨**만 담당. (P3/P4 LLM 채점은 픽클래스 Gemini)

## 6. 인증

- Doc B는 원타임 `X-Access-Token`(핸드오프). 레벨테스트는 다-단계 세션이라 **세션 토큰**(시작 시 발급, 이후 호출에 재사용)이 자연스러움.
- 후보: `/external/level-test/sessions` 시작 시 세션 스코프 토큰 발급 → 이후 `:id` 호출 검증. (또는 기존 파트너 키 + userId)

## 7. `alt_*` 테이블 연계 (이미 생성·시드됨)

- 세션: `alt_sessions`(PT/AT, previous_session_id 체인) → `alt_p1~p4_responses`
- 결과: `alt_results`(최종레벨·루브릭) + `alt_script_errors`(P3/P4 오류) + `alt_level_history`(recordLevelChange 재사용)
- 콘텐츠: `alt_p1_questions`(720)·`alt_p2_sentences`(216)·`alt_p3_topics`(50)·`alt_p4_topics`(50)·`alt_exam_conversion`(18)

## 8. 미해결·협의

- **ASR 경계**(§5) — A/B 확정.
- **LLM 채점** — 픽클래스 Gemini 사용(P3/P4). 프롬프트·4축 루브릭 매핑 상세.
- **P3 동적 생성**(AT 학습연계 주제) — 우유랩스엔 학습이력이 없음 → 픽클래스가 주제/probe 생성(§8-1 각주). AT의 "직전 진단" 참조는 우유랩스 유저 식별 필요.
- **우유랩스 유저 ↔ 픽클래스 user 매핑** — Doc B는 verify 토큰의 uuid 기준. 레벨테스트도 동일 사용자 식별 필요.
- **엔드포인트·페이로드 세부** — 우유랩스와 규격 합의(Doc B처럼 별도 확정).
- **세션 만료·중단 재개** 정책.

## 9. 단계 계획

| 단계 | 내용 |
|---|---|
| P1 | 세션 스캐폴드 + `alt_sessions` 생성/조회 + P1(어휘 CAT) 출제·채점·레벨 |
| P2 | P2 낭독 복합점수 CAT(전사+지표 입력) |

## 10. 구현 근거 (2026-07-11 조사)

### 10-1. alt_ 스키마 (실DB 확인)
- `alt_sessions`(id int, **user_id**, test_type, previous_session_id, status, p4_executed, p1~p4_final_level, started/completed_at)
- `alt_p1_questions`(level, sentence, target_word, option_1~4, correct_option, coca_rank, **response_threshold_ms**, is_active) — 720행
- `alt_p1_responses`(session_id, question_id, item_sequence, selected_option, is_correct, response_time_ms, judgment, level_at_time, level_upper, level_lower)
- `alt_results`(6대 rubric_* smallint, final_level, cefr, opic/toeic_s/ielts/toefl_range, rubric_avg/stddev, cat_efficiency, p4_skipped_reason, prescription jsonb)

### 10-2. 🔴 해결한 블로커 — user_id 타입
- `alt_sessions.user_id`·`alt_results.user_id` = **integer**(legacy), 그러나 `users.id`·`alt_level_history.user_id` = **uuid**. → UUID 사용자 세션 저장 불가.
- **둘 다 0행 + FK 없음** → DDL `manual-sql/2026-07-11_p-alt-user-id-uuid.sql`(integer→uuid, 무손실). **Studio 적용 대기**.

### 10-3. P1 어휘 CAT 알고리즘 (기획서 §4·§6)
- **PT**: 시작 L9, 범위 L1~L18. 판정: **상**(정답+응답≤`response_threshold_ms`)→**+2**, **중**(정답+초과)→**+1**, **하**(오답)→**−1**.
- **AT**: 시작=직전 진단 레벨, 범위 ±4. 판정: 상→+2, 중→+1, **하 1회→유지**, **하 연속2회→−1**, **직전 레벨 이하 하향 불가**(하한보호).
- P1 결과 → `p1_final_level` + P2 시작난이도 + 어휘 루브릭(환산표 0.5가중).

### 10-4. P1 잔여 미확인 (구현 전 확인)
- **CAT 종료조건**(수렴 폭/최대 문항수) — 기획서 §6 표가 잘림 → `P-ALT_콘텐츠_개발.md`/DB설계 §5.2(level_upper/lower)로 확인 필요.
- **외부 사용자 식별/인증** — 우유랩스 유저 → picklass user uuid 매핑(Doc B verify 토큰 재사용 여부).

### 10-6. 공인시험 환산 = LLM (OMP 정합) — 확정(2026-07-11)
- **P4(1분 주제발표) = 우유랩스 OMP 모듈과 동일 채점.** 공인시험(OPIc·토익S) 환산은 **고정 공식/표가 아니라 LLM이 직접 산출**한다(스피킹 모듈 시나리오 §8.12: "[LLM] 1회 = 5축 + 4영역 + OPIc·토익S 환산 + 코칭").
- 흐름: **전사문(우유랩스 전송, §5-A) → 픽클래스 LLM 1회 → 5축 + OMP 4영역(logic·expression·pronunciation·time) + OPIc·토익S 환산 + 코칭.**
- OMP KPI 7종: `MLU_LENGTH`·`TOTAL_UTTERANCE`(STT) + `PRESENT_FLUENCY`·`PRESENT_STRUCT`·`PRESENT_CONTENT`·`GRAMMAR_ERROR`·`EXPRESSION_APPROP`(LLM) — [module-kpi-mapping §OMP].
- → **환산표/계산식 신규 구현 불요.** LLM 프롬프트만. `alt_exam_conversion`(레벨→예상구간)은 P-ALT 최종레벨 표시용으로 병존.
- 문서: 스피킹 모듈 시나리오 §8.12 · module-kpi-mapping §OMP · kpi-catalog · KPI수식엔진(프롬프트) · results-payload §1.

## 11. 구현 진척 — P1 완료 (2026-07-12)

- **모듈**: api `src/level-test/`(controller·service·module). `app.module` 등록. 부팅·라우트 매핑·가드(파트너키 401) 확인.
- **엔드포인트**: `POST /external/level-test/sessions`(PT/AT 시작→세션ID+P1첫문항), `POST /external/level-test/sessions/:id/p1-answers`(답안→채점·CAT이동→다음문항 or 수렴레벨).
- **CAT 엔진**(순수 함수 `judgeP1`·`nextP1Level`·`countTrailingBelow`): 상(정답+≤threshold)+2 / 중(정답+초과)+1 / 하(오답)−1(PT). AT: 하1회 유지·연속2회−1·하한보호. 5턴 수렴 → `alt_sessions.p1_final_level`.
- **상태 무상태화**: 세션 상태를 `alt_p1_responses`로 도출(서버 무상태). 정답 노출 안 함.
- **검증**: typecheck/lint/build 0. **e2e 22/22**(순수 판정 12 + 실서비스 10: L9시작·exceeds+2·출제 9·11·13·15·17·수렴18·5행 저장). 잔여물 0.
- **미확정(P1)**: 수렴레벨 산식은 "마지막 이동 레벨" 채택(궤적 bounds는 level_upper/lower 기록) — 정밀 수렴식(브래킷 중앙 등) 필요 시 교체 지점 1곳.
- **인증**: 현재 파트너 API Key(Bearer). 우유랩스 실제 핸드오프(verify 토큰으로 picklass userId 확보)는 Doc B 정합 협의.

### P2 완료 (2026-07-12)
- **엔드포인트**: `POST /external/level-test/sessions/:id/p2-start`(P1 수렴레벨 시작→첫 낭독문장), `POST .../p2-answers`(전사 지표 제출→복합점수→다음 or 수렴레벨).
- **복합점수**(순수 `judgeP2`): WPM(50%)+단어일치율(30%)+ASR conf(20%). 3축 등급→종합(하 하나라도 below/모두 상 exceeds/그외 meets). 레벨이동은 `nextP1Level` 재사용.
- **입력**(결정 A): 우유랩스가 `actualWpm·wordMatchRate·asrConfidence`(+audioUrl?) 전송. `target_wpm`은 문장에서. → `alt_p2_responses` 적재.
- **종료(해석)**: 최소3~최대7, 최소3 이후 첫 '하'(천장) 또는 7. 수렴레벨=마지막 통과(상/중) 문장 레벨.
- **검증**: typecheck/lint/build 0. **e2e 16/16**(판정 7 + 실서비스 9: 9→11→13 상승·below 종료·수렴11·3행 저장·p2_final_level). 잔여물 0.

### P3 완료 (2026-07-12)
- **LLM 인프라 신규**: api에 `@google/genai`(pnpm) + `src/llm/LlmService`(gemini-2.5-flash+2.0-flash fallback, speaking 미러). `GEMINI_API_KEY`는 speaking에서 api `.env`로 복사.
- **엔드포인트**: `POST .../p3-start`(레벨 적합 대화 주제+오프너), `POST .../p3-turns`(전사문 제출→다음 질문 or 채점).
- **흐름**: `alt_p3_topics`(레벨 적합) 선정 → `alt_p3_probes` 순서로 질문 출제(pending 턴 행) → 6~10턴 전사문 수집(`alt_p3_turns`) → **LLM 1회 4축 채점**(문법·표현·화용·어휘 1~18 + 오류 추출) → `p3_final_level`=4축 평균, `alt_results` 4축 upsert.
