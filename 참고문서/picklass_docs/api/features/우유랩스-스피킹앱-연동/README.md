# 우유랩스 스피킹앱 ↔ 픽클래스 연동

## 확정된 결정 (2026-06-28)

| 항목 | 결정 |
|---|---|
| **구현 범위** | **Doc B 세 API만** — `/external/verify` 확장, `/external/results` 신설, `/external/tokens/expire` 재사용 |
| **Doc A 범위** | 파고다↔우유랩스 중 **8(출석완료)·9(수료완료) 우선, 10(평가) 추후**, 1~7 제외. (우유랩스 책임이나 픽클래스가 데이터 공급) |
| **데이터 정본** | `스피킹모듈 데이터 샘플_최종.xlsx` — 콘텐츠 값·모듈명·필드 형태는 엑셀 기준으로 제공 |
| **경로 컨벤션** | **계약대로 `/external/*`** (버전 prefix 없이, tutoring 선례와 동일) |
| 인증 | 원타임 액세스 토큰 (`X-Access-Token` + `X-Module-Code`) — 기존 handoff 재사용 |

## 연동 주체

```
파고다(LMS)  ←Doc A(10 API)→  우유랩스(스피킹앱/외부업체)  ←Doc B(3 API)→  픽클래스(우리)
```

- **픽클래스 = 우리.** 우유랩스 = 외부 고객사. Doc A는 픽클래스 직접 당사자가 아니나, 우유랩스가 파고다에 보낼 데이터(출석 총평·교정·평가·추천과정)의 원천이 픽클래스 AI 산출물이므로 `/external/results` 설계에 반영한다.
