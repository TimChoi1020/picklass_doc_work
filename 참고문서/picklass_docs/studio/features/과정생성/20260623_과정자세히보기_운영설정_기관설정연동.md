## 1. 한 줄 요약

> **과정 생성 화면에만 적용되어 있던 기관설정 제약을 과정 자세히보기(편집) 화면의 `운영 설정` 탭에도 동일하게 적용한다. 강사가 과정 편집 시 기관 설정 범위를 우회하는 것을 막는다.**

---

## 2. 배경

| 화면 | 기관설정 제약 상태 (작업 전) |
|---|---|
| 과정 생성 (`/course` → `course/page.tsx`) | 적용 완료 — `useInstitutionSettings()` 사용 |
| 과정 편집 (`/course/[courseId]` → `CourseEditModal.tsx`) | **미적용** — `OperationSettingsTab`이 institution settings 무관하게 자유 변경 허용 |

과정 생성 시에는 기관설정을 반영하더라도, 동일 과정을 편집할 때 제약이 없으면 기관 설정을 우회할 수 있었다.

---

## 3. 적용 항목

과정 생성 화면(`course/page.tsx:1598-1664`)의 패턴을 `OperationSettingsTab`에 이식했다.

| `institution_settings` 필드 | 운영 설정 탭 적용 내용 |
|---|---|
| `free_learning_enabled` | `false`면 "허용" 버튼 disabled + 반투명, "비허용"만 선택 가능 |
| `max_frt_module_minutes` | 초과하는 FRT 시간 프리셋(5·10·15·20·25·30분) disabled |
| `allowed_mic_modes` | 목록에 없는 마이크 모드 버튼 disabled |
| `mic_mode_user_change` | `false`면 "학습자 모드 변경 허용" 체크박스 disabled + "(기관 설정에 의해 비활성)" 안내 |
| `max_total_class_minutes` | 이 화면에 전체 수업시간 입력 없음 → 해당 없음 |
| `default_completion_*` | 기본값 제안이지 상한 제약 아님 → 이수 조건 섹션은 제약 없음 |

## 4. 구현

### 4.1 변경 파일

| 파일 | 분류 | 내용 |
|---|---|---|
| `apps/web/src/components/CourseEditModal.tsx` | 프론트엔드 | 기관설정 훅 추가 + UI 제약 |

| `apps/api/src/courses/courses.service.ts` | 백엔드 서비스 | `update()` JSONB 저장 로직 추가 |

### 4.2 프론트엔드 — `CourseEditModal.tsx`

**import 추가** (line 22):
```ts
import { useInstitutionSettings } from '@/hooks/use-institution-settings';
```

**상수 추가** (TABS 선언 직후):
```ts
// 기관설정 로드 전 폴백 — permissive (로드 완료 전 UI가 잠기지 않도록)
const DEFAULT_INSTITUTION_SETTINGS = {
  maxFrtModuleMinutes: null as number | null,
  freeLearningEnabled: true,
  allowedMicModes: ['push_to_talk', 'hybrid', 'always_on'] as MicMode[],
  micModeUserChange: true,
};
```

> 폴백을 permissive(`freeLearningEnabled: true`)로 설정한 이유:
> 기관설정 API 응답이 오기 전에 UI가 잠겨 강사가 아무것도 선택하지 못하는 상황을 방지한다.
> 로드 완료 후 실제 설정이 적용된다.

**`OperationSettingsTab` 훅 추가**:
```ts
const { data: institutionSettings } = useInstitutionSettings();
const settings = institutionSettings ?? DEFAULT_INSTITUTION_SETTINGS;
```

### 4.3 프론트엔드 — UI 변경 상세

#### 나만의 수업 (자유 학습)
```tsx
<button
  onClick={() => setFreeLearning(true)}
  disabled={!settings.freeLearningEnabled}
  className={`... ${!settings.freeLearningEnabled
    ? 'opacity-30 cursor-not-allowed ...'
    : freeLearning ? '...선택...' : '...미선택...'}`}
>
  허용
</button>
```
기관이 비허용이어도 기존 DB 저장값(허용)을 read-only로 보여주되, "허용"으로 **다시 설정하는 것**은 막는다.

#### FRT 시간
```tsx
const isDisabled = settings.maxFrtModuleMinutes !== null && min > settings.maxFrtModuleMinutes;
```

#### 마이크 모드
```tsx
const isDisabled = !settings.allowedMicModes.includes(value);
```

#### 학습자 모드 변경
```tsx
<input
  checked={micUserChange && settings.micModeUserChange}
  disabled={!settings.micModeUserChange}
  ...
/>
<span>
  학습자 모드 변경 허용
  {!settings.micModeUserChange && <span>(기관 설정에 의해 비활성)</span>}
</span>
```

### 4.4 백엔드 수정 — 저장 버그 수정

운영 설정 저장 버튼이 동작하지 않는 버그가 동반 발견되어 함께 수정했다.

#### 원인
`PATCH /courses/:id` 엔드포인트에 `ValidationPipe({ whitelist: true })`가 전역 적용되어 있어,
**DTO에 선언되지 않은 필드는 컨트롤러 도달 전에 모두 제거**된다.
`UpdateCourseDto`에 `course_options`, `speaking_options`가 없었으므로 프론트가 보내도 서버에서 무시됐다.

#### `apps/api/src/courses/dto/courses.dto.ts` — `UpdateCourseDto`에 필드 추가

```ts
@IsObject()
@IsOptional()
course_options?: CourseOptions | null;

@IsObject()
@IsOptional()
speaking_options?: SpeakingOptions | null;
```

`CreateCourseDto`에는 이미 있었으나 `UpdateCourseDto`에 누락되어 있었다.

#### `apps/api/src/courses/courses.service.ts` — `update()` 저장 로직 추가

기존 `updateData`는 `Record<string, string | number | string[] | null>` 타입이라 JSONB 값을 담을 수 없다.
`Prisma.InputJsonValue` / `Prisma.DbNull`을 허용하는 `jsonUpdateData`를 별도 구성해 Prisma에 전달한다.

```ts
const jsonUpdateData: Record<string, unknown> = { ...updateData };
if (dto.course_options !== undefined) {
  jsonUpdateData['course_options'] = dto.course_options
    ? (dto.course_options as unknown as Prisma.InputJsonValue)
    : Prisma.DbNull;
}
if (dto.speaking_options !== undefined) {
  jsonUpdateData['speaking_options'] = dto.speaking_options
    ? (dto.speaking_options as unknown as Prisma.InputJsonValue)
    : Prisma.DbNull;
}

// Prisma.update에 jsonUpdateData 전달
```

> `null`을 그대로 넘기면 Prisma가 필드를 무시한다. JSONB 컬럼을 명시적으로 null로 저장하려면 `Prisma.DbNull`을 사용해야 한다.

## 5. 미적용 항목 (범위 밖)

- **기관설정 서버 검증**: `PATCH /courses/:id`에서 기관설정 한도 초과 여부를 서버에서 재검증하는 로직은 미추가. 현재는 프론트 UI 제약만 있다. 조작 우회 차단이 필요하다면 `courses.service.ts`의 `update()`에 `create()`의 `assertWithinInstitutionLimits` 패턴을 이식해야 한다.
- **이수 조건**: `default_completion_*`는 상한이 아닌 기본값이므로 제약 없음.
- **`max_total_class_minutes`**: 운영 설정 탭에 전체 수업시간 입력 필드가 없으므로 해당 없음.

## 6. 검증 항목

### 기관설정 UI 제약
- [ ] `freeLearningEnabled=false` 기관 소속 강사 → "허용" 버튼 disabled
- [ ] `maxFrtModuleMinutes=15` 기관 → 20·25·30분 FRT 프리셋 disabled
- [ ] `allowedMicModes=['push_to_talk']` → Hybrid, Always on 버튼 disabled
- [ ] `micModeUserChange=false` → 체크박스 disabled + 안내 문구 표시
- [ ] 기관 미소속 / 설정 없음 → 전 항목 활성, 기존과 동일 동작
- [ ] 기관설정 API 응답 전(로딩 중) → 제약 없이 정상 렌더링

### 저장 동작
- [ ] 저장 버튼 클릭 → `course_options`, `speaking_options` DB에 정상 저장
- [ ] 저장 후 탭 재진입 → 저장된 값이 UI에 복원됨
- [ ] `speaking_options=null` (tutoring 과정) → DB에 `null` 저장, 오류 없음
