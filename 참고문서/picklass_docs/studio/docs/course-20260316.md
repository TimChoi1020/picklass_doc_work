## 3. 정책 (Policy / Business Rules)

### 상태 정책
- `in-use` = 수업진행중 → 빨간 뱃지, 수정 불가 (현재 UI 미구현, 향후 적용 필요)
- `not-used` = 수업진입전 → 회색 뱃지, 수정 가능
- 생성 시 기본값: `not-used` (마법사 완료 시)

### 과정 생성 마법사 정책
- Step 1 필수 입력: 과정명, 레슨 회차(1~100), 레벨, 단어수, 장르(1개 이상)
- Step 1 → Step 2 전환 시 AI 자동 주제 생성 (현재 시뮬레이션, 실제 AI 미연동)
- 장르는 복수 선택 가능 (Select 컴포넌트 + ChevronDown 드롭다운)
- 모듈은 레벨+장르 기반으로 자동 추천 (`getRecommendedModules`)
- `topicsSource`: 'ai' = AI 생성, 'lesson' = 기존 레슨에서 선택
- 레슨 선택 시 해당 레슨의 title/level/genre/wordCount로 회차 데이터 덮어쓰기

### 삭제 정책
- 삭제 시 AlertDialog 확인 필수 (`confirm()` 직접 사용 금지)
- 삭제 후 toast.success 표시

### 정책 변경 사항 (이전 문서 대비)
- **과정 수정 버튼 제거**: 과정 행 오버레이에서 "수정" 버튼 삭제 → "자세히 보기"로 상세 페이지 이동
- **과정 상태 라벨 변경**: '배포 중'/'미배포' → '수업진행중'/'수업진입전'
- **장르 정책 변경**: 이전 문서의 '일반영어, 비즈니스, 발음...' → `@classsnap/shared`의 `GENRES` 상수로 대체 (뉴스기사, 설명문, 대화문 등 텍스트 기반 장르)
- **모달 분리 철회**: CreateCourseModal/EditCourseModal 별도 컴포넌트 없음 → page.tsx 인라인 마법사 Dialog

## 8. DB/API 구조 (Data Contract)

### 현재 상태
- 데이터: `mockCourses` 상수 (3개 하드코딩)
- API 미연동

### Course 인터페이스

```typescript
interface Course {
  id: string;                    // UUID
  round: number;                 // 목록 순번
  title: string;                 // 과정명
  lessonCount: number;           // 레슨 수
  deploymentCodeCount: number;   // 배포코드 수
  studentCount: number;          // 수강자 수
  status: 'in-use' | 'not-used'; // 수업 상태
  level: string;                 // CEFR 레벨
  genre: string;                 // 장르
  goal: string;                  // 과정 목표
  wordCount: string;             // 단어 수 범위 (예: '100~200')
}
```

### 향후 API 설계 (예정)

```
GET    /api/courses              → Course[] 목록 (검색, 레벨, 장르, 페이지 필터)
POST   /api/courses              → 과정 생성 (마법사 2단계 완료 데이터)
DELETE /api/courses/:id          → 과정 삭제
POST   /api/courses/:id/access-code → 액세스코드 생성
```

### 과정 생성 Request Body (예정)

```typescript
interface CreateCourseRequest {
  title: string;
  goal?: string;
  level: string;
  genre: string[];          // 복수 선택
  lessonRound: number;
  wordCount: string;        // 단어 수 범위
  lessons: Array<{
    round: number;
    topicSource: 'ai' | 'lesson';
    lessonId?: string;      // topicSource === 'lesson' 일 때
    topic: string;
    wordCount: string;
    genre: string;
    modules: string[];      // 모듈 코드 배열
  }>;
}
```

### DB 테이블 설계 (예정)

```sql
CREATE TABLE courses (
  id               UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title            VARCHAR(100) NOT NULL,
  goal             TEXT,
  level            VARCHAR(10) NOT NULL,
  genre            VARCHAR(50) NOT NULL,
  word_count_range VARCHAR(20),
  lesson_count     INTEGER DEFAULT 0,
  deployment_count INTEGER DEFAULT 0,
  student_count    INTEGER DEFAULT 0,
  status           VARCHAR(20) DEFAULT 'not-used',
  sort_order       INTEGER DEFAULT 0,
  created_by       UUID REFERENCES users(id),
  created_at       TIMESTAMP DEFAULT NOW(),
  updated_at       TIMESTAMP DEFAULT NOW()
);
```
