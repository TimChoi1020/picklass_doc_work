# 수업 시퀀싱 — 쉬운 설명서

**작성일**: 2026-04-24
**최종 수정**: 2026-04-24 (로직 정정)
**대상 독자**: 기획자, 디자이너, 신규 합류자, 비개발 팀원
**한 줄 요약**: 학생이 수업을 시작하기 전, 시스템이 활동을 어떻게 골라서 어떤 순서로 짜주는지 설명합니다.

## 들어가며 — 한 줄 비유

> **요리사가 코스 메뉴를 짜는 과정과 같습니다.**
>
> ① 손님 수준에 맞는 음식만 추리고
> ② 손님이 원하는 맛(목표) 중 하나라도 만족하는 것만 남기고
> ③ 식사 시간에 맞춰 너무 많으면 덜 중요한 것 빼고, 부족하면 옆 카테고리 음식까지 가져오고
> ④ 마지막으로 애피타이저 → 메인 → 디저트 순서대로 줄을 세웁니다.

## 시퀀싱은 2단계입니다

```
┌─────────────────────────────┐      ┌─────────────────────────────┐
│   1단계: 모듈 선정          │  →   │   2단계: 순서 정하기        │
│   (어떤 활동을 할지)        │      │   (어떤 순서로 할지)        │
└─────────────────────────────┘      └─────────────────────────────┘
```

---

## 1단계: 모듈 선정 (점점 줄어드는 깔때기)

```
[전체 모듈 21개]
      ↓
  ① 레벨 필터       ← 지문 레벨에 맞는 모듈만
      ↓
  ② KPI 합집합      ← 선택한 KPI들 중 하나라도 매칭되는 모듈
      ↓
  ③ 시간 조정       ← 시간에 맞춰 모듈 수 조정
      ├─ 부족: 옆 레벨까지 확장
      └─ 남음: 우선순위 낮은 것부터 버림
      ↓
[최종 선정된 모듈]
```

### ① 레벨 필터

지문 레벨이 A2면 → A2 레벨용 모듈만 남김.

```
전체 21개 중
A2 레벨용:  WSD, WRD, ORL, PWR, READ, FRT, GMN, ...
A1 레벨용:  (제외)
A3 레벨용:  (제외)
```

> ⚠️ 만약 매칭 모듈이 없으면 → **레벨이 먼저 확정되어야 함** (다음 단계 진행 불가)

### ② KPI 합집합 (중요!)

선택한 KPI **중 하나라도** 매칭되는 모듈은 모두 포함합니다.

**예시:** "발음 정확도" + "독해 속도" 선택한 경우

```
"발음 정확도"에 도움 되는 모듈:  {WSD, WRD, ORL, PWR}
"독해 속도"에 도움 되는 모듈:    {WSD, READ, FRT}

합집합 (중복은 1개로):
  {WSD, WRD, ORL, PWR, READ, FRT}   ← 6개
```

> 💡 **AND가 아니라 OR(합집합)** — 두 KPI 모두 만족하는 모듈만 골라내는 게 아닙니다.
> 한쪽 KPI만 매칭되어도 후보에 들어갑니다.

### ③ 시간 조정 (부족하거나 남으면 동적으로 조정)

#### 케이스 A: 시간보다 모듈이 **부족할 때**

```
20분 수업이면 보통 4~5개 활동 필요
그런데 합집합 결과가 2개뿐?

→ 레벨을 옆으로 확장해서 모듈 추가
  A2 → A1, A3 레벨용 모듈도 후보에 포함
```

#### 케이스 B: 시간보다 모듈이 **남을 때**

```
20분에 4개면 적당한데 합집합 결과가 8개?

→ ai_modules.priority 값 낮은 것부터 제거
  (priority 높음 = 중요 = 살림)
  (priority 낮음 = 덜 중요 = 버림)
```

## 2단계: 순서 정하기 (선정된 모듈을 줄 세우기)

```
[최종 선정 모듈]
       ↓
  ① 전/중/후로 분류        ← 1순위 조건 (수업 단계)
       ↓
  ② 같은 단계 내에서 인지레벨 정렬   ← 2순위 조건
       ↓
[최종 시퀀스]
```

### ① 전/중/후 (수업 단계, 1순위)

각 모듈은 백오피스에 **수업 어느 단계에 쓸지** 미리 정해져 있습니다:

```
class_before  : 수업 시작 전 (워밍업)
class_middle  : 수업 중간 (본 학습)
class_after   : 수업 마무리 (정리/복습)
```

**규칙:** before → middle → after 순서로 줄 세움.

### ② 인지 레벨 (2순위)

같은 단계(예: 모두 middle) 내에서는 **인지 레벨 1→6 순으로 정렬**.

```
1단계: 기억하기
2단계: 이해하기
3단계: 적용하기
4단계: 분석하기
5단계: 평가하기
6단계: 창조하기
```

쉬운 단계부터 어려운 단계로 점진적 진행.

### 정렬 예시

```
선정된 모듈 5개:
  WSD  (before, 인지1)
  WRD  (middle, 인지2)
  ORL  (middle, 인지2)
  PWR  (middle, 인지3)
  READ (after,  인지4)

정렬 후:
  1. WSD   (before, 1)   ← before 그룹
  2. WRD   (middle, 2)   ← middle 그룹 시작, 인지2
  3. ORL   (middle, 2)   ← 같은 인지2면 카탈로그 등록 순
  4. PWR   (middle, 3)   ← 인지3
  5. READ  (after,  4)   ← after 그룹
```

## 전체 흐름 한 장 요약

```
┌────────────────────────────────────────┐
│ 입력: 지문 레벨 + KPI들 + 수업 시간   │
└────────────┬───────────────────────────┘
             ↓
┌────────────────────────────────────────┐
│ 1단계: 모듈 선정                      │
│   ① 레벨 필터                          │
│   ② KPI 합집합 (OR, 중복 제거)         │
│   ③ 시간 조정 (확장 or 우선순위 컷)    │
└────────────┬───────────────────────────┘
             ↓
┌────────────────────────────────────────┐
│ 2단계: 순서 정하기                    │
│   ① 전/중/후 분류                      │
│   ② 같은 단계 내 인지레벨 1→6          │
└────────────┬───────────────────────────┘
             ↓
┌────────────────────────────────────────┐
│ 출력: 순서 정해진 활동 리스트         │
└────────────────────────────────────────┘
```

## 화면에서는 어떻게 보이나

### 동작 시점
**KPI + 수업 시간이 둘 다 선택되는 순간** 시스템이 자동으로 위 2단계를 실행합니다.
(지문 레벨은 이미 페이지 진입 시점에 확정됨)

### 모듈 리스트 표시
- 모듈 리스트 UI는 **변하지 않음** (전체 모듈 그대로 표시)
- 사용자가 모듈을 선택하면 **시퀀스 순서대로 번호 자동 부여**

### 예시

**상황:** 지문 A2, KPI = 발음 정확도, 시간 = 20분

```
시스템이 계산한 시퀀스 (내부):
  [1] WSD  (단어 인식)
  [2] WRD  (단어 학습)
  [3] ORL  (음독)
  [4] PWR  (발음 연습)

선생님이 "음독" 클릭
  → ☑ 음독 [1]    ← 선택된 것 중 1번

선생님이 "단어 학습" 추가 클릭
  → ☑ 단어 학습 [1]   ← 시스템 순서상 더 앞이라 1번
    ☑ 음독      [2]   ← 자동 갱신

선생님이 "발음 연습" 추가 클릭
  → ☑ 단어 학습 [1]
    ☑ 음독      [2]
    ☑ 발음 연습 [3]
```

> 클릭 순서랑 무관하게 **시스템 시퀀스 순서대로 자동 정렬**됩니다.

---

## 옵션을 바꾸면?

KPI 또는 수업 시간을 변경하면 → **즉시 1단계부터 다시 계산**

```
변경 전: 발음 정확도, 20분
변경 후: 독해 속도, 30분

→ ① 레벨 필터 (동일)
→ ② KPI 합집합 다시 (독해 속도 매칭 모듈로)
→ ③ 시간 조정 다시 (30분 기준)
→ 1단계, 2단계 전부 재실행
```

화면도 자동으로 재정렬됩니다.

## 부록: 자주 묻는 질문

**Q1. KPI를 여러 개 선택하면 모듈이 늘어나나요, 줄어드나요?**
→ **늘어납니다.** 합집합이라 KPI를 추가할수록 후보가 많아집니다.

**Q2. 시간을 짧게 하면 모듈이 적게 추천되나요?**
→ 네. 시간이 짧으면 우선순위 낮은 모듈부터 잘려나갑니다.

**Q3. 모듈이 부족하면 KPI에 안 맞는 것도 들어가나요?**
→ 아니요. KPI는 그대로 유지하고 **레벨을 옆으로 확장**해서 채웁니다.

**Q4. 인지 레벨이 같으면 어떤 순서가 먼저인가요?**
→ 백오피스 카탈로그에 등록된 순서(`sort_order`)를 따릅니다.

**Q5. 우선순위(priority)는 누가 정하나요?**
→ 백오피스에서 `ai_modules.priority` 값으로 관리합니다. (높을수록 중요)

**Q6. 같은 입력이면 항상 같은 결과가 나오나요?**
→ 네. 운영 DB가 바뀌지 않는 한 결정적(deterministic).

## 한 줄로 마무리

> **"지문 레벨로 일단 거른 뒤, 선택한 KPI 중 하나라도 만족하는 모듈을 모두 모으고, 수업 시간에 맞춰 부족하면 옆 레벨로 확장하고 남으면 덜 중요한 것을 버린다. 그렇게 골라낸 모듈을 전→중→후 단계 순으로, 같은 단계 안에서는 쉬운 인지 레벨부터 어려운 순으로 줄 세운다."**
