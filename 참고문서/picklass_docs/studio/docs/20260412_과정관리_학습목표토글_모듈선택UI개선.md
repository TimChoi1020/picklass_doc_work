## 1. User Flow

### 과정 생성 마법사 (1/2 → 2/2)

**Step 1/2 — 기본 정보 + 학습 목표 선택**
1. 과정명, CEFR 레벨, 단어수, 장르 입력
2. "과정 목표" 항목: 기존 textarea → **학습 목표 토글 버튼** 다중 선택
   - DB `ai_modules.learning_objectives` 필드에서 전체 목표 수집 (중복 제거 + 정렬)
   - 로딩 중이면 "학습 목표를 불러오는 중..." 문구 표시
3. "다음" 클릭 → Step 2/2

**Step 2/2 — 주제별 레슨 + 모듈 선택**
1. AI 주제 생성 또는 수동 입력
2. 레슨별 모듈 선택: 기존 checkbox 목록 → **카테고리별 토글 버튼** (선택 순서 뱃지 포함)

### 과정 상세 (`/course/[courseId]`)

**모듈 편집 모달**
- 기존: `bg-gray-900` 배경 + checkbox UI
- 변경: 흰 배경 모달 + 카테고리별 토글 버튼 (동일 디자인 패턴 적용)

## 3. Policy (정책/규칙)

- **학습 목표**: `ai_modules` 전체 레코드의 `learning_objectives` 배열을 flat + Set으로 중복 제거 + sort
- **selectedObjectives → 저장**: `selectedObjectives.join(', ')` 형태로 문자열 변환
  - `course_goal` (AI 주제 생성 프롬프트용)
  - `description` (과정 DB 저장용)
  - 기존 text 기반 소비와 하위 호환 유지
- **모듈 선택 순서**: 클릭 순서대로 1, 2, 3… 번호 뱃지 표시
- **선택 상태 토글 색상**:
  - 선택됨: `border-2 border-[#18c37e] bg-[#e9f9f3] text-[#008c5b]`
  - 미선택: `border-2 border-transparent bg-gray-100 text-gray-700`
- **순서 뱃지**: 우측 상단, 초록 원(`bg-[#18c37e]`), 흰 숫자

## 4. Dev Tasks (구현 내용)

### 4-1. `useLearningObjectives` 훅 추가

**파일**: `apps/web/src/hooks/use-modules.ts`

```typescript
export function useLearningObjectives(): string[] {
  const { data } = useModulesList();
  if (!data) return [];
  const all = data.data.flatMap((m) => m.learning_objectives);
  return [...new Set(all)].sort();
}
```

**UI 변경** — textarea → 토글 버튼 그리드:

```tsx
{/* 로딩 상태 */}
{learningObjectives.length === 0 ? (
  <p className="text-sm text-gray-400">학습 목표를 불러오는 중...</p>

  <div className="flex flex-wrap gap-2">

                ? selectedObjectives.filter((o) => o !== obj)
                : [...selectedObjectives, obj],
            )
          }
          className={`rounded-full px-3 py-1 text-xs transition-all cursor-pointer ${
            isSelected
              ? 'border-2 border-[#18c37e] bg-[#e9f9f3] text-[#008c5b] font-semibold'
              : 'border-2 border-transparent bg-gray-100 text-gray-700 hover:bg-gray-200'
          }`}
        >
          {obj}
        </button>
      );
    })}
  </div>
)}
```

## 5. Coding Rules

- `selectedObjectives.join(', ')` — 쉼표+공백으로 합치는 형식 고정 (AI 프롬프트 + DB 모두)
- 학습 목표 토글: `rounded-full` (둥근 pill 형태), 모듈 토글: `rounded-xl` (모서리 약간)
- 모듈 버튼 최소 너비: `min-w-[80px]` — 너무 짧아지지 않도록
- 뱃지 위치: `absolute right-1.5 top-1.5` — 버튼에 `relative` 필수
- `useLearningObjectives()`는 **클라이언트 컴포넌트**에서만 사용 가능

## 6. Known Issues

- **학습 목표 로딩 지연**: API 응답 전까지 "불러오는 중..." 표시. `learningObjectives.length === 0` 조건 사용 중 — `isLoading` 상태를 별도로 전달받는 방식으로 개선 가능.
- **모듈 선택 순서 초기화**: AI 주제 재생성 시 `selectedModulesPerTopic`이 추천 모듈로 리셋됨 — 의도된 동작이지만 사용자가 수동으로 조정한 내용이 사라질 수 있음.
- **학습 목표가 없는 모듈**: `learning_objectives = []`인 모듈은 목표 선택 UI에 영향 없음. Backoffice에서 목표를 채워야 의미 있는 선택지가 표시됨.
