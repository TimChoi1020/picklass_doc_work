## 2. 아키텍처 결정사항

### 2.1 API 이원화 원칙

`03-nestjs-backend.md`에 따라 **기존 Next.js API Routes와 신규 NestJS API를 분리** 운영한다.

```
┌─────────────────────────────────────────────────────────┐
│                    브라우저 (Client)                      │
│                                                          │
│   /class/* 기능          /course, /report 신규 기능       │
│        │                          │                      │
└────────┼──────────────────────────┼──────────────────────┘
         │                          │
         ▼                          ▼
┌─────────────────┐      ┌─────────────────────┐
│  Next.js API    │      │  NestJS API          │
│  Routes         │      │  (apps/api/)         │
│  (apps/web/)    │      │                      │
│  Port: 3000     │      │  Port: 3001          │
│                 │      │                      │
│  기존 20개 유지  │      │  신규 비즈니스 모듈    │
│  - /api/texts   │      │  - /courses          │
│  - /api/generate│      │  - /reports          │
│  - /api/*-feed  │      │  - /passages/analyze │
│  - /api/azure-  │      │  - /ai/topics        │
│    speech       │      │  - /auth             │
│  - /api/word-*  │      │  - /classes          │
│  - etc (20개)   │      │  - /code-items       │
└────────┬────────┘      └──────────┬───────────┘
         │                          │
         └──────────┬───────────────┘
                    ▼
           ┌──────────────┐
           │   Supabase   │
           │  PostgreSQL  │
           │  (공유 DB)    │
           └──────────────┘
```

### 2.2 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **기존 API 불변** | `/app/class/`가 사용하는 Next.js API Routes 20개는 절대 변경하지 않음 (01-cleanup.md, 02-extract-modules.md) |
| **신규 API는 NestJS** | Course, Report, PassageAnalysis, AI Topics, Auth 등 모든 신규 API는 NestJS에 구현 |
| **NestJS 마이그레이션 금지** | 기존 API를 NestJS로 옮기지 않음 (03-nestjs-backend.md 명시) |
| **Shared 패키지 활용** | 타입, 상수, 순수 유틸은 `@classsnap/shared`로 공유 (04-project-setup.md) |
| **동일 DB** | NestJS도 Supabase PostgreSQL에 연결 (SupabaseService 재사용) |

### 2.3 프론트엔드 API 호출 경로

```typescript
// 기존 class/ 기능 → Next.js API Routes (상대 경로)
const texts = await fetch('/api/texts');
const generated = await fetch('/api/generate-text', { method: 'POST', ... });

// 신규 기능 → NestJS API (NEXT_PUBLIC_API_URL, 04-project-setup.md §5.1)
const API_URL = process.env.NEXT_PUBLIC_API_URL; // http://localhost:3001
const courses = await fetch(`${API_URL}/courses`);
const report = await fetch(`${API_URL}/reports/students`);
const topics = await fetch(`${API_URL}/ai/topics`, { method: 'POST', ... });
```
