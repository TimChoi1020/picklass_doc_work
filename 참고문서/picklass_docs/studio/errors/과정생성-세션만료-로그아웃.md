# 오류: 과정 생성 중 세션 만료로 인한 로그아웃

> **최초 발견일**: 2026-07-02
> **최종 업데이트**: 2026-07-02
> **서비스**: studio.picklass.com3
> **관련 기능**: 과정 생성 (course/page.tsx)

---

## 증상 (Symptom)

과정 생성 마법사 진행 중 갑자기 로그인 페이지로 이동하거나 "세션이 만료되었습니다" 다이얼로그가 표시됨.
AI 지문 생성(여러 회차) 중 또는 폼 입력 도중에 발생.

---

## 원인 (Root Cause)

### 원인 1 — 세션 유휴 타임아웃

`IDLE_TIMEOUT_SECONDS=3600` (1시간): 마지막 NestJS API 호출 후 1시간 이내에 다음 API 호출이 없으면
`touchActivity()`가 `{ ok: false }`를 반환 → 401 → 로그아웃.

과정 생성 페이지는 초기 로드 시 React Query 쿼리를 실행한 후, **폼 입력 단계에서 NestJS API 호출이 전혀 없다.**
`refetchOnWindowFocus: false`, `staleTime: 5분`이므로 백그라운드 갱신도 없음.

```
// apps/api/src/auth/auth.service.ts:206
if (last > 0 && elapsed > this.idleTimeoutMs) {
  return { ok: false };  // → AuthGuard가 401 throw
}
```

### 원인 2 — JWT 클라이언트 사이드 만료 감지

`JWT_EXPIRES_IN=7d`. 7일 이상 재로그인 없이 사용 시, `getStoredToken()`이 토큰 삭제 후 null 반환.
Authorization 헤더 없이 요청 → 백엔드 401.

```
// apps/web/src/lib/auth-token.ts:24
if (exp === null || exp * 1000 <= Date.now()) {
  localStorage.removeItem(TOKEN_KEY);
  return null;
}
```

### 공통 트리거 — 즉시 강제 이동

```
// apps/web/src/lib/api.ts:105-110
if (response.status === 401 && path !== '/auth/login') {
  removeToken();
  window.dispatchEvent(new CustomEvent('auth:session-expired'));
}
// apps/web/src/components/AuthProvider.tsx (수정 전)
window.location.replace('/login');  // 작업 내용 유실
```

---

## 해결 방법 (Resolution)

### 1. 세션 킵얼라이브 훅 추가

`apps/web/src/hooks/use-session-keepalive.ts` 신규 작성.
4분 주기로 `/auth/me`를 호출해 `last_active_at`을 갱신. 과정 생성 페이지에 적용.

```typescript
// apps/web/src/app/course/page.tsx
useSessionKeepalive();
```

### 2. 유휴 타임아웃 연장

`apps/api/.env`

```
IDLE_TIMEOUT_SECONDS=3600  →  IDLE_TIMEOUT_SECONDS=7200
```

킵얼라이브 4분 간격 + 유휴 타임아웃 2시간 → AI 지문 대량 생성 시나리오도 여유 있게 커버.

### 3. 세션 만료 시 즉시 강제 이동 → 다이얼로그로 변경

`apps/web/src/components/AuthProvider.tsx`

`window.location.replace('/login')` 대신 `SessionExpiredDialog` 렌더.
사용자가 진행 중이던 작업 내용을 메모할 시간 확보 후 수동으로 로그인 페이지로 이동.

---

## 재발 방지 대책 (Prevention)

- 장시간 폼 입력이 있는 **모든 페이지**(과정 생성, 수정 등)에 `useSessionKeepalive()` 적용.
- `AuthGuard`에서 `!user || !hasValidToken()` 체크 시 킵얼라이브가 미처 못 막은 경우를 위한 안전망 유지.
- `.env` 변경(`IDLE_TIMEOUT_SECONDS`) 후 API 서버 반드시 재시작.
