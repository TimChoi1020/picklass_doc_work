## 4. 시퀀싱 설계

### 4.1 교육 5단계 vs DB 3플래그 매핑

Pick-Speak Method는 PICK → LEARN → DRILL → APPLY → MEASURE 5단계 교육 흐름을 가진다.
그러나 `ai_modules` 시퀀싱 컬럼은 세션 내 위치를 기준으로 **3개 boolean 플래그**로만 구분한다.

| 플래그 | 의미 | 해당 교육 단계 |
|---|---|---|
| `class_before = true` | 세션 본격 시작 전 — 도입·준비 영역 | **LEARN** (LRN) |
| `class_middle = true` | 세션 핵심 — 드릴 실습 영역 | **DRILL** (VLM·SHD·SFB·SMK) |
| `class_after = true` | 세션 이후 — 말하기 적용 영역 | **APPLY** (RPB·RPF·FRT·OMP) |

> 5단계 중 PICK(진입)과 MEASURE(측정)는 모듈 실행 단계가 아니라 시스템 흐름이므로 플래그에 반영하지 않는다.
> `open_before`, `open_after` 는 현재 speaking에서 사용 의미가 불명확. 기본값(`false`) 유지.

**모듈별 플래그 적용:**

| 모듈 | `class_before` | `class_middle` | `class_after` | 이유 |
|---|---|---|---|---|
| LRN | ✓ | ✗ | ✗ | LEARN 단계 — 세션 도입부 |
| VLM | ✗ | ✓ | ✗ | DRILL 워밍업 — 세션 실습 시작 |
| SHD, SFB, SMK | ✗ | ✓ | ✗ | DRILL — 세션 핵심 실습 |
| RPB, RPF, FRT, OMP | ✗ | ✗ | ✓ | APPLY — 세션 적용 실습 |

### 4.2 DRILL 내부 권장 순서

```
VLM (워밍업) → SHD (쉐도잉) → SFB (빈칸) → SMK (문장 만들기)
```

| 모듈 | priority | prerequisites | 비고 |
|---|---|---|---|
| VLM | 1 | `[]` | DRILL 선행 워밍업 |
| SHD | 2 | `["VLM"]` | |
| SFB | 3 | `["VLM"]` | SHD와 독립 — 동시 선택 가능 |
| SMK | 4 | `["SHD", "SFB"]` | 드릴 심화 — SHD·SFB 이후 |

> 시퀀서가 DRILL에서 1~2개만 선택할 때는 priority 오름차순으로 선택.
> SHD와 SFB는 상호 독립적으로 사용 가능.

### 4.3 APPLY 내부 권장 순서

```
RPB (표준 대화) · RPF (자유 대화) — 동시 선택 가능
FRT (자유 대화) — 독립
OMP (발표) — 독립
```

| 모듈 | priority | prerequisites | 비고 |
|---|---|---|---|
| RPB | 1 | `[]` | 표준 다이얼로그 연습 |
| RPF | 2 | `[]` | RPB와 동시 선택 가능. RPF만 단독 선택도 허용 |
| FRT | 3 | `[]` | 자유 대화 |
| OMP | 4 | `[]` | 발표 모듈 |

> 시퀀서는 priority 순서를 반드시 준수한다. RPB → RPF → FRT → OMP 순.
> RPB와 RPF는 같은 시나리오를 단계별로 활용하므로 동시 세션 선택이 가능하다.

### 4.4 비호환(incompatibleWith) 규칙

비호환 규칙을 적용하지 않는다. 모든 모듈의 `incompatible_with = []`.

시퀀서는 `class_before` / `class_middle` / `class_after` 슬롯 구분과 `priority` 순서만으로 실행 흐름을 제어한다. **priority는 반드시 준수**해야 한다.
