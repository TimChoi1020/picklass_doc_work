# **1\. 프로젝트 개요**

서비스명: Picklass AI Adaptive Level Test (P-ALT)

목적: 자체 코퍼스 기반의 어휘량 측정(Vocab Size)과 연동된 적응형 스피킹 진단. 6개 공통 루브릭 축으로 L1-L18 전 구간을 정밀 진단하며, 공인시험(OPIc·TOEIC Speaking·IELTS·TOEFL) 예상 점수와 연계하여 결과의 공신력을 제공합니다.

*핵심 철학: "아는 단어만큼 말할 수 있다. — Vocab Size 기반의 적응형 스피킹"*

## **1-1. 테스트 유형 체계 (v8.1 개정 — "PT 1회 + AT 체인")**

> **v8.1 개정 (2026-07-03)**: 기존 PT/AT-1/AT-2 3분류를 **PT/AT 2종**으로 단순화한다.
> "AT-1(Pre)/AT-2(Post)" 고정 짝을 폐지하고, **각 AT가 직전 진단과 비교되는 체인** 구조로 정리했다.
> 이유: 신규 사용자가 PT 직후 다시 AT-1을 봐야 하는 억지와 AT-1 시작점 모호성을 제거하기 위함.
> DB 반영: `P-ALT_DB_설계.md §5.1`.

| 유형 | 대상 | 시점 및 목적 | 결과 활용 |
| :---: | :---: | ----- | ----- |
| **Placement Test (PT)** | 신규 사용자(최초 자동) + **원하는 사용자 언제든** | 가입 시 자동 1회 → 반 편성·모듈 배치. 이후 재배치 원하면 재응시 | 레벨별 반 편성, 커리큘럼 경로 설정. **직후 AT의 baseline 겸함** |
| **Achievement Test (AT)** | 기존 사용자 (학습 후 성장 확인) | 학습 사이클 후 응시 → **직전 진단(PT 또는 직전 AT) 대비 성장** | 직전 대비 성장 \+ 공인시험 구간 변화 리포트. **자신도 다음 AT의 baseline이 됨** |

**체인 구조**

```
PT ─── AT ─── AT ─── AT ─── ...      (PT는 원하면 중간에 재응시하여 재-앵커 가능)
 │      │      │      │
 └──▶ baseline ◀──────┘   각 AT는 "직전 진단"과 비교 (previous_session_id)
```

- 하나의 AT는 **"직전 대비 Post"이자 "다음 대비 Pre"** 역할을 동시에 한다.
- 성장 = 이번 AT 레벨 − 직전 진단 레벨. 리포트: "**직전 진단 대비 +X**" (+ 선택적 "PT 누적 +Y").
- **하한 보호**: 이번 AT 레벨은 직전 진단 레벨 이하로 하락하지 않는다(§4-2).
- 첫 AT는 baseline이 PT라 교차 설정 비교이나 6대 루브릭 축 공통으로 유효, 2번째 AT부터 동일 설정.

## **1-2. 파트 구조**

| 단계 | 파트명 | 형식 | 측정 목표 | PT / AT 운영 차이 |
| :---: | ----- | ----- | ----- | ----- |
| **P1** | **Vocab Size** | 문장 내 밑줄 단어 뜻 찾기 (4지선다 CAT) | 어휘 레벨 확정 \+ P2 시작점 | PT: L1-L18 전 문항 / AT: **직전 진단 레벨 ±4** 구간 문항 |
| **P2** | **문장 낭독** | 수준별 문장 낭독 (최소3, 최대7문장 CAT) | 유창성·발음 독립 레벨 산출 | PT: L9 시작 / AT: **직전 진단 P2레벨 ±2** 출제. 하향 기준 엄격 |

| **P4** | **주제 발표\[IELTS P2형\](조건부)** | 1분 스피치 (IELTS P2형) | 발화 지속력 \+ 논리 전개 | P3 평균 L7 이상 시 실행. PT·AT 공통 조건 |

"L11이 어느 수준인가"보다 "OPIc IH 수준"이 학습자·학부모에게 훨씬 직관적입니다. P-ALT 레벨을 주요 공인시험 점수와 연계하여 결과의 공신력을 높이고, B2B 파트너사의 수강생 설득력을 강화합니다.

# **4\. 테스트 유형별 운영 기준**

## **4-1. PT vs AT 핵심 차이**

> AT의 기준점 "직전 진단"은 **PT 또는 직전 AT**(체인, §1-1)를 뜻한다.

| 항목 | Placement Test | Achievement Test |
| ----- | ----- | ----- |
| **문항 범위** | L1-L18 전 구간 | **직전 진단 레벨** ±4 구간 제한 |
| **CAT 시작점** | L9 고정 | **직전 진단 레벨** 고정 — 하향 출발 없음 |
| **하향 기준** | 판정 하 1회 → \-1 하향 | 연속 하 2회 → \-1 하향 (더 엄격) |
| **P3 주제** | 범용 일상 주제 | 학습 콘텐츠 연계 주제 우선 |
| **공인시험 연계** | 최종 레벨 \+ 공인시험 예상 구간 | **직전 진단 대비** 성장 \+ 공인시험 구간 변화 |
| **리포트** | 절대 레벨 \+ 6대 루브릭 \+ 스크립트 분석 | 성장률 \+ 루브릭 변화 \+ 스크립트 비교 |
| **응시 조건** | 최초 자동 + **원하면 언제든 재응시** | 학습 사이클 후 |

## **4-2. AT 전용 CAT 규칙 (직전 진단 기준)**

| AT CAT 판정 | 난이도 이동 | PT와의 차이점 |
| :---: | :---: | ----- |
| **상 (Exceeds)** | \+2 상향 | PT와 동일 |
| **중 (Meets)** | \+1 상향 | PT와 동일 |
| **하 1회** | 이동 없음 | PT는 즉시 \-1. AT는 일시적 컨디션 변수로 처리 — 레벨 유지 |
| **하 연속 2회** | \-1 하향 | 연속 2회만 실제 하락으로 처리. **직전 진단 레벨 이하로는 하향 불가** |

| *AT 하한 보호 규칙: AT 최종 레벨은 직전 진단(PT 또는 직전 AT) 레벨보다 낮아질 수 없습니다. 리포트에 "일부 루브릭 축 재점검 권장" 메시지를 함께 표시합니다.* |
| :---- |

## **4-3. AT 결과 표현 가이드라인 (직전 진단 대비)**

> v8.1 체인(§1-1): "AT-2 vs AT-1"이 아니라 **"이번 AT vs 직전 진단(previous_session)"** 으로 비교한다.

| AT 결과 (vs 직전 진단) | 리포트 헤더 표현 | 강조 방식 |
| ----- | ----- | ----- |
| 이번 AT \> 직전 진단 | L{N} 달성 — {기간} 학습 후 \+{X} 레벨 성장 | 레벨 성장 수치 \+ 공인시험 구간 향상 표시 |
| 이번 AT \= 직전 진단 | L{N} 유지 — {루브릭 강점 축} 향상 확인 | 전체 레벨 유지 \+ 상승 루브릭 축 전면 표시 |
| 이번 AT \< 직전 진단(하한 보호) | L{N} 현재 수준 — {루브릭 강점 축} 성장 확인 | "하락" 표현 금지. 성장 루브릭 강조 \+ 추가 학습 권장 |

| **P2** | **문장 낭독** | 수준별 문장 낭독 (최소3, 최대7문장 CAT) | 유창성·발음 독립 레벨 산출 | AT: 직전 진단 P2레벨 ±2 출제. 하향 기준 엄격 |

# **6\. P1 — Vocab Size 측정**

## **6-1. 설계 목적**

자체 구축 코퍼스 CAT 방식으로 잠재 어휘량을 측정합니다. 공인시험 환산표의 어휘 레벨 축에 0.5 가중치로 반영되며 P2 시작 난이도를 결정합니다.

## **6-2. CAT 판정 기준**

| 판정 | 기준 | 다음 문항 | 의미 |
| :---: | ----- | :---: | ----- |
| **상 (Exceeds)** | 정답 \+ 응답 시간 3초 이내 (즉각 인지) | \+2 상향 | 해당 레벨이 너무 쉬움 |
| **중 (Meets)** | 정답 \+ 응답 시간 3초 초과 (추론 후 선택) | \+1 상향 | 해당 레벨에 적합 |
| **하 (Below)** | 오답 (응답 시간 무관) | PT:-1 / AT:유지 | PT·AT 하향 기준 다름 |

> 1. **목표 WPM 하향**: 위 6밴드(L1 80~)는 실제 학습자 결과상 과도하게 높다는 관측에 따라 **L1=50 / L18=148 앵커의 18레벨 선형 보간**으로 하향 개정되었다. 실제 채점·콘텐츠 제작은 개정값을 따른다 → `P-ALT_콘텐츠_개발.md §3.1`.
> 2. **레벨 축 = CEFR(picklass_rank), COCA 아님**: "어휘 빈도 COCA n위" 밴드는 **참고 표기**이며, 실제 어휘 레벨링·검증은 `words_18levels_6000.picklass_rank`(CEFR 18단계)를 단일 권위 기준으로 한다. COCA(`frequency_rank`)는 부가 참고값 → `P-ALT_콘텐츠_개발.md §3a`, `P-ALT_DB_설계.md §4.1~4.2`.
