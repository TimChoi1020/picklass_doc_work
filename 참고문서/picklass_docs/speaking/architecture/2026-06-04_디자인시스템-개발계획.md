## 2. 타이포그래피

```css
font-family: 'Pretendard Variable', 'Pretendard', -apple-system,
             BlinkMacSystemFont, 'Apple SD Gothic Neo', 'Malgun Gothic',
```

### 2.2 폰트 크기 스케일

| 토큰 | px | rem | 용도 |
|---|---|---|---|
| `text-xs` | 10 | 0.625 | 캡션, 마이크로 |
| `text-sm` | 12 | 0.75 | 보조 텍스트, 라벨 |
| `text-base` | 14 | 0.875 | 본문 |
| `text-md` | 16 | 1.0 | 강조 본문, 버튼 |
| `text-lg` | 18 | 1.125 | 카드 제목 |
| `text-xl` | 20 | 1.25 | 섹션 제목 |
| `text-2xl` | 24 | 1.5 | 페이지 제목 |
| `text-3xl` | 28 | 1.75 | 화면 메인 헤더 |
| `text-4xl` | 32 | 2.0 | 표지·중요 숫자 |
| `text-5xl` | 48 | 3.0 | MEASURE 종합 점수 |

### 2.3 폰트 굵기

- `font-normal` 400 — 본문

**원칙**: `font-extrabold`(800) 이상 절대 사용 금지 (가독성 저하).

- 본문: `leading-relaxed` (1.625)
- 제목: `leading-tight` (1.25)

## 7. 핵심 컴포넌트 사양

### 7.1 5단계 진행 인디케이터 (모든 학습 화면 상단 고정)

- 5개 점·게이지가 가로 균등 배치
- 활성 단계: `bg-blue-500` (#3B82F6)
- 비활성: `bg-gray-200` (#e5e7eb)
- 가로폭: 화면 폭 60% 권장
- 높이: 4px (slim style)

### 7.2 마이크 버튼 (DRILL·RPL 등)

- 직경: 88px (대형) 또는 64px (보조)
- `bg-blue-500` 단색
- 활성 시 펄스 애니메이션 (`animate-pulse` 또는 framer-motion)
- 활성 ring: 8px blue-500 20% 투명도

### 7.3 4축/5축 피드백 그리드 (DRILL 시그니처)

- 2×3 그리드 (4축 + 발화량 통합 셀)
- 각 셀: `rounded-md` `p-2` `border-{color}/30`
- 셀 내부: 라벨 + 점수 + 게이지 바 + 1줄 피드백
- 게이지 바 높이: 4px
- 색상: 5대 KPI 토큰 그대로

### 7.4 5각 레이더 차트 (MEASURE)

- Recharts `RadarChart` 사용
- 5개 축: 발음·유창성·문법·화용성·발화량
- 메인 폴리곤: `stroke-primary` `fill-primary/20`
- 비교 폴리곤 (7일 평균): `stroke-border` `fill-transparent` `stroke-dasharray-2`

### 7.5 챌린지 미터 (FRT 시그니처)

- 가로 진행 바 + 카운터
- "지난 7일 평균 28문장 → 오늘 목표 30문장" 텍스트
- 실시간 업데이트 (학습자 발화 시 +1)
- 도달 시 `bg-success` 변경 + 콘페티 애니메이션

### 7.6 미션 카드 HERO (홈 화면)

- 화면 1/3 높이
- `bg-blue-500` (강의 이어하기 카드) / `bg-teal-500` (FRT 카드) `rounded-xl` `p-5`
- 내부: 아이콘 박스 + 제목 + 부제목 + 소요시간 + 진행률 바 + CTA 버튼
- CTA 버튼: `bg-white text-gray-900`, 클릭 시 `framer-motion` `scale: 0.98`

### 7.7 AI 캐릭터 카드 (RPL·챌린지)

- 아바타 + 이름 + 친밀도 단계 라벨
- 친밀도 게이지: `bg-kpi-flu` (보라)
- 5단계 표시: "Lv 3 친구"

### 7.8 KpiMiniRadar (홈 ProgressTrioWidget 내부)

홈 탭 3진척 위젯의 5축 점수 미니 레이더. 순수 SVG, `'use client'` 없음.

```
SIZE = 72px  CX = CY = 36  MAX_R = 26
ANGLES_DEG = [-90, -18, 54, 126, 198]   // pron, flu, gram, prag, vol 순서
```

- **50% 기준선**: `stroke-muted` `strokeWidth=0.5`
- **외곽 펜타곤**: `stroke-border` `strokeWidth=0.5`
- **축선 5개**: `stroke-muted` `strokeWidth=0.5`
- **데이터 폴리곤**: `fill=none` `stroke=#185FA5` `strokeWidth=1.5` (윤곽선만, KPI pron 색상)
- 하단에 `diffFromAvg` ±N점 표시: 양수 → `text-emerald-600`, 음수 → `text-rose-500`

### 7.9 챌린지 카드 공통 패턴 (망각곡선·표현카드 챌린지)

두 챌린지 섹션이 공유하는 UI 패턴:

```
<section>
  <div class="섹션 헤더 (제목 + 카운트/탭)">

  <div class="rounded-2xl border border-border bg-background overflow-hidden">
    <!-- 아이템 목록 -->
    <div class="divide-y divide-border">
      {items}
      {더 보기 버튼 (hasMore && !expanded)}
    </div>

    <!-- 단일 도전하기 버튼 -->
    <div class="border-t border-border p-3">
      <button class="w-full rounded-xl bg-primary py-2">도전하기</button>
    </div>
  </div>
</section>
```

**망각곡선 챌린지**: violet 테마 (`bg-violet-500`, Brain 아이콘, violet 배지)
**표현카드 챌린지**: primary 테마 버튼, 필터 탭(전체|미학습|마스터), Star 아이콘

### 7.10 발화량 챌린지 HERO

챌린지 탭 발화량 통계 카드. 흰 카드 (`bg-white border border-gray-200`).

```
[타이틀 + 메인 수치 (N문장)]   [연속 학습 🔥 N일]
[일간 | 주간 | 월간] 탭
[서브스탯 3칸 그리드 (발화속도 / 기간별 지표)]
[바 차트 — 주간(7일) or 월간(4주) 시 노출, 오늘 막대 흰색 강조]
```

기간별 서브스탯:
- **일간**: 발화속도 / 발화 문장 / 발화 시간
- **주간**: 발화속도 / 일 평균 / 최고 하루
- **월간**: 발화속도 / 주 평균 / 최고 기록

## 10. 접근성 (Accessibility)

- 모든 인터랙티브 요소 `aria-label` 필수
- 텍스트 vs 배경 대비 최소 4.5:1 (WCAG AA)
- 마이크 버튼에 `<button aria-label="음성 녹음 시작">`
- 5축 게이지에 `<div role="progressbar" aria-valuenow={75}>`
- 다크 모드 자동 대응
