## **8.0 공통 설계 원칙 (v1.5 재정의) ★**

v1.17.2 cross-ref ★: 자유 학습("나만의 수업")은 9개 모듈 중 FRT 단일만 사용 — 콘텐츠 자동 생성 시간·데이터 비용 대응 (6차 ㉟). 다른 모듈(LRN/VLM/SHD/SFB/SMK/RPB/RPF/OMP)은 자유 학습에서 호출되지 않는다. 정규 과정 시퀀싱(Part 13 §13.1)에서는 9개 모듈 모두 사용 가능. 자유 학습 FRT 옵션: 학습시간 10분 / 마이크 모드 PTT 고정.

| 원칙 | 내용 |
| :---- | :---- |
| 피클 페르소나 | 친근한 존댓말 · 칭찬·격려 중심 · 비판적 단어 지양 |

| 재시도 한계 | 모듈마다 다름 — 대부분 1회 또는 없음 (§8.4 매트릭스 참조) |
| 재도전 (모듈 전체) | 정답률 70% 미만 시 1회 자동 재도전 (1회 초과 불가). OMP만 재도전 불가 |

| :---- | :---- | :---- | :---- | :---- |

| VLM | 없음 | 없음 | 탭 강제 | ✗ |

### **재도전 흐름 (전 모듈 공통)**

첫 진행 종료 시 정답률 측정

┌─ 70% 이상 → 재도전 없음 → 5단계 완료  
└─ 70% 미만 → \[Seed\] "한 번 더 해볼까요? 익숙해질 거예요\! 🔄"  
자동 재도전 1회 시작 → 모듈 처음부터  
두 번째 사이클 종료 → 5단계 완료 (재도전 1회 초과 불가)  OMP만 예외: 재도전 불가 — 첫 진행 끝나면 무조건 5단계 완료

## **8.5 LRN — Learn & Study (강의 영상)**

> ★ LRN→SHD→SFB→SMK 표현 연계 1단계 — 레벨 N개 표현 **소개**

| 단계 | 내용 |
| :---- | :---- |
| 0 | 영상 \+ 표현 카드 N개 로딩 |
| 1 | \[Seed\] "오늘 강의 영상으로 시작\! 🎬" \+ 영상 인트로 \+ 표현 N개 미리보기 |
| 2 | 본 영상 자동 재생 (자막 ON) \+ 표현 카드 N장 순차 노출 |
| 3 | 표현 카드별 "이해했어요" / "다시 보기" 탭 (무발화 불가) |
| 4 | \[Slot\] "표현 N개 만남 완료\!" → 카드 N장 전부 "이해했어요" 완료 시 완료처리 (재도전 없음) |
| 5 | \[Seed\] "다음 모듈로 이동\! ✨" |

*측정: STAY\_TIME · READ\_COMPLETION / 서브웨이: ✓ / LLM: ✗*

## **8.7 SHD — Shadowing Drill ★**

> ★ LRN→SHD→SFB→SMK 표현 연계 2단계 — LRN에서 소개된 N개 표현 **따라말하기**

| 단계 | 내용 |
| :---- | :---- |
| 0 | 핵심 문장 N개 \+ TTS·IPA 로딩 |
| 1 | \[Seed\] "듣고 따라 말해보세요\! 🎙️" \+ 문장 수·발음 포인트 안내 |
| 2 | 좌상단 문장 \+ 원어민 음성 자동 재생 (3패스: 빠름 1.2 → 빠름 1.2 → 정상) |
| 3 | 마이크 발화 → ASR (무발화 불가) |
| 4 | 정답: \[Slot\] "딩동댕\! 🌟" / 오답: \[Slot\] \+ 1회 재시도. ASR 70% 미만 시 자동 재도전 1회 |
| 5 | \[Seed\] "쉐도잉 완료\! 🔥" |

*재시도: 1회/문장 / 측정: 5축 (발음·유창·문법·화용·발화량) / 서브웨이: ✓ / LLM: ✗*

## **8.13 FRT — Free Talking (시나리오 제외)**

v1.17 정정: FRT 옵션은 레슨 메타데이터의 frtOptions 객체에 부착된다 (학습 종료 조건 TIME/TOKEN · 마이크 모드 PTT/HYBRID/ALWAYS\_ON). 수강신청 default가 아닌 레슨 단위 적용 — §3.0 Tier 1 ③ 참조.

FRT는 개발 완료된 모듈로 본 통합기획서의 시나리오 명세에서 제외됨. 상세 진행 방식은 별도 "Picklass Speaking\_Free-talking 설계 v3.1" 문서 참조. FRT는 Phase 1(진입) · Phase 2(순환 루프 — 매 턴 LLM 호출) · Phase 3(종료) 3단계 구조로 운영되며, 본 Part 8의 6단계 표준과는 별개로 작동한다.

## **8.14 LLM 호출 비용 모델 (v1.5)**

| 모듈 | LLM 호출 / 세션 | 비고 |
| :---- | :---- | :---- |
| LRN · VLM · SHD · SFB · RPB · RPF | 0회 | Seed/Slot만 |
| SMK | 1\~2회 | 사이클당 1회 (재도전 발생 시 \+1) |
| OMP | 1회 | 재도전 불가, 사이클 1회만 |
| 합계 (FRT 미포함) | 2\~3회 / 세션 | 대부분 학습자 2회 |
| FRT (참고) | 5\~10회 | 매 턴 LLM 필수 (별도 모듈) |

v1.5 LLM 사용 최소화: 9개 모듈 중 SMK·OMP 2개만 LLM 사용. 대부분의 학습자가 첫 사이클 70% 이상이면 세션당 2회. 어려운 학습자의 SMK 재도전 발생 시 3회. 스피킹 엔진 개발 범위에 LLM 호출 단가 명시 \+ 비용 안정성 확보.

| 유창성 | Fluency | 발화 속도·끊김·휴지의 자연스러움 | WPM \+ 멈춤/분 | \#534AB7 |
| 문법정확성 | Grammar | 문장 구조·시제·일치 오류 | 오류/문장 | \#BA7517 |
| 화용성 ✦ | Pragmatics | 상황·역할·관계 적절 표현 사용률 | % (0\~100) | \#D4537E |
| 발화량 | Speech Output | 전 모듈 통합 누적 발화 문장 수 | 문장 (정수) | \#0F6E56 |

*화용성은 두 경쟁사가 측정 못하는 픽클래스 차별 지표. OPIc·토익S 시험 채점 기준의 핵심 항목과 직접 연결.*

## **9.2 v1.4 신규 KPI 2개 (서브웨이 모드 측정) — 절대 단위**

| KPI | 영문명 | 측정 정의 | 단위 |
| :---- | :---- | :---- | :---- |
| 듣기 누적 분 | Listening Minutes | 서브웨이 모드 4활동의 실청취 시간 | 분 (정수) |
| 섀도잉 카운트 | Shadow Count | 서브웨이 모드 "들었어요" 또는 머릿속 발화 완료 카드·문장·턴 수 | 회 (정수) |

v1.7 절대 단위 원칙: 100점 환산을 모두 폐기. 스피킹 엔진 ASR이 응답하는 절대 단위(%·WPM·오류/문장·문장 수)를 그대로 학습자 앱·B2B 리포트에 노출. 평균·환산·가중치가 필요한 경우 픽클래스 백엔드에서 별도 계산하며, 외부 노출에는 사용하지 않음.

## **9.3 모듈별 내부 측정 지표 — FRT 저장 데이터 구조 공통 사용 방침**

> **설계 방침**: 모듈별 내부 지표는 FRT에서 이미 검증·구현된 저장 데이터 구조를 전 모듈 공통으로 재사용하는 것이 가장 바람직하다. 모듈별 독자 스키마를 신규 설계하지 않고, FRT 저장 포맷을 확장·공유하는 방향으로 구현한다.

### **v1.7 KPI 계층 구조**

| 계층 | 개수 | 노출 범위 |
| :---- | :---- | :---- |
| 공식 외부 KPI | 5+2 \= 7개 | 학습자 앱 / B2B 리포트 / 스피킹 엔진 응답 / 파고다 운영툴 |

### **5축 ↔ 스피킹 엔진 응답 매핑 공식**

| 외부 KPI | 스피킹 엔진 응답 매핑 |
| :---- | :---- |
| 발음정확도 | ASR 음소 정확도 % (그대로) |
| 유창성 | ASR WPM \+ 멈춤/분 (그대로) |
| 문법정확성 | 스피킹 엔진 GRAMMAR\_ERROR 응답 → 오류/문장 (그대로) |
| 화용성 | EXPRESSION\_APPROP (EDR) \+ INTERACTION\_ACT (RPL) 가중 평균 — 백엔드 계산 |
| 발화량 | 전 모듈 응답의 sentence\_count 누적 — 백엔드 계산 |

스피킹 엔진은 절대 단위 값과 내부 8개 지표를 응답으로 제공. 평균·환산·가중치는 모두 픽클래스 백엔드 책임. 스피킹 엔진 응답 스키마는 Part 15 §15.3 Group C 참조.

## **9.4 Q/Q/G 3축 균형 (v1.7 정정 — 절대 단위 \+ Growth 단순화) ★**

7개 KPI를 "3축 균형"으로 묶어 피드백 탭에서 시각화. v1.7에서 "점수·도달%" 표기를 모두 폐기하고 절대 단위 그대로 표시, Growth 산정도 단순화.

| 축 | 산정 (절대 단위) | 보여주는 의미 |
| :---- | :---- | :---- |
| Quality (정확성) | 5축 중 발음·유창·문법·화용 4축의 절대값 (각각 %·WPM·오류/문장·%) | 정규과정에서 얼마나 정확하게 배웠는가 |
| Quantity (양) | 발화량 KPI (문장 수) \+ 듣기 누적 분 \+ 섀도잉 카운트 | Mode B·서브웨이에서 얼마나 많이 학습했는가 |
| Growth (성장) ★ | 5축 KPI 통합 추이 — 주간·월간 절대 변화량 (전 모듈) | 장기적으로 자라고 있는가 |

*v1.7 단순화: Growth는 OMP·CEFR 도달% 의존을 폐기하고 5축 KPI의 절대 변화량만으로 산정. 모든 레벨에서 자연스럽게 작동.*
