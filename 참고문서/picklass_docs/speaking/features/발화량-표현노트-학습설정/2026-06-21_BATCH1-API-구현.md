## 1. 발화량 통합 집계 — utterance_logs write 훅 (C안)

`POST /lessons/:lessonId/modules/:moduleCode/history` 확장. 8모듈·FRT 공통 엔드포인트로,
**클라이언트가 완료 시 발화 수치를 보고**하면 `utterance_logs`에 rollup 1행을 동시 기록한다.
→ FRT도 동일 경로를 타므로 **speaking 스키마를 cross-read 하지 않는다**.

- 파일: `apps/api/src/lessons/lessons.service.ts` (`saveModuleHistory`, `SaveModuleHistoryBody`)
- 추가 body 필드(모두 옵션): `kpis`, `sentenceCount`, `wordCount`, `tapMode`, `topic`, `sessionRef`
- 동작: `module_histories` 생성 + `sentenceCount > 0`이면 `utterance_logs` insert
  (`source_module`=moduleCode, `session_ref`=sessionRef ?? lessonId, `topic`=body.topic ?? 레슨 topic)
- ⚠️ 프론트 연동 필요: 발화 모듈(SHD/SFB/SMK/RPB/RPF/OMP/FRT) 완료 시 `sentenceCount`/`wordCount`/`tapMode`/`topic` 전송

## 2. GET /challenge/utterance — 발화량 4종 미터

- 파일: `apps/api/src/challenge/{challenge.module,challenge.controller,challenge.service}.ts`
- `utterance_logs` 단일 테이블에서 사용자·기간 한정 조회 → cross-schema 0
- 미터: daily(30) · weekly(월~일, 200) · monthly(800) · persona(롤링30일 top topic, 50)
- 탭모드 발화는 ×0.6 가중치
- 응답: `{ daily:{current,target,pct}, weekly, monthly, persona:{topic,current,target,pct} }`

## 3. 표현노트 — user_expressions API

- 파일: `apps/api/src/expressions/{expressions.module,expressions.controller,expressions.service}.ts`
- `GET /expressions?filter=all|unlearned|master` — 목록(레벨·복습수·다음복습일 포함)
- `POST /expressions` — 저장(동일 `user_id+expression` upsert)
- `POST /expressions/:id/review` — 복습 완료 → 레벨·망각곡선 갱신
  - 레벨: 0회=0 / 1~2=1 / 3~4=2 / 5~7=3 / 8+=4 (§4.7)
  - 망각곡선 간격(일): `[1,2,4,7,16,35]`

## 4. 학습설정 — user_learning_profiles API

- 파일: `apps/api/src/users/{users.controller,users.service}.ts` (기존 UsersModule)
- `GET /users/learning-profile` — 없으면 기본값(daily_goal_min=20, speed=1.0 등) 반환
- `PATCH /users/learning-profile` — 부분 업데이트(upsert)
- 필드: cefrLevel·learningGoal·examTarget·jobRole·interests[]·personaCode·dailyGoalMin·preferredMode·subtitleDefault·speedDefault·studyStartedAt

## 5. GET /config/program — 동적 수료조건 (backoffice 단일 소스 READ)

- 파일: `apps/api/src/config/{config.service,config.controller,config.module}.ts`
- `institution_settings`·`access_codes`는 speaking 스키마 모델이 아니므로 **raw SQL**(`$queryRawUnsafe`)로 읽음
- 매핑:
  - target: `institution_settings.default_completion_sentences`→utterance_sentences, `default_completion_lesson_rate`→course_completion_pct
  - 수강/종료일: `access_codes`(status_code='active') `usage_end_date`→endDate/daysLeft
  - current: `utterance_logs`(발화 합산·탭모드×0.6) / `lesson_results`(완료/전체 레슨 %)
  - dailyGoalMinutes: `user_learning_profiles.daily_goal_min`(없으면 20)
- 수강 없음 → `{programName:null, endDate:null, daysLeft:null, dailyGoalMinutes, completionRules:[]}`
