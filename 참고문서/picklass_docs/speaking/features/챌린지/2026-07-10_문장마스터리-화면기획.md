## 1. 화면 인벤토리

| ID | 화면 | 경로 | 역할 |
|---|---|---|---|
| **S1** | 챌린지 탭 진입점 | `/challenge` | Quiz 카드(오늘 복습 N) + 표현노트 행(N개) |
| **S2** | Quiz 섀도잉 세션 ★ | `/player/quiz` | 문장별 듣기→발화→평가→리워드 (핵심 루프) |
| **S3** | 세션 종료 요약 | S2 내 오버레이 | 발화수·레벨업·마스터 결산 |
| **S4** | 표현노트 목록 | `/player/expressions` | 필터·마스터리 게이지·추가·도전하기 |
| **S5** | 표현 추가 시트 | S4 내 BottomSheet | 사용자 문장 직접 입력(`source='note'`) |
| **S6** | 단일 문장 섀도잉 | S2 엔진 재사용 | S4 카드 탭 시 1문장 발화 |

> **엔진 1개, 진입점 3개**: S2(Quiz 세트)·S4 도전하기(표현노트 세트)·S6(단일)은 **동일 섀도잉 플레이어**를 세트만 바꿔 재사용.


## 3. 공통 컴포넌트

### 3.1 마스터리 게이지 (`MasteryGauge`)
문장의 누적 발화수(0~8)를 8칸 pip로. 현재 레벨 색(§통합기획 3.1).

```
Lv2 (발화 3/8)     ●●●○○○○○   ← 채운 칸=현재 색(파랑), 빈 칸=회색
```
- 발화 +1 시: 다음 빈 칸이 **팝 애니메이션**으로 점등.
- 레벨 경계 도달 시: 채운 칸 전체 **색 전환**(회→연파→파→보→초).
- 8/8 도달: 게이지 → **트로피/별 배지**로 변환.

### 3.2 발화 컨트롤 (`UtteranceControl`)
```
   ┌─────────────────────────┐
   │   🎙  (탭하여 말하기)    │   ← 대기: 큰 마이크 버튼
   │   ~~~~~ 파형 ~~~~~       │   ← 녹음 중: 실시간 파형 + 타이머
   │   [ 탭 모드 ] 토글       │   ← 마이크 OFF 시 텍스트 탭(×0.6)
   └─────────────────────────┘
```
- 상태: `대기 → 녹음중 → 평가중(스피너) → 결과`.
- 탭 모드: 발음 평가 없이 텍스트를 탭으로 따라 읽기(가중치 0.6, §통합기획 6.1).

### 3.3 리워드 연출 (`RewardBurst`) — L1 순간 피드백 (Juice)
> 게임감의 핵심: **발화 순간이 즉각·감각적으로 기분 좋아야 한다** (통합기획 §3.4 L1).

발화 성공 시 **3-감각 동시 반응(0.1s 내)**:
| 채널 | 연출 |
|---|---|
| 시각 | `+1` 숫자 플로팅 + pip 팝 점등, 게이지 스프링 |
| 청각 | 짧은 성공 사운드(레벨 오를수록 음정 상승) |
| 촉각 | 가벼운 햅틱(성공), 마스터 시 강한 햅틱 |

- 마스터 근접(7/8) → 파티클 강도↑ 예고. **마스터(8/8)**: 풀카드 트로피 + 별 파티클 0.8s → 다음 문장.
- 레벨업 순간: 카드 상단 "Lv3 달성!" 배너 토스트 + 게이지 색 전환.
- ⚠️ **반응 지연 최소화**가 절대 원칙(느리면 게임감 소멸). `prefers-reduced-motion` 시 파티클·스프링 생략, 사운드/숫자만.

### 3.4 완성도 미터 (`CollectionMeter`) — L4 수집·완성 (Collection)
> 게임감의 지속: **채우고 싶은 컬렉션**이 복귀를 만든다 (통합기획 §3.4 L4).

```
마스터 15 / 20   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░  75%   🏆
```
- 세트/과정/전체 단위의 **마스터 비율(%)** 진행바. 100% 도달 시 완성 리워드 + 배지.
- 우측 🏆 탭 → **마스터 갤러리**(마스터한 문장 컬렉션, 배지 갤러리와 연결).

## 4. S1 — 챌린지 탭 진입점 (마스터리 연동)

[재디자인 문서](./2026-07-10_챌린지-탭-재디자인.md) 기준에 **실데이터 바인딩만 반영**.

```
┌──────────────────────────────────────┐
│  Quiz   오늘 복습 6문장          ▶    │  ← due 카운트(GET /expressions/quiz)
│  배운 표현을 잊기 전에 복습하세요       │
└──────────────────────────────────────┘
        └ due=0 상태:
┌──────────────────────────────────────┐
│  Quiz   오늘 복습 완료 🎉        ▶    │  ← "표현노트로 계속 학습" 유도
└──────────────────────────────────────┘

┌──────────────────────────────────────┐
│ 🗒 표현 노트   28                  ›  │  ← listExpressions('all').length
└──────────────────────────────────────┘
```
- Quiz 카드 문구는 due 수에 따라 3-상태: `N문장` / `완료(0)` / 로딩(`–`).

## 5. S2 — Quiz 섀도잉 세션 ★ (핵심)

문장 1개 = 1 스텝. 스텝 내부 4단계: **듣기 → 발화 → 평가 → 리워드**.

```
┌──────────────────────────────────────┐
│  ✕                      ▓▓▓░░░  2/6   │  ← X 닫기 + 진행바 + 카운터
├──────────────────────────────────────┤
│                                      │
│   🔊  (듣기)                         │  ← TTS 재생(속도 1.0/0.8 토글)
│                                      │
│   "Could you recommend a good        │  ← 대상 문장(크게)
│    restaurant nearby?"               │
│                                      │
│   근처에 괜찮은 식당 추천해 주실래요?    │  ← 뜻(토글 표시/숨김)
│                                      │
│   Lv2   ●●●○○○○○   (3/8)             │  ← MasteryGauge
│                                      │
├──────────────────────────────────────┤
│                                      │
│           🎙  탭하여 말하기            │  ← UtteranceControl
│           [ 탭 모드 ]                 │
│                                      │
└──────────────────────────────────────┘
```

**발화 후(평가 결과) 상태**:
```
├──────────────────────────────────────┤
│  발음 82점   👍                       │  ← 점수 + 등급
│  Could you recommend a good ...       │  ← 단어별 색상(정확=초록/주의=주황)
│  ▲ +1 발화   ●●●●○○○○ (4/8)          │  ← pip 점등 애니메이션
│                                      │
│   [ 다시 말하기 ]      [ 다음 ▶ ]     │
└──────────────────────────────────────┘
```

**흐름/규칙**
- 발화 1회 → `POST /expressions/:id/utterance {score,tapMode}` → 게이지 +1.
- 문장별 **최소 1회 발화 후 "다음"** 활성. "다시"로 반복(추가 발화 = 추가 pip).
- 마지막 문장 완료 → **세션 종료** → `POST /:id/complete-session`(전체 세트 망각곡선 전진) → S3.
- 문장 도중 X → "중단할까요?(진행분은 저장됨)" 확인.

## 6. S3 — 세션 종료 요약 (오버레이)

```
┌──────────────────────────────────────┐
│              🎉 복습 완료!             │
│                                      │
│   오늘 발화        12회               │
│   레벨업           3문장              │
│   신규 마스터  🏆  1문장              │
│                                      │
│   컬렉션  이 과정 15/20 마스터        │  ← L4 CollectionMeter
│   ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░  75%          │
│                                      │
│   ── 발화량 챌린지 +12문장 반영 ──     │  ← utterance_logs 연동 고지
│                                      │
│   마스터한 문장                       │
│   • "Could you recommend ..."  🏆     │
│                                      │
│   [ 마스터 갤러리 ]      [ 확인 ]      │  → 갤러리 / 챌린지 탭 복귀
└──────────────────────────────────────┘
```
- **L1**: 마스터 순간 트로피·별 파티클 + 강한 햅틱으로 결산의 절정 연출.
- **L4**: 세트 완성도 상승분을 즉시 반영(‥%→‥%), "마스터 갤러리"로 컬렉션 확인 유도.
- 발화량 챌린지 반영을 명시해 **이중 리워드** 체감(§통합기획 6.1).

## 7. S4 — 표현노트 목록

```
┌──────────────────────────────────────┐
│  ‹      표현 노트                 +   │  ← 뒤로 / 추가
├──────────────────────────────────────┤
│  마스터 12 / 40  ▓▓▓▓▓░░░░ 30%   🏆   │  ← L4 CollectionMeter(전체) → 갤러리
├──────────────────────────────────────┤
│  [ 전체 ] [ 미학습 ] [ 마스터 ]        │  ← 필터 탭
├──────────────────────────────────────┤
│  "Let me get back to you."      📘    │  ← 문장 + source 아이콘
│  다시 연락드릴게요                     │
│  Lv3 ●●●●●●○○ (6/8)   복습 D-2        │  ← 게이지 + 다음복습
│  ────────────────────────────────    │
│  "It depends on the situation."  ✏️   │  ← ✏️=note / 📘=learning / ⭐=preset
│  상황에 따라 달라요                    │
│  Lv1 ●○○○○○○○ (1/8)   복습 오늘       │
│  ────────────────────────────────    │
│  ...                                 │
├──────────────────────────────────────┤
│         [ 도전하기 (n문장) ]           │  ← 필터된 세트 일괄 섀도잉 → S2 엔진
└──────────────────────────────────────┘
```
- **source 아이콘**: `learning`(과정) / `note`(내 입력) / `preset`(필수). 구분 노출.
- 카드 탭 → **S6 단일 섀도잉**. 완료 시 게이지 즉시 갱신.
- 정렬: 복습 도래일 오름차순(오늘 할 것 위) 기본. 필터별 하위 정렬 조정.
- **L4**: 상단 CollectionMeter로 전체 마스터 완성도(%) 상시 노출 → 🏆 탭 시 마스터 갤러리.
- 빈 상태: "저장된 표현이 없어요. + 로 추가하거나 학습을 진행하세요."

## 8. S5 — 표현 추가 시트 (BottomSheet)

```
┌──────────────────────────────────────┐
│  표현 추가                        ✕   │
│  표현(영문) *  [___________________]   │
│  뜻            [___________________]   │
│  예문          [___________________]   │
│                                      │
│         [ 취소 ]     [ 저장 ]          │  → POST /expressions (source='note')
└──────────────────────────────────────┘
```
- 필수: 표현. 저장 시 `@@unique(user_id,expression)` upsert → 중복은 기존 행 유지.
- 저장 후 목록 새로고침, 신규 문장 Lv0으로 표시.

## 9. 상태 · 엣지 케이스

| 상황 | 처리 |
|---|---|
| 마이크 권한 없음 | 최초 발화 시 권한 요청. 거부 → **탭 모드로 폴백** 안내 |
| 발음 평가 실패/지연 | 스피너 후 실패 시 "점수 없이 발화 인정"(pip는 +1), 재시도 버튼 |
| Quiz due=0 | S1 카드 "복습 완료" + 표현노트 유도. S2 진입 차단 |
| 오프라인 | 발화 큐 로컬 보관 → 복구 시 동기화(1차는 온라인 필수 + 오류 토스트) |
| 세션 중 이탈 | 진행분 저장(발화별 즉시 POST). complete-session만 누락 → 다음 진입 시 보정 |
| 표현 0개 | S4 빈 상태 안내 |

## 10. 모션 · 접근성

- **L1 3-감각**: pip 점등 120ms 팝, 레벨업 토스트 1.5s, 마스터 트로피 0.8s + **성공 사운드(레벨↑ 음정↑)** + **햅틱**(성공 약/마스터 강). `prefers-reduced-motion` 시 파티클·스프링 생략, 사운드/햅틱/숫자 유지. 사운드 음소거 설정 존중.
- **접근성**: 발화 버튼 44px+ 터치 타깃, 점수 색상은 아이콘/텍스트 병기(색맹 대응), TTS/뜻 토글 라벨 제공.
- **일관성**: 게이지·리워드·발화 컨트롤은 공통 컴포넌트(§3)로 S2·S4·S6 공유.

## 11. 화면 ↔ API 매핑

| 화면 | 호출 |
|---|---|
| S1 Quiz 카드 | `GET /expressions/quiz?limit=6` (due 카운트) |
| S1 표현노트 행 | `GET /expressions?filter=all` (개수) |
| S2 세트 로드 | `GET /expressions/quiz` / (도전하기) 필터 세트 |
| S2 발화 | `POST /expressions/:id/utterance` |
| S2 종료 | `POST /expressions/:id/complete-session` |
| S4 목록 | `GET /expressions?filter=` |
| S5 추가 | `POST /expressions` |
| 전 발화 | (부수) `utterance_logs` insert → 발화량 챌린지 |

> API 계약 상세는 [통합 기획 §6.4](./2026-07-10_문장마스터리-통합기획.md). 본 문서는 화면·상태·연출 정의.
