## 0. 배경 / 결정 사항

기존 [challenge/page.tsx](../../../speaking.picklass.com/apps/web/src/app/(tabs)/challenge/page.tsx)는
IA §4.3의 5개 섹션을 구현했으나 헤드라인 문장 수만 실API이고 나머지는 Mock이었다.
첨부 목업은 정보 밀도를 낮추고(3-stat 제거) 발화량 카드를 "주간 리듬 대시보드"로 단순화하는 **시각 재구성 시안**이다.
IA §4.3의 섹션 골격(발화량→Quiz→표현노트→배지→랭킹 서브시트)은 유지하고 표현만 교체했다.

| 항목 | 결정 |
|---|---|
| 일별 시계열 | **첨부 이미지와 동일** — 막대 3-상태(막대/점/점선원). 현재는 **디자인만**(Mock, API 미연동) |
| 평균선 | **자기 기간평균(주/월)** — 경과일 기준 산술평균(미도래 제외) |
| 막대 차트 | **첨부 이미지와 동일**, 디자인 전용 Mock |

| 배지 방패 그래픽 | **1차 프론트 상수 카탈로그** (`BADGE_CATALOG` + `BadgeShield`) |

## 2. 범위 (Scope)

**In scope (구현됨)**: 전 섹션 시각 재구성 · `_components/` 분리(CLAUDE §6.3) · 막대 3-상태 차트 + 자기 기간평균 점선(Mock) · 방패 배지(프론트 상수) · 주간/월간 토글.

**유지(변경 없음)**: 헤드라인 = `getUtterance()[period].current` 실API · 랭킹 바텀시트(PKS-CH-002) · Quiz/표현노트/배지 라우팅.

**Out of scope (후속 §7)**: 시계열 실API(`series[]`) · 배지 데이터 모델/`GET /badges` · `/challenge/badges` 상세 그래픽 통일 · Quiz·표현노트 카운트 실데이터.

> ⚠️ **디자인 전용 명시**: 막대값(Mock)과 헤드라인 문장 수(실API)는 **서로 독립**이라 숫자가 합산 일치하지 않을 수 있다. 실데이터 연동 시 정합.

## 5. 핵심 구현 상세

### 5.1 발화량 카드
레이아웃(위→아래): **헤더행(아이콘+제목 / 주간·월간 토글) → 기간범위 → 차트 → 헤드라인 → 랭킹 pill**.
- 토글 `period: 'weekly'|'monthly'` (일간 제거). period 전환 시 `series`·`rangeLabel`·`periodTitle`·헤드라인 동시 갱신.
- 헤드라인 `getUtterance()[period].current`. 로딩/실패 시 `–`.
- 랭킹 pill → 기존 `BottomSheet`(PKS-CH-002) 재사용.

### 5.2 차트 (`UtteranceChart`) — 3-상태 + 평균선
입력 `series: { label; value: number|null; state: 'filled'|'zero'|'empty' }[]`, 플롯 높이 `H=120`.

| state | 렌더 | 의미 |
|---|---|---|
| `filled` | 살몬 pill 막대(`height = max(value/max*H, 6)`) | 발화 있음 |
| `zero` | baseline `bg-slate-300` 6px 점 | 학습했으나 발화 ~0 |
| `empty` | baseline `border-dashed border-rose-200` 빈 원 | 미도래/무데이터 |

- **평균선**: `avg = (empty 제외 값 합) / (empty 제외 개수)`, `bottom = avg/max*H`. 가로 점선 + "평균 발화량" 라벨.
  - Mock 기준: 주간 avg = (18+0+24+20+14)/5 = **15.2**, 월간 avg = (210+180+240+96)/4 = **181.5**.

### 5.3 Quiz / 표현노트 / 배지
- **QuizCard**: red 카드 + 원형 흰 재생버튼 → `/player/quiz`. 문제 수 Mock(`12`).
- **ExpressionRow**: slate compact 행 → `/player/expressions`. 카운트 Mock(`28`).
- **BadgeGallery**: `BADGE_CATALOG` 상위 3개를 `BadgeShield`로. 더 보기 → `/challenge/badges`.
  - `BadgeShield`: viewBox `0 0 84 96` SVG. 방패 path(색상 grad) + 상단 광택 + 금색 리본(라벨 SVG text) + 중앙 lucide 아이콘 오버레이. 색/아이콘은 `color`/`icon` prop.

## 7. 후속 (Out of scope, 별도 작업)

1. **일별 시계열 실API** — `GET /challenge/utterance`에 `series[]` 확장 → `_mock` 교체.
2. **배지 데이터 모델·`GET /badges`** — 획득/티어/일자, 갤러리·상세 실데이터화.
3. **`/challenge/badges` 상세 그래픽 통일** — 이모지 → `BadgeShield` 재사용(획득=컬러 / 미획득=그레이스케일).
4. **카운트 실데이터** — Quiz 문제 수, 표현노트 개수(`listExpressions`).
5. **AI 캐릭터 챗** — 재노출 여부/위치 결정(이번 시안 제외).
