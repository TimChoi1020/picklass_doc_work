## 디렉터리 규칙

각 기능마다 하위 폴더 1개를 만든다:

```
features/
├── 발음평가/
│   ├── README.md
│   ├── api-spec.md
│   └── 점수계산-개선.md
├── 모듈오케스트레이터/
│   └── ...
```

## 파일명

- 한 기능 안의 작은 작업은 `[작업내용].md` (예: `점수계산-개선.md`).
- 기능 전반을 다루는 메인 문서는 `README.md`.

## 포함 권장 항목

- 변경 사항 요약
- API 스펙 (요청/응답 예시)
- 관련 코드 경로 (`speaking.picklass.com/apps/api/src/...:42` 형태로 행번호까지)
- 테스트 항목 / 검증 방법
- 관련 문서 링크 (errors/, architecture/, shared/api-contracts/)
