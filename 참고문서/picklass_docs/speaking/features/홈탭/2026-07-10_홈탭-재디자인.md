## 1. 배경 / 목표

홈 탭을 목업에 맞춰 **네이비+레드 톤 / 카드 스택 구조**로 재구성한다.
캐러셀·3열 그리드 중심의 기존 레이아웃을 **카드 세로 스택 + 스탯 2행 스택 + 평균 비교 레이더**로 바꾼다.

**디자인 전용 작업**(결정: "디자인만 수정")이라 백엔드 변경 없이 Phase 1로 완료한다.
이미 올바른 형태로 들어오는 실데이터(발화량 `current/target`, 5축 KPI)는 유지하고,
목업에만 있는 요소는 **주석 단 Mock**으로 채워 비주얼을 맞춘다.

---

## 2. 목업 vs 현재 구조

| 영역 | 목업 | 현재(재디자인 전) | 처리 |
|---|---|---|---|
| 전체 톤 | 블루-슬레이트 배경 + 네이비 텍스트 + 레드 액센트 | `bg-gray-50` 회색, 파랑/틸 컬러 카드 | 톤 전면 교체 |
| 헤더 | `Good Morning, Tim!` (바 없음) | 흰색 바 + `Hi, {name}!` | 시간대 인사 + 바 제거 |
| 섹션1 | 흰색 카드 2종 세로 스택 + 빨강 play 버튼 | Today's Mission **캐러셀**(컬러 카드) | 스택으로 전환, 드래그 제거 |
| 섹션2 | 기간칩 + 2행 스택(이수율 `N/전체강`, 발화량 `N/Goal`) | 3열 그리드(발화량·이수율·**수업시간**) | 2행 스택, 수업시간 제거 |
| 섹션3 | 스피킹 밸런스 — 사용자 + 평균(점선) + 범례 | "5축 점수" 사용자 1폴리곤 | 평균 폴리곤·범례 추가·리네이밍 |

## 4. 화면 구성

### 4.1 헤더

| 요소 | 데이터 / 동작 | 상태 |
|---|---|---|
| 시간대 인사 | `new Date().getHours()` → Good Morning(<12)/Afternoon(<18)/Evening | ✅ |
| 이름 | `user.name?.split(' ')[0] ?? 'Tim'` | ✅ 기존 |
| 레벨테스트 팝오버 | `LevelTestPopover`(진단 필요 시) | ✅ 기존 유지 |

### 4.2 섹션1 오늘의 학습 (카드 2종 세로 스택)

| 카드 | 내용 | 동작 |
|---|---|---|
| ① 정규 | 제목·챕터·분(clock)·**진행바** + 빨강 play | → `/learn-flow/pick` |
| ② Talk with Pickle(FRT) | 제목·안내문·분 + 빨강 play | → `/player/frt` |

> 미션 데이터는 **Mock**(`MISSIONS` 상수). `GET /lessons/today` 미연결.

### 4.3 섹션2 학습 현황 (기간칩 + 2행 스택)

| 행 | 표시 | 데이터 |
|---|---|---|
| 이수율 | 아이콘 + **바(실 %)** + `N / 전체강` | 바 = `config/program` `course_completion_pct.pct` (✅) / 개수 = Mock |
| 발화량 | 아이콘 + `current / Goal target` | `challenge/utterance` `monthly.current`·`monthly.target` (✅) |
| 기간칩 | `2026.06.01 ~ 2026.08.31` | Mock (startDate 부재) |

### 4.4 섹션3 스피킹 밸런스 (레이더)

| 요소 | 데이터 |
|---|---|
| 사용자 폴리곤(빨강) | `feedback/kpi-trends` 최신 스냅샷 (✅) |
| 기관 평균 폴리곤(점선) + "평균" 범례 | `AVG_SNAPSHOT` Mock |
| 5축 | 발음·유창성·문법·활용성·발화량 |

> 데이터 없을 시 "학습 데이터가 쌓이면 스피킹 밸런스가 표시됩니다" 안내.

## 5. 목업 반영 편차 (의도적 · Mock)

- **오늘의 학습 카드** — `GET /lessons/today` 미연결 → `MISSIONS` Mock.
- **이수율 개수 `N/전체강`** — 강 수 소스 부재 → `DONE_LESSONS=8`·`TOTAL_LESSONS=20` Mock. (바 채움은 실 %)
- **스피킹 밸런스 평균 폴리곤** — 기관 평균 KPI API 부재 → `AVG_SNAPSHOT` Mock.
- **수강 기간 칩** — `config/program`에 startDate 부재 → `periodLabel` Mock.

각 항목 소스 코드에 WHY 주석 명시.

## 6. Phase 구분

**Phase 1 — 디자인 재작업 (백엔드 무변경, 완료)**
- 배경/헤더/컬러 토큰 네이비+레드로 교체, 시간대 인사
- 섹션1 캐러셀 → 카드 스택(드래그/슬라이드 상태·핸들러 제거)
- 섹션2 3열 그리드 → 2행 스택 + 기간칩, 수업시간 위젯 제거, 발화량 `current/Goal`
- 섹션3 리네이밍 + 평균 폴리곤·범례 추가

**Phase 2 — 데이터 정합 (백엔드 협의)**
- 오늘의 학습 `GET /lessons/today` 연동
- 이수율 강 수(완료/전체) 소스
- 기관 평균 KPI 폴리곤 실연동
- 수강 시작일(`config/program` startDate)
