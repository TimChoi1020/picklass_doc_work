## 1. 배경 / 목표

my 페이지를 목업에 맞춰 **"블루 그라디언트 히어로 헤더 + 카드 리스트"** 구조로 재구성한다.
계정 정보(이름·레벨·수강권·로그아웃)를 카드에서 **헤더 히어로로 승격**하고, 설정을 단일 카드로 통합한다.

**대부분 기존 데이터·컴포넌트 재사용**이라 Phase 1은 백엔드 변경 없이 레이아웃 작업으로 완료된다.

## 2. 목업 vs 현재 구조

| 영역 | 목업 | 현재 | 처리 |
|---|---|---|---|
| 헤더 | 블루 히어로(아바타·이름·레벨·수강권·로그아웃) | "MY" 타이틀만 | 전면 재구성 |
| 아바타 | 원형 캐릭터 + 카메라 | 없음 | 🆕 캐릭터+카메라(준비중) |
| 레벨 | `CEFR B2` + [레벨 테스트 리포트] | `L12·B2+·파트너명` 배지 | **배지 유지**(§4.1.3) + 리포트 버튼 추가 |
| 수강권 | 헤더에 과정명+기간 | 계정 섹션 **드롭다운** | 드롭다운 **헤더로 이동**(기능 유지) |
| 수강내역 | 카드 1행 | 동일 | 유지 |
| 공지사항 3 | 카운트 배지 행 | 섹션5 "알림"(숨김) | **"공지사항"으로 복원·라벨 변경** |
| 설정 | 학습시간·알림·페르소나·사운드 한 그룹 | 수업설정+앱설정 2그룹 | 단일 카드 통합 |
| 섹션 라벨 | 없음 | "계정/수업설정/앱설정" | 제거 |

## 3. 확정 결정 (2026-07-10)

| # | 항목 | 결정 |
|---|------|------|
| 1 | **레벨 표시** | 목업의 `CEFR B2`(6밴드) **미채택**. 기존 **`L{n} · 18라벨 · 파트너명` 배지 유지**(§4.1.3). 헤더에 배지 + [레벨 테스트 리포트] 버튼 병치 |
| 2 | **아바타** | **캐릭터 이미지 + 카메라 버튼**. 카메라는 **"준비 중"**(UI만, 업로드 실동작 없음) |
| 3 | **수강권** | 계정 섹션 **드롭다운 기능 유지**, **헤더로 이동**하고 **목업 디자인만 적용** |
| 4 | 공지사항 | 숨겼던 알림 내역을 **"공지사항"으로 라벨 변경해 복원**, 진입 `/my/notifications`. 카운트는 Phase 1 정적, 실데이터는 Phase 2 |
| 5 | 레벨 테스트 리포트 버튼 | **"준비 중"**(비활성/안내). 전용 리포트 연결은 Phase 2(§6) |
| 6 | 설정 통합 | 학습시간·학습알림·페르소나·사운드를 **단일 카드**로, 섹션 라벨 제거 |

## 4. 화면 구성

### 4.1 헤더 히어로 (블루 그라디언트)

| 요소 | 데이터 / 동작 | 재사용 |
|---|---|---|
| **4.1.1 아바타 + 카메라** | 캐릭터 이미지 + 카메라 버튼(클릭 시 "준비 중" 안내) | 🆕 UI만 |
| **4.1.2 이름 + 연필** | `englishNickname ?? user.name`, 연필→닉네임 바텀시트 | ✅ 기존(PKS-MY-002) |
| **4.1.3 레벨 배지 + 리포트** | `levelBadge`(`L{n} · picklassLabel · displayLevel(파트너)`) + [레벨 테스트 리포트] 버튼 | ✅ 기존 배지 로직 유지 |
| **4.1.4 수강권 드롭다운** | 접힘=수강중 첫 과정 `title` + 기간(`formatEnrollmentPeriod`), 펼침=수강중 목록. 항목 탭→`/learn?courseId=` | ✅ 기존 드롭다운(§수강내역통합 6.6) 이동 |
| **4.1.5 로그아웃** | `logout()` → `/home` | ✅ 기존 |

> **4.1.3 주의**: 목업은 `CEFR B2`지만, 결정 #1로 **기존 18라벨·파트너명 병기 배지를 유지**한다.
> 헤더 스타일(위치·색)은 목업을 따르되 값 포맷은 배지 정책(§프로필문서 §5.1.1/§10)을 유지.

### 4.2 본문 카드

| 카드 | 내용 | 동작 |
|---|---|---|
| **수강내역** | 1행 | → `/my/history` |
| **공지사항 N** | 빨강 카운트 배지 | → `/my/notifications` (기존 알림 내역 복원·라벨 변경) |
| **설정**(단일 카드) | 학습 시간 설정 / 학습 알림 설정 / AI 캐릭터 페르소나 설정 / 사운드 설정 | 각 바텀시트(기존 재사용) |

> **알림 설정(카테고리 토글)은 목업에 없음** → 계속 숨김/보류(별도 결정). 공지사항(알림 내역)만 노출.

## 5. 목업 반영 편차 (의도적)

- **레벨**: 목업 `CEFR B2` 대신 **`L{n}·18라벨·파트너명` 배지 유지**(결정 #1). 6밴드 단순 표기는 미채택.
- **아바타**: 카메라 버튼은 **"준비 중"**(실제 업로드는 Phase 2).
- **수강권**: 목업은 정적 텍스트처럼 보이나 **드롭다운 기능 유지**(디자인만 적용).

## 6. Phase 구분

**Phase 1 — 레이아웃 재구성 (백엔드 무변경, 지금 가능)**
- 헤더 히어로 컴포넌트화(아바타·이름·레벨배지+리포트버튼·수강권 드롭다운·로그아웃)
- 계정/수업설정/앱설정 섹션 라벨 제거, 설정 단일 카드 통합
- 공지사항 카드(숨김 해제·라벨 변경), 수강내역 카드 유지
- 카메라·리포트 버튼은 자리·핸들러만(준비 중/임시)

**Phase 2 — 신규 백엔드 요소**
- 프로필 **사진 업로드**: `user_learning_profiles.avatar_url` + Supabase Storage
- **레벨 테스트 리포트** 페이지: `alt_results` 기반(별도 기획)
- **공지사항** 실데이터·카운트: 알림 생성 파이프라인 연동([알림 문서](../알림/2026-07-09_알림-생성-파이프라인.md))
