## 1. 배경 및 목적

speaking learn 페이지의 "오늘의 FRT 10분" 섹션은 tutoring의 "내가 만든 과정"과 동일한 개념이다.
차이점은 모듈 구성이 **FRT 단일 모듈로 고정**된다는 점이다.

| 항목 | tutoring "내가 만든 과정" | speaking "오늘의 FRT 10분" |
|------|--------------------------|--------------------------|
| `genre_code` | `custom` | `custom` |
| 콘텐츠 생성 | Gemini AI 지문 생성 + analyzer 모듈 시퀀싱 | **지문 생성 없음** — `text_id = null`, topic만 저장 |
| 모듈 구성 | analyzer 기반 다중 모듈 | **FRT 단일 모듈 고정** |
| 미리보기 단계 | 있음 (지문·모듈 확인 후 시작) | **없음** — 주제 입력 즉시 생성 후 진입 |
| 진입 조건 | `activeCourses.length > 0` | 동일 |
| FRT 실행 | speaking.picklass.com으로 외부 리다이렉트 (externalTokens) | **자체 `/player/frt` 플레이어** |
| 이력 | CourseCard 그리드 | FRT 세션 이력 (경량) |

### tutoring의 FRT 실행 흐름 (참고)

tutoring에서 FRT 모듈 도달 시의 흐름:
```
LessonSession → FRT 모듈 감지 (EXTERNAL_REDIRECT_MODULE_CODES)
  → lessonPlan.externalTokens에서 원타임 토큰 추출
  → window.location = {NEXT_PUBLIC_OIZI_SPEAKING_URL}/speaking/gateway?token=...
  → speaking.picklass.com이 토큰 검증 → FRT 실행
```

speaking.picklass.com은 tutoring FRT의 **실행 주체**이므로, 자체 플레이어를 보유한다.
tutoring → speaking 외부 진입 라우트(`/speaking/gateway`)는 Phase 5에서 별도 구현한다.

## 4. Phase 2 — 주제 입력 → FRT 레슨 생성

### 4-1. 프론트엔드: 주제 입력 바텀시트

**파일**: `apps/web/src/app/(tabs)/learn/page.tsx`

"시작하기" 클릭 시 바텀시트 열림:
- 텍스트 인풋: "오늘 연습할 주제를 입력하세요" (placeholder)
- "시작하기" 버튼 → `POST /lessons/frt` 호출
- 로딩 중: 버튼 스피너 표시
- 성공 → `/player/frt?lessonId={lessonId}` 이동

```ts
const [frtSheetOpen, setFrtSheetOpen] = useState(false);
const [frtTopic, setFrtTopic] = useState('');
const [frtLoading, setFrtLoading] = useState(false);

async function handleStartFrt() {
  setFrtLoading(true);
  try {
    const { lessonId } = await createFrtLesson(frtTopic.trim() || undefined);
    router.push(`/player/frt?lessonId=${lessonId}`);
  } finally {
    setFrtLoading(false);
    setFrtSheetOpen(false);
  }
}
```

### 4-2. 백엔드: `POST /lessons/frt`

**파일**: `apps/api/src/lessons/lessons.service.ts`, `lessons.controller.ts`

**controller**:
```ts
// POST /lessons/frt
@Post('frt')
createFrtLesson(
  @Req() req: AuthenticatedRequest,
  @Body() body: { topic?: string },
) {
  return this.lessonsService.createFrtLesson(req.user.id, body.topic);
}
```

**service** — tutoring `createCustomLesson()` 단순화 버전:
1. 사용자의 speaking custom 과정 조회 or 생성
   - `title = '나의 FRT 연습'`, `genre_code = 'custom'`, `course_type = 'speaking'`
2. `course_lessons` 레코드 생성
   - `skill_modules: [{ order: 1, moduleCode: 'FRT' }]`
   - `topic`: body.topic (미전달 시 `'자유 주제'`)
3. 반환: `{ lessonId, courseId }`

> analyzer 호출 없음 — 모듈이 FRT 하나로 고정.

### 4-3. Web 서비스 함수 추가

**파일**: `apps/web/src/lib/services/lessonsService.ts`

```ts
export async function createFrtLesson(topic?: string): Promise<{ lessonId: string; courseId: string }> {
  const res = await authFetch(`${api()}/lessons/frt`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ topic }),
  });
  if (!res.ok) throw new Error('FRT 레슨 생성 실패');
  return res.json() as Promise<{ lessonId: string; courseId: string }>;
}
```

## 5. Phase 3 — FRT Player 연동 (차후 진행 예정)

> FRT Player(`/player/frt`)는 이미 개발되어 있다.
> Phase 2에서 생성된 `lessonId`를 query param으로 수신하고, 레슨 플랜을 조회하여 플레이어와 연결하는 작업을 진행한다.

**파일**: `apps/web/src/app/player/frt/page.tsx`

### 5-1. lessonId 수신 및 플랜 조회

```ts
'use client';
import { useSearchParams, useRouter } from 'next/navigation';
import { useEffect, useState } from 'react';
import { getLessonPlan, LessonPlan } from '@/lib/services/lessonsService';

export default function FrtPlayerPage() {
  const searchParams = useSearchParams();
  const lessonId = searchParams.get('lessonId');
  const [plan, setPlan] = useState<LessonPlan | null>(null);

  useEffect(() => {
    if (!lessonId) return;
    getLessonPlan(lessonId).then(setPlan);
  }, [lessonId]);

  // plan.moduleSequence[0].moduleCode === 'FRT' 확인 후 FRT 플레이어 렌더링
}
```

### 5-2. 플랜 응답 구조 (FRT 레슨)

`GET /lessons/:id/plan` 반환값:
```json
{
  "lessonId": "...",
  "courseId": "...",
  "lessonOrder": 1,
  "topic": "오늘 연습할 주제",
  "passage": null,
  "moduleSequence": [{ "order": 1, "moduleCode": "FRT" }],
  "statusCode": "active"
}
```

- `passage = null` — FRT는 지문 없음
- `topic`을 Azure Speech FRT 세션의 대화 주제로 활용

### 5-3. 완료 결과 저장

FRT 세션 종료 시:
```ts
POST /lessons/:lessonId/modules/FRT/history
{
  "score": ...,
  "startedAt": "...",
  "completedAt": "..."
}
```

`saveModuleHistory()`가 이미 구현되어 있으므로 (`lessons.service.ts`) 별도 API 추가 불필요.

## 7. Phase 5 — tutoring → speaking 외부 진입 게이트웨이 (별도 일정)

> tutoring의 FRT 모듈 실행 시 speaking.picklass.com으로 리다이렉트되는 외부 진입 경로.
> speaking의 자체 FRT 흐름(Phase 1~4)과 독립적으로 구현한다.

### 흐름

```
tutoring LessonSession (FRT 모듈 도달)
  → speakingGateway.ts: window.location = {SPEAKING_URL}/speaking/gateway?token=...
  → speaking: /speaking/gateway 페이지 (Next.js route)
  → GET /external/verify?token=... (speaking API)
  → 토큰 검증 → lessonId 조회 or FRT 레슨 자동 생성
  → redirect to /player/frt?lessonId=...
```

### 구현 대상

| 파일 | 작업 |
|------|------|
| `apps/web/src/app/speaking/gateway/page.tsx` | token query param 수신 → API 검증 → /player/frt 리다이렉트 |
| `apps/api/src/external/external.controller.ts` | `GET /external/verify` — 원타임 토큰 검증 |
| `apps/api/src/external/external.service.ts` | 토큰 디코드 → lessonId 반환 |

### 참고: tutoring 측 구현 위치

- `apps/web/src/lib/services/speakingGateway.ts` — `EXTERNAL_REDIRECT_MODULE_CODES = ['FRT']`
- `apps/web/src/app/modules/[lessonId]/_components/LessonSession.tsx:60-85` — FRT 감지 + 리다이렉트 로직
- 환경변수: `NEXT_PUBLIC_OIZI_SPEAKING_URL` (tutoring 측), `EXTERNAL_TOKEN_ISSUE_SECRET` (공유)
