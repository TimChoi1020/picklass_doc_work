# 디자인 — UI/UX 전달 문서

스피킹앱의 **모든 화면과 상태**를 디자이너가 기획·제작할 수 있도록 정리한 문서 묶음입니다.

기능 개발이 먼저 완료된 상태에서, **현재 구현된 화면을 기준으로** 작성했습니다. 즉 이 문서는 "이렇게 만들어 주세요"가 아니라 **"지금 이렇게 동작합니다 — 여기에 디자인을 입혀 주세요"** 에 가깝습니다.

## 이 문서 묶음의 특징

**① 모든 화면이 같은 틀로 서술됩니다.**
목적 / 진입·이탈 / 와이어 / 요소 표 / 상태 변형 / 카피 / 참조

**② 「데이터 출처」와 「제약」 칸이 핵심입니다.**
콘텐츠 대부분이 외부(픽클래스)에서 주입되거나 AI가 생성해 **길이·개수가 고정되지 않습니다.** 요소 표의 제약 칸에 구체적인 범위를 적어 두었습니다.

**③ ⚠️ 표시는 디자인 판단이 필요한 지점입니다.**
기능 우선 개발로 비어 있거나, 현재 구현에 개선 여지가 있는 곳입니다. 전체 목록은 [브리프 §8](0_디자인브리프.md)에 있습니다.

**④ 와이어는 시안이 아닙니다.**
ASCII 와이어는 "어떤 요소가 어떤 순서로 있는지"를 보여주는 **구조 참조용**입니다. 비주얼은 새로 설계해 주세요.

## 캡처 현황

실제 앱을 구동해 촬영한 화면이 각 명세에 삽입돼 있습니다. 파일은 [캡처/](캡처/) 폴더에 화면 ID로 저장됩니다.

**촬영 완료 — 28장**

| 영역 | 촬영된 화면 |
|---|---|
| 진입·홈 | 타이틀 · 로그인(빈/입력) · 홈 허브 · 세션 생성 |
| 모듈 1단계 | 8개 모듈 전부 |
| 모듈 2단계 | LRN(영상·표현카드×2) · VLM · SHD · SFB(기본·힌트) · SMK · RPB · OMP |
| 레벨테스트 | 인트로(PT/AT) · 1부 어휘 · 전환 안내 |
| 기록 | 목록 빈 상태 |

**미촬영 — 명세에 `📷 미촬영`으로 표시**

발화·채점·AI 응답·리포트·기록 재현 화면은 **백엔드(PostgreSQL + Gemini/Azure Speech/OpenAI 키)** 가 있어야 도달할 수 있어 촬영하지 못했습니다. 해당 화면의 명세·상태 정의는 코드를 읽어 작성했으므로 **내용 자체는 완전합니다.**

운영 환경이나 키가 준비되면 나머지 캡처를 추가할 수 있습니다.

## 범위

**포함** — 학습자가 보는 모든 화면(진입 · 홈 · 9개 모듈 · 리포트 · 지난 기록 · 레벨테스트 · 픽클래스 진입)

**제외** — 어드민 4화면(로그인 · 세션 목록 · 통계 · 튜닝). 내부 운영용이라 우선순위가 낮습니다. 필요해지면 별도로 요청해 주세요.
