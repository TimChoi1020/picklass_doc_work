## B. FRT 자유대화 — 대표 조합 10장

**조합 폭이 매우 큽니다**(대화 단계 6 × 표시 모드 2 × 조건부 요소 5). 전부 그릴 필요는 없고, **아래 10가지가 확정되면 개발이 흔들리지 않습니다.**

| ✓ | # | 조합 | 확인 포인트 |
|---|---|---|---|
| ☐ | 1 | 음성 모드 · 내 차례(idle) | 파형 + PTT 버튼 기본 |
| ☐ | 2 | 음성 모드 · 내가 말하는 중 | 파형 반응 + 실시간 전사 말풍선 + 버튼 활성 |
| ☐ | 3 | 음성 모드 · 인식 중(processing) | 버튼 비활성 표현 |
| ☐ | 4 | 음성 모드 · AI가 말하는 중 | 파형 + 끼어들기 허용/금지 두 경우 |
| ☐ | 5 | **채팅 모드 · 기본** | 말풍선 목록 + 타이핑되듯 노출되는 AI 응답 |
| ☐ | 6 | **음성 모드 + 교정 노트** | 교정 문구가 파형 아래 삽입 |
| ☐ | 7 | **따라 말하기(repeating)** | 교정 문장 + 녹음 상태 + 실시간 전사 |
| ☐ | 8 | **힌트 1~3단계** | 침묵이 길어질 때. 단계별 구체성이 달라짐 |
| ☐ | 9 | 자동 감지(VAD) 모드 | PTT 대신 감지 표시기 + 음소거 토글 |
| ☐ | 10 | 종료 대기 바 | `5초 후 학습 리포트로 이동` + [대화 내역 보기] |
