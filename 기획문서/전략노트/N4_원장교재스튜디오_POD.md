> 📝 **전략 노트** — 결정 문서 아님. 저작권·IP 정책 확정 전 교재 판매 실행 금지. 상세 소재 분류·저작권 분석은 원본 파일 참조.

## 핵심 결론

원장이 생성한 콘텐츠(3개 소재 경로)를 **라이브러리로 축적 → 북빌더로 편집 → 교재 POD·eBook**으로 출판하는 기능. **저작권·IP 귀속 정책 확정이 실행 전제.**

## 콘텐츠 소재 3방향

| 코드 | 소스 | 내용 | AI 역할 | 저작권 |
|---|---|---|---|---|
| **A** | 업로드 | 원장 기존 자료(PDF·이미지·HWP) | OCR·구조화 | 원장 IP |
| **B** | 변형 | Picklass 생성 콘텐츠(진단·출제) 기반 교재화 | 재구성·편집 | 요주의(교과서 변형 시 2차 저작물) |
| **C** | 프롬프트 | 원장 프롬프트로 신규 생성 | 생성 | 원장+Picklass 공동 정책 필요 |

→ 셋 모두 **P0-4 검수(원장 승인) 필수** 후 라이브러리 축적.

## 기능 흐름 (미래 스펙, P2 이후)

```
[Studio] 소재 입력 (A/B/C) → P0-4 검수 승인
  → 콘텐츠 라이브러리 (원장별 누적)
  → 북빌더 (드래그앤드롭 편집·조판)
  → POD 출판 / eBook(EPUB) 출력 (N5 파이프라인 활용)
  → 학생 배포 또는 POD 인쇄 발주
```

## 주의사항

- **저작권 미확정 전 판매 금지**: 소재 B(교과서 지문 변형)는 2차적저작물 해당 가능성 → 법률 검토 필수
- 이퓨쳐 출판 IP·유통 자산 연계 시 계약 조건 협의 필요
