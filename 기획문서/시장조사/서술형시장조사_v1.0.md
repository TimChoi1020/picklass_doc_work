## 한 줄 요약

> 한국 중·고 영어 서술형 평가는 **정책적으로 확대 국면**이며, 경쟁 지형은 *AI 서술형 채점*(CLIPO·Engram)과 *변형문제 자동출제*(너른터·QBank)로 **분리되어 있다.** **"내신 서술형 내용 중심 채점 + 자동출제"를 학원용으로 결합한 솔루션은 아직 공백** — Picklass의 포지셔닝 기회.

## 1. 정책·제도 트렌드

**서술형은 정기고사에 구조적으로 내재.**

| 교육청 | 학년도 | 서·논술형 반영 비율 | 비고 |
|---|---|---|---|
| 서울 | 2025 | 중 30% / 고 25% 이상 **권장** | |
| 서울 | 2027 | **35%** → 별도안 50%까지 상향 | |
| 경기 | 2025 | 고교 논술형 **35% 이상 의무** | |
| 경기 | 2026 | 중·고 30%로 통일 | |

> ⚠️ 특정 %는 반드시 연도·교육청 단위로 스코프를 명시해야 하며 단일 현재값으로 제시하면 오류.

**영어 교과**: 쓰기 40% 내 "수행 서·논술형 20% + 정기고사 서·논술형 20%" 예시(서울시교육청 2025). **영어는 서술형이 수행·정기고사 양쪽에 구조적으로 내재.**

## 3. 경쟁 서비스 — 핵심 3가지 발견

### 경쟁사 매트릭스

| 구분 | 서비스 | 타깃 | 서술형 채점 | 자동출제 |
|---|---|---|:---:|:---:|
| AI 서술형 채점 | **CLIPO(클리포)** | 공교사 | ✅ 손글씨 포함 | ✗ |
| AI 서술형 채점 | **Engram Class** | 학원/학교 | ✅ 영어 라이팅 5차원 | ✗ |
| 자동출제 | **너른터** | 고등 변형문제 | ✗ | ✅ |
| 자동출제 | **QBank** | 중·고 시험대비 | ✗ | ✅ 35만+ 문항 |
| 해외 채점 | Cambridge Write & Improve | 글로벌 EFL | △ 형식 중심 | ✗ |
| 해외 채점 | ETS e-rater | 글로벌 시험 | △ 형식 중심 | ✗ |
| 공공 (진입 중) | **서울교육청 AI 서·논술형 시스템** | 공교육 | ✅ (2025~2027 개발) | ✗ |

### 발견 1 — 결합 공백 (Picklass 포지셔닝 기회)

국내에서 서술형 채점(CLIPO·Engram)과 변형문제 자동출제(너른터·QBank)는 **서로 다른 사업자로 분리**. **"내신 서술형 자동출제 + 내용 중심 채점"을 학원용으로 결합한 제품 미존재** → Picklass 포지셔닝 공백.

### 발견 2 — 해외 엔진의 한계 = 차별화 포인트

Cambridge Write & Improve 공식 문서: *"에세이가 문항에 얼마나 잘/완전히 답했는지(내용 적합성)는 평가하지 못한다."* → **내용·정답 중심인 한국 내신 서술형 채점은 해외 엔진이 못 하는 영역.** Picklass의 "범위 종속 내용 채점"이 차별화 포인트.

### 발견 3 — LLM 채점 불안정 → Human-in-the-loop 정당화

GPT-4를 TOEFL Junior 구성형 과제 1,908개에 적용한 연구(Language Testing, 2025)에서 지표·과제·시험형태별 **성능 불일치** 보고. → **P0-4 검수(원장 최종 확인) 설계가 시장 실증적으로 정당함.**

## 4. 기획 반영 결론

| 신호 | 방향 |
|---|---|
| 정책 순풍 + 자사 설문 1순위 | 서술형은 P0-5의 폴백 대상이 아니라 **핵심 차별화**로 격상 |
| 결합 공백 | **"자동출제 + 내용 중심 채점" 결합**을 명시적 포지셔닝으로 |
| 해외 엔진 한계 | **"내신 범위 종속 내용 채점"**을 FR·마케팅 메시지로 명문화 |
| LLM 불안정 연구 | **P0-4 Human-in-the-loop = 신뢰성 근거**로 인용 |
| 공공(서울교육청) 진입 | 위협(무상 대체)이자 기회 — **모니터링 항목 신설** |

→ **P0-5 내신자동출제 FR-3·FR-7**(LLM 생성 + 원장 검수 루브릭 채점)의 핵심 근거. 상세: [기획서_내신자동출제](../Studio/기획서_내신자동출제.md), [기획서_Writing영역](../Tutoring/기획서_Writing영역.md)
