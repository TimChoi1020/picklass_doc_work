## 한 줄 요약

> 12개 학원은 거의 **같은 1년 리듬**(평소·시험기간·방학)으로 돌아가며, 시기가 달라도 AI에 바라는 뼈대는 하나다 — **지문 넣으면 영역별 변형문제 자동 생성 → 자동 채점 → 약점만 재출제 → 실시간 학부모 리포트**로 잇는 폐루프. 기존 제품 논지(진단→출제→리포트)를 **현장 발언으로 재확인**한다. 새로 드러난 것은 ①**스피킹은 교수법·도구·관리·시간이 통째로 공백 = 차별화 기회**, ②채택 전제로 **"일을 덜어주는 방향·정확성·선생님 터치·쉬움"**이 결정적이라는 점.

## 1. 지난 미팅 확인요청 4문항 점검 (원본 §1)

| 질문 | 상태 | 답 |
|---|---|---|
| 온라인에 뭘 넣나 | ✅ | 지문 기반 **변형문제(쌍둥이)**. "지문 넣으면 변형 문제 20~30개 다 뽑아보고"(김포IH) |
| 정보가 믿을만한가 | ◐ | "과정 데이터 있어야 정밀 진단" 3곳 교차확인. **단 학생 실사용 데이터는 아직 전무**(선생님 관찰뿐) |
| 어떤 기기로 | ✅ | 리딩=태블릿 확인. **스피킹은 도구·관리·시간이 다 없음** = 기회 신호 |
| 자료 확보 | ◐ | 인터뷰 원문 재확인 완료. **학원 실물 자료(시험지·프린트물)는 미수령** |

**남은 숙제**: ①해설영상 반응 인터뷰 문항 추가 ②실물 자료 "수령" 체크리스트 고정.
**가치제안 재정립**: "대치동 콘텐츠를 지방에"(반박됨) → **"대형만 가진 자체 콘텐츠 제작 인프라를 AI로 중소형에도"**.

## 2. 시기별 운영 리듬 (원본 §2)

| 시기 | 현장 운영 | AI에 바라는 역할 |
|---|---|---|
| **평소(진도)** | 매일·매주 단어시험 + 진도 병행, 통과 못하면 재시험 | 데일리 평가 자동 출제·채점·재시험 자동화 |
| **시험기간(4주)** ★물량 | 내신 전 2주 주말까지, 학교별 범위로 그룹 나눠 물량 대비 | 학교별 지문 → 유형·수준별 대량 변형 + 약점 재출제 |
| **방학(특강)** | 내신 부담 없는 특강, 신입생 유입 = 도입 적기 | 난이도·구문·어휘 지정 자동생성 + "너를 위한 특강" 편성 |

> **시기 관통 공통**: 어느 시기든 **자동 채점 → 리포트 → 실시간 학부모 전송**이 "관리 잘하는 학원" 신뢰를 만든다. → **12월 도입은 기말 직후+방학특강 직전이라 타이밍 양호**.

## 4. 영역별 교수법 근거 (원본 §4)

단어(발음 3회독·누적)·문법(단계확장·마인드맵)·독해(5단계 스캐폴딩)·서술형(문법→서술형 확장) — AI 생성물은 이 교수법을 그대로 옮겨야 채택된다.

> **스피킹만 정립된 교수법 자체가 공백 = 기회.** "체계화된 말하기가 시중에 없어요"(에이플러스) · "스피킹은 AI 튜터에 맡기고 싶다"(LTS·JK). → Speaking 서비스([기획서_Speaking](../Speaking/기획서_Speaking.md))의 **학원 B2B 수요 근거**(연결 미결, 원본 §7 참조).

## 5. 교수부장 AI 학습 그림 (원본 §5) — 김포 IH

**넣는다 → 만든다(★AI 엔진) → 학습한다 → 증명한다** 4단계. 지문 하나 넣으면 4개 영역이 학교별 난이도로 자동 출제 → 딴짓 막고 학습만 → 약점 자동 재출제 → 실시간 학부모 전송.

> **전제**: "일을 덜어주는 방향이어야 쓴다"(리포트까지 시키면 수업 50% 반납, 늘리면 안 씀). **브랜딩**: "우리 선생님이 만든 교재"로([N4](../전략노트/N4_원장교재스튜디오_POD.md)). **타이밍**: "교과 개정 교재 공백, 빨리 들어와야 선점".
