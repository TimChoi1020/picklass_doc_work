## Speaking 대화 엔진 (SpeakingConversationAgent · 콘텐츠 생성 3모드)

> 본 문서는 구 §12.5(대화 Agent)와 구 §10.15(콘텐츠 생성 모드 3종)를 통합한 Speaking 도메인 엔진 문서이다. Pick-Speak Method·모듈·KPI는 [기획서_Speaking.md](./기획서_Speaking.md) 참조.

### 12.5 SpeakingConversationAgent (신설)

#### 12.5.1 3-Phase 대화 플로우

| Phase | 단계 | 처리 방식 | 소요 |
|---|---|---|---|
| 1. 진입 | 세션 초기화 | 로컬 | 즉시 |
| 1. Opening | 첫 질문 + 힌트 3단계 생성 | AI API 1회 | ~800ms |
| 1. TTS | 첫 질문 음성 출력 | 로컬 TTS | 레벨별 WPM |
| 2. 순환 루프 | Step A~E 반복 | - | - |
| 3. 종료 | Session Summary | 로컬 | 즉시 |
| 3. KPI | 5지표 분석 | AI API 1회 | ~1,000ms |
| 3. 저장 | 대화 기록 DB | DB | ~200ms |

#### 12.5.2 통합 AI 처리 (1회 호출)
Step C에서 단일 API 호출로 다음 6개를 동시 수행:
1. 상황 판단 (답변/역질문/도움요청)
2. 문법/어휘/표현 분석
3. 피드백 생성
4. 응답 생성
5. 다음 질문 생성
6. 힌트 3단계 생성

**최적화 효과**: 2회/턴 → 1회/턴(50%↓), 응답시간 1,300ms → 800ms(38%↓), 세션당 비용 $0.057 → $0.049(14%↓)

#### 12.5.3 추임새 / 즉시 피드백 / 따라 읽기
- **300ms 내 추임새** ("Great!") → 즉각 반응 체감
- 문법 오류 있음: 텍스트 교정 + TTS 재생 + 따라 읽기(L1–12)
- 문법 오류 없음: 메인 응답만 TTS

#### 12.5.4 침묵 감지 · STT Confidence · 로컬 Fallback

| 이벤트 | 임계값 | 동작 | LLM 호출 |
|---|---|---|---|
| 침묵 1차 | 5초 | 💡 Hint 1 | 없음 |
| 침묵 2차 | 10초 | 📝 Hint 2 | 없음 |
| 침묵 3차 | 15초 | 🔄 Hint 3 + 질문 변경 | 없음 |
| STT Confidence | < 0.5 | "못 들었어요" 재요청 | 없음 |

#### 12.5.5 꼬리 질문 vs 질문 유도 전환
- AI 질문 3–4회 누적 후, L4+ 학생에게 질문 유도(주도권 역전)
- 레벨별 주도권 배분: L1–3 AI 100% → L16–18 학습자 90%

#### 12.5.6 레벨 그룹별 대화 차원 정책 *(v1.1 신설 — Free-talking 설계 3.1 반영)*

> 📋 **기획 — 대화 정책**. 출처: `참고문서/Picklass_Speaking_Free-talking_설계_3_1_.md` §2~§4. 본 절은 대화 엔진이 레벨 6그룹별로 **어떻게 다르게 말하고·기다리고·교정하는가**의 정책을 정의한다. 구현 상세(출력 JSON 스키마, 가드 후처리 의사코드, LLM 프롬프트 원문, 토큰·비용 수치)는 **Speaking 리포 `docs/` 소유** — 여기엔 원칙만 기술한다.

**(1) 레벨 그룹 × 대화 차원 요약** — 같은 WPM이어도 아래 차원이 체감 난이도를 결정한다.

| 그룹 (CEFR) | AI 1턴 영어 발화 단어 수 상한 | 문장 간 인터벌 | 대기 정책 (사고시간→힌트) | 교정 강도 | 따라 읽기 |
|---|---|---|---|---|---|
| Starter (L1–3) | 8 단어 | 0.5초 | 10초→TYT, +10초→힌트 | 완전 교정문 | ✅ 강제 |
| Beginner (L4–6) | 12 단어 | 0.4초 | 10초→TYT, +10초→힌트 | 완전 교정문 | ✅ 강제 |
| Intermediate (L7–9) | 16 단어 | 0.3초 | 15초→TYT, +15초→힌트 | 부분 교정+선택지 | ✅ 문법 오류 시 |
| Upper-Inter. (L10–12) | 22 단어 | 없음 | 15초→TYT, +15초→힌트 | 부분 교정+선택지 | ✅ 중대 문법만 |
| Advanced (L13–15) | 28 단어 | 없음 | 20초→TYT, +20초→힌트 | 부분 교정+선택지 | ❌ 없음 |
| Proficient (L16–18) | 제한 없음 | 없음 | 20초→TYT, +20초→힌트 | 대안 제시만 | ❌ 없음 |

- **AI 발화 단어 수 상한**: 청크 길이 상한은 도입하지 않음(LLM 자연성 저해). 한국어 설명(한국어 TTS)은 카운트에서 제외.
- **대기 정책 = 2단계 (TYT = "Take your time")**: 1단계는 사고시간 보호(힌트 미발동), 2단계 경과 후 힌트 발동. 이는 기존 §12.5.4 단일 침묵 타이머(5/10/15초)를 **레벨 그룹별 2단계로 대체**하는 정책이다. "힌트가 곧 나옵니다" 예고는 노출하지 않음(힌트 대기 학습 방지).

**(2) 교정 우선순위 ①②③ 원칙** — 매 턴 모든 오류를 잡지 않고 우선순위로 통제한다.

| 순위 | 항목 | 처리 |
|---|---|---|
| ① 문법적 완전 오류 | 시제·단복수·관사·주술 일치 등 명확한 규칙 위반 (전 레벨 공통) | **교정(correction)** — 그룹별 강도 적용 |
| ② 레벨 학습 포인트 | Starter/Beginner=완전한 문장, Inter.=복문 활용, Adv./Prof.=격식 | **권장(suggestion)** — 강제 없이 방향 유도 |
| ③ 일반적 어색함 | ①②에 없으나 부자연스러운 영어 | 약하게, 흐름 유지되면 통과 |

**(3) ② 가드 메커니즘 (원칙)** — ②는 저레벨에서 "대부분 발화가 학습 포인트 미달"이라 매 턴 발동될 위험이 있어, 다음 3원칙으로 빈도를 통제한다. (구현 로직·의사코드는 리포 docs)
- **발화량 cool-down**: ② 발동 후 학습자 누적 발화 **30단어** 이상 채워져야 재발동 가능(세션 길이 무관 자동 비례, 시간 cool-down 미적용).
- **직전 1턴 룰**: 직전 턴에 ② 발동이 있었으면 이번 턴 ② 비활성.
- **마스터리 트래킹**: ② 발동 후 학습자가 권장 패턴을 다음 2~3턴 안에 시도하면 해당 학습 포인트는 마스터 처리 → 같은 영역 ② 미발동.

**(4) 바이링구얼 피드백 = 별도 한국어 TTS 채널 결정**

| 채널 | 역할 | 발동 |
|---|---|---|
| **영어 TTS** | 대화 진행(응답 + 다음 질문) | 매 턴 |
| **한국어 TTS** | 교정 설명 + 영어 권장 표현 낭독 | should_correct 인 턴만 |

- 인지 부담을 줄이기 위해 교정 설명을 영어 대화 흐름과 **분리된 한국어 TTS 채널**로 처리한다(결정). 1차 적용은 한국어 화자가 영어 표현도 그대로 낭독, 이후 다국어 TTS(SSML) 단계적 개선. 두 채널 **병렬 처리 권장**(체감 지연 최소화).
- 이는 기존 [기획서_Speaking §14.5.7](./기획서_Speaking.md)의 "초·중급 바이링구얼 / 고급 영어 메타" 정책과 정합한다 — 본 절은 그 **채널 구현 방식(2 TTS 트랙)** 결정을 추가한다.

> ✅ **WPM 앵커 확정 (2026-07-17)**: WPM 앵커를 **L1=50 → L18=148 단일 통일**로 확정했다(기존 `80+(N−1)×4` 폐기). 진단(P-ALT)·TTS 출력 속도·발화 벤치마크에 동일 앵커를 적용한다. 근거·전개는 [06 §15.3.4](../00_공통/06_진단평가_PPD.md), 공식은 [기획서_Speaking §14.2.2](./기획서_Speaking.md).


### 10.15 Speaking 콘텐츠 생성 모드 (3종) *(v0.11 신설 — 회의록 260413)*

> 📋 **기획 단계** — Speaking AI 회화 상품의 **레슨 콘텐츠 생성 방식 3종**을 정의한다. 이는 §10.1 Tutoring 시퀀싱 엔진(passage→module sequence)과는 다른 별개의 흐름이며, **Speaking 단일 도메인 내 dialogue/mission 자동 생성 파이프라인**이다.

**기본 원칙: 사전 미션 기반 진행 (Pre-Set Mission Mode)**

회의에서 다음 두 가지 후보 중 **후자**로 확정:

| 안 | 진행 방식 | 채택 여부 |
|---|---|---|
| 안 A. **동적 변경** | 학습자 수준에 따라 수업 진행 중 콘텐츠가 실시간으로 변경됨 | ❌ 미채택 |
| 안 B. **사전 미션 기반** | 콘텐츠 생성 후에는 사전에 설정된 미션 시퀀스에 따라 진행 | ✅ **채택** |

→ 모든 콘텐츠 생성 모드(아래 3종)는 **수업 시작 전 단일 콘텐츠/미션 세트를 확정**하고, 이후 수업 중에는 그 미션을 따라간다. 학습자 수준 미스매치 발생 시 **사후 분석을 통해 다음 회차 콘텐츠에 반영**(피드백 루프).

#### 10.15.1 모드 ①: 교재 기반 자동 생성

| 항목 | 정책 |
|---|---|
| 입력 | 학습자가 사용 중인 **교재 (textbook)** 의 단원/챕터 |
| 레벨 | **교재 자체의 레벨 메타데이터를 그대로 사용** (별도 레벨 진단 불필요) |
| 출력 | 해당 단원의 핵심 표현·어휘·대화 시나리오 → SpeakingSession 미션 |
| 강점 | 학원·기관에서 사용 중인 기존 교재와 일치 — 강사 검수 부담 ↓ |
| 사용 예 | "Pagoda Power Speaking Vol. 2, Unit 5 — Travel" → AI가 Travel 시나리오 dialogue 생성 |

#### 10.15.2 모드 ②: 주제 & 레벨 선택 기반 자동 생성

| 항목 | 정책 |
|---|---|
| 입력 | **주제(Topic) + 학습자 레벨** |
| 레벨 | 학습자의 **현재 레벨**에 맞춰 어휘·문법·발화량 조정 |
| 출력 | 해당 주제·레벨에 적합한 dialogue + 미션 |
| 강점 | 교재 없이 빠른 시작, 흥미 기반 주제 선정 가능 |
| 사용 예 | "Job Interview, A2" → A2 수준 어휘로 면접 dialogue 생성 |

#### 10.15.3 모드 ③: 프리토킹 (Free Talking) — **보조 수단**

| 항목 | 정책 |
|---|---|
| 입력 | 명확한 주제 없이 자유 대화 |
| 레벨 | 학습자 레벨 (시스템 추정값) |
| 출력 | 미션 없이 자유 대화, 사후에 발화 데이터로부터 KPI 추출 |
| ⚠️ 제약 | **고레벨이 아닌 학습자에겐 학습 효과가 떨어질 수 있음** — 회의록 명시 |
| 권장 사용 | 정규 레슨이 아닌 **보조적 수단** (예: 주말 free 학습 슬롯, 워밍업) |
| 게이트 | B2 이상 학습자에게 우선 노출, A1~A2는 기본 비노출 (⚠️ 정책 검토 중) |

#### 10.15.4 3종 통합 비교

| 비교 축 | 모드 ① 교재 기반 | 모드 ② 주제+레벨 | 모드 ③ 프리토킹 |
|---|---|---|---|
| 레벨 결정 | 교재 메타데이터 | 학습자 현재 레벨 | 학습자 추정 레벨 |
| 미션 사전 설정 | ✅ | ✅ | ❌ (자유 대화) |
| 진행 방식 | 사전 미션 시퀀스 | 사전 미션 시퀀스 | 자유 대화 후 KPI 측정 |
| 수업 중 변경 | ❌ (사전 확정) | ❌ (사전 확정) | N/A |
| 정규 레슨 가능 | ✅ | ✅ | ⚠️ 보조 수단 |
| 권장 학습자 | 교재 사용자 | 모든 레벨 | B2+ |

> 📎 콘텐츠 생성 후 사전 미션의 **레벨 일치 검증/조정**은 §15 레벨 테스트(Achievement Test) 결과를 다음 회차에 반영하는 형태로 수행한다(피드백 루프).
