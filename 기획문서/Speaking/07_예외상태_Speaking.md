## 2. 예외 시나리오 카탈로그

### SP-E-001 · 세션 만료 (401)
- **원인**: JWT 만료/유휴
- **처리**: `authFetch` `401 && sentAuth` → 토큰 제거 + `auth:unauthorized` → `setUser(null)` → `/onboarding/login`
- ⚠️ **금지 패턴**: 401을 `.catch(()=>setEmpty([]))`로 삼키면 "등록된 과정이 없습니다"로 **오인** — 인증실패와 정상 빈결과를 반드시 구분
- **근본원인 이력**: `JWT_SECRET` 폴백 서명 불일치(cwd 기준 `.env` 미로드) → 절대경로 고정 + 폴백 제거 + 미로드 시 부팅 throw

### SP-E-002 · 네트워크 / 5xx 일시 오류
- **원인**: API 재시작 블립 등
- **처리**: `checkAuth()`는 **401일 때만 로그아웃**, 네트워크 오류는 토큰 유지 + 최대 3회 재시도(800ms)

### SP-E-003 · 마이크 권한 거부
- **발생 화면/기능**: PKS-FL-002~005 / SP-F-031, 060, 061
- **처리**: **탭 모드 폴백** 안내(SP-P-007), 발화 ×0.6 인정

### SP-E-004 · 발음 평가 실패/지연
- **발생 화면/기능**: PKS-FL-004 / SP-F-031
- **처리**: 스피너 후 "점수 없이 발화 인정"(pip +1), 재시도. 오프라인 → 1차 온라인 필수 + 오류 토스트
- **세션 이탈**: 진행분 즉시 POST 저장(complete-session만 누락 시 다음 진입 보정)

### SP-E-005 · 레벨테스트 하드블록 (403)
- **발생 화면/기능**: PKS-HM-001 / SP-F-071
- **조건**: 신규 사용자(진단 0건 + 레벨없음)
- **처리**: `LessonAccessGuard` → 수업 시작 `403 {code:'LEVEL_TEST_REQUIRED', testType:'PT'}`. 프론트 수신 시 진입 차단 + 팝오버(매 홈 진입 재노출, 스누즈 무의미)
- ⚠️ 가드 구현·export 완료, **엔드포인트 부착 미결**
- **연관 정책**: SP-P-001

### SP-E-006 · 데이터 없음 / P0 의존
- **발생**: 홈 레이더·리포트·1MP 등 별도 학습앱(P0) 산출물 의존 화면
- **처리**: 0점 폴백 + "데이터가 쌓이면 표시됩니다". 실데이터 유입(P0 → public DB) 전까지 배선·집계만 검증
