> ⚠️ **S1 스코핑 필수** — 현 `analyzer`/§9 엔진이 '내신 시험범위 텍스트'를 입력으로 받아 문항·서술형 쌍둥이를 생성하도록 확장 가능한지 개발팀 확인 전까지 착수 불가. 불가 시 Writing 모듈 재활용 범위로 축소.

## 개요

**우리 학원의 내신 시험범위·교과서에 종속된 문제와 서술형 쌍둥이 문항을 자동 생성**한다. 현행 엔진(지문→교수법 수업 설계)과는 입력·출력이 다른 **유일한 진짜 신규 개발** 트랙.

**현 엔진과의 차이**:
- 기존 `analyzer`: 지문(레벨) + KPI + 시간 → 교수법 모듈 시퀀싱
- 본 트랙: 내신 범위 텍스트 → 시험 대비 문항 생성

**시장 근거**: AI 기대영역 1위 = 자동출제 51%. "시험범위와 모르는 부분을 접목한 맞춤 문제"(현장 인터뷰). 개정 교과서 자료공백(~7년 시한부) 기회. 2차 정성조사 재확인: 12곳이 온라인 핵심 콘텐츠를 **지문 기반 변형문제(쌍둥이)**로 수렴, 시험기간엔 **학교별 범위로 그룹 나눠 물량 대비** — 본 트랙이 정확히 그 수요([학원장AI니즈 §1·§2·§3](../시장조사/학원장AI니즈_2차정성조사_v1.0.md)).

**경쟁 공백**: 국내 서술형 채점(CLIPO·Engram)과 변형문제 자동출제(너른터·QBank)가 분리 운영 — "내신 서술형 자동출제 + 범위 종속 내용 채점" 결합이 공백. 상세: `이퓨쳐/10_시장조사_서술형_v1.0.md`.

## 핵심 개념

### 출처 종속성 — "내신 범위·교과서 종속"

범용 문제은행이 아니라, **학원이 업로드한 그 학교 시험범위 지문의 실제 문장·어휘·문법 포인트만을 소재로 생성**한다. 이것이 범용 출제기와의 차별점.

### 서술형 쌍둥이 (FR-4)

기준 문항 1개에서 **유형·구조는 유지하고 표면 내용만 바꾼 N개 변형** 생성.

> 예: 조건 영작 기준 "Without bees, many crops would not grow." (조건: `without` + `crops`·`grow`) →
> 쌍둥이1 (소재 치환): `crops→fruits` / 쌍둥이2 (조건 유지·단어 교체) / 쌍둥이3 (다른 문장 동일 유형)

## 기능 요구사항 (FR)

| # | 요구사항 | 판정 |
|---|---|---|
| FR-1 | 범위 입력 — AcademyScope(P0-3) 참조 또는 지문 직접 업로드. §9.4 난이도 분석 적용 | 재사용+확장 |
| FR-2 | 유형·수량 선택 — 출제 유형·문항 수·난이도 선택. 서술형 선택 시 하위유형 지정 | 신규 |
| FR-3 | 문항 생성 — 범위 텍스트 기반 문항+정답+해설 생성 (LLM 런타임, Seed+LLM 전략 준용) | 신규 |
| FR-4 | 서술형 쌍둥이 — 기준 문항에서 유형 유지·표면 변형한 N개 변형 생성 | 신규 |
| FR-5 | 검수 연동 — P0-4 검수 큐로 전달, 승인 전 배포 불가 | 재사용 |
| FR-6 | 세트화·출력 — 승인 문항을 문제지/온라인 세트로 저장, PDF 출력. 종이 출력분은 QR 결속(학생×문항 인스턴스)·답란 포함 | 신규 |
| FR-7 | 서술형 채점 연계 — Writing 모듈 채점 루브릭으로 학생 답안 채점·피드백. 종이 답안은 P1에서 OCR 경로 | 재사용+확장 |
