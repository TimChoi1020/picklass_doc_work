> 📋 **기획 단계 (P0 우선).** 이 문서는 `이퓨쳐/P0-1_진단온보딩_상세기획.md` 의 핵심 명세를 기획문서 구조로 이식한 것이다. 상세 KPI·루브릭·CAT 알고리즘은 원본 파일 참조.

## 개요

신규생 입학 시점에 **적응형 진단(P-ALT R/W 트랙)** 으로 어휘·독해(·작문) 수준과 약점을 파악하고, 결과를 P0-2 성장 리포트의 baseline으로 저장한다. 이 진단 세션이 **Placement Test(PT)** 이며, 이후 Achievement Test(AT, P1-3)와 체인을 이룬다.

**시장 근거**: AI 학습진단 추가희망 1위 45%, 보습 세그먼트 1순위 59%. "입학 테스트를 봐도 리포트 카드가 안 나온다"는 아쉬움(현장 인터뷰).

---

## P-ALT 트랙 구조

| 트랙 | 측정 스킬 | 상태 |
|---|---|---|
| **R/W 트랙 ← 본 문서** | Vocab(공유) · Reading · Writing(조건부) | P0 신규 |
| 스피킹 트랙 | Vocab(공유) · Speaking(낭독·대화·발표) | 별도 완결 (참고문서 참조) |

두 트랙의 **P1 Vocab Size CAT**(문장 내 밑줄 단어 4지선다, 18단계 `words_18levels_6000`)은 동일 어휘 진단 엔진을 공유한다.

---

## 파트 구조 (R/W 트랙)

| 파트 | 파트명 | 형식 | 측정 | MVP |
|---|---|---|---|---|
| **P1** | Vocab Size | 4지선다 CAT (스피킹 트랙 공유 엔진) | 어휘 레벨(1–18) | ✅ |
| **P2** | Reading | 지문+이해 문항 적응형(CAT) | 이해도·독해속도(WPM) | ✅ |
| **P3** | Writing (조건부) | 프롬프트 기반 작문 → LLM 채점 | 문법·표현·구성 | ⏳ P1-1 연동 시 |

- **P2 CAT**: §9.4 8지표·18단계 난이도 기준으로 지문 상/하향. 이미 ✅ 완료된 Reading 모듈·난이도 분석 재사용.
- **P3 활성화 조건**: P1-1 Writing 엔진 완성 시 활성화. 미실행 시 Reading·어휘 값으로 대체.

## 기능 요구사항 (FR)

| # | 요구사항 | 상태 |
|---|---|---|
| FR-1 | P1 Vocab Size CAT — 스피킹 트랙 어휘 엔진 재사용, 어휘 레벨 확정 + P2 시작점 산출 | 재사용 |
| FR-2 | P2 Reading 적응형 — 정답→상향/오답→하향 분기, 종료 조건, 레벨 산출(1–18/6그룹) | 확장 |
| FR-3 | 결과 저장 — `DiagnosticResult` 엔티티: 레벨·영역별 강약점 저장 → P0-2 리포트 초기값 | 신규 |
| FR-4 | 결과 요약 — 학생·원장·학부모 각각 다른 뷰 (학생: 격려 중심 / 원장: 수치 중심) | 신규 |
| FR-5 | PT baseline 훅 — 이후 AT 비교를 위해 측정 시점(PT) 스냅샷 보존 | 신규 |
| FR-6 | (P1-1 연동 후) P3 Writing 파트 활성화 | 조건부 |

## 데이터 모델 (요약)

**`DiagnosticResult`** (신규 엔티티)

| 필드 | 설명 |
|---|---|
| id, studentId, institutionId | 대상 |
| type | PT \| AT |
| sessionDate | 진단 일시 |
| vocabLevel, readingLevel, writingLevel | 영역별 레벨(1–18) |
| weakAreas | 약점 키워드 배열 |
| wpm | Reading WPM |
| baselineFlag | true = PT 기준점 |
| linkedReportId | P0-2 리포트 참조 |

## 진단 결과 리포트 스펙 (P0-2-2 준용)

> 출처: `이퓨쳐/P0-2-2_진단리포트_RW트랙_스펙.md`. 스피킹 트랙 리포트(p_alt_report_v8)를 R/W 도메인으로 이식한 2탭 상세 진단 리포트. 목업: `이퓨쳐/RW진단리포트_목업_v1.html`

### 역할 분담

| 리포트 | 성격 | 대상 |
|---|---|---|
| **진단 리포트 (본 절)** | 영역별 상세 진단 (PT/AT 2탭) | 원장·강사 |
| **성장 리포트 MVP (P0-2)** | 학부모용 1페이지 요약 | 학부모 |

두 리포트는 AT 탭의 **성장 배너·델타 컴포넌트를 공유**한다. 중복 제작 금지.

### PT 탭 섹션 (입학 진단 결과)

| # | 섹션 | 내용 |
|---|---|---|
| 헤더 | **3레벨 히어로** | Vocab L__ · Reading L__(주) · Writing L__ + CEFR + 공인시험 배지 |
| 메트릭 | 요약 4칸 | 추정 어휘량 · 스킬 편차 · CAT 수렴효율 · 이해도 게이트 상태 |
| §1 | CAT 수렴 경로 | P1 Vocab → P2 Reading 문항별 레벨 궤적 |
| **§2** | **Reading 3대 KPI** | R1(어휘지식)·R2(이해도·과정유형 4분할)·R3(유창성·이해도 게이트) + 비교군 % |
| **§3** | **Writing 5대 KPI** | W1~W5 레이더 + CAF 객관수치(P1-1 활성 시) |
| §4 | 오류 분석 | 작문 오류 13유형 + Reading 오답 과정유형 |
| §5 | 학습 처방 | KPI 약점 우선순위 3개 + 모듈 연계 |
| §6 | 공인시험 예상 | Reading(TOEIC RC·TOEFL R·IELTS R) / Writing(TOEFL W·IELTS W) |

### AT 탭 추가 요소 (P1-3 연동 후)

| 요소 | 내용 |
|---|---|
| 성장 배너 | 직전 진단 대비 레벨·KPI 변화 (P1-3 `deltaFromPrevious`) |
| 정체 축 경고 | `stalledAxes[]` 배열 기반 표시 |
| 체인 추이 | PT → AT → AT 레벨 변화 그래프 |

> ⚠️ **스키마 정합 필요**: P0-2-1 데이터 정의가 구 스키마(`finalLevel`, `skillScores`) 참조 — P0-1 개정 스키마(`vocabLevel/readingLevel/writingLevel`, `readingKPI`, `writingKPI`)로 동기화 필요.
