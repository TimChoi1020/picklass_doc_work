## 0. 공통 화면 상태 표준

각 상태의 표준 UI·행동을 먼저 1회 정의하고, 전 화면에서 재사용합니다.

| 상태 | 표준 UI | 행동 |
|---|---|---|
| **Loading** | 스켈레톤/스피너 + 대상 영역 그레이아웃 | 조작 비활성(중복요청 방지) |
| **Empty** | 안내 문구 + 주요 CTA | 예: "과정이 없습니다 → 새 과정 만들기" |
| **Error** | 오류 배너/문구 + [다시 시도] | mock 폴백 금지(2026-04-23 정책) |
| **Partial** | 성공분 표시 + 실패분 표식 | 예: 회차 지문 부분 실패 시 해당 회차만 표식 |
| **권한없음** | 버튼 disabled + opacity 저하 + 툴팁 | 사유 툴팁("기관 설정에 의해 비활성" 등) |
| **세션만료** | **SessionExpiredDialog**(즉시 로그아웃 아님) | 작업 메모 시간 확보 후 재로그인 |
| **준비중** | 버튼 노출 + "준비중" 라벨 | 클릭 불가(미구현 기능) |

**공통 규칙**
- `alert()/confirm()` 금지 → **`toast.error()` / `AlertDialog`** 사용.
- 삭제·상태변경 등 파괴적 액션은 **항상 AlertDialog 확인**.

## 2. 예외 시나리오 카탈로그

### ST-E-001 · 입력검증 실패 (공통)
- **발생**: 필수값 누락·형식 위반(전 폼)
- **표시**: 인라인 오류 문구 또는 `toast.error()`, 제출 버튼 disabled
- **처리**: 클라 검증 우선, 서버 재검증 방어

### ST-E-002 · 학생 아이디 중복
- **발생 화면/기능**: ST-S-030 / ST-F-031, 033
- **조건**: 중복확인 미실행 또는 이미 존재하는 아이디
- **표시**: 등록 버튼 차단 + `toast.error`
- **처리**: 중복확인 통과(`GET /users/check-duplicate?userId=` → `{available}`) 전 제출 불가
- ⚠️ 현재 클라이언트 목록 기준만 — **서버 실시간 중복확인 미구현**
- **연관 정책**: P-013

### ST-E-003 · 액세스코드/학생 개수 상한 초과
- **발생 화면/기능**: ST-S-031·030 / ST-F-034, 033
- **조건**: 생성 개수 < 1 또는 > 1000
- **표시**: 인라인 오류, 생성 버튼 비활성
- **처리**: 요청 미전송(클라 검증) + 서버 400 방어
- **연관 정책**: P-010

### ST-E-004 · 수업 준비 시퀀싱 분석 실패
- **발생 화면/기능**: ST-S-011 / ST-F-015
- **조건**: analyzer HTTP 503(DB 끊김) / 4xx / 네트워크 / timeout
- **표시**: "시퀀싱 분석에 실패했습니다" + [다시 시도]
- **처리**: 모듈 선택 차단 + "수업 들어가기" 비활성. **가짜데이터 폴백 폐지**(2026-04-23~)
- **경고 코드(성공하되 주의)**: `FALLBACK_KPI_IGNORED`(KPI 매칭 0), `MISSING_COGNITIVE_LEVEL`(기본 2단계 추정)

### ST-E-005 · 세션 만료 (401)
- **발생**: JWT 만료/IDLE 초과(P-024)
- **표시**: **SessionExpiredDialog** (구: 즉시 `/login` 강제이동 → 변경됨)
- **처리**: 작업 메모 시간 확보 후 재로그인. keepalive 훅으로 만료 지연

### ST-E-006 · AI 주제 생성 실패 (400)
- **발생 화면/기능**: ST-S-022 / ST-F-021
- **조건**: KPI 미선택 → `course_goal` 빈값
- **처리**: `course_goal='일반 영어 학습'` 폴백으로 400 방지
- ⚠️ 응답 타입 불일치(front `course_focus` 기대 vs `courseFocus`) — 확인 필요

### ST-E-007 · 액세스코드 생성 실패
- **발생 화면/기능**: ST-S-031·020 / ST-F-034, 022
- **표시**: `toast.error(ApiError.message ?? '액세스코드 생성에 실패했습니다.')`

### ST-E-008 · 최종상태 코드 전환 시도
- **발생 화면/기능**: ST-S-031 / ST-F-035
- **조건**: `completed`/`expired` 코드
- **처리**: 상태 전환 버튼 미노출(최종 상태, P-030)

### ST-E-009 · in-use 편집 시도
- **발생 화면/기능**: ST-S-020·021 / ST-F-025, 027
- **조건**: 레슨/과정 status = `in-use`
- **표시**: 버튼 disabled(opacity-40) + title 툴팁("수업진행중인 과정은 삭제할 수 없습니다")
- **처리**: 모듈 수정·과정에서제외·과정 삭제 차단(↑/↓ 이동은 허용). 학생 포함 과정은 not-used 변경 시 경고
- **연관 정책**: P-031

### ST-E-010 · 기관설정 위반
- **발생 화면/기능**: ST-S-022·023 / ST-F-021, 023
- **조건**: 한도 초과 시간·비허용 마이크 모드·free-learning 위반
- **표시**: 해당 프리셋/버튼 disabled+회색, 툴팁("기관 설정에 의해 비활성"). 자유학습 비허용 시 "허용" 반투명(기존 저장값은 read-only)
- **처리**: 생성 POST는 서버 `assertWithinInstitutionLimits`로 **400**. ⚠️ **편집 PATCH는 서버 재검증 미이식**(P-043, UI 제약만)
- **연관 정책**: P-041, P-043

### ST-E-011 · 텍스트/모듈 미선택 (레슨 추가)
- **발생 화면/기능**: ST-S-021 / ST-F-026
- **조건**: Step1 텍스트 미선택 / Step2 모듈 미선택
- **표시**: "다음" 불가(`toast.error`) / "추가" disabled + tooltip

### ST-E-012 · 지문 생성/저장 경로 불일치
- **발생 화면/기능**: ST-S-022 / ST-F-021, 012
- **조건**: 과정 생성 시 회차 지문 부분 실패(해당 회차 `text_id=null`)
- **표시**: Partial 상태(성공분 저장, 진행 UI "(3/10)")
- ⚠️ **알려진 결함**: `generateAndSavePassage`가 NestJS `/passages`에 저장하나 class는 Next `/api/texts`로 조회 → 생성 후 지문 미표시. 저장/조회 경로 정합 필요

## 3. 에러코드 ↔ 사용자 메시지

| 상황 | HTTP | 사용자 메시지 | 후속 |
|---|---|---|---|
| 시퀀싱 DB 끊김 | 503 | "시퀀싱 분석에 실패했습니다" | [다시 시도], 선택 차단 |

| 세션 만료 | 401 | SessionExpiredDialog 안내 | 재로그인 |
| 코드 생성 실패 | — | "액세스코드 생성에 실패했습니다." | toast |
| 주제 생성 실패 | 400 | (폴백으로 사전 차단) | — |

## 4. 복구·재시도 정책

- **시퀀싱**: 옵션 변경 시 이전 진행 요청 **abort**(race 방지) 후 재호출. 실패 시 명시적 [다시 시도].
- **부분 실패(과정 생성)**: 성공 회차는 보존, 실패 회차만 `text_id=null` — 재편집으로 보완.
- **세션**: keepalive 4분 주기로 만료 지연, 만료 시 다이얼로그 → 재로그인 후 복귀.
- **삭제/상태변경**: AlertDialog 취소 시 원상 유지.
