## 개요

AT(Achievement Test)는 **P0-1 진단과 다른 시험이 아니다.** 같은 R/W 트랙 CAT 엔진을 **`testType=AT`로 돌리는 운영 모드**다. 신규 엔진 개발 없이 P0-1 엔진의 AT 운영 규칙·성장 델타·체인 관리만 신설한다.

**목적**: 학습 사이클 후 성취도를 재측정해 직전 진단(PT 또는 직전 AT) 대비 **성장 추이를 축적**하고, P0-2 리포트의 "이만큼 컸다"를 정식 데이터로 뒷받침한다.

**시장 근거**: "1년 전엔 알파벳, 지금 라이팅 하는 걸 보여주고 싶다"(현장 인터뷰). 재원생 정기평가 수요.

## PT/AT 체인 구조

```
PT ─── AT ─── AT ─── AT ─── ...
│       │      │      │
└──▶ baseline ◀──────┘   각 AT는 "직전 진단"(previousSessionId)과 비교
```

- **PT** (P0-1): 신규생 입학 시 자동 1회 → **baseline**
- **AT** (본 문서): 학습 사이클 후 응시 → 직전 진단 대비 성장 측정. 자신이 다음 AT의 baseline이 됨
- **성장 = 이번 AT 레벨 − 직전 진단 레벨**. 리포트 표기: "직전 대비 +X" (선택적 "PT 누적 +Y" 병기)
- 대상 스킬: Vocab·Reading(파일럿) → Writing(P1-1 활성 시)

## AT 운영 규칙 (PT와의 차이)

### PT vs AT 비교표

| 항목 | PT (P0-1) | AT (본 문서) |
|---|---|---|
| 문항 범위 | 전 구간 (1–18) | **직전 진단 레벨 ±4 구간** |
| CAT 시작점 | 추정 레벨/기본값 | **직전 진단 레벨 고정** |
| 하향 기준 | 하 1회 → 즉시 −1 | **하 1회 유지, 연속 2회 → −1** |
| **하한 보호** | 없음 | **최종 레벨 ≥ 직전 진단 레벨** (하락 불가) |
| P2 지문 | 범용 범위 | **학습 이력 기반(학습한 범위 우선)** |
| 리포트 | 절대 레벨 + KPI 프로파일 | **성장 델타 + KPI 변화 + 정체 축 경고** |

### AT CAT 판정 규칙

| 판정 | 난이도 이동 | 이유 |
|---|---|---|
| 상 (Exceeds) | +2 상향 | PT와 동일 |
| 중 (Meets) | +1 상향 | PT와 동일 |
| 하 1회 | **이동 없음(유지)** | 일시적 컨디션 변수 처리 |
| 하 연속 2회 | −1 하향 (하한 보호 내) | 실제 하락으로 처리 |

> **하한 보호**: AT 최종 레벨이 직전 진단 레벨보다 낮아질 수 없음. 하한 도달 시 "일부 KPI 축 재점검 권장" 메시지 표시.

### AT 결과 표현 가이드라인

| 결과 | 리포트 표현 |
|---|---|
| 이번 AT > 직전 | "L{N} 달성 — {기간} 학습 후 **+{X} 레벨 성장**" |
| 이번 AT = 직전 | "L{N} 유지 — {강점 KPI 축} 향상 확인" |
| 이번 AT < 직전 (하한 보호) | **"하락" 표현 금지**. 성장 KPI 강조 + 추가 학습 권장 |

## 기능 요구사항 (FR)

| # | 요구사항 | 판정 |
|---|---|---|
| FR-1 | 평가 트리거 — 구간 종료/원장 수동 실행 시 AT 시작. `previousSessionId` = 직전 DiagnosticResult 자동 참조 | 재사용+확장 |
| FR-2 | 평가 구성 — P0-1 엔진 공유 (`testType=AT`). 직전 진단 레벨 ±4 범위·시작점 고정. P2 지문은 학습 이력 기반 우선 | 재사용+확장 |
| FR-3 | AT CAT 분기 — 하 1회 유지·연속 2회 −1 + **하한 보호** 적용 | 신규 규칙 |
| FR-4 | 성장 델타 산출 — 직전 진단 대비 레벨 + KPI 축별 변화량 산출, 정체 축 플래그 | 신규 |
| FR-5 | 리포트 공급 — 성장 델타·성취 스코어·결과 표현을 P0-2 `GrowthReport.growthDelta`로 전달 | 신규 |
| FR-6 | 시퀀싱 반영 — 결과를 §10 다음 수업 사전 미션 레벨·약점 가중치에 반영 (피드백 루프) | 재사용 |
| FR-7 | 체인 이력 — 평가 회차 이력 보존, PT→AT→AT 추이 그래프 제공 | 신규 |

## 데이터 모델

**P0-1 `DiagnosticResult` 재사용** (`testType=AT`). 성장 파생 필드만 추가.

| 추가 필드 | 설명 |
|---|---|
| `testType` | `AT` (기존 `PT`와 동일 엔티티, 타입 구분) |
| `previousSessionId` | 직전 DiagnosticResult ID (비교 기준점) |
| `deltaFromPrevious` | `{ level: {vocab, reading, writing}, kpi: {R1, R2, R3, W1..W5} }` |
| `deltaFromBaseline` | PT 기준 누적 성장 |
| `achievementRate` | 목표 달성률 (%) |
| `stalledAxes[]` | 정체 축 플래그 배열 |

## 화면·플로우

```
구간 종료 / 원장 실행 → [성취도 평가 시작] (testType=AT, previousSessionId 자동)
  → P0-1 CAT 엔진 공유 (직전 레벨 ±4 범위, 시작점 고정)
  → AT CAT 판정 + 하한 보호
  → 성장 델타 산출 (직전 진단 대비, KPI 축별)
       ├─ 리포트(P0-2): GrowthReport.growthDelta 공급 + 결과 표현 가이드
       └─ 시퀀싱(§10): 다음 회차 레벨·약점 반영
  → 체인 이력 업데이트 (PT ─ AT ─ AT …)
```
